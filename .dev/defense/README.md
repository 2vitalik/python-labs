# defense — захисти: сторінка захисту, враження, результат; слоти й регламент

Захист як документ і робоче місце викладача: хто, що, коли, враження, результат; далі — планування (слоти) й регламент. Сусіди: зауваження — [remarks](../remarks/README.md), правила оцінювання — [grading](../grading/README.md), заявки й відео — [reports](../reports/README.md), заняття-день — [lessons](../lessons/README.md).

## Сторінки

- `/defenses` — список викладача: тривають · сьогодні · раніше; «Почати захист» — пошук студента, лаби, вид, старт зараз · [T327](.t/T327-P--defense-page-design.md) §5
- `/defenses/<id>` — робоче місце на час розмови, вузьке: стає поруч із вкладкою гри · [T327](.t/T327-P--defense-page-design.md) §2–3
  - шапка: студент, лаби й вид чіпами, «Гра» й «Репозиторій» у сусідній вкладці;
  - час: початок, «триває N хв», «Завершити»; обидва часи правляться кліком; після 30 хв лічильник теплішає;
  - не закрите з минулих захистів — зверху;
  - зауваження — списком, поле диктовки під ним, як у чаті · [remarks](../remarks/README.md);
  - враження, нотатка, результат і «Надіслати студентові».
- `/my/remarks` — студент: результат і зауваження з відповідями · [remarks](../remarks/README.md)
- Меню: «Захисти» — лише викладачеві; студентам пункту нема · [T331](.t/T331-Q--defense-choices.md) Q14

## Враження викладача

- Мета — памʼять, яка не «пливе» за місяць; у бали не входить · [T327](.t/T327-P--defense-page-design.md) §4
- Порядок на сторінці — від побаченого до відчутого: факти → рівні → «Загалом» останнім · [T339](.t/T339-C--defense-research.md) §1
- Факти («код свій», «пояснив місце», «змінив код на ходу», «гра не падала», «прийшов підготовлений», «код від ШІ пояснює як свій») — так · частково · ні; не чіпав — не перевіряв.
- Шкали зі словами, по чотири сходинки, між сусідніми — точка «між ними»: розуміння коду · гра · код · захист · загалом.
- Позначки для памʼяті: еталон · своя ідея · потрібен повторний · затягнуто · хвилювався · технічні проблеми.
- Слова — в одному місці, `app/api/defense_vocab.py`; з враженням зберігається версія шкали (`SCALE`).
- Бачить лише викладач: ні студент, ні агент з токеном цих полів не отримують.

## Результат

- Зараховано · з умовою · повторити; студент бачить його разом із зауваженнями після «Надіслати» · [T329](../grading/.t/T329-P--defense-grading.md) §4
- Що результат означає для оцінки — пропозиція, не рішення: [grading](../grading/README.md).

## Дані й доступ

- `Defense` (`app/api/models/defense.py`): студент, лаби, вид, час, враження, нотатка, результат, `rank`, версія шкали, запис розмови (`link`), `sent_at`, хто провів.
- Викладач — усе; агент з токеном — читає без вражень і нотатки, нічого в захисті не міняє; студент — лише надіслане.
- Сторінка дня заняття читає захисти як частини дня (вузол lessons, `app/api/lesson_defenses.py`); `link` заповнює вона.

## Запит по пунктах

1. Сторінка, з якою викладач працює під час захисту: хто, що захищає, коли; початок і кінець.
2. Свої нотатки й враження: слова, емодзі, перемикачі, зірочки; критерії «розуміє · сильний · сподобалось · програма · захист · розуміння» — швидко, кліками; градації, які не «пливуть» за місяць.
3. Дослідити, як із цим дають раду інші.
4. Зауваження студентові: диктую рядками, ШІ розкладає по категоріях (Haiku або Sonnet), іноді перефразовує, обʼєднує; категорії — папки чи теги.
5. Студент відповідає на кожне: виправив чи ні, коментар, посилання GitHub на коміт і рядок; викладач перевіряє; агент перевіряє через API зі своїм токеном.
6. Оцінювання захистів: монетки за доробку, запобіжник від «гіршого коду заради балів», «кнут» за слабкий захист, правила — заздалегідь.
7. Мозковий штурм: що ще потрібно для захистів викладачеві й студентам.
8. Гра й захист поруч: дві сторінки чи одна.
9. Нагадати про базу старих зауважень (C#, ООП, перший курс) — стане зразками для ШІ й каталогом типових.
10. Досвід командної роботи сесій — у `CLAUDE.md`.

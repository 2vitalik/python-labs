# T137 · Постійний процес бота і /start bizChat

`2026-09-25` · ❓ question

Контекст:
- журнал перевірено наживо (2026-09-25, чат): форум, приват із ботом в обидва боки, чат зі студентом через Chat Automation — усе в `messages`; бізнес-рядки тепер `chat_type=business`.
- бот пише лише те, що отримує, поки працює: Bot API історію не читає, чергу неотриманих оновлень Telegram тримає близько доби (при старті дістав службові події форуму 12-годинної давнини). Зараз бот запускається руками локально (`uv run python -m bot`) — «все-все» зберігається лише поки відкритий термінал.
- клієнт Telegram при відкритті бота з бізнес-чату (кнопка біля імені бота в чаті зі студентом) шле `/start bizChat<tg id студента>`; зараз бот відповідає «❌ Не впізнаю це посилання».

**Q1 — Постійний процес до VPS.** Форма деплою вирішиться з VPS ([T19](T19-C--tgbot-concept.md)), але журнал потрібен уже щодня.
- a) launchd-агент на цьому Mac від v6u (як `local.mongodb-backup`): старт при вході, перезапуск після падіння, лог у `~/Library/Logs/`, Mongo тут же; мінус — Mac спить або вимкнений → пауза, черга ~доба (рекомендую як міст до VPS);
- b) лишити ручний запуск до VPS (втрати повідомлень у паузах);
- c) VPS уже зараз (окремий крок: Mongo туди ж або тунель).

> 

**Q2 — `/start bizChat<id>` від адміна.**
- a) коротка картка студента (імʼя-лінк, група, нік) + підказка `/note` · `/hide` (рекомендую — саме з чату зі студентом туди й ведуть);
- b) лише підказка про команди;
- c) лишити як є («не впізнаю»).

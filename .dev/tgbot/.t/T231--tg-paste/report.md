# T231 · Імпорт листування з Telegram вставкою тексту — код — звіт

`2026-10-24` · ⚙️ задача · план — `plan.md` · дизайн — [T230](../T230-P--tg-paste-import.md)

## Зроблено

- **Парсер** `core/api/core/tg_paste.py`: шапка `Імʼя, [дата час]` впізнається лише коли в дужках є час `гг:хх` — так рядок тексту на кшталт «Ок, [чекаю]» лишається текстом (уточнення T230: без цього власний тест спіткнувся на такому рядку); шапка з часом, але нерозібраною датою («[вчора 12:34]», локалізовані місяці) → у `errors` з цитатою. Дати: `дд.мм.рррр`, `дд.мм.рр`, `дд/мм/рррр`, `рррр-мм-дд`, `24 Oct 2026`, `Oct 24, 2026`; час із секундами й AM/PM; зона — `TZ` сайту (Europe/Kyiv). Текст до першої шапки відкидається. `guess()` — студент за словом з ПІБ/`name`/`aliases`/ніка, інакше той, хто не викладач.
- **Маршрут** `POST /api/students/{nick}/messages` (`core/api/core/routes/student_messages.py`): без `student` — огляд `{authors: [{name, n}], student: здогад, errors}`; зі `student` (імʼя з шапки або `""` = усе моє) — запис, відповідь `{added, skipped, student, teacher}`; 422 — коли є помилкові шапки або жодного повідомлення; 404 — чужий нік.
- **Рядки `messages`** — як живі Chat Automation: `chat_type=business`, `dir=in`, `kind=import`, `message_id=0`, `raw={"author": <імʼя з шапки>}`; `user`/`from_id`/`username` — автора (викладач або студент; `from_id` `None`, поки людина не привʼязала бота), `chat_id` — Telegram id студента або `0`; нове поле `TgMessage.about` — пошта студента на обох сторонах.
- **Дублі:** ключ `(хвилина в UTC, текст)` серед бізнес-рядків чату — за `about` (попередні вставки) і за `chat_id` (живі рядки бота, коли студент привʼязаний); повторна вставка того самого шматка нічого не додає; два однакові тексти в одну хвилину — другий пропускається (свідомо).
- **Стрічка** `activity_feed.about()`: для `tg` ще умова `{"about": email}` — рядки викладача в стрічці студента є й у непривʼязаного; у загальній стрічці рядки викладача сховані як службові, як і живі.
- **UI** `core/ui/components/TgPaste.vue` (76 рядків) на `/students/<нік>/edit` під формою профілю (не для адмінів): textarea → «Розібрати» → автори з кількістю й перемикач «хто студент» (здогад вибрано; «ніхто — усе моє») → «Імпортувати» → «✓ Додано N · студента a, твоїх b · вже було k»; помилкові шапки — червоним списком, кнопка імпорту неактивна. `/activity`: бейдж «імпорт» поруч з «особистий чат» (`TG_KINDS`).

## Хвости

- Формат вставки з телефону (iOS/Android) не бачив наживо — парсер терпимий, але локалізований місяць («24 жовт. 2026») піде в помилку: тоді додати місяці UA.
- Медіа у вставці — лише підпис клієнта (`[Photo]` тощо) як текст; правки, видалення, реакції — ні.
- Експорт `result.json` з Telegram Desktop — тим самим маршрутом, окремим парсером, якщо знадобляться медіа чи точний час.
- Пастка сесії: `uv run` у `core/api` пересинхронізував спільний venv під `core/api/pyproject.toml` і створив `core/api/uv.lock` — відкотив (`rm`, `uv sync --frozen` в `app/api`); запускати лише з `app/api`.

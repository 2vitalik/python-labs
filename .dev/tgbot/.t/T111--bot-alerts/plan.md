# T111 · Адмін-алерти про зміни профілю: чат/гілка через /here — план

`2026-09-19` · ⚙️ задача · запит Vitalik у чаті: «всі зміни, які студенти роблять в профілі, відправлялись мені у системний чат… якщо чата ще немає — особисто від бота… окремий чат або гілка форуму… на різні види повідомлень… раз-раз, і налаштував… красиво, інформативно, лаконічно» · звіт — [report.md](report.md)

Контекст: бот-пустишка [T106](../T106--tgbot-stub/report.md), стиль повідомлень [T109](../T109-C--bot-message-style.md), `record()` пише diff у `history` ([T57](../../../platform/.t/T57-B--history-storage.md)) — саме цей diff і є змістом алерту.

## Рамки

- Джерело — той самий diff, що йде в `history`: `record()` повертає `changes`, алерт будується з нього; нових полів у студента нема.
- Види (kinds) — за важливістю, як просив Vitalik: `fill` — нові дані (порожнє → заповнене), `change` — заміна або видалення наявного; плюс `login` — вхід людини, якої нема в базі (не з імпорту → статус «очікує»). Список видів — один словник `KINDS`; новий вид = один рядок.
- Привʼязка — прямо в Telegram командою `/here` у потрібному чаті або гілці форуму; UI на сайті нема. Без привʼязки — особисто кожному адміну, що привʼязав бота.
- Надсилання — з процесу API напряму через aiogram `Bot` (той самий `TG_BOT_TOKEN`), у `BackgroundTasks` після відповіді; черги нема. Порожній токен — алерти мовчки вимкнені.

## Кроки

1. `record()` повертає diff; модель `Route(kind, chat_id, thread_id, title)` у `models/notify.py`.
2. `bot/notify.py` — `KINDS`, спільний `bot()`, `send(kind, text)`: маршрут → чат/гілка; нема або не доставилось → адмінам особисто.
3. `bot/alerts.py` — тексти: `profile(user, changes)` (шапка = найгірша зміна, рядок на поле), `signed_in(user)`.
4. `bot/here.py` — `/here [види|all|off]`; `start.py` — лише приватні чати.
5. Хуки: `routes/profile.py`, `routes/me.py` (відвʼязка), `routes/auth.py` (новий юзер), `bot/link.py` (привʼязка, дзеркало ніка).
6. Смоук `tests/smoke_notify.py`; доки — README вузла, `app/README.md`, CHANGELOG; питання — [T112](../T112-Q--bot-alerts-questions.md).

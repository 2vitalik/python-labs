## Що додалось

Видів тепер сім; `/here` показує ключ, який треба писати: «🟢 fill · нові дані в профілі → тут».

- `claim` 🎯 — заявка створена (🟢 картка + обʼєкт), відредагована (рядки нотатка/лінк/параметри; рівень як у профілі: порожнє→заповнене 🟢, заміна 🟠), видалена (🔴 «→ ✖️»). Авто-заявка при створенні вікна алерту не дає — є алерт про саме вікно.
- `game` 🧩 — картка гри створена (назва + основа) чи змінена (рядок на поле; опис — лише «змінено»), обʼєкт додано/видалено («🧩 вікно «Головне»»), правило додано/видалено — реченням як на сайті: «📜 КОЛИ «Гравець» × «Ворог» → ТО шкода 3 · спавн «Гравець»».
- `error` 💥 — необроблений виняток: «💥 API · PUT /api/profile · vasya / ❗ ValueError: … / 📍 routes/profile.py:31 update_profile»; від бота — «💥 Бот · message · @nick». Клієнт отримує 500 одразу, алерт — після відповіді; 4xx (`HTTPException`, валідація) не алертяться.
- `digest` 📊 — щодня о 09:00 (Київ) з процесу бота: «📊 Профілі не заповнені · студентів: 58 / 👥 ПЗПІ-25-1 · 🪪 2 · 🐙 7 · 🤖 9 / … / ☝️ 🪪 ПІБ · 🐙 GitHub · 🤖 бот»; група без прогалин не показується; усе заповнено — тиша.
- `login` 👋 — тепер **кожен** перший вхід (поле `User.seen_at`, оновлюється при кожному вході): імпортований студент — «👋 Перший вхід · Пупкін Василь · ПЗПІ-25-1»; невідомий — плюс 📧 і «☝️ … статус «очікує»» з лінком на редагування. Разово: у всіх, хто входив до цього оновлення, `seen_at` порожній — наступний вхід дасть «перший».
- `/mute <види>` — вид іде «нікуди» (маршрут із `chat_id = 0`); у статусі «🔇 вимкнено»; зняти — `/here <види>` у будь-якому чаті. `/mute off` навмисно нема.

Приклади:

```

🎯 Меню паузи
🧩 вікно «Головне»
```
```

📜 КОЛИ «Гравець» × «Ворог» → ТО шкода 3 · спавн «Гравець» · бум
```
```

❗ ValueError: boom
📍 routes/profile.py:31 update_profile
```

## Рішення по ходу

- Правки обʼєктів/правил і скриншоти не алертяться: студент, що будує гру, робить десятки збережень поспіль — сигнал губиться; створення/видалення достатньо, щоб бачити активність і підозріле.
- Помилки API — `Exception`-хендлер Starlette, не middleware: після хендлера виняток і далі летить у лог uvicorn; алерт у `BackgroundTask` відповіді, щоб Telegram не тримав клієнта.
- Дайджест у процесі бота, не в API: бот і так довгоживучий, а в API довелося б плодити фонові цикли у воркерах.
- `/mute` замість «замуть гілку в Telegram»: без групи це єдиний спосіб зупинити шумний вид; вимкнений вид — той самий `Route`, тож статус і перепривʼязка працюють без спецвипадків.

# T244 · /due: ! «лише просив», 🙋 при подовженні, причина не губиться — план

`2026-10-27` · ⚙️ задача · вибори — [T243](../T243-Q--due-command-choices.md) · базова команда — [T237](../../github/.t/T237--lab-deadlines-v1/report.md)

Запит Vitalik (чат, 2026-10-27): команда для приватного чату зі студентом — подовжити до числа або «приблизно, поки без числа», потім число; факт попередження фіксувати завжди.

## Кроки

1. `core/bot/due.py`: `patch()` — `!` → `asked` (+ `asked_for` зі слів); дата і `?` → ще й `asked`; текст у патч лише коли він є (дата без слів не стирає `reason`); `line()` статусу — `🙋 просив <слова>` і `💬 причина`; `HINT`.
2. `LabEdit.vue`: рядок «🙋 просив подовжити» + «на скільки, його словами» над подовженням; `LabCell.vue` — 🙋 у лівому куті; `labs.js describe` — рядок у підказці; `activity.js COLLS` — назви `deadlines`/`lab_marks` у стрічці.
3. `smoke_due.py`: 🙋 при даті, причина при `?` і при даті без слів, статус з 🙋/💬, `-` лишає 🙋, `!` зі словами і повтор «без змін».

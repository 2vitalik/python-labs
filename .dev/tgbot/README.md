# tgbot — Telegram-бот: нотифікації, опитування, вхід у систему

Бот як другий інтерфейс до тієї ж БД: нотифікації (захисти, дедлайни, зарахування), опитування зі статистикою, кандидат на основну автентифікацію сайту. Сусіди: [defense](../defense/README.md), [journal](../journal/README.md), [platform](../platform/README.md).

## Вирішено / реалізовано

- **Бот існує: `@python_nure_bot`** (факт від Vitalik, [T60](../platform/.t/T60-Q--profile-questions.md) Q3); юзернейм — у `TG_BOT_NAME` конфіга сайту.
- Привʼязка акаунтів — deep link `t.me/python_nure_bot?start=<токен>` ([T58](.t/T58-C--tg-link-binding.md)): випадковий `tg_token` у документі юзера (не пошта і не ID — їх можна підробити), кнопка на сторінці профілю; **бік сайту реалізовано** ([T64](../platform/.t/T64--profile-v1/report.md)).
- Контракт для майбутнього бота: та сама Mongo-база; на `/start <token>` — знайти юзера за `tg_token`, записати `tg_chat_id` + справжній `tg_username`, привітатися на імʼя; невідомий токен → відіслати до кнопки в профілі.

## Дані

- `users`: ПІБ трьома полями (префіл з Google-клеймів лише в порожні), `group` рядком, `github` — одне поле-URL (старі значення видно в історії), `tg_username` + `tg_token`/`tg_chat_id` (механіка привʼязки — [T58](../tgbot/.t/T58-C--tg-link-binding.md)) · [T61](../.rounds/.t/T61-R--profile-decisions.md)
- **Історія змін** — одна глобальна колекція `history` з диффами `{coll, doc_id, actor, at, {поле: old→new}}` ([T57](.t/T57-B--history-storage.md), варіант a): `record()` у PUT-роутах + `record_new()` при створенні; покриває всі майбутні колекції тим самим хелпером; сторінка перегляду — потім
- `games` + `tasks` — каталог ([T68](.t/T68-P--catalog-v1-design.md) + [T79](.t/T79-C--family-v2.md)): дім зона/підзона (константа `zones.py` — дзеркало `data/wiki/tasks/_map.md`), теги (`algo` = ⭐), застосовність `games` ([] = універсальне), ціна `coin`+`amount` (довідково до рішень grading), `max_count` (1 / N / 0=∞), `parent` (сімʼї батько-діти, 1 рівень), статуси draft/active/archived (draft бачить лише адмін, DELETE нема); `slots` — спеки параметрів заявки ([T103](.t/T103--ludopedia-slots/report.md); канал редагування v1 — лише YAML, адмін-форма їх не чіпає); правки — через `record()`; знімок — `data/catalog/` (games плоско, tasks — дерево рядків `taskline.py`, картки зі слотами — dict-нодами)
- **«Моя гра»** ([T90](.t/T90-P--my-game-v1-design.md), імена — [T92](.t/T92-Q--naming-urls.md)): `student_games` (клас `Game`; одна на студента, основа — слаг `BaseGame` або свій текст), `game_parts` (клас `Part`; вікно: `task`-тип з тегом `window`, скриншоти; меню: `window`-хост + `items` `{title, window, task, note}` — обидві цілі порожні = текстовий пункт), `claims` (`task`+`part`+`params` — значення слотів картки, унікальність трійки, `status=claimed` — життєвий цикл виросте з [T10](../reports/.t/T10-Q--reports-open-questions.md)); файли — `app/api/uploads/<game>/<uuid>` (git-ignored), видалені — у кошик `uploads.trash/` (у проді `UPLOADS_DIR` → тека на VPS, бекап поруч із mongodump); усі видалення логуються `record_delete()`, включно з каскадними
- **Правила і знахідки** ([T101](.t/T101--ludopedia-core/report.md)): `rules` (клас `Rule`: `when {kind…}` · `cond` порожній на виріст · `then [{kind…}]` · `note`; словники тригерів/ефектів — константи `models/rule.py`, ростуть правилом трьох) — сторони контакту й цілі spawn/transform лише сутності гри, ціль window — вікна; `refs` (клас `Ref`: `url·title·note·author·status=inbox·task=""` — два останні поля чекають Д3 «приклади на картках»)
- Ескіз майбутніх колекцій (reports, defenses, remarks, coins-журнал, surveys…) — [T59](.t/T59-C--data-model-sketch.md); зараз існують `users` + `history` + `games` (каталог) + `tasks` + `student_games` + `game_parts` + `claims` + `rules` + `refs`

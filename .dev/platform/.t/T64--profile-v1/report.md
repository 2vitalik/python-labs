## Зроблено

- api (усі кроки плану): `User` розширено (ПІБ×3, `group`, `github`, `tg_username`/`tg_token`/`tg_chat_id`); `models/history.py` — колекція `history` + `record()`/`record_new()` ([T57](../T57-B--history-storage.md), варіант a); `deps.py` — `active_user`/`admin_user`; префіл ПІБ з Google-клеймів лише в порожні поля; `/api/me` віддає повний профіль + `tg_link` (лінива генерація токена, [T58](../../../tgbot/.t/T58-C--tg-link-binding.md)); `PUT /api/profile`; `GET/PUT /api/students(/{id})` + `POST /api/students/import`.
- vue: `ProfileForm.vue` (спільна форма: картки ПІБ/GitHub/Telegram, режими hints/admin), `ProfilePage.vue` (інструкції, кнопка «Привʼязати бота», бейдж привʼязки), `StudentsPage.vue` (таблиця «хто що вніс» + textarea-імпорт), `StudentEditPage.vue`; лінки в NavBar і на головній.
- Конфіг: `TG_BOT_NAME=python_nure_bot` у `.env`/`.env.example`.
- Імпорт адаптовано під реальний `data/students/cist.txt`: група з шапки регекспом, пошта регекспом, ПІБ — перше tab-поле без `@`.

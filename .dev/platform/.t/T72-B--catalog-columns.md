# T72 · Багатоколонкова стрічка каталогу: підходи

`2026-08-05` · 🧠 brainstorm

Контекст:
- запит із чату 2026-08-05: дерево зон → верхня навігація, стрічка завдань → кілька колонок, «щоб якомога менше скролити»;
- база: каталог v1 — [T71](T71--catalog-v1/report.md), подача — [T67](T67-B--catalog-ui.md).

## Дано

162 картки · 38 підзон · медіана ~4 картки на підзону · заголовок ~25–35 символів. Тобто стрічка — це багато **дрібних груп**, і саме групи вирішують, який лейаут виграє.

## Підходи

**A — CSS multicol (`columns`), підзона = нерозривний блок.** Увесь вміст зони тече по колонках як газетний покажчик; `break-inside: avoid` тримає групу цілою. Читання — вниз по колонці, потім наступна.
- ➕ максимальна щільність (нема порожніх «хвостів» рядків), нуль JS, одна CSS-властивість; групи по 2–7 карток лягають ідеально;
- ➖ порядок «вниз-потім-вправо» незвичний для таблиць (для покажчика — норм); розгортання картки перекомпоновує колонки; дуже велика група (9+ карток) робить колонку високою.

**B — CSS grid (`auto-fill minmax`), картка = комірка, заголовок підзони на всю ширину.** Читання — зліва направо.
- ➕ передбачуваний порядок; розгорнута картка не переносить сусідів між колонками;
- ➖ кожна підзона стартує з нового рядка: при 38 групах × 4-колонковій сітці постійно лишаються порожні комірки → стрічка помітно довша (гірше для «менше скролити»);
- ➖ заголовки-роздільники на всю ширину зʼїдають вертикаль.

**C — masonry (JS-бібліотека або `grid-template-rows: masonry`).** Ідеальна упаковка блоків будь-якої висоти.
- ➖ `masonry` у CSS ще не крос-браузерний, JS-бібліотека — зайва залежність проти правил проєкту; виграш проти A мізерний, бо групи й так дрібні.

## Рішення

Взяв **A**: для профілю даних (багато дрібних груп) він і найщільніший, і найпростіший — `columns: 20rem` (~320px під заголовок + монетку), група з шапкою підзони як один блок. Зона = окрема секція зі своїм multicol-контейнером (зони не перемішуються в одній колонці). `/tasks` переведено на всю ширину екрана (`container-fluid`, route meta `wide`) — на FHD виходить 4–5 колонок, на ноутбуку 3, на телефоні 1.

Перехід на B, якщо «газетний» порядок не зайде, — заміна двох CSS-правил, компоненти не змінюються.

# T298 · Вигляд секцій «Гри»: ⌥-клік — у всіх, верх — за замовчуванням — план

`2026-11-15` · ⚙️ задача · після [T296](../T296--game-desc-v10/report.md) · вибори — T299

Запит Vitalik (голосом, одна вставка): кнопки вигляду на заголовку секції «Гри» — змінити не лише цю секцію, а й усі одразу (клавіша-модифікатор? як прийнято на сайтах; Windows, Mac, Linux; підказка); верхні перемикачі — значення за замовчуванням: кнопка на заголовку синя, лише поки секція відрізняється від верху, а повернулась до верху — сіра.

## Пункт 1. «У всіх секціях» із заголовка

Як прийнято: **⌥ / Alt + клік** по перемикачу = «те саме з усіма сусідами».

- GitHub: Alt-клік по стрілці файлу в PR згортає / розгортає всі файли — найближчий веб-аналог.
- Finder: ⌥-клік по трикутнику розкриває всі вкладені; Chrome DevTools: Alt-клік по вузлу розкриває все дерево.

Платформи:

| | ⌥ / Alt | Shift | ⌘ / Ctrl |
|---|---|---|---|
| Mac | вільна | вільна | ⌘ вільна; Ctrl-клік = правий клік |
| Windows | вільна | вільна | вільна |
| Linux | Alt-клік забирає менеджер вікон (XFCE, MATE, Cinnamon — тягнути вікно) | вільна | вільна |

Рішення:
- підказка називає одну клавішу — ⌥ на Mac, Alt деінде;
- але спрацьовує будь-який модифікатор (Shift, ⌘, Ctrl теж): хто натисне «не ту», все одно отримає результат, а на Linux, де Alt забраний, працює Shift;
- поки ⌥ / Alt затиснута, кнопки заголовка під мишкою беруться пунктирною рамкою, а та, що під курсором, одразу каже, що зробить: «⌥ у всіх секціях: кілька стовпців»;
- на телефоні модифікатора нема — там верхні перемикачі, як і було.

Семантика: ⌥-клік робить у всіх секціях те, що звичайний клік зробив би тут. Тобто ця секція переходить на наступне значення, і всі інші — на нього ж; свої значення секцій скидаються, як від верхньої кнопки.

Де працює:
- стовпці, «Розкладка», «Картки» на заголовку;
- шеврон секції (згорнути всі / розгорнути всі) і «коротко» (усі коротко / усі повністю);
- стрілка однієї картки та «розгорнути» на згорнутій картці — усі картки сторінки.

Ширина — і так одна на сторінку, без змін.

## Пункт 2. Верх — значення за замовчуванням

- Кнопка на заголовку синя ⇔ секція відрізняється від верху. Клік, що повертає до верхнього значення, стирає «своє», і кнопка сіріє.
- Так для стовпців, «Розкладки», «Карток», а також для «коротко / згорнуто» (`fold.js`): трійка «усе · коротко · згорнуто» вгорі стає значенням за замовчуванням для сторінки, а не разовою дією «зробити всім».
- Шеврон розгортає секцію до значення за замовчуванням: якщо вгорі «коротко», то коротко; якщо вгорі «згорнуто», то повністю.
- Окрема картка, розгорнута чи згорнута інакше, ніж її секція, — стрілка синя; повернулась до секції — сіра.
- Верхня кнопка, як і досі, скидає всі «свої». Це узгоджено з ⌥-кліком: «у всіх» означає справді в усіх.
- Ширина на заголовку більше не синя: вона не буває своєю для секції, тож синя на кожному заголовку казала б «тут своє» неправдиво. Стан і так видно зі значка.

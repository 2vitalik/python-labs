2. ✅ Підказки:
   - під мишкою кожна кнопка каже «⌥-клік — у всіх секціях»;
   - поки ⌥ затиснута, кнопки заголовка під мишкою беруться пунктиром, а та, що під курсором, одразу пише «⌥ у всіх секціях: рядами»;
   - угорі — закривне пояснення ⓘ (на телефоні його нема) · ❓ Q5
3. ✅ Верх — значення за замовчуванням. Кнопка на заголовку синя, лише поки секція відрізняється від верху. Клік, що повертає до верхнього, стирає «своє», і кнопка сіріє.
   - Так для стовпців, «Розкладки», «Карток», «коротко».
   - Трійка «усе · коротко · згорнуто» вгорі тепер теж значення за замовчуванням: світиться обране, «свої» лічить у підказці під мишкою.
   - Окрема картка, інакша за свою секцію, — синя стрілка.
4. ✅ Верхня кнопка, як і досі, скидає «свої» в секціях. Так узгоджено з ⌥-кліком · ❓ Q6

Дрібне, що випливло з правила «синє = своє»:
- шеврон розгортає секцію до значення за замовчуванням, а не завжди повністю · ❓ Q3;
- ширина на заголовку більше не синя · ❓ Q4;
- «коротко» синіє лише тоді, коли відрізняється саме «коротко / повністю»: розгорнута секція під «згорнуто» вгорі його не фарбує.

## Чому ⌥ / Alt

| | ⌥ / Alt | Shift | ⌘ / Ctrl |
|---|---|---|---|
| Mac | вільна | вільна | ⌘ вільна; Ctrl-клік = правий клік |
| Windows | вільна | вільна | вільна |
| Linux | Alt-клік забирає менеджер вікон (XFCE, MATE, Cinnamon) | вільна | вільна |

- Звичай: GitHub (Alt-клік по стрілці файлу в PR — усі файли), Finder (⌥ по трикутнику), Chrome DevTools (Alt по вузлу — усе дерево).
- Тому підказка називає ⌥ / Alt, а приймається будь-який модифікатор: Linux-у з Shift теж добре.
- Shift-клік не виділяє текст між кліками: `mousedown` на таких кнопках гаситься.

## Зроблено

### Ядро (`core/ui`)
- `allkey.js` (новий) — `toAll(e)` (будь-який модифікатор), `ALL_KEY` (⌥ на Mac, Alt деінде; платформа з `userAgentData.platform` = «macOS» — регістр не важить); клас `all-key` на `<html>`, поки затиснута ⌥ / Alt; Shift-клік по `.every` не виділяє текст.
- `style.css` — `.every`: пунктир під затиснутою ⌥ (усі в `[data-all-host]` під мишкою), миттєвий підпис `data-all` під кнопкою (`.every-start` — праворуч від кнопки зліва).

### Сайт (`app/vue`)
- `layout.js` — `isOwn(id)` (своє лише там, де відрізняється від верху), `ownCount` за ним; `nextCols(id, all)`: повернення до верху стирає своє, `all` — для всіх.
- `looks.js` — `set(v, id)` стирає своє, рівне верху; на старті вичищає старі такі; `cardOwn`, `toggleCard(card, scope, all)` — так само для однієї картки.
- `fold.js` — значення за замовчуванням сторінки `ed:*`. API:
  - `setAll(page, mode)` / `allMode(page)`, `isOwn`, `ownShort`;
  - `toggleFold(key, all)` — розгортає до значення за замовчуванням, `toggleShort(key, all)`;
  - `setFold` / `setShort(false)` (переходи «показати де», `#`-посилання, «＋») — як і були, повністю.
- `ColsSwitch`, `LookSwitch` — ⌥-клік, підказка «як угорі / своє (угорі — …)», «Клік — …, як угорі», рядок угорі «свої (сині на заголовках)».
- `SectionHead` — шеврон і «коротко» з ⌥, `title` у шеврона, `data-all-host`; «коротко» синє за `ownShort`.
- `WideSwitch` — на заголовку завжди сіра.
- `CardFold`, `CardShut` + `EntityCard`, `WindowCard`, `LevelCard` — ⌥ на стрілці й на згорнутій картці, синя стрілка.
- `GameEditor` — трійка згортання як значення за замовчуванням (`allMode('ed')`), лічильник своїх у `title`, закривне пояснення `Tip id="all-key"` (лише з мишкою).

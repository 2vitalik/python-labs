## Хвилі

Кожна хвиля закінчується комітом (або кількома), після якого збірка й смоуки цілі.

1. **Правила й дизайн** — «коміти одразу» в `CLAUDE.md`, записка сусіднім сесіям, T315.
2. **Логіка без екрана** (я): стан виду з кількома рівнями груп і сортування, ключі «цієї лаби», умови фільтрів `+` / `-` / `~N` / `^N`, склад виду словами й «що змінилось», каталог колонок з родинами, перетягування списку, дата-плашка.
3. **Бекенд** (агент Opus, паралельно з 2): `View` + `ViewVersion` + `Pref`, заводські види в базі, версії, архів, лік, папки; `smoke_views.py`.
4. **Таблиця й рядок налаштувань** (агенти Opus за контрактом): `TableGrid` — вкладені групи з підсумками, рядок підсумків-фільтр, меню заголовка, перетягування колонок; `TableSetup` з панелями Колонки · Фільтри · Групи · Сортування; свої колонки в каталозі.
5. **Види** (агенти Opus): вкладки, заголовок з назвою й «для чого» на місці, зберегти / як новий / скинути, незбережене в браузері, картка під мишкою, лік роботи; бібліотека `/table/views` — папки, теги, еталони, дерево походження, версії, порівняння.
6. **Зміст**: колонка «Реєстрація», колонки гри й «Опис гри», еталони лаб 1 · 2 · 3+.
7. **Перевірка на стенді** (агент-QA + я): сценарії з T315, знімки; правки.
8. **Доки**: звіт, CHANGELOG, README вузла й кореня, STATUS, T317.

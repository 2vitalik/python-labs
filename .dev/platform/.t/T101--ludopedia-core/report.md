# T101 · Лудопедія: сутності, правила, знахідки — звіт

`2026-08-18` · ⚙️ задача · план — [plan.md](plan.md); питання по збудованому — [T102](../../../games/.t/T102-Q--ludopedia-build-questions.md)

Зроблено все за планом; смоук **60/60 PASS**, `npm run build` зелений.

## Бекенд

- `Part` + `kind="entity"` + поле `role` (словник у `models/rule.py`: `player·enemy·object·pickup·static`); створення/редагування в `my_parts.py`, без картки-типу й авто-заявки; заявки механік чіпляються звичайним `Claim.part`.
- **`models/rule.py`** — модель `Rule` (`rules`): `when·cond(на виріст)·then·note` + словники `TRIGGERS` (contact, timer) і `EFFECTS` (15); `rule.uses(part_id)` для каскаду.
- **`routes/my_rules.py`** (`/api/my/game/rules`, POST/PUT/DELETE): валідація по словниках — сторони контакту лише сутності гри, цілі spawn/transform — сутності, window — вікна, числа/тексти перевіряються; все через history.
- Каскад: видалення частини зносить (через `record_delete`) правила, де вона фігурує в тригері чи ефектах.
- **`models/ref.py` + `routes/refs.py`** (`/api/refs`): інбокс знахідок; GET/POST — всі активні, PUT/DELETE — автор або адмін; `status/task` — поля на виріст до Д3 «приклади на картках»; в API автор віддається ніком.
- Паспорт віддає `rules`; галерея — лічильники `entities`/`rules`.
- Смоук: +17 перевірок (ролі, валідація правил, каскад сутність→правила, паспорт, знахідки з правами).

## Фронт

- `rules.js` — UI-дзеркало словників + рендер речення (`whenText`/`effectText`); `ROLES` з іконками в `catalog.js`.
- **`EntityCard.vue`** — картка сутності (роль+назва, опис, скриншоти, заявки через наявні ShotStrip/ClaimRow/ClaimPicker).
- **`RuleRow.vue`** — речення «КОЛИ → ТО»: читається рядком («КОЛИ 🧍Гравець × 👾Ворог → ТО шкода 1 · зникає Б»), редагується селектами зі словників; ефекти-чіпи з міні-аргументами (число / ціль / текст); один компонент на редактор і паспорт.
- `/my/game`: секції «Сутності» (＋ роль+назва) і «Правила» (＋ правило, потребує сутностей); `/students/<nick>`: ті самі секції read-only + лічильники в шапці.
- **`RefsPage.vue`** (`/refs`, навбар «Знахідки»): форма «кинути лінк» + спільна стрічка з YouTube-превʼю, нотаткою, автором і датою; редагування/видалення — своє (адміну — все).

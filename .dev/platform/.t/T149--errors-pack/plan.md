## Як саме

- Одне місце для відповіді API — `http.js`: помилка несе `status`; немає відповіді або не JSON → «сайт недоступний» (`status = 0`), 5xx → «щось пішло не так на сервері», 4xx — текст від API.
- Прапорець `down` ставить і знімає кожен запит; поки він стоїть і невідомо, хто дивиться, — замість сторінки лише банер; банер сам пробує API раз на 5 с.
- Усе, що ніхто не зловив (`errorHandler`, `error`, `unhandledrejection`), іде в `report()`: 404 → сторінка 404 замість відкритої, решта → блок над сторінкою; сторінка лишається, щоб не губити введене у форму.
- Сторінки з параметром більше не ловлять помилку мовчки — вона доходить до `report()`.
- `GET /api/students/<нік>/game`: нема студента → 404, студент без гри → `game: null` — щоб «ще не створена» не плуталась із «такої сторінки нема».
- `POST /api/errors` приймає помилки від усіх, і від гостей; ліміт — 5 на хвилину з однієї IP; алерт про той самий текст — не частіше ніж раз на 10 хв, у базу лягає кожна.
- Колекція `errors` — джерело стрічки `/activity`: чіп «💥 Помилки», traceback розгортається.

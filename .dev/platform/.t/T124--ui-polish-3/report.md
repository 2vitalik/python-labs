## Рішення по ходу

- **`noflash`** — клас-опція для `flash()` в `anchors.js`: скрол є, підсвітки нема. Потрібен зонам каталогу (спалах фарбував би весь masonry-блок) і рамці змісту на `/method`.
- **`guideClick` зберігає `?query`**: `router.push({ hash })` у vue-router скидає query — на `/tasks` клік по якорю в тексті блоку (а тепер і по зоні в змісті) обнуляв фільтри й пошук. Тепер `{ query: router.currentRoute.value.query, hash }`.
- **`local.js`** — `load`/`save` для `localStorage` у `try` (приватний режим) — замість двох копій у `GuideHead` і `wide.js`.
- «Методичка» у крихтах `/games` і `/tasks` — так, бо вони розділи на `/method`; на підсторінках каталогу — ні. Якщо для адмінського `/tasks` це зайве — прибрати один елемент масиву в `TasksPage`.
- «↑» веде до рамки змісту (`#toc`), а не на самий верх: користувач просив «до змісту».
- Ghost-рядок замість фону — щоб не зливався з шапками груп; якщо хочеться саме фон — один рядок CSS у `StudentsTable` (`.ghost { --bs-table-bg: … }`).

# T246 · /table: швидкі чіпи-фільтри «у кого є» з лічильниками — звіт

`2026-10-28` · ⚙️ задача · план — `plan.md` · таблиця — [T242](T242--table-v1/report.md)

## Зроблено

- **Рядок чіпів над таблицею** (`TablePage.vue`): по одному на кожну показану колонку типу так/ні, посилання чи вибір — у виді «Лаба N» це 🔑 заходив · 🤖 бот · 🐙 GitHub · 💾 репозиторій · 🙋 просив · **⏳ подовжено** · ✍ слово викладача · ⚖️ розбіжність з опитуванням · свої чекбокси й вибори. Клік — лишити тих, у кого в колонці щось є (для вибору — будь-який варіант: `until,open` ⏳), ще клік — зняти; у чіпі — лічильник з урахуванням пошуку й решти фільтрів; активний — залитий, у URL — звичайний `f.labN.ext=until,open`, тож вид можна зберегти з ним.
- Бейдж фільтра, що покриває всі варіанти, пише «є» замість «⏳ ⏳»; підказка внизу сторінки згадує чіпи.
- Детальніший фільтр («подовжено до дати» окремо від «дата невідома», «ні», «порожньо») — як і раніше, ▾ у заголовку колонки.

## Перевірено

- Збірка `app/vue` — ок; `smoke_table` не чіпався (бекенд той самий). У браузері — не клікав: клік-тест на `/table?view=lab1` → чіп ⏳ → лишаються лише подовжені, бейдж «⏳ є», лічильники на інших чіпах перераховуються.

## Хвости

- Чіпи — лише «є»; «нема» (хто ще без бота) — через ▾. Якщо захочеш обидва стани одним чіпом (клік-клік-клік: є → ні → усі) — дрібна правка `flipQuick`.
- Для `lab` (стан) і опитувань чіпів нема — там варіантів багато, «є будь-що» не має сенсу.

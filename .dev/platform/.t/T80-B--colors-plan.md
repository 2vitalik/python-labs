# T80 · Кольори v2: ємність сімейств і розкладка зон

`2026-08-06` · 🧠 brainstorm

Контекст:
- твоя відповідь у [T78](T78-Q--catalog-ui2.md) Q2: окремий брейншторм — які сімейства «ємніші», близькі сімейства сусіднім зонам (логіка+рівні = синій+фіолетовий), дизайн — червоним, сутності — зелено-жовтим, код — сірим, супровід — особливим; куди подіти рожевий і бежевий;
- наочно: пропозиція — сторінка **`/colors2`** (кожна підзона з реальною назвою й іконкою у своєму кольорі, коди E1…S3); майстерня варіацій — `/colors` (лишилась).

## Ємність сімейств (скільки «прям різних» відтінків тримає око)

Оцінка перцептивна: скільки відтінків у сімействі середньої насиченості людина впевнено розрізняє поруч на білому фоні:

| Сімейство | Ємність | Нотатка |
|---|---|---|
| зелений (жовтозелений→бірюза, 46°–175°) | **7–8** | найширший діапазон хʼю — чемпіон |
| синій (блакить→індиго, 190°–260°) | **6–7** | другий за шириною |
| червоний+помаранч (+беж, 345°–40°) | **6–7** | беж = ненасичений помаранч — легальний член сімейства |
| фіолетовий (265°–315°) | 5–6 | |
| фуксія/рожевий (315°–345°) | 3–4 | вузький клин |
| чистий жовтий (45°–60°) | 2–3 | темніший жовтий = олива/беж — тому жовтий не тягне окрему зону, він **край зеленого** |
| сірий | 4–5 | розрізнення світлістю, не хʼю |

## Пропозиція П1 (виставлена на `/colors2`)

Принцип: **зона = діапазон одного сімейства**; підзони — кроки по діапазону (дуже різні, бо крок ~13–15° + гойдання світлості); **сусідні зони — сусідні сімейства**, тож межові підзони автоматично на межі діапазонів.

- 👾 **Сутності (7)** — жовтий→зелений→бірюза: найбільша ємність під 7 підзон; «живе» (твоє зелено-жовте);
- 🎲 **Логіка (9)** — блакить→синій→індиго: найбільша зона отримує другий за ємністю діапазон; впритул до…
- 🗺️ **Рівні (6)** — фіолетовий→пурпур: твоя пара «логіка+рівні близькі»;
- 🕹️ **Інтерфейс (8)** — червоний→помаранч→**беж**: «дизайн червоним», беж прилаштований сюди (I7–I8);
- 💻 **Код (5)** — сірі світлості з легкою синню: «базове ремесло»;
- 📣 **Супровід (3)** — **фуксія**: особливий колір, якого нема в жодній зоні; і рожевий прилаштований.

Разом закриті всі твої «куди подіти»: жовтий → край Сутностей, беж → край Інтерфейсу, рожевий/фуксія → Супровід, сірий → Код.

Альтернативи, якщо П1 не зайде: П2 — Інтерфейс і Супровід міняються (Супровід червоний «афіша», Інтерфейс фуксія-рожевий); П3 — Код не сірий, а бірюза (тоді Сутності звужуються до 46°–150°, сірий вільний для чернеток/службового). Можу виставити на `/colors2` другим рядом — скажи.

Відповідь зручно кодами з `/colors2`: «беремо П1», «I3 → інший», «E1 і E4 поміняти».

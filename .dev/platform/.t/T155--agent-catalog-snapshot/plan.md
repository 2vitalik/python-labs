## Як є

- Токен агента відкриває лише методичку ([T153](../T153--agent-guide-access/report.md)).
- `bin/guide` без `-t` ходить у дев.
- Знімок у git (`data/guide/*.md`, `data/catalog/*.yaml`) знімається з локальної бази: `guide_io.py export`, `catalog_io.py export`.
- Локальна база й сервер уже розійшлись, тож у git лежить не те, що бачать на сайті.

## Рішення

- Q1: скрипти без `-t` ходять на сервер; дев — `-t dev`.
- Q2, Q3: без змін — публікація «Що змінилось» за адміном, агенти під своїми іменами.
- Q4: знімок у git знімається із сервера. Правка агента на сервері закінчується знімком сама; окремо — команда `snap`.
- Q5: токен відкриває ще каталог — читання з чернетками, додавання й правку карток ігор і завдань.
- Картки правляться так само, як сторінки: файл → правка → `push`.

**Q1 — Емодзі монеток.** Поставив: медалі для «справжніх» цін + окремі знаки для дрібних, як ти й схилявся: 🥇 золота · 🥈 срібна · 🥉 бронзова · 🔵 оловʼяна · 🌿 деревʼяна. Логіка: медалі = основна тріада нагород; дерево — зелена гілочка (жива, «росте», не плутається з металами); олово — просто інший колір без претензії на цінність. Альтернативи: дерево — 🌱 (паросток) / 🍃 (листок) / 🪵 (колода, але коричнева — плутається з бронзою); олово — 🔷 (синій ромб, «жетон») / 🔩 (метал, але сірий — плутається зі сріблом) / 🧿 (синє «око»-амулет, кругле як монета, але незвичне). Лишаємо 🥇🥈🥉 + 🌿 + 🔵?
- a) так, лишаємо як є;
- b) інші — вкажи, які саме.

> 👑 🥇 🥈 🥉 📎 🌱

**Q3 — Іконки зон.** Поставив: 👾 Сутності (ігровий монстрик = живі обʼєкти поля) · 🎲 Логіка гри (кубик = правила/випадок) · 🗺️ Рівні (мапа) · 🕹️ Інтерфейс (джойстик = те, чим граєш) · 💻 Код (ноутбук) · 📣 Супровід (рупор = промо). Альтернативи, якщо щось не лягає: Сутності 🤖/♟️ · Логіка ⚖️/🧠/⚙️ · Рівні 🧩/🪜 · Інтерфейс 🖥️/🎛️ · Код 🐍 (зайнято підзоною Python-фічі) /⌨️ · Супровід 🎬/🌐.

## Хвости

- Таблиця тягне все одним `GET /api/table` (~0.5 МБ на 108 студентів з 5 лабами): для сотні — ок, для тисячі треба буде віддавати лаби й опитування окремо.
- Зміна `type`/`scope` поля зі значеннями заборонена (409) — переконвертувати можна лише новим полем.
- `polls:labN` бере опитування за тегом; «Перший дедлайн» на проді має лише тег `дедлайн` — додати `lab1` (або «дедлайн 1»).
- Вид зберігає колонки як сімʼї (`polls:lab1`, `fields:lab1`), поки їх не чіпати в «Колонках»: після ручної правки — явний список (нові поля/опитування вже не долучаються самі).
- Часи в клітинках — у зоні браузера: на цьому ноутбуці (MSK) дедлайн 23:59 Київ читається як «28 жовт., 00:59».

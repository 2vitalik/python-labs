# T108 · Ідеї для сторінки профілю

`2026-09-19` · ❓ question

Контекст:
- запит Vitalik у чаті (2026-09-19) після правок «Зберегти лише при змінах» + статус праворуч: «чи є ще якісь ідеї, що можна покращити на сторінці профіля?»;
- зараз: `ProfilePage.vue` + `ProfileForm.vue` (картки ПІБ/GitHub/Telegram з підказками), `useForm()` у `form.js` дає `dirty`; шапка — лише «Мій профіль» + пошта; ручне поле Telegram-ніка — окреме питання [T107](../../tgbot/.t/T107-Q--tg-username-field.md), після відповіді «a» картка Telegram стане коротшою (статус привʼязки + нік лише для читання).

**Q1 — Які з ідей робити** (можна кілька; порядок — за співвідношенням користь/ціна, як я бачу):
- a) **попередження про незбережені зміни** при переході на іншу сторінку — `onBeforeRouteLeave` + `dirty`, ~3 рядки; студент не втратить набране (рекомендую);
- b) **шапка з аватаром і групою**: фото з Google (`user.picture` вже є в моделі) + `ПЗПІ-25-1 · nick` під заголовком — студент бачить, що система знає його групу; група лишається read-only (рекомендую);
- c) **чекліст заповненості** над формою: «ПІБ ✓ · GitHub — · Telegram ✓» — прогрес онбордингу і підказка, що ще треба; та сама логіка, що в таблиці `/students`;
- d) **GitHub: перевірка формату на клієнті** — атрибут `pattern` з тим самим регекспом, браузер підкаже до відправки; поруч із заповненим полем — маленьке «відкрити ↗»;
- e) **дрібне**: помилка зникає при першому редагуванні (зараз висить до наступного «Зберегти»); `autocomplete="off"` на ПІБ, щоб браузер не підсовував латинські імена з автозаповнення;
- f) **підказки згортаються** для вже заповнених полів (ПІБ-підказка після заповнення зайва; GitHub-підказку про розшарення лишити завжди) — спірне, можна не робити.

1. **`GameGraph.vue`** — SVG без залежностей: вузли = вікна (мініатюра першого скриншота + назва), стрілки = пункти меню «вікно-хост → вікно-ціль» (мітка = назва пункту, паралельні ребра зливаються в одну мітку через кому); розкладка — BFS-шари зліва направо (недосяжні вікна — нові корені); клік по вузлу — скрол до картки вікна; порожній граф без ребер — підказка, як їх отримати.
2. **Паспорт** (`/students/<nick>`): секція «Карта переходів» + рядок монеток заявок (довідково, без зарахування: 👑×N 🥇×N …).
3. **Редактор** (`/my/game`): та сама карта — студент бачить структуру, поки будує.
4. `npm run build`; report, доки, коміт-меседж. Бекенд не чіпається (смоук лишається 43/43).

# T94 · Report: етап D — граф переходів і фініш паспорта

`2026-08-17` · виконано (фронт-онлі; бекенд і смоук 43/43 не чіпались)

## Що зроблено

- **`GameGraph.vue`** — SVG-карта переходів без залежностей (~110 рядків): вузли = вікна (мініатюра першого скриншота + назва), стрілки = пункти меню «хост → ціль» (мітка = назва пункту; паралельні пункти між тією ж парою вікон зливаються в одну стрілку з мітками через кому); розкладка BFS-шарами зліва направо, недосяжні вікна стають новими коренями; самопосилання і цілі-функції в граф не входять (це не переходи між вікнами). Клік по вузлу — плавний скрол до картки вікна; горизонтальний скрол при переповненні; якщо ребер нема — підказка, звідки вони беруться.
- **Паспорт** (`/students/<nick>`): секція «Карта переходів» між описом і вікнами + у рядку лічильників — монетки заявленого за типами (`👑×N 🥇×N …`, сума `amount` по картках; title пояснює «довідково, без зарахування»).
- **Редактор** (`/my/game`): та сама карта після секції меню — студент бачить структуру гри, поки будує; оновлюється разом з рештою при кожній зміні.

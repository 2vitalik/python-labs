# T118 · Меню коротше з «Ще», єдина ширина сторінки, тексти в стилі Notion — звіт

`2026-09-20` · ⚙️ задача · план — [plan.md](plan.md) · питання — [T119](../T119-Q--nav-naming-questions.md) · аватар — [T120](../T120-C--avatar-glitch.md)

Усі 10 пунктів запиту зроблено; `npm run build` чистий; клік-тест у Chrome (розширення підключене з v6u) на 1320 / 864 / 700 / 480 / 390 px.

## Як працює

- **Меню** (`NavBar.vue` + `NavUser.vue` + `navFit.js`): пункти Ігри · Лаби · Таски · Бали · Здача · Студи · Моя гра · Профіль (назви — у `guide.js` і `NavBar.vue`). Завжди один рядок, гамбургера нема. `useNavFit` міряє ширини `<li>` (nowrap, не стискаються) проти вільної ширини `<ul>` (`flex: 1 1 0; min-width: 0`) і в три кроки прибирає зайве: 1) імʼя користувача, 2) «Python Labs» → іконка-дім і «Вийти» → іконка-вихід (inline SVG з Bootstrap Icons, без залежності), 3) хвіст пунктів — у дропдаун **«Ще»** (Bootstrap-стилі, стан на Vue; закривається кліком поза ним і при переході). Перерахунок — `ResizeObserver` на `<nav>`, зміна списку пунктів (роль) і поява користувача. «Ще» підсвічується `active`, якщо поточна сторінка всередині. Відступи пунктів .45rem замість .5, бренд — .5rem замість 1rem. Пункти на два рядки тепер не буває (nowrap), тож висота меню стала — 57 px на всіх ширинах.
- **Знахідки** — з меню прибрано; кнопка «💡 Знахідки» поруч із «➕ Нова гра» / «➕ Нове завдання» на робочих `/games` і `/tasks` (адмін), плюс лінк у `tasks.md#ideas`.
- **Аватар** — `Avatar.vue` (меню 32, шапка профілю 56, картки студентів і сторінка гри студента 28): `referrerpolicy="no-referrer"` і на помилці завантаження — кружечок з ініціалом; той самий кружечок без фото. Розбір — [T120](../T120-C--avatar-glitch.md).
- **Ширина** — `style.css`: `--page-max: 52rem` (832 px) і клас `.page` (max-width + auto-margin + 1rem поля). `App.vue` — `<main class="page">`, навбар — `<div class="page …">`; з усіх сторінок прибрано `col-lg-8/9/10 mx-auto` (профіль, домашня, знахідки, студент/редагування, моя гра, гра студента, форми гри/завдання, `/guide`, вхід), `GuideHead` — без свого `max-width`. Широкі робочі сторінки (`meta.wide`: `/tasks`, `/games/:slug`) лишились `container-fluid`; шапка гри там — `.page px-0`.
- **Домашня** — `home.md` цілком (лід + «Як влаштований курс» з лінками на розділи + «З чого почати»), без розкривашок і без `lead` — текст 16 px як усюди; знизу лінки «🆕 Що змінилось» (`/changes`, окрема сторінка через `GuidePage`, у меню її нема; `CHANGES` у `guide.js`, є на `/guide`) і «Уся методичка». `GuideBrief.vue` видалено; маркери `<!-- sections -->` і `<!-- more -->` у файлах більше не потрібні (API далі підтримує `more` для `brief` у списку).
- **Зміст** (`GuidePage.vue`) — тепер поза колонкою тексту: `position: fixed` у правому полі (`left: calc(50% + 26rem + 1rem)`), по центру вертикалі, ширина 11rem, лінія зліва, заголовок «ЗМІСТ», сірі лінки (`text-secondary`, темніші на hover), 0.8rem, щільно; зʼявляється від `76rem` (1216 px) вікна, вужче — нема. Будується з усього тексту сторінки (раніше — лише з частини нижче `more`).
- **Профіль** — мітки без даних червоні (`bg-danger-subtle`), «Telegram-бот» → «Telegram» (як секція нижче).
- **Тексти `data/guide/`** — усі 12 файлів переписано в стилі Notion-методички: короткі фрази, вкладені пункти замість довгих речень, жирне ключове слово, емодзі; заголовки розділів — як пункти меню («📚 Лаби», «🧩 Таски», «💯 Бали», «📤 Здача»), лінки на розділи — тими ж словами; `/grading` у `home.md` → `/score`; якорі збережено. README: конвенції (стиль, `more` необовʼязковий, `sections` прибрано, `/changes`).

## Рішення по ходу

- «Як здавати» → **«Здача»** (варіанти — T119 Q1); «Студенти» → «Студи» (запит).
- Ширина 52rem — між профілем на xl (760) і xxl (880), збігається з колишнім `GuideHead`; T119 Q2.
- Перенесення пунктів на два рядки не робив — з «Ще» воно не потрібне і ламало б сталу висоту; nowrap + переливання в «Ще» дає те, що просилось («видимо якомога довше», висота не росте).
- Імʼя користувача — nowrap і зникає першим при нестачі місця, тож «зайвої ширини» під перенесене імʼя більше нема.
- Гостю в компактному режимі «Увійти з Google» → «Увійти», «Dev-вхід» ховається.

## Перевірка

- `npm run build` — чисто. API без змін (лише коментар до `MORE`).
- Chrome, адмін (dev-користувач тимчасово `admin` з фото — повернуто): **1320** — усі 8 пунктів + фото + імʼя + «Вийти», зміст праворуч (11 лінків, сірі, по центру); **864** — те саме без змісту; **700** — імʼя сховане, іконки дому й виходу, 8 пунктів; **480** — 5 пунктів + «Ще» (Студи · Моя гра · Профіль у дропдауні, відкривається/закривається); **390** — те саме, домашня з новим текстом і однаковим шрифтом; `/profile` на 390 — фото, «○ GitHub» і «○ Telegram» червоні, «✓ ПІБ» зелена.
- Аватар: `curl` і `new Image()` у Chrome — усі 200; збій не відтворився (T120).
- Не перевірено вживу: гість на вузькому екрані (кнопка «Увійти»), справжній збій фото, `/guide` після прибирання колонки — лише build.

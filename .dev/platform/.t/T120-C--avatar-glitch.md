# T120 · Аватар Google інколи не вантажиться — розбір і захист

`2026-09-20` · 🔆 clarification · запит Vitalik: «лише текст alt, некрасиво; це лише локально? має завжди працювати; досліди окремо» · код — [T118](T118--nav-width-polish/report.md)

## Що відбувається

- `user.picture` — URL з Google OAuth (`lh3.googleusercontent.com/a/…=s96-c`), фото тягне браузер напряму з Google; сервер лише зберігає рядок.
- Коли `<img>` не вантажиться, браузер показує `alt` (імʼя) — звідси текст замість кружечка.
- Відтворити не вдалось: `curl` (без referer, з referer `127.0.0.1:5030` і `localhost:5030`, серія з 15) — усі 200 `image/png`; у Chrome `new Image()` з referer і без — ok.

## Ймовірні причини (за досвідом інших проєктів)

1. **429 Too Many Requests** від Google — найчастіша: ліміт на URL+referer при частих перезавантаженнях (dev-режим з HMR, багато вкладок). Стандартна порада — `referrerpolicy="no-referrer"` на `<img>`: без referer ліміт не спрацьовує.
2. **Застаріле посилання** — Google міняє URL після зміни фото акаунта; старе якийсь час працює, потім 404. Оновлюється при наступному вході (`upsert_user` перезаписує `picture`).
3. Мережа/VPN/блокувальник, що ріже `googleusercontent.com` — тоді лише локально в конкретного користувача.

На сервері буде так само, як локально: картинка все одно йде з браузера студента до Google, тож 1–3 можливі й там.

## Зроблено (T118)

- Спільний `Avatar.vue` (меню, шапка профілю, картки студентів, сторінка гри студента): `referrerpolicy="no-referrer"` + на `@error` — кружечок з ініціалом (прізвище → імʼя → нік → пошта) замість alt-тексту. Той самий кружечок — коли `picture` порожній.
- Тобто «завжди іконка або кружечок» — виконано; що саме падало — не встановлено, бо не відтворилось.

## Якщо повториться

- Відкрити DevTools → Network, фільтр `googleusercontent` — код відповіді скаже: 429 → причина 1 (тепер має зникнути), 404/403 → причина 2 (перевхід), «failed» без коду → мережа.
- Радикально «щоб ніколи»: **кешувати фото на сервері** — при вході скачувати `picture` у `data/avatars/<nick>.png` (або GridFS) і віддавати `/api/avatar/<nick>`; Google тоді не в ланцюжку взагалі. Розмір: S (один ендпоінт + скачування при `upsert_user`, ~40 рядків). Робити — коли підтвердиться, що фолбек не рятує, або перед деплоєм.

## Бекенд: нові імена і URL

- **Моделі**: каталожна `Game` → `BaseGame` (`models/base_game.py`, колекція `games` без змін) · `models/work.py` → `models/game.py`: `Game` (колекція `student_games`) + `Part` (`game_parts`) + `Claim` (поле `object` → `part`); живі колекції були порожні — жодних міграцій.
- **API за Q4a**: `/api/my/game` (+`/parts`, скриншоти) і `/api/my/claims` — власна гра (`my_game.py` / `my_parts.py` / `my_claims.py`); `/api/students` — тепер галерея для всіх активних (role-shaped: пошти/GitHub/tg і pending-користувачі — лише адміну) + паспорт `GET /{nick}/game` (`student_games.py`); адмінські get/put студента — по **nick** (частина пошти до `@`; `User.nick` + `User.by_nick()`).
- **Кошик**: `uploads.drop_shot` переносить файл у `uploads.trash/<game>/` (сусідня тека — поза StaticFiles-роздачею, git-ignored) замість unlink; каскадні видалення заявок тепер теж через `record_delete` — **в Mongo і на диску не зникає ніщо**.

## Фронт (нові сторінки)

- **`/my/game`** — редактор: створення/правка гри (`MyGameForm`, основа з каталогу або своя); вікна картками (`WindowCard`: тип з монеткою, ✏️ назви/опису, двоклікове видалення, скриншоти `ShotStrip`, чіпи заявок `ClaimRow` з нотаткою/лінком, автокомпліт заявок `ClaimPicker`, 💡-підказки пар елемент→функція з `PAIRS` у catalog.js); меню (`MenuCard`: вікно-хост, пункти «назва → вікно | картка + нотатка», datalist карток); заявки рівня гри.
- **`/students`** — галерея карток (аватар, група, обкладинка гри, лічильники) для всіх активних; адмін — перемикач «Картки/Таблиця» (стара таблиця з імпортом ЦІСТ; клік → `/students/<nick>/edit`).
- **`/students/<nick>`** — паспорт гри: шапка (гра, основа-лінк, автор, лічильники), опис-markdown, вікна зі скриншотами і чіпами, меню з пунктами-стрілками, заявки рівня гри; для власника — лінк на редактор.
- NavBar: «Студенти» і «Моя гра» для всіх активних; `GameForm.vue` → `BaseGameForm.vue`.

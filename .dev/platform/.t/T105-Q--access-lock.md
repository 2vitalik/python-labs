# T105 · Питання по тимчасовому замку сторінок

`2026-09-19` · ❓ question · запит Vitalik у чаті: «всі сторінки й меню невидимі для всіх; студентам поки лише Профіль»

Зроблено на фронті одним джерелом правди: у `router.js` кожен маршрут має `meta.access` (`'admin'` · `'active'` = студент або адмін · нема = публічний), guard роутера відкидає чужих на `/`, а меню в `NavBar.vue` будується з тих самих `meta` — сторінка і її пункт відкриваються разом. Зараз: `/` — публічна, `/profile` — `active`, решта (ігри, завдання, студенти, знахідки, моя гра, кольори) — `admin`. Гостьовий перегляд каталогів `/games`+`/tasks` (ітерація 2026-08-06) тим самим теж закритий. Відкрити сторінку студентам = поміняти одне слово в `router.js`.

**Q1 — API для студентів.** Замок лише в UI: бекенд відповідає як раніше — студенту `/api/students…`, `/api/my/game…`, `/api/refs`, гостю `/api/games` і `/api/tasks` (лише active). Допитливий студент може смикнути API напряму. Лишаємо?
- a) так, поки лише UI — рекомендую: секретів там нема, смоук 70/70 навмисно ганяє студентські сценарії, відкривати сторінки назад — без бекенд-правок;
- b) замкнути й API: один рядок у `main.py` — `include_router(…, dependencies=[Depends(admin_user)])` для замкнених роутерів, смоук перевести на адміна.

Мета: механізм опису гри, яким студенти користуються з завтрашньої пари — логічний, компактний, достатній для розмаїття корпусу; викладачу зручно перевіряти.

## Кроки

- [ ] **Словники** — один модуль `models/vocab.py`: ролі (5 → 20, групами), тригери (2 → ~30), умови (0 → ~30, включно з предикатами пазлів), ефекти (15 → ~55, групами), аргументи з типами (`entity · window · int · text · bool · choice`), шаблони речень; `GET /api/vocab`; бот рендерить речення тим самим кодом.
- [ ] **Модель** — `Part kind=field` (одне на гру; `props`: розмір, сітка, тор, вид, гравітація, час, керування, шари), `Part.stats` (характеристики сутності: HP, життя, швидкість…), `Part.states` (стани сутності — переходи правилами `set_state`), `Game.phases` (порядок тіку), `Rule.cond` — список умов з `not`, посилання на сторони тригера `@a/@b`, «будь-хто» `*`; `Claim.part` можна перепризначити (пул чернеток), `Claim.status` зараховано/повернуто + `verdict` (лише адмін); `Task.aliases` (синоніми) у `data/catalog/aliases.yaml`.
- [ ] **Каталог** — типи вікон +19 і сімʼя `undo-redo` активними, підзони `game-logic/history` і `game-logic/program`, решта ~90 карток з `analysis/03-cards-draft.yaml` чернетками на ревізію; синоніми для всіх карток (Opus-агент).
- [ ] **Редактор `/my/game`** — відкритий студентам; секції зі змістом збоку: Поле · Сутності · Правила · Вікна й меню · Гра загалом · Чернетки; одна пошукова «＋ Додати…» з синонімами (картки, ролі, типи вікон, правило); компактні картки сутностей з параметрами, станами, механіками й правилами; правило з «ЯКЩО»; меню всередині вікна; пул непривʼязаних заявок з «→ привʼязати»; підказки «чого бракує».
- [ ] **Каталог `/tasks`** — «＋ у гру» на картці (з параметрами, якщо є обовʼязкові), ✓ на вже заявлених.
- [ ] **Паспорт `/students/<нік>`** — ті самі компоненти в read-only, усім, хто бачить студента; адміну — ✅/↩ на заявках з вердиктом; підсумок «заявлено · зараховано».
- [ ] **Еталони (Д4)** — `data/catalog/templates/<основа>.yaml` для 17 базових ігор із корпусу (Opus-агенти за спекою словників) + `POST /api/my/game/template` «Почати з еталона».
- [ ] **Перевірка** — `smoke_games` розширити (поле, параметри, умови, перепризначення, статус заявки, еталон), `npm run build`, клік-прохід у Chrome на 5030 дев-входом.
- [ ] **Доки** — P-тікет концепції v2, Q-тікет виборів, C-тікет про GitHub-лінки/ШІ/оцінювання; README games/tasks/reports/platform, `app/README.md`, CHANGELOG, STATUS, памʼять.

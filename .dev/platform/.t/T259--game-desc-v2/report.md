## Зроблено

### Мова опису — `app/api/models/vocab.py` (одне джерело для API, форм і бота)
- Ролі: 5 → **20** (гравець · союзник · ворог · бос · нейтрал · обʼєкт · предмет · снаряд · контейнер · ресурс · стіна · підлога · пастка · двері · кнопка · генератор · зона · фігура · плитка · розмітка), групами для селекта.
- Тригери: 2 → **37** (контакт · стає на клітину · поруч · бачить · вперся · ввід · таймер · тік · розклад · ймовірність · фаза · лічильник · HP = 0 · стан увімкнувся/вимкнувся · зникли всі · усі на цілях · нема ходів · шаблон · поле осіло · старт/кінець рівня · хвилі · зʼявився/загинув/підібрав/знищено · обмеження пазла · інше).
- Умови (було 0): **35**, включно з предикатами пазлів (`unique · sum · no_adjacent · no_2x2 · region_size · single_loop · cover_all · run_lengths`), кожна із запереченням «не»; кілька умов — через «і».
- Ефекти: 15 → **67** групами (поява і зникнення · рух · стан і числа · інвентар · клітини й поле · хід гри · інше), з `undo`, `unmark`, `explode(shape, into)`, `set_state(dur)`.
- Аргументи типізовані (`entity · window · int · text · bool · choice:<список>`); сутність у правилі — сутність гри, `*` (будь-хто), `@a`/`@b`/`@both` (сторони тригера). Шаблони речень `tpl` з необовʼязковими `[…]`; `vocab.sentence()` рендерить для бота те саме, що бачить сайт.
- Поле: 8 властивостей (`size · topology · wrap · view · gravity · time · control · layers`); параметри сутності — підказки 13 типових (HP, життя, швидкість, шкода, броня…), будь-яке своє слово теж.
- `GET /api/vocab` — фронт будує з нього всі селекти (`WordPick`, `ArgFields`) і рендерить речення (`rules.js`).

### Модель і API
- `Part kind=field` (одне на гру, `props` за `FIELD`, 409 на друге), `Part.stats` (`{key,label,value,unit}`), `Part.states` (≤ 12), `Game.phases` (≤ 12), `Rule.cond` — список (валідатор приймає старий `{}`), `Rule.refs()` для каскаду по всіх аргументах.
- `routes/my_rules.py` — одна генерична перевірка `clean_item()` за специфікаціями аргументів: невідоме слово, чужа сутність, брак обовʼязкового, не число, не зі списку, `@a` без такої сторони — усе 422 людською мовою.
- `routes/my_claims.py` — `part` можна перепризначити (пул чернеток → сутність/вікно → інша), дубль після переносу → 409; параметри **обовʼязкові лише на привʼязаній заявці** (`loose` на рівні гри — щоб «＋ у гру» з каталогу не змушував заповнювати все одразу; підказка про порожні параметри є в редакторі).
- `Claim.status` (`claimed · accepted · returned`) + `verdict`: `PUT /api/students/{nick}/claims/{id}` — лише адмін; алерт студентові `game_alerts.verdict`; галерея/таблиця несуть `accepted`, `coins_accepted`, `field`.
- `Task.aliases` — синоніми у `data/catalog/aliases.yaml` (окремий файл, щоб `tasks.yaml` лишався читабельним; export/import/snapshot знають про нього).
- Еталони (Д4): `data/catalog/templates/<основа>.yaml` для **всіх 17** базових ігор (4 Opus-агенти за [README](../../../../data/catalog/templates/README.md) і валідатором `validate.py`), `POST /api/my/game/template` (`app/api/templates.py`): поле + сутності зі статами/станами/картками + вікна з меню + правила + заявки; збіг назв = не дублювати, повторний імпорт нічого не додає; `GET /api/templates` — лічильники для кнопки.
- Бот: речення правил через `vocab.sentence` (назви в «»), алерт вердикту, фази в картці гри.

### Редактор `/my/game` (студентам) і паспорт `/students/<нік>` — один компонент `GameEditor.vue`
- Шапка-форма згортається в одну картку: основа (змінити), назва, опис, **порядок тіку** (фази чипами).
- Рядок лічильників + монетки заявлено/зараховано; **«＋ Додати…»** (`AddBar`) — одне поле на все: картки за назвою/синонімами, ролі («ворог» → нова сутність), типи вікон («пауза»), параметри («броня» → на картку сутності), слова «поле»/«правило» → форми; другий крок — «куди?» чипами (гра загалом/чернетки · сутності · вікна) і параметри картки.
- **«Почати з еталона»** — коли гра порожня й у основи є еталон: кнопка з лічильниками, після імпорту — викреслювати й додавати своє.
- Підказки «чого бракує» (`hints.js`, ≤ 5): нема поля, нема гравця, сутність без механік, нема перемоги/поразки, нема ігрового екрана, вікно без скриншота, ⭐ без лінка, картка без параметрів, чернетки без господаря, порожній опис — клік веде до місця.
- Секції зі змістом збоку: 📥 Чернетки (лише коли є) · 🗺️ Поле (чипи властивостей, картки про поле) · 👾 Сутності (масонрі-колонки без пустот: роль, параметри, стани, скриншот, механіки-чіпи, «＋ механіка», правила про неї, ≤ 4 + «ще N») · 📜 Правила (групами за тригером; рядок КОЛИ → ЯКЩО → ТО; редактор — `WordPick` з пошуком і групами + `ArgFields` за типами: селекти сутностей/вікон, числа, списки, тексти з підказками станів/лічильників/фаз) · 🪟 Вікна й меню (тип, скриншот, елементи, **меню всередині вікна** — пункти → вікно/картка/текст; граф переходів, якщо вікон ≥ 2) · 🎮 Гра загалом (заявки за зонами з кольором зони).
- Чіп заявки (`ClaimChip`): колір зони, параметри текстом або ⚙️? коли порожні, 🔗 💬 ✓ ↩; клік — параметри, нотатка, лінк, **селект «до чого привʼязано»**, прибрати; у викладача на чужому паспорті — вердикт: заявлено / ✅ зараховано / ↩ повернуто + слово студентові.
- Каталог `/tasks`: «＋ у мою гру» на картці (параметри спершу, якщо обовʼязкові), ✓ на вже заявлених (веде в «Мою гру»); синоніми показані на картці (🔎) і підсвічуються пошуком.
- Галерея «Ігри студентів»: лічильники опису видно всім; адміну — ✓ зараховано.
- Прибрано: `MyGameParts`, `MenuCard`, `ClaimRow`, `ClaimPicker`; `TagInput` ядра отримав `placeholder`.

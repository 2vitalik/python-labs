# T23 · Журнал викладача

`2026-07-17` · 🔆 clarification

Контекст:
- брейндамп [T01](../../.rounds/.t/T01-R--braindump-readback.md), секція «Журнал викладача (таблички)»;
- це «кабіна пілота»: зведення даних з усіх інших вузлів в одному місці.

## Що з старих табличок стає автоматичним

- «Що студент зробив» — похідне від зарахованих завдань ([reports](../../reports/)).
- Формули оцінки — рахує система за правилами [grading](../../grading/), живий перерахунок.
- Дедлайни виконав/ні — з дедлайн-зрізів git ([github](../../github/)) і дат зарахування.
- Захисти й зауваження — з [defense](../../defense/) і [remarks](../../remarks/).
- Тобто ~80% старого ручного веденння зникає; журнал — це **подання**, а не ще одна таблиця для заповнення.

## Що лишається ручним вводом

- Відвідування (якщо вирішимо його враховувати — [T08](../../grading/.t/T08-Q--grading-open-questions.md) Q5).
- «Яку оцінку хоче студент» — цікаве поле зі старої системи: студент сам заявляє ціль → система показує розрив «хочеш 90, маєш 68, бракує: …». Пропоную зберегти — це сильний мотиваційний механізм і фільтр очікувань.
- Разові бонуси/корективи з коментарем (rare, але клапан потрібен).

## Екрани (начерк)

- **Потік/група:** таблиця студентів × прогрес (бали, монетки по типах, остання активність, незакриті зауваження, наступний захист). Сортування «кому потрібна увага».
- **Студент:** повний профіль — прогрес, історія захистів, зауваження, git-активність, опитування.
- **Семестр:** дедлайни, розклад слотів, статистика по завданнях (для рекалібрації цін — [T05](../../tasks/.t/T05-C--task-catalog-concept.md)).
- **Експорт відомості:** бали → формат кафедри (CSV/XLSX) в один клік наприкінці семестру.

## Про що ти, схоже, ще не думав

- **Мультисеместровість з першого дня:** сутності «курс → семестр → група → студент» в моделі даних одразу, інакше друга осінь системи перетвориться на міграційний біль. Архів минулих семестрів = твоя статистика для калібрування.
- **«Кому потрібна увага»:** система сама підсвічує студентів без активності N тижнів, із заваленим дедлайном, із застряглими зауваженнями — замість твого ручного сканування табличок очима.

## Головне рішення

Форми картки більше нема. Картка завжди та сама картка. Олівець вмикає на ній **інструменти** — те, що в спокої показувати нема сенсу:

- порожнє стає видимим: «＋ параметр», «＋ стани», «＋ нотатка», «＋ од.», властивості «не вказано» / «як у поля»;
- біля кожного рядка, який можна прибрати, — мінус;
- клік по тому, що в спокої веде кудись, тепер це змінює (куди веде перехід);
- усе, що змінюється кліком, світиться блідим тлом — не треба шукати мишкою.

Вимкнув олівець (або Esc) — зайве зникло, картка як була. Зберігається все одразу, як і значення на місці ([T306](../../platform/.t/T306--inline-edit/plan.md)): режим нічого не «тримає», тож рамки «збережи або закрий» у нього нема — лише підсвічений олівець і помаранчевий край картки.

## Десять питань брифу

1. **Прибрати режим форми зовсім.** Так — для сутності, вікна, рівня, поля, переходів. Огляд «усе, що можна правити» (T284) дає сам режим інструментів: він показує більше, ніж форма, і на тому самому місці. Лишились з власними «Зберегти / Скасувати» дві речі, бо це не одне значення, а багато дій поспіль: мапа рівня (малюнок) і правило (п. 3).
2. **Нове — карткою-чернеткою.** Один рядок у вигляді заголовка майбутньої картки: значок, назва, тип. Enter — картка зʼявляється на своєму місці вже з увімкненими інструментами, решта дописується на ній. Без типу сутність не зберігається: Enter відкриває список типів, вибір — зберігає. Вікно — як було: спершу тип, його назва стає назвою вікна. Порожня чернетка просто закривається (Esc або «✕»).
3. **Правила.** Форма правила лишається: речення зі словника з аргументами — це структура, а її форма вже стоїть на місці речення й має ту саму сітку КОЛИ / ЯКЩО / ТО. Наступний крок, якщо захочеш: клік по шматку речення відкриває ту саму форму з курсором на цьому шматку (S).
4. **Конфлікти кліків — одне правило.** У спокої клік робить те, що й у читача: посилання веде, рядок картки відкриває панель, згорнута картка розгортається. Текстове значення завжди відкривається кліком. Усе, де клік уже зайнятий, змінюється з увімкненим олівцем. Картка під мишкою з увімкненим олівцем не спливає над рядками параметрів — вона закривала б «＋ параметр».
5. **Телефон.** Наведення нема — тому олівець і є відповіддю на «що тут можна змінити»: він підсвічує кожне редаговане значення. Дотик відкриває поле, як і раніше; вибір — шторкою знизу.
6. **«Скасувати» після збереження.** Так: унизу сторінки на кілька секунд — «Змінено: опис · Повернути». Повертає лише змінене поле (не всю картку), через те саме збереження — в історії гри видно обидва кроки. Завдяки цьому мінус рядка не питає «точно?».
7. **Одне правило для сторінки.** Назва гри тепер одна — у великому заголовку, змінюється кліком і зберігається одразу. Поле назви під нею прибрано (це був дубль). Опис гри — як і був: довгий Markdown, «Зберегти / Скасувати» під полем.
8. **Одночасні правки.** Не чіпав: потрібен бекенд (часткове оновлення `PATCH`) і деплой з перезапуском. Ризик малий — викладач і студент рідко правлять ту саму картку в ту саму хвилину. Рекомендація — зробити разом з найближчою зміною бекенда (S); див. [T312](T312-Q--inline-tools-choices.md) Q7.
9. **Клавіатура.** Tab ходить по значеннях, Enter зберігає. Додано лише одне: у новому рядку переходів Enter зберігає рядок і ставить під ним наступний порожній — меню з пʼяти пунктів набирається без мишки. Стрілки не робив.
10. **Порожні необовʼязкові значення.** Їх показує олівець. У спокої картку нічим не захаращено; винятки лишились ті самі — червоне «бракує» опису й скриншота та тихе «＋ опис».

## Що з таблиці «досі лише формою» (T308)

| Що | Тепер |
|---|---|
| Новий параметр сутності чи рівня | олівець → «＋ параметр»: список каталогу з пошуком або «свій»; рядок стає з відкритим значенням і зберігається, щойно воно є |
| Одиниця свого параметра | клік по одиниці; нема — олівець → «＋ од.» |
| Назва свого параметра | клік по назві |
| Прибрати параметр | олівець → мінус біля рядка |
| Стани, коли їх нема | олівець → «＋ стани» |
| Незаповнені властивості поля й рівня | олівець → «не вказано» / «як у поля», клік — вибір |
| Куди веде перехід | олівець → клік по цілі |
| Новий пункт переходів | «＋» біля підпису або олівець → «＋ перехід або дія» |
| Нотатка переходу, коли її нема | олівець → «＋ нотатка» |
| Звідки й скільки рівня, коли їх нема | олівець → «звідки береться?», «скільки?» |
| Мапа рівня | олівець → «змінити мапу» / «＋ намалювати рівень»: редактор на місці картинки, у своїй рамці |
| Нова сутність, вікно, рівень | картка-чернетка: назва й тип |
| Назва гри | клік по великому заголовку |
| Правило: КОЛИ / ЯКЩО / ТО; нотатка правила, коли її нема | форма правила, як було |
| Параметри заявки, доказ, перенести | панель заявки, як було |
| «Про гру» гри-основи | сторінка редагування, як було |

## Анімація

- Блок, що зʼявляється (параметри, стани, пояснення, «＋ перехід»), розкривається вниз і проявляється за 0,2 с — те, що під ним, зʼїжджає, а не стрибає.
- Дрібне (мінус, «＋ од.») виростає з точки.
- Рядки властивостей, що зсуваються, пересуваються плавно.
- У кого в системі вимкнено анімації (`prefers-reduced-motion`) — без руху.

## Q1. Опис гри: показ і клік

Показ — Markdown, як у інших. Клік — джерело на місці, курсор там, де клацнув. Без змін — назад до показу. Зі змінами — поле чекає «Зберегти / Скасувати».

- **a** — так.
- b — ще й кнопка «👁 як бачать інші» поряд з полем, поки воно відкрите (показ без закриття поля).
- c — так само й назва гри: показ великим шрифтом, клік — поле (зараз назва — поле завжди, що вже виглядає як текст).

## Q2. Значок параметрів

Дві смужки, заповнені до значення («здоровʼя / мана»).

- **a** — так.
- b — табличка «12» у рамці (число).
- c — інший — скажи, на що має бути схожий.

## Q3. Групи правил разом

Кнопка на заголовку «Правил» поряд із «＋ правило» — усі групи згорнути чи розгорнути. ⌥-клік чи утримання заголовка групи — те саме. Стан памʼятається в браузері.

- **a** — так.
- b — ще й рядок угорі сторінки, в рамці «Вигляд» («Групи правил: розгорнуті — у всіх»), як для карток.
- c — групи не памʼятати: після перезавантаження завжди розгорнуті.

Формат робіт студентів: ігри на клітинному полі за мотивами класики. Сусіди: завдання-цеглинки — [tasks](../tasks/README.md), ціни — [grading](../grading/README.md).

## Матеріали

- Девʼять ігор-прикладів зі старого Notion — `data/v2/notion/games/` (Maze, Boulder Dash, New Ball Game, Lode Runner, Battle City, Mined-Out, Inertia, Bomberman, Pac-Man): задум, елементи, покрокові ігрові моменти.
- Ресерч-каталог ~40 зовнішніх grid-ігор у 7 сімʼях (штовхання, копання, аркади, тактики, thinky, курсорні, автомати) з лінками й ідеями механік · [T32](.t/T32-C--grid-games-catalog.md); шортліст кандидатів у приклади: Sokoban, Snake, Minesweeper, 2048, PvZ-лайт, Frogger.
- Пропозиція spec-моделі: гра = сума фрагментів обраних тасків, спека генерується системою (чек-ліст захисту, порівняння варіантів) · [T34](.t/T34-P--game-spec-model.md).

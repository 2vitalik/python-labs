# games — ігрові концепти: клітинне поле, каталог ігор, варіанти

Формат робіт студентів: ігри на клітинному полі за мотивами класики. Сусіди: завдання-цеглинки — [tasks](../tasks/README.md), ціни — [grading](../grading/README.md).

**Дальня мета вузла — лудопедія** (мрія Vitalik, 2026-08-17): єдина мова опису ігрового розмаїття світу без синтаксису — словник (картки) + морфологія (сутності+слоти) + граматика (речення КОЛИ→ЯКЩО→ТО) + корпус (приклади з реальних ігор, осі варіацій); той самий апарат описує і референсні ігри з YouTube, і роботи студентів · [T98](.t/T98-B--ludopedia.md).

## Матеріали

- Девʼять ігор-прикладів зі старого Notion — `data/v2/notion/games/` (Maze, Boulder Dash, New Ball Game, Lode Runner, Battle City, Mined-Out, Inertia, Bomberman, Pac-Man): задум, елементи, покрокові ігрові моменти.
- Ресерч-каталог ~40 зовнішніх grid-ігор у 7 сімʼях (штовхання, копання, аркади, тактики, thinky, курсорні, автомати) з лінками й ідеями механік · [T32](.t/T32-C--grid-games-catalog.md); шортліст кандидатів у приклади: Sokoban, Snake, Minesweeper, 2048, PvZ-лайт, Frogger.
- Пропозиція spec-моделі: гра = сума фрагментів обраних тасків, спека генерується системою (чек-ліст захисту, порівняння варіантів) · [T34](.t/T34-P--game-spec-model.md).
- База знань — **`data/wiki/games/`** (створено 2026-08-03): 17 чернеток ігор — девʼятка (зведена зі старого Notion) + шортліст T32 (Sokoban, Snake, Minesweeper, 2048, PvZ-лайт, Frogger) + парасолі нових класів (chess, paper-puzzles); карта класів — `data/wiki/games/_classes.md`.

## Класи ігор (прийнято) · [T49](.t/T49-B--game-classes.md), рішення [T54](../.rounds/.t/T54-R--kb-round-decisions.md)

- Перша вісь опису гри — клас за актором: **аватарні · курсорні · фігурні · пазли-розмітки**; усі чотири — **рівноправні напрями робіт** одразу (T53 Q1a).
- Решта осей: поле (квадрат/гекс/граф/вільне) · час (покрокове/real-time/статичне) · суперник (нема/AI/hot-seat) · інформація · випадковість · мета.
- Фігурні: база — hot-seat на двох + правила ходів/перемоги; AI-суперник — золоте завдання зверху (T53 Q2a).
- Пазли-розмітки: робота студента — плеєр пазлів (поле, ввід, перевірка, банк рівнів); генератор і розвʼязувач — золото (T53 Q3a).
- Нестандартні поля (гекс, вільні координати, графи) — тег-модифікатор «для сміливих», не окрема гілка (T53 Q4a).

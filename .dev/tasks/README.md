## Пропозиція таксономії (чекає рішення) · [T33](.t/T33-B--task-taxonomy.md)

- Аналіз 7 років категорій v3: чисте дерево не виживало (маятник «за елементом» ↔ «за аспектом», мультизначення комами у 2020) — таск багатовимірний.
- Пропоную фасети: один дім (6 зон × ~5 підзон: Сутності, Логіка гри, Рівні, Інтерфейс, Код, Супровід) + виміри тегами (сутності, механіки, ігри, `algo`); «Алгоритми» — тег, не гілка.
- Сімʼї-таски (картка з варіантами) стискають ~2130 рядків v3 у ~300–400 канонічних карток; спадщина дає стартові ціни (медіана по роках).
- Звʼязка зі spec-моделлю гри: кожен таск несе фрагмент спеки — [T34](../games/.t/T34-P--game-spec-model.md).
- Розширення 2026-08-02: зони узагальнюються на нові класи ігор (фігурні, пазли-розмітки — [T49](../games/.t/T49-B--game-classes.md)) — одна таксономія на всі класи, клас = ще один тег; нові підзони-кандидати (легальність ходу, суперник, перевірка обмежень) · [T50](.t/T50-B--kb-task-groups.md).
- База знань — **`data/wiki/tasks/`** (створено 2026-08-03, рішення [T54](../.rounds/.t/T54-R--kb-round-decisions.md)): 6 зон-файлів з курованим ядром (~150 пунктів) + карта зон `_map.md` + staging `_v3-raw.md` — вся v3-сировина (2019 унікальних назв) розкладена по зонах для поступового зведення.

## Рішення по v3-конвертації · [T28](.t/T28-Q--v3-csv-questions.md)

- Props обʼєднуються у файл року (`pzpi-21.csv` = tasks + props), розрізняє колонка `source`.
- Чотири зайві колонки викидаються: 20 `Баллы` (дубль), 20 `Title` (похідний декор), 21/23p `Add`, 23p `✔️`.
- Notion: проміжні групи-заголовки всередині категорій → колонка `subcategory` (Vitalik окремо підкреслив: підкатегорії-групування тасок врахувати обовʼязково).
- Notion: вступні описи категорій у CSV не переносяться — md лишається їх джерелом.

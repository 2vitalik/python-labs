## Рішення по v3-конвертації · [T28](.t/T28-Q--v3-csv-questions.md)

- Props обʼєднуються у файл року (`pzpi-21.csv` = tasks + props), розрізняє колонка `source`.
- Чотири зайві колонки викидаються: 20 `Баллы` (дубль), 20 `Title` (похідний декор), 21/23p `Add`, 23p `✔️`.
- Notion: проміжні групи-заголовки всередині категорій → колонка `subcategory` (Vitalik окремо підкреслив: підкатегорії-групування тасок врахувати обовʼязково).
- Notion: вступні описи категорій у CSV не переносяться — md лишається їх джерелом.

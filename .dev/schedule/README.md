# schedule — розклад потоку: час для спільних пар, тиждень студента

Коли збирати потік на пари поза основним розкладом: студенти позначають типовий тиждень (не можу · незручно · зручно), викладач бачить зведення й шукає вікно для всіх. Сусіди: алерти й опитування — [tgbot](../tgbot/README.md), студенти й профіль — [platform](../platform/README.md), захисти зі своїми слотами — [defense](../defense/README.md).

## Задача

- ~100 студентів у 6 групах (ПЗПІ-25-1…6), потрібен один регулярний час на тиждень для спільної пари потоку; Google-форми й Telegram-опитування не підходять → сторінка на сайті (Vitalik, 2026-10-01).
- Регулярний тиждень Пн–Сб 15:00–23:00; разові обмеження конкретних днів — не тут.

## Вирішено / запропоновано

- **Пропозиція v1** — [T177](.t/T177-P--week-design.md): сітка Пн–Сб × 15:00–23:00 по 15 хв; порожнє = можу; 🔴 не можу з обовʼязковою причиною (чипи 🏋️ 💼 📚 🏫 🚌 👨‍👩‍👧 + текст), 🟡 незручно, 🟢 найзручніше; малювання прямокутником, той самий інструмент стирає, на телефоні — потримати й вести; автозбереження + «Готово»; сховище — блоки в колекції `weeks`, рамка з конфігу (`WEEK_HOURS`, `WEEK_DAYS`); зведення `/week`: прогрес заповнення з «хто ще не заповнив», теплова карта шарами, пошук вікна за тривалістю, «хто саме» з причинами й `@tg`, тиждень викладача як виняток, «два вікна» за бажанням; алерт 🗓 на «Готово»; усе в ядрі, python реєструє маршрути й пункт меню «Тиждень».

## Рамки

- **Сховище**: `data/guide/<slug>.md`, віддає `GET /api/guide` (список без тіл) і `GET /api/guide/{slug}` → `{slug, title, brief, body, updated}`; кеш по mtime; `updated` = дата файлу. Контракт лишається для майбутнього редактора (T115 §4 в.3).
- **Маршрути**: `/labs`, `/labs/:n`, `/score` (ex `/grading`), `/howto`, `/guide` (уся методичка однією сторінкою — Ctrl+F і друк). `/games` і `/tasks` — публічні: текст розділу всім, каталог лише адміну, іншим — заглушка «відкриється незабаром» (Q13). Slug = маршрут = імʼя файла; перейменування = файл + один рядок у `guide.js`.
- **Рендер**: свій екземпляр `marked` (`md.js`): `{#id}` у заголовку → `id` на `<hN>` + «🔗» копіювання лінка; у пункті — `<span id class="anchor">`; заголовок без `{#id}` — авто-id транслітерацією; `> 💡` → callout; таблиці — `table-responsive`; зовнішні лінки — нова вкладка. На сторінці «уся методичка» id отримують префікс slug (`#score-79`), щоб `#deadlines` з двох розділів не бились.
- **Якорі й підсвітка** (`anchors.js`): скролити після завантаження тексту (router `scrollBehavior` спрацьовує раніше, ніж прийде markdown — тому хеш обробляє сама сторінка) → відкрити батьківські `<details>` → спалах ~2.5 с на секції (заголовок + сусіди до наступного заголовка того ж/вищого рівня; для пункту — `li`); `prefers-reduced-motion` — без анімації. Внутрішні лінки в тексті — делегування кліку → `router.push`.
- **Домашня**: лід із `home.md` (витяг) + смужка для того, хто увійшов + розкривашки-витяги розділів у місці маркера `<!-- sections -->` + решта `home.md` («З чого почати») + «Що змінилось» (`changes.md`, теж розкривашка).
- **Сторінка розділу**: заголовок, текст, зміст `h2/h3` праворуч на `lg+` (від 3 пунктів), «Оновлено дата», для лаб — «← попередня · усі · наступна →».
- **Меню**: гість — Ігри · Завдання · Лабораторні · Оцінювання · Як здавати; далі ролеві пункти як були. Нижче `md` — тоглер на Vue (bootstrap-JS не підключений), бо студенти читають з телефона.
- **Тексти**: правки лише під рішення T116 (Q12 — захисти й чат; словник у «Як здавати»; `home.md` під нову домашню); решта — Vitalik сам.
- Поза рамками: деплой (T116 Q14), редактор (T115 §4), числа з констант, бот-команда `/guide`.

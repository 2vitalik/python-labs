## Як працює

- **API** `routes/guide.py`: `GET /api/guide` — список `{slug, title, brief, updated}` усіх `data/guide/*.md` (крім README); `GET /api/guide/{slug}` — ще й `body`. Файл ріжеться по першому рядку (`# Назва`) і `<!-- more -->`; `updated` — mtime файла; кеш по mtime, тож правка файла видна одразу без рестарту.
- **`guide.js`** — єдине місце зі списком розділів: `SECTIONS` (slug · шлях · пункт меню · `page: true` для тих, що рендерить `GuidePage`), `LABS`, `ALL` (порядок для `/guide`). Меню й маршрути будуються з нього.
- **`md.js`** — власний екземпляр `Marked`: перед парсом `{#id}` → `<span id class="anchor">`; у заголовку span переїздить в `id` самого `<hN>` і додається «🔗» (`href="#id"`); заголовок без `{#id}` → авто-id транслітерацією; цитата з емодзі → `blockquote.callout`; таблиці → `.table-responsive`; `https://` → нова вкладка; на `/guide` усі id і `#`-лінки з префіксом розділу (`#score-79`), бо `#deadlines`, `#defense`, `#required` повторюються.
- **`anchors.js`**: `flash(id)` — відкрити батьківські `<details>`, скрол до блока (`li` → сам пункт; заголовок → він + сусіди до наступного заголовка того ж/вищого рівня), клас `.flash` на 2.5 с (анімація фону; `prefers-reduced-motion` — без анімації); `guideClick` — делегування кліків у тексті: «🔗» → буфер + `router.replace({hash})`, `#x` → `router.push` + flash, `/…` → `router.push`.
- Хеш обробляє **сама сторінка** після завантаження тексту (`nextTick` → `flash`), бо `scrollBehavior` роутера спрацьовує до того, як прийде markdown; `scrollBehavior` лише повертає нагору при переході без хеша й відновлює позицію на «назад».
- **Сторінки**: `GuidePage` (`/labs`, `/labs/:n`, `/score`, `/howto`) — заголовок, текст, зміст `h2/h3` праворуч на `lg+` (від 2 пунктів), «Оновлено дд.мм.рррр», для лаб — «← попередня · Усі лаби · наступна →»; невідомий slug → «Такої сторінки нема». `GuideAllPage` (`/guide`) — усі розділи підряд, `@media print` ховає навбар і зміст. `HomePage` — лід (витяг `home.md`) + смужка «Привіт, … · роль · Профіль / Моя гра» + розкривашки `GuideBrief` (витяг + «Уся сторінка →») + «Що змінилось» (`changes.md`) + решта `home.md`; місце розкривашок — маркер `<!-- sections -->`. `GuideHead` на `/games` і `/tasks`: не-адміну — вся сторінка розділу + заглушка «каталог відкриється незабаром», адміну — згорнутий блок над каталогом.
- **Навбар**: гість бачить Ігри · Завдання · Лабораторні · Оцінювання · Як здавати; нижче `lg` (адміну — `xl`, бо 9 пунктів) — гамбургер на Vue-стані, без bootstrap-JS; імʼя користувача ховається нижче `xl`.

## Перевірка

- `npm run build` — чисто. API: `curl /api/guide` — 11 сторінок; `/api/guide/README`, `/api/guide/..%2Fwiki` → 404.
- Рендер (`node`, скрипт у scratchpad, живі тексти з API): id на `h2/h3`, «🔗», span у `li`, callout, таблиця в обгортці, внутрішні/зовнішні/`#`-лінки, префікси на `/guide`, авто-id, TOC, прихований коментар у `home.md` — **20/20**.
- Headless Chrome (`--dump-dom`, `--virtual-time-budget`): `/` — h1, 6 карток-розкривашок, «З чого почати» після них, лінк на `/guide`, меню гостя з `/score`, тоглер; `/score#79` — `h3#79` спалахнув (при 3 с бюджету клас уже знято — тобто таймер працює), зміст, «Оновлено 20.09.2026»; `/labs/2` — назва, ← Лаба 1 / Лаба 3 →, зміст; `/games` гостем — «🎮 Гра», заглушка, без «Нова гра»; `/guide#score-89` — `h3#score-89` спалахнув, секція `lab5`, `#score-deadlines`; `/howto#glossary` — заголовок і список спалахнули; `/labs/9` — «Такої сторінки нема»; `/` при 390 px — `navbar-expand-lg`, меню згорнуте. Скриншоти `/`, `/score`, `/games` — верстка як задумано (зміст праворуч, таблиця, картки).
- **Не перевірено вживу**: клік по розкривашці, «🔗» → буфер, гамбургер, плавний скрол, вигляд на телефоні (headless не дає вікна вужче ~500 px). Коли Chrome із розширенням буде під рукою — 5 хвилин клік-тесту.

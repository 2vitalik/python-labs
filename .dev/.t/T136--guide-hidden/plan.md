# T136 · Методичка закрита від студентів до завершення — план

`2026-09-25` · ⚙️ задача · запит Vitalik у чаті: «давай поки все ж таки всі сторінки методички заховаємо від студентів… я з нею ще не завершив, а незавершений варіант не хочу показувати. Але сайт показати вже треба, щоб вони зареєструвались на ньому та в телеграм-боті».

Контекст: методичка v1 публічна ([T117](../T117--guide-v1/report.md)), тексти в Mongo з редактором ([T128](../../platform/.t/T128--guide-editor-v1/report.md)); ще в [T116](../T116-Q--guide-questions.md) Q13 Vitalik: тимчасовий варіант показувати не хоче. Мета — сайт лишається відкритим для входу, профілю й привʼязки бота; будь-який текст методички (включно з домашньою) — лише адміну.

## Рамки

- API: усі `GET /api/guide*` — `admin_user`. SPA: маршрути методички — `access: 'admin'` одним прапорцем `hidden`, щоб відкрити назад однією правкою.
- Домашня: адміну — як була; гостю/студенту — статичні кроки реєстрації (вхід → профіль → бот) зі станом ✅/⬜ з `/api/me`.
- Меню — сховається саме (будується з доступу маршрутів). Бот — без змін (лінкує лише профіль і сайт).
- Поза рамками: деплой (T116 Q14), правки текстів методички.

## Кроки

1. `routes/guide.py` — `admin_user` на список і сторінку; смоук під новий доступ.
2. `router.js` — `hidden` на маршрути методички, `/games`, `/tasks`.
3. `HomePage.vue` — гілка адміна; новий `StartSteps.vue` — кроки реєстрації.
4. Перевірка: смоук, `npm run build`, headless Chrome гостем.
5. Доки: README (Стан, Наступний крок), platform README, CHANGELOG, STATUS.

# T183 · Заняття й транскрипти: вибори

`2026-10-02` · ❓ question

Контекст:
- дизайн — [T182](T182-P--lessons-design.md); пілот злиття — [T184](T184--transcript-pilot/plan.md); порівняння джерел — [T185](T185-C--transcript-sources.md);
- правила вже написані за варіантами «a» — [merge.md](../../../.claude/skills/lesson/merge.md), [summary.md](../../../.claude/skills/lesson/summary.md); інший вибір — правка одного-двох рядків там;
- Q14–Q15 — факти, без яких транскрипт заняття 1 не добити.

**Q1 — Рядок репліки.**
- a) один рядок: `**Віталій** · 15:01 — текст` (рекомендую — найкомпактніше на телефоні, парситься регуляркою, рендериться всюди однаково);
- b) імʼя й час окремим рядком, текст під ним — просторіше, але у звичайному Markdown рядки злипаються в один абзац без двох пробілів у кінці;
- c) пункт списку: `- **Віталій** (15:01): текст`.

> 

**Q2 — Час у транскрипті.**
- a) хвилина на кожній репліці + час у заголовку розділу (рекомендую — достатньо, щоб знайти момент у відео, і не рябить);
- b) лише в заголовках розділів;
- c) секунди на кожній репліці.

> 

**Q3 — Як називати тебе.**
- a) **Віталій** (рекомендую — так тебе звуть студенти, і транскрипт читається як розмова);
- b) **Викладач** — безособово, один формат на будь-який курс і викладача;
- c) **Віталій Ляпота**.

> 

**Q4 — Як називати студентів.**
- a) «Імʼя Прізвище» українською за реєстром сайту; невідомі — як у Zoom без транслітерації (рекомендую — Zoom-імена різні: латиниця, «Прізвище Імʼя»; реєстр це вирівнює);
- b) завжди як у Zoom;
- c) лише імʼя;
- d) усі — «Студент», без імен.

> 

**Q5 — Рівень чистки тексту.**
- a) читабельний: без заповнювачів і фальстартів, формулювання й порядок думок збережені (рекомендую — так зроблено пілот);
- b) майже дослівно, з паразитами — для розбору мовлення;
- c) літературна редактура — можна перефразовувати й стискати.

> 

**Q6 — Суржик і російські слова, які сказав сам мовець.**
- a) українським відповідником, крім цитат і термінів (рекомендую — транскрипт читають як навчальний текст);
- b) як сказано.

> 

**Q7 — Де працює модель.**
- a) зараз — локально через Claude Code (`/lesson` + `bin/lesson pull/push`, підписка); на сервер через API — коли правила устояться (рекомендую — нуль ризику з ключами й умовами, і видно результат до публікації);
- b) одразу сервер з API-ключем і фоновою задачею;
- c) лише локально — назавжди.

> 

**Q8 — Модель для злиття на сервері.**
- a) Opus 5.5 (рекомендую, якщо пілот T184 влаштовує: ≈ $1–2 за заняття);
- b) Sonnet 5.5 — удвічі дешевше; перевірити на занятті 2 поруч з Opus;
- c) обидві: Sonnet на чернетку, Opus на складні місця — зайва складність для такої ціни.

> 

**Q9 — Хто бачить транскрипти й конспекти.**
- a) підтверджені студенти курсу й адміни, після «Показати студентам» (рекомендую — як лекції ods);
- b) поки лише адмін — подивитись, як воно, перш ніж відкривати;
- c) усі, хто ввійшов із поштою NURE, без підтвердження.

> 

**Q10 — Конспект.**
- a) два кроки: автоматична чернетка одразу, потім контекст від тебе → перегенерація, або правка руками (рекомендую);
- b) лише автоматично;
- c) лише після твого контексту — нічого без нього.

> 

**Q11 — Бот.**
- a) після публікації — конспект у гілку групи: заголовок + «Коротко / Домовились / Зробити» в розгорнутій цитаті + кнопки «на сайті» · «відео» (рекомендую);
- b) лише рядок із посиланням;
- c) бот не причетний.

> 

**Q12 — Відео.**
- a) поле з посиланням (Google Drive · YouTube · Telegram) + час старту запису для «до відео» (рекомендую — без зберігання відео на сервері);
- b) кілька посилань на заняття (Zoom-хмара + Drive);
- c) відео на сайті не показуємо.

> 

**Q13 — Імена в транскрипті для тих, хто не хоче.**
- a) прапорець у профілі «не називати мене в транскриптах» → «Студент» (рекомендую — дешевий запобіжник, і є що сказати студентам);
- b) без цього — усі були на одній зустрічі;
- c) замість цього — транскрипт лише для викладача, студентам — конспект.

> 

**Q14 — Дата й назва заняття 1.** У файлах дати нема (скопійовано сьогодні), агентам заборонено вгадувати. Напиши дату (РРРР-ММ-ДД) і, якщо хочеш, назву замість придуманої.

> 

**Q15 — Для яких груп заняття 1** (ПЗПІ-…?) і чи є інші потоки з тими самими заняттями.

> 

**Q16 — Zoom-чат і Telegram-гілка як джерела.**
- a) так: Zoom зберігає `meeting_saved_chat.txt` — додавати як пʼяте джерело, репліки з позначкою «(чат)» (рекомендую);
- b) ні, лише голос.

> 

**Q17 — Назва пункту меню.**
- a) «Заняття» (рекомендую);
- b) «Записи»;
- c) «Пари».

> 

**Q18 — Твої стійкі звороти** («в принципі», «фактично», «знову ж таки», «і тому подібне», «і так далі»). У пілоті субагент лишив їх майже всі заради тону — від цього прямо залежить обсяг.
- a) не більше одного на репліку (рекомендую — тон лишається, текст коротшає на ~5 %; так записано в `merge.md`);
- b) лишати всі — максимально «як сказано»;
- c) прибирати всі — як заповнювачі.

# lessons — заняття: записи, транскрипти, конспекти

Кожна зустріч зі студентами (ПЗ, лаба, лекція, консультація) стає записом на сайті: кілька машинних транскриптів різних сервісів зводяться в один вивірений транскрипт і конспект, поруч — відео, файли, чат. Для всіх курсів однаково — живе в ядрі. Сусіди: [platform](../platform/README.md) — ядро, методичка й редактор, на які це спирається; [tgbot](../tgbot/README.md) — куди бот шле конспект; [ods](../ods/README.md) — перший курс із записами.

## Задача

- На заняттях увімкнені кілька сервісів транскрибування: Zoom (імена й годинник), Whisper, Tana, Plaud; набір щоразу може відрізнятися — щось забулось чи не спрацювало, щось додалось (Vitalik, 2026-10-02).
- Чим більше джерел — тим певніше, що саме було сказано; результат — один надійний Markdown: хто, приблизно коли, що сказав; читається з телефона, копіюється куди завгодно, сайт показує красиво.
- Заняття на сайті для студентів: перелік, конспект, транскрипт, відео, файли, чат; конспект — з контекстом від викладача; бот — конспект у чат зі згортанням; обробка — поки локально через Claude Code, агент завантажує результат на сайт через API (Vitalik, 2026-10-14).
- Обробка — на Opus: Fable щоразу задорого.

## Як є: етап 1 у коді · [T218](.t/T218--lessons-v1/report.md)

- **Заняття** — `Lesson` у ядрі: `slug` = вид + номер (`pz1` ПЗ · `lab2` Лаба · `lec3` Лекція · `cons1` Консультація · `x1` Зустріч), нумерація своя в кожному виді, slug — адреса `/lessons/pz1` і тека на диску; дата (порожня = невідома, не вгадується), час «18:35–20:10», назва, групи, посилання (іконка за хостом: 🎬 YouTube/Zoom · 📁 Google · ✈️ Telegram · 🔗), старт запису для «до відео» (працює лише з YouTube `?t=`), контекст, транскрипт, конспект, нотатки злиття, чат Zoom, `published`, `rev` · [T219](.t/T219-P--lessons-brief-v2.md).
- **Файли** — `LessonFile`, байти в Mongo (нічого на диску сервера, нічого в git): `source` — сирі транскрипти (`zoom.txt`, `plaud.txt`, `chat.txt`…), бачать викладач і агент; `file` — «з чим працювали», бачать читачі; ліміт 15 МБ; те саме імʼя в тій самій ролі замінюється. `chat.txt` серед джерел = і текст `lesson.chat` для блоку «💬 Чат Zoom».
- **Мовці → студенти** (`lesson_people.py`): псевдоніми `User.aliases` («Імена в Zoom» в адмінській картці студента) або ПІБ у двох порядках; викладач — за імʼям. Збіг — аватарка й посилання на `/students/<nick>` для всіх читачів; невідомих викладач привʼязує на сторінці заняття («хто це?»), псевдонім лишається в профілі й іде в `roster` для злиття.
- **API** `/api/lessons` (ядро): `GET` список і заняття — `active`, чернетки лише адміну й агенту (студентові 404); `POST`/`PUT`(`rev` → 409, `note` → `history`)/`DELETE` — адмін + агент, видалення — лише адмін; `…/files` (завантажити multipart з `role`, скачати, прибрати); `…/alias`; `…/bundle` — усе для локальної обробки.
- **Сторінки** (ядро, обидва сайти, пункт меню «Заняття»): `/lessons` — від нових до старих, чипи видів, бейджі 📝 🗣 🎬 📎, чернетки сірі; `/lessons/<slug>` — шапка, конспект (без свого H1, «Теми» → розділи транскрипта), згорнутий транскрипт як чат (розділи з часом і змістом справа, аватарки, викладач синім, підряд одного мовця — імʼя раз), чат Zoom, викладачу — нотатки, картка «Джерела й мовці» з командами, інлайн-редактори конспекту й транскрипта (той самий, що в методички), «показати студентам»; `/lessons/new`, `/lessons/<slug>/edit` — форма (вид і номер — лише при створенні).
- **Локальний цикл** — `bin/lesson` ([T153](../platform/.t/T153--agent-guide-access/report.md)-токен, тека `data/transcripts/<slug>/`, для іншого сайту `LESSONS_DIR`): `new` → `pull` (`meta.yml` з `roster`, `raw/`, тексти) → `/lesson merge`, `/lesson summary` → `push -m "…"` (тексти, `meta.yml`, нові сирі) → перегляд → `publish`; `attach` — файли студентам; `.taken` береже `rev`. Опис — у [SKILL.md](../../.claude/skills/lesson/SKILL.md) §«Сайт».
- **Приватність**: `data/transcripts/` і `sites/ods/transcripts/` в `.gitignore`; читають підтверджені студенти після публікації; прапорець «не називати мене» — досі питання T183 Q13.

## Вирішено раніше (T182, чинне)

- **Формат транскрипта** — Markdown із жорсткою граматикою рядків · [T182](.t/T182-P--lessons-design.md), повний опис — [merge.md](../../.claude/skills/lesson/merge.md): фронтматер · `# заголовок` · розділи `## Назва · HH:MM` · репліки `**Мовець** · HH:MM — текст` одним рядком · ремарки `*[…]*`; `check.py` перевіряє; сайт парсить ту саму граматику (`core/ui/lesson.js`).
- **Злиття** · T182 §«Злиття», [merge.md](../../.claude/skills/lesson/merge.md): Zoom — «хто» і «коли»; формулювання — з найповнішого джерела; повнота важливіша за гладкість; розбіжності — більшість → краще джерело → `[нерозбірливо]`, непевне — `[?]`; дату не вигадувати; `notes.md` поруч.
- **Конспект у два кроки** · [summary.md](../../.claude/skills/lesson/summary.md): чернетка одразу, далі контекст викладача → перегенерація або правка руками з історією.
- **Правила — проєктний skill `/lesson`** (`.claude/skills/lesson/`): `merge` · `summary` · `check`; важку роботу робить субагент Opus; ті самі файли стануть промптами серверної обробки.
- **Обробка**: зараз локально (A), на сервері через Anthropic SDK — коли правила устояться (B, ≈ $1–2 за заняття на Opus 5.5); Claude Code на VPS за підпискою — не спиратися (C).
- **Бот**: після публікації — заголовок + «Коротко / Домовились / Зробити» розгорнутою цитатою + кнопки у гілку групи; алерт адміну `lesson` 📝.

## Джерела: що дає кожне

Порівняння на занятті 1 — [T185](.t/T185-C--transcript-sources.md):

- **Zoom** — «хто» і «коли» без помилок; текст — уламки. **Whisper** — найкращий текст, імена мовців хибні. **Tana** — дубль Whisper без мовців і часу. **Plaud** — гладкий і стислий, губить ≈15–20 % і вигадує правдоподібне.
- **Мінімальний набір — Zoom + Whisper**, третім — Plaud; корисні зміни: окремі аудіодоріжки й чат у Zoom, словник для Whisper і Plaud, називати автора при читанні чату.
- Zoom API може віддавати хмарний транскрипт (VTT), чат і запис одним викликом разом з учасниками — [T221](.t/T221-C--zoom-attendance.md).

# lessons — заняття: записи, транскрипти, конспекти

Кожна зустріч зі студентами (ПЗ, лаба, лекція, консультація) стає записом на сайті: кілька машинних транскриптів різних сервісів зводяться в один вивірений транскрипт і конспект, поруч — відео. Для всіх курсів однаково — живе в ядрі. Сусіди: [platform](../platform/README.md) — ядро, методичка й редактор, на які це спирається; [tgbot](../tgbot/README.md) — куди бот шле конспект; [ods](../ods/README.md) — перший курс із записами.

Шапка:
- Оновлено: 2026-10-02
- Інтегровано: [T182](.t/T182-P--lessons-design.md) (дизайн), [T184](.t/T184--transcript-pilot/report.md) (пілот злиття заняття 1), [T185](.t/T185-C--transcript-sources.md) (порівняння чотирьох сервісів)
- Не інтегровано: [T183](.t/T183-Q--lessons-questions.md) (18 виборів — зроблено за «a», відповідей ще нема)

## Задача

- На заняттях увімкнені кілька сервісів транскрибування: Zoom (імена й годинник), Whisper, Tana, Plaud; набір щоразу може відрізнятися — щось забулось чи не спрацювало, щось додалось (Vitalik, 2026-10-02).
- Чим більше джерел — тим певніше, що саме було сказано; результат — один надійний Markdown: хто, приблизно коли, що сказав; читається з телефона, копіюється куди завгодно, сайт показує красиво.
- Заняття на сайті для студентів: перелік, конспект, транскрипт, відео; конспект — з контекстом від викладача; бот — конспект у чат зі згортанням.
- Обробка — на Opus: Fable щоразу задорого.

## Вирішено (пропозиція, чекає «ок»)

- **Формат транскрипта** — Markdown із жорсткою граматикою рядків · [T182](.t/T182-P--lessons-design.md), повний опис — [merge.md](../../.claude/skills/lesson/merge.md):
  - фронтматер (курс, номер, тип, дата, час, джерела) · `# заголовок` · розділи `## Назва · HH:MM` · репліки `**Мовець** · HH:MM — текст` одним рядком · ремарки `*[…]*`;
  - час — хвилина за годинником із Zoom; розділи 5–15 хв за темою → зміст сторінки і «Теми» конспекту;
  - викладач — на імʼя, студенти — «Імʼя Прізвище» з реєстру сайту, невідомий — «Студент»;
  - перевірка — `check.py`: граматика, порядок часу, частка слів від найбільшого джерела (60–85 %).
- **Злиття** · T182 §«Злиття», [merge.md](../../.claude/skills/lesson/merge.md): Zoom — «хто» і «коли»; формулювання — з найповнішого в цьому місці джерела; повнота важливіша за гладкість; чистяться лише заповнювачі, фальстарти й системні фрази; розбіжності — більшість → краще джерело → `[нерозбірливо]`, непевне — `[?]`; дату не вигадувати; поруч `notes.md` — зсув годинників, безіменні мовці, розбіжності.
- **Конспект у два кроки** · [summary.md](../../.claude/skills/lesson/summary.md): чернетка одразу (Коротко · Домовились · Зробити 🎓/🧑‍🏫 · Q&A · Теми · Відкрите · Нотатки викладачу), далі контекст викладача → перегенерація або правка руками з історією.
- **Правила — проєктний skill `/lesson`** (`.claude/skills/lesson/`): `merge` · `summary` · `check`; важку роботу робить субагент Opus; ті самі файли стануть промптами серверної обробки.
- **Сховище** (ядро): `Lesson` (мета, відео, контекст, транскрипт, конспект, `published`) · `LessonSource` (сирі файли, вічно) · `LessonJob` (запуски моделі, витрати) · `User.aliases` (імена в Zoom → студент); правки — `record()` → `history`.
- **Сторінки**: `/lessons` «Заняття» (перелік із чипами 📝 🗣 🎬) · `/lessons/<n>` (конспект, згорнутий транскрипт зі змістом і репліками як чат, «до відео» з часу); адміну там само — джерела з дроп-зоною, контекст, кнопки обробки, редактор, «Показати студентам».
- **Обробка**: спершу локально через Claude Code за підпискою (`/lesson` + `bin/lesson pull/push` за зразком `bin/guide`), потім на сервері через Anthropic SDK (Opus 5.5, ≈ $1–2 за заняття); Claude Code на VPS за підпискою — не спиратися.
- **Бот**: після публікації — заголовок + «Коротко / Домовились / Зробити» розгорнутою цитатою + кнопки «на сайті» · «відео» у гілку групи; алерт адміну `lesson` 📝.
- **Приватність**: читають підтверджені студенти й адміни; сирі файли й результати — ніколи в git (`sites/ods/transcripts/` в `.gitignore`); прапорець «не називати мене» — питання T183 Q13.

## Джерела: що дає кожне

Порівняння на занятті 1 — [T185](.t/T185-C--transcript-sources.md):

- **Zoom** — «хто» і «коли» без помилок (імена з акаунтів, мітка кожні ≈6 с); текст — уламки, терміни понівечені або викинуті; не чує вимкнений мікрофон і чат.
- **Whisper** — найкращий текст (повний, читабельний, латиниця правильна); **імена мовців хибні в ≈40 % студентських рядків** — не джерело «хто».
- **Tana** — дубль Whisper на 95 %, без мовців і часу, склеює мовців у пункти; у «більшості» рахується разом із Whisper як один голос.
- **Plaud** — найгладкіший і найстисліший: губить ≈15–20 % (студентів і коротких реплік найбільше) і вигадує правдоподібне (назви продуктів, числа); час рівний зі сталим зсувом до Zoom.
- **Мінімальний набір — Zoom + Whisper**, третім — Plaud; корисні зміни: окремі аудіодоріжки й чат у Zoom, словник для Whisper і Plaud, називати автора при читанні чату.

Конспект — 13 тем 1:1 із розділами. Результати — `sites/ods/transcripts/lesson_1/` (поза git).
- Правила після пілота переписано за відгуками агентів ([T184](.t/T184--transcript-pilot/report.md) §«Що змінилося»): імена Whisper не брати, Whisper+Tana один голос, факти лише з Plaud не брати, полярність і числа за змістом, `prep.py` для Zoom/Plaud.

## Обʼєктна модель (прийнято, [T87](../.rounds/.t/T87-R--game-round-decisions.md) — відповіді [T84](.t/T84-Q--game-objects-questions.md), всі «a»)

- Три шари «каталог → обʼєкти гри → заявки»: обʼєкт (у v1 — вікно, меню) — якір заявок і скриншотів; один скрин вікна покриває всі його заявки · [T83](.t/T83-B--game-objects-model.md).
- Вікно — лише від типу з каталогу (тег `window`, засіяно [T88](../tasks/.t/T88--catalog-objects-seed/report.md)); нестандартне — картка `custom-window` з договірною ціною.
- Пункт меню — дія на вибір: `→ вікно` / `→ функція-заявка` / текст; звʼязки дають граф переходів.
- Докази — атрибут картки (`none/screenshot/gif/link`); GitHub — гібрид: поле опційне, обовʼязкове для ⭐/золота, нормалізація URL у коміт-пін.
- Старт без монетної математики: ціни довідково, grading не блокує.

## Заявки v2 · [T259](../platform/.t/T259--game-desc-v2/report.md), [T263](.t/T263-C--evidence-github-ai.md) (2026-11-09)

- Заявка (`Claim`) живе на частині гри — полі, сутності, вікні — або на грі загалом; **чернетка** — заявка картки, що хоче господаря (зона сутностей, HUD/налаштування), але ще без нього; привʼязку можна міняти (`PUT part`), дубль на тому ж господарі — 409.
- Параметри (слоти картки) обовʼязкові на привʼязаній заявці; на рівні гри картка може чекати їх (чіп показує ⚙️?, підказка «чекає параметрів») — так «＋ у гру» з каталогу не змушує заповнювати все одразу.
- **Вердикт викладача** — на заявці: `status` заявлено · зараховано · повернуто + `verdict` (слово студентові), `PUT /api/students/{nick}/claims/{id}` лише адмін, алерт студентові `game_alerts.verdict`, історія через `record()`. Зараховані монетки рахуються окремо (`coins_accepted` у галереї й `/table`) — основа для «монетки → бали» ([grading](../grading/README.md)); чи це і є життєвий цикл T10 Q1–Q2 — [T262](../games/.t/T262-Q--game-desc-v2-choices.md) Q2.
- Докази: скриншот на частині (вікно, сутність, поле), лінк на заявці опційний (⭐ без лінка — підказка), ШІ-звірка опису з кодом — у ревʼю лаби через `bin/repos`, не в редакторі студента ([T263](.t/T263-C--evidence-github-ai.md)).

## Заявки v3 · [T270](../games/.t/T270-P--game-desc-v3-design.md) §6, [T271](../platform/.t/T271--game-desc-v3/report.md) (2026-11-10)

- **Місце заявки каже тип картки**: механіка — на сутності, елемент — на вікні, картка про поле — на полі, про рівні — на рівні чи в секції «Рівні», **картка-правило — на правилі** (`Claim.rule`), гра загалом — без привʼязки. Сервер не дає привʼязати не туди; непривʼязана картка не-«гри» — чернетка 📥. «Перемістити» — дія в панелі заявки, зі списком дозволених місць.
- **Авто-заявки** (`Claim.auto`): тип сутності, параметр, властивість поля й тип вікна заявляються самі, коли їх обирають; сервер тримає їх у згоді з описом (`auto_claims.sync`); руками не створюються й не видаляються, нотатка й лінк — редагуються, вердикт ставиться як на звичайній.
- **Монетки з лімітом**: картка рахується не більше `max_count` разів на гру (пʼять ворогів — одна монетка за тип «ворог»); рахує сервер (`passport.coins_of`), фронт показує.
- Заявка на екрані — рядок (монетка · назва · параметри · нотатка · 🔗 · статус); клік — панель з **описом картки з каталогу**, вердиктом викладача чи діями власника; вигляд «Картки» — усі заявки гри деревом, де лежать і в якому статусі.
- ШІ: чернетку опису за кодом через підписку можна робити лише коли викладач запускає сам; автомат на сервері — тільки API ([T272](.t/T272-C--ai-game-draft.md)).

## Відео — рядками, а не заявками · [T323](../games/.t/T323-P--game-desc-v12-design.md) §1, код [T318](../platform/.t/T318--game-desc-v12/plan.md) (2026-11-17)

- Демка, асинхронний захист і пояснення золотої картки — не заявки, а **рядки відео**, які є в кожній грі: `Video` на пару «гра + рядок».
- Рядок тримає всі версії посилання; «вчасно» рахується за першим посиланням проти дедлайну лаби студента.
- Слово викладача на рядку: чи потрібне від цього студента («треба» / «не треба» з рядком чому) і перевірка, як на заявці, — заявлено · зараховано · повернуто.
- Монеток рядки не дають; файлів сайт не приймає — лише посилання.
- Відео з посиланням без слова викладача рахується в «⏳ є що перевірити» разом із заявками.

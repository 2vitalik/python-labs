## Обʼєктна модель (прийнято, [T87](../.rounds/.t/T87-R--game-round-decisions.md) — відповіді [T84](.t/T84-Q--game-objects-questions.md), всі «a»)

- Три шари «каталог → обʼєкти гри → заявки»: обʼєкт (у v1 — вікно, меню) — якір заявок і скриншотів; один скрин вікна покриває всі його заявки · [T83](.t/T83-B--game-objects-model.md).
- Вікно — лише від типу з каталогу (тег `window`, засіяно [T88](../tasks/.t/T88--catalog-objects-seed/report.md)); нестандартне — картка `custom-window` з договірною ціною.

- Докази — атрибут картки (`none/screenshot/gif/link`); GitHub — гібрид: поле опційне, обовʼязкове для ⭐/золота, нормалізація URL у коміт-пін.
- Старт без монетної математики: ціни довідково, grading не блокує.
- Джерело-брейндамп Vitalik — [T82](../.rounds/.t/T82-R--game-desc-braindump.md); студентський YAML-файл остаточно не потрібен — файл лише експорт-артефакт.

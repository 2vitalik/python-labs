# T84 · Питання по обʼєктній моделі заявок

`2026-08-15` · ❓ question

Контекст:
- пропозиція, яку це уточнює, — [T83](T83-B--game-objects-model.md); брейндамп-джерело — [T82](../../.rounds/.t/T82-R--game-desc-braindump.md);
- відповіді відкривають реалізацію «Моєї гри» v1 (крок 1 плану в T83).

**Q1 — Три шари.** Приймаємо модель «каталог → обʼєкти гри → заявки» як основу «Моєї гри»?
- a) так, обʼєкти як якорі заявок і скриншотів — рекомендую;
- b) простіше: без обʼєктів, плоскі заявки на картки каталогу;
- c) інше (опиши).

>a

**Q2 — Типи обʼєктів у v1.** З чого стартуємо?
- a) вікно + меню; сутності/рівні — наступною фазою разом з [T85](../../games/.t/T85-B--mechanics-formalization.md) — рекомендую (швидший старт, менше форм одразу);
- b) одразу вікно + меню + сутність + рівень;
- c) свій список.

>a

**Q3 — Вікна і типи.** Вікно створюється лише від типу з каталогу?
- a) так: тип обовʼязковий, для нестандартного — картка `custom-window` з ручною ціною через «запропонувати завдання» — рекомендую;
- b) вільна назва без типу, ціна за замовчуванням.

>a

**Q4 — Пункт меню.** Формальний звʼязок чи текст?
- a) дія на вибір: `→ вікно` / `→ функція-заявка` / просто текст — рекомендую (дає граф переходів, текст лишає свободу);
- b) лише текстовий опис (без графа);
- c) лише формальний звʼязок (жорстко, без текстових пунктів).

>a

**Q5 — Рівні доказів.** Вводимо `none / screenshot / gif / link` як атрибут картки каталогу?
- a) так, з gif для динаміки — рекомендую;
- b) простіше: лише screenshot/нічого, gif не вводимо у v1;
- c) інакше (опиши).

>a

**Q6 — GitHub-лінки у v1.** Яка політика?
- a) гібрид: поле опційне всюди, обовʼязкове для ⭐/золота, система нормалізує URL у коміт-пін — рекомендую;
- b) обовʼязкове для всіх карток з кодом;
- c) у v1 без лінків, чекаємо AI-передперевірку.

>a

**Q7 — Старт без grading.** Починати «Мою гру» v1 одразу після цих відповідей, не чекаючи монетної математики [T08](../../grading/.t/T08-Q--grading-open-questions.md)?
- a) так, монетки поки довідково, як у каталозі — рекомендую;
- b) спершу вирішити T08 Q1–Q2.

>a

**Q8 — Сімʼя «елементи налаштувань».** Засіяти в каталог чернетки: слайдер гучності, перемикач музики, вибір теми, вибір аватару, розмір поля, вибір мови + відповідні картки-функції, і добудувати типи вікон (splash/лого, екран налаштувань, магазин-вікно…)?

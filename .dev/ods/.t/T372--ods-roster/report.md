## Що побачить студент

1. Входить через Google з поштою `@nure.ua` — сайт знаходить готовий профіль за поштою. Статус уже «студент», а не «очікує».
2. Профіль: прізвище, імʼя, по батькові й група заповнені; лишається привʼязати бота.
3. «Лаби» → «Моя лаба»: одразу його картка `ПЗПІ-24-NN`. Кроку «назви свій номер» більше нема.

Студент із `@nure.ua`, якого в списку нема, як і раніше стає «очікує»; після твого «пустити» він називає вільний номер.

## Копія бази для сервера — з користувачами

Рецепт [T367](../T367--ods-state/report.md) плюс один рядок (`users`); має надрукувати `guide 47 · media 150 · lab_pages 27 · lab_shapes 5 · variants 310 · users 48`:

```sh
mongosh ods --quiet <<'JS'
const seed = "ods_seed", plain = ["guide", "media", "lab_pages", "lab_shapes"];
db.getSiblingDB(seed).dropDatabase();
for (const c of plain) db[c].aggregate([{ $out: { db: seed, coll: c } }]);
db.variants.aggregate([{ $match: { group: { $ne: "ТЕСТ" } } }, { $out: { db: seed, coll: "variants" } }]);
db.users.aggregate([{ $match: { status: "student", test: { $ne: true } } }, { $out: { db: seed, coll: "users" } }]);
const s = db.getSiblingDB(seed);
print([...plain, "variants", "users"].map((c) => c + " " + s[c].countDocuments()).join(" · "));
JS
```

- Дев-користувач і тестовий студент у копію не потрапляють; ти на сервері стаєш викладачем за `ADMIN_EMAILS` при першому вході.
- Якщо сервер уже піднято без цього рядка: ті самі дві дії я повторю через твій Chrome, де ти увійшов на ods (токен агента студентів не створює й карток не передає) — за словом.

## Чим сайт упізнає студентів

Що працює на сайті (ядро, обидва сайти):

| Механізм | Що дає | Стан |
|:--|:--|:--|
| Вхід Google, лише `@nure.ua` | пошта, імʼя з акаунта, фото; новий — «очікує» | працює |
| Імпорт списку на `/students` | профіль зі статусом «студент», ПІБ, група | працює для двох форм: список групи з ЦІСТ і учасники курсу з DL |
| Бот: посилання з профілю | Telegram напевно | працює |
| Нік Telegram у профілі, вставка листування | Telegram здогадом | працює |
| Імена в Zoom (`aliases`) | відвідування й транскрипти | працює |
| ods: номер у списку = картка | варіант лаб | тепер закріплено наперед |
| ods: переслане боту | автор за Telegram, інакше здогад за карткою, ніком, імʼям | код є, справжнього Telegram ще не було |

- Список у формі, яку ти вставив сьогодні (номер · пошта · код дисципліни · група), імпорт на `/students` не читає: рядки мовчки пропускає, та й імен у ньому нема. Тому сьогодні — через файл і скрипт.
- Закріплені картки допомагають «Вхідним»: картка у пересланому файлі тепер одразу каже, чий він, навіть без привʼязаного бота. Якщо студент здав лабу 1 чи 2 з чужим номером, «Вхідні» скажуть «У файлі картка X, а студент тримає Y».

Звідки брати імена за поштою:

| Джерело | Що в ньому | Стан на 20.11 | Мій доступ |
|:--|:--|:--|:--|
| ЦІСТ, вхід викладача `/nik/` | списки груп: ПІБ, залікова, контракт, пошта | закрито ззовні з 15.10 — 403 від nginx усім, і серверу теж | нема ні в кого ззовні |
| Знімки ЦІСТ у базі бота `nure-students` на сервері | факультет цілком, до 14.10 | лежать | нема: `ssh vv3` питає пароль ключа |

## Як перевірено

- API по кожному з 48: профіль (статус, група, ПІБ) і картка в кожній з пʼяти лаб — розбіжностей 0.
- «Очима студента» на № 1, 20 і 48: профіль як у списку, свої картки в лабах 1–3 (4–5 сховано), «Моя лаба» 3 — картка без запитання про номер.
- Сторінки в headless Chrome на дев-сайті очима студента № 20: «Профіль», «Лаби», «Моя лаба» 1 і 3 — `img/profile.png`, `img/mylab3.png` (імена замальовано до знімка).
- Повторний запуск `roster.py`: додано 0, без змін 48, карток «ті самі» 240.
- Рецепт копії — на тимчасовій базі: 48 користувачів, 240 карток за студентами, жодної картки за тим, кого в копії нема; базу видалено.

## Не перевірено

- Справжній вхід студента через Google: у деві його нема. За кодом `upsert_user` знаходить профіль за поштою й імен зі списку не перетирає.
- Сервер: сайту там ще нема.
- Чи номери 1–48 ті самі, з якими студенти робили лаби 1–2: локально старого списку нема. Покажуть «Вхідні» після пересилання ([T373](../T373-Q--ods-roster-choices.md) Q3).
- Каталог Google сьогодні: спираюсь на запис `nure-students` T76 від вересня.

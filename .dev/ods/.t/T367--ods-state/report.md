- **Пастку з push прибрано з README** (`.dev/README.md`, `.dev/ods/README.md`, `.dev/platform/README.md`): уся робота з 14.11 — на гілці `ods`, локальна `main` відстала. `git push origin main main:ods` не привіз би на ods нічого нового і відвіз би на python стан 13.11. Правильно: ods — `git push origin ods`; python — окремо, `git push origin ods:main` (271 коміт). У плані vps-infra T76/00 рядок лишився старий.
- **Рецепт копії бази для сервера розширено й перевірено на пробній базі** (має надрукувати `guide 47 · media 150 · lab_pages 27 · lab_shapes 5 · variants 310`):

```sh
mongosh ods --quiet <<'JS'
const seed = "ods_seed", plain = ["guide", "media", "lab_pages", "lab_shapes"];
db.getSiblingDB(seed).dropDatabase();
for (const c of plain) db[c].aggregate([{ $out: { db: seed, coll: c } }]);
db.variants.aggregate([{ $match: { group: { $ne: "ТЕСТ" } } }, { $out: { db: seed, coll: "variants" } }]);
const s = db.getSiblingDB(seed);
print([...plain, "variants"].map((c) => c + " " + s[c].countDocuments()).join(" · "));
JS
```

Чим відрізняється від плану T76: push `ods` (не `main:ods`); копія бази з пʼяти колекцій; `BODY_MAX=20MB` у `apps/ods-labs/units/ods-labs-web.conf`; після деплою — список потоку з групами `ПЗПІ-24-N` на `/students` (новий користувач «очікує») і дедлайни на `/deadlines` (колекція порожня); `bin/guide -t ods ls` має показати 47 сторінок, не 20.

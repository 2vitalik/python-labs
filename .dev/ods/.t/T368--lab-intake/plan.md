## 2. Перенос із Telegram — контракт

### 2.1 Дані

`sites/ods/api/models/forward.py` — `Forward` (колекція `forwards`), `ForwardHead` — те саме без байтів. Одне переслане повідомлення — один документ: хто й коли написав, слова, файл; ноутбук лежить цілим (zlib), як у `LabFile`. Поля — у файлі моделі, він і є контракт.

- `key` — чия розмова: `tg:<id>`; `name:<імʼя>` — коли акаунт сховано за пересиланням; рядки викладача отримують `key` розмови, до якої належать.
- Повтор не множиться: той самий `file.uid`, або та сама трійка (`key`, `sent_at`, `text`) — один документ.

### 2.2 Бот — `sites/ods/api/bot/intake.py`

- Ловить: приватний чат із ботом, відправник — адмін, що привʼязав бота (`core.bot.notes.as_admin`), повідомлення переслане (`forward_origin`).
- Автор: `MessageOriginUser` → `tg_id`, імʼя, нік; `MessageOriginHiddenUser` → лише імʼя; чат чи канал — не береться, одне речення у зведенні. Час — `forward_origin.date`.
- Автор — сам викладач → `mine`; `key` — наприкінці пачки: розмова найближчого за `msg` рядка студента тієї ж пачки.
- Файл: `.ipynb` або `.py` до 12 МБ качається (`bot().download`) і читається (§2.3); інше — лише назва й розмір. У тексті є посилання Colab чи Drive, а файла нема → `labs_pull.pull`, `file = {name, link}`.
- Пачка: бот ставить ✍ на кожне й відповідає **одним** зведенням через 3 с тиші (стиль T109: значок-роль на початку рядка, без крапок): по людях — хто (студент із сайту або «не впізнаю»), рядок на ноутбук «лаба · варіант · n/N ✅ · коли», лік повідомлень, 🙋, «вже були», посилання на `/intake`.
- Тексти — `bot/intake_say.py`. Перед зведенням — `settle()` (§2.5).

### 2.3 Читання файла — `intake_read.py`

`async read(name, data) → {kind, sha, raw, lab, vid, line, ok, total, why}`; нічого не виконується.

- `labs_nb.read` → `labs_facts.facts(nb, None)` дає `vid` і `line`.
- Лаба: з рядка відповідей (`LAB<n>`); нема — шаблон якої лаби найближчий (`LabShape`, `labs_align.match`: частка клітинок шаблону, знайдених у файлі; поріг — щоб порожній чужий ноутбук не «впізнавався»); нема — номер із назви файла; нема — `None`, скаже викладач.
- `ok / total` — рядок проти ключа картки (`LabVariant` за лабою й `vid`, `labs_check.verdict`); студент для цього не потрібен.

### 2.4 Чий — `intake_match.py`

- Напевно (`how = tg`): є користувач із `tg_chat_id == tg_id` → усі рядки цього `key` його.
- Слово викладача (`how = hand`): `PUT /api/intake/person`.
- Здогад, не рішення (`guess`, рахується під час читання, у базі не лежить): власник картки з файла (`card`), збіг ніка Telegram (`username`), слова імені (`name`). Викладач підтверджує одним кліком.

### 2.5 Версія на сайті — `intake_apply.py`

- `async apply(f)` — ноутбук із відомими лабою й студентом → `lab_store.store(lab, user, name, data, at=f.sent_at, via="telegram", by=f.by)`: версія з часом повідомлення; той самий файл удруге — та сама версія; раніша за останню — картка лишається за останньою. Помилка `store` (чужа картка, чужий рядок, не той потік) → `trouble` словами, версії нема.
- `async settle(user=None) → int` — усе, що вже можна: кому знайшовся студент за Telegram, чиї ноутбуки ще не стали версіями. З `user` — лише його (кличе «Моя лаба»: студент привʼязав бота — файл і картка зʼявились самі).
- Рядок із `trouble` загальний `settle()` вдруге не пробує: його повторює «ще раз» (`POST …/apply`) або зміна, що чистить причину (інший студент, інша лаба); `settle(user)` пробує й такі. Рядки викладача (`mine`) самі не переносяться — лише явним кліком.
- Дві найчастіші причини сказано для викладача: «У файлі картка X, а студент тримає Y», «Картку X тримає <Прізвище Імʼя>»; решта — слова `lab_store`.
- Гейти тут не діють: це дія викладача. Сповіщення бота про «здав файл» не шлеться.

### 2.6 API — `routes/intake.py`, усе — викладач і агент (`editor_user`)

- `GET /api/intake` → `INTAKE`; перед відповіддю — `settle()`.
- `PUT /api/intake/person` `{key, student}` — `student`: нік або `""` (знову нічий); усі рядки розмови; далі `settle()`; відповідь — `INTAKE`.
- `PUT /api/intake/{id}` `{lab?, asks?, skip?}` — змінюється лише надіслане; нова лаба — перечитати `ok / total`, спробувати `apply`; відповідь — `INTAKE`.
- `POST /api/intake/{id}/apply` — ще раз; відповідь — `INTAKE`.
- `GET /api/intake/{id}/raw` — файл, як надіслано.

```text
INTAKE = {people: [PERSON…], strips: [STRIP…]}
PERSON = {key, name, username, tg_id, student: WHO | null, how, guess: WHO + {why: card | username | name} | null,
          last, rows: [ROW…]}            люди — найсвіжіша розмова перша; рядки — від старих до нових
WHO    = {nick, name, group}
ROW    = {id, mine, sent_at, text, asks, skip, file: FILE | null}
FILE   = {name, size, link, kind, lab, vid, line: bool, ok, total, why, version, trouble, due, late}
         due — дедлайн студента (нема студента — спільний), late — sent_at > due; обидва null, коли дедлайну нема
STRIP  = {lab, due, top, cells: [{n, vid, who, sent_at, ok, total, late, version, id}…]}
         лаба, з якої є хоч один ноутбук; top — найбільший номер картки потоку; у cells — лише номери з файлом,
         найсвіжіший файл номера; who — імʼя студента або імʼя з Telegram; version — файл уже на сайті
```

Рядки викладача, що не причепились до жодної розмови (`key == ""`), у `people` не потрапляють.

### 2.7 Сторінка «Вхідні» — `/intake`, `pages/IntakePage.vue` + `components/Intake*.vue`

- Угорі — як користуватись, одним рядком, що згортається.
- Смужки номерів: на лабу рядок клітинок `1…top`; є файл — кольорова (вчасно · пізно · дедлайну нема): залита — уже на сайті, лише рамка — ще ні; нема файла — порожня; під мишкою — хто, коли, n/N; клік — до рядка.
- Фільтри пігулками з підписом ряду: усі · без студента · не перенесено · просять час · лаба N.
- Люди картками: імʼя з Telegram, нік → студент (посилання на `/students/<нік>/edit`) або здогад із кнопкою «це він» і вибором іншого; рядки — час, слова (рядок викладача позначено), файл одним рядком: «Лаба 2 · варіант 07 · 13/14 ✅ · вчасно», далі стан: «на сайті» (посилання на перевірку) · «перенести» · причина червоним із «ще раз» · «не ноутбук» · «твій файл» (ноутбук у рядку викладача). Поки версії нема, «Лаба N» — вибір на місці: хибно впізнану лабу виправляє клік.
- 🙋 на тексті — перемикач; «відкласти» — рядок сіріє й ховається за фільтром.
- Версія «з Telegram» на «Моїй лабі» й столі перевірки — позначка в `LabVersions.vue`.

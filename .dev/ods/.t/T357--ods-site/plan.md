## 3. Бекенд

- **Сторінки методички «лише викладачам»** (ядро): `GUIDE_STAFF` у `site.env` — префікси slug-ів через кому (ods: `old-`). Не-адмін таких сторінок не бачить ні в переліку `GET /api/guide`, ні за адресою (404). Агент — як адмін.
- **Картинки** (`routes/media.py`): файл сторінки з префіксом `GUIDE_STAFF` (`old-lab3/x.png`, `files/old-lab3/…`) — лише адмінові.
- **Імпорт** — `routes/content.py`, префікс `/api/content`, усе під `editor_user` (адмін або агент із токеном):

| Метод | Шлях | Що |
|:--|:--|:--|
| GET | `/api/content` | `{pages: {slug: sha1}, media: {path: sha1}, labpages: [...]}` — що вже є; `sha1` сторінки — від `title + "\n" + body` |
| PUT | `/api/content/pages/{slug}` | `{title, body, note?}` → сторінка методички створена або оновлена: `{state: new · updated · same, rev}`; slug — `[a-z0-9-]+` |
| PUT | `/api/content/media/{path}` | тіло — байти файла, `Content-Type` — його тип → `{state}`; до 12 МБ |
| PUT | `/api/content/labpages` | `[{slug, kind, lab, part, nav, order, files}]` → перелік замінено: `{count}` |

- **Диск** — `content_disk.py` (без бази й без ядра): `lectures()`, `lab_pages()` (маніфест `labs/site/pages.json`, решта лаб — із `labs/new`), `old_labs()` (`labs/old/labN/labN-student.md` → `old-labN`), `parse()`; відсутній файл із маніфесту — рядок «нема файла» й далі. `content_io.py` (прямо в Mongo, локально) і `bin/content` (через API) читають диск ним.
- **`bin/content -t <ціль> ls | push [lectures · labs · old · <slug>…] [--dry]`** — ціль обовʼязкова (без неї скрипт пішов би на прод python); шле лише те, чий `sha1` відрізняється.
- **«Очима студента»** (ядро): `POST /api/me/as` без ніка — тестовий студент сайту; нема жодного — створюється «Студент Тестовий» (`test.student@…`, `test: true`).

## 4. Розмітка сторінок лаб (домовлено з T355)

Усе проходить крізь `marked`; сайт додає вигляд і трохи поведінки.

| Що в md | Як показує сайт |
|:--|:--|
| `> 💡 …` · `> ⚠️ …` · `> 🎯 …` | три види виносок: порада · пастка · відповіді |
| перший `> 🎯` на початку сторінки справи | «паспорт справи»: смужка чипів, поділ за « · » |
| `<details class="demo · lecture · ref · hint">` | згортка зі значком за класом; стан памʼятається читачеві |
| кілька поспіль `<details name="x">` | вкладки; обрана памʼятається на всіх сторінках |
| `### 1.4. … {#s14}` | якір кроку ноутбука; пізніше — ⬜ / ✅ / ❌ студента біля заголовка |
| `![…](img/…)` | лайтбокс ядра |
| блок коду | кнопка «копіювати» |

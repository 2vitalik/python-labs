## 2. Дані (Mongo сайту ods)

`LabVariant` (`variants`) — нові поля: `way: str = ""` (як студент збирається захищатись: `none` · `record` · `live`), `video: str = ""` (посилання на запис), `defended: str = ""` (який захист прийняв викладач: `record` · `live`), `stars: int | None = None` (слово викладача про зірочки; `None` — як видно з файла), `files: int = 0`, `file: dict = {}` (остання версія: FILE), `facts: dict = {}` (FACTS останньої версії), `token: str = ""`, `live: dict = {}` (`name → {ok, value, tries, at}`), `live_at`.

`LabFile` (`lab_files`) — одна версія: `lab`, `vid`, `student`, `kind` (`ipynb` · `marimo`), `name`, `size`, `sha` (sha256 оригіналу), `raw: bytes` (zlib), `at`, `by`, `origin` (`student` · `run` — виконана копія від `bin/nbrun`), `of` (для `run` — id версії студента), `facts: dict`, `line: str`, `run: dict | None` (RUN). Ліміт оригіналу — 12 МБ. Індекси: `(lab, vid, at)`, `student`.

`LabShape` (`lab_shapes`) — будова ноутбука лаби, з диска через `lab_io.py`: `lab` (унікальний), `cells` і `mcells` (шаблон Jupyter і marimo клітинка за клітинкою: `{kind, sig, role, key, title, names, source}`), `tasks` (`{key, role, case, title, plot, names}`), `plots` (скільки графіків чекає рівень 14 — з розвʼязаного ноутбука), `jupyter: bytes`, `marimo: str` (шаблони для видачі), `live: bool` (службова клітинка шле на сайт), `updated_at`.

## 3. Розбір ноутбука — `labs_nb.py`

Без виконання й без бібліотек обчислень: `.ipynb` — JSON, marimo `.py` — `ast`.

- **Ролі клітинок**: `card` (`# ✂` або `VARIANT =`), `service` (`def check(`), `task` (`# ✍ 1.3`), `star` (`# ✍ ★ зірочка N`), `conclusion` · `report` · `ai` · `note` (markdown з `✍ *Мітка:*`), `line` (`print("LAB…`), `given` (решта шаблону), `extra` (своє).
- **Зіставлення зі шаблоном**: підписи клітинок (`sig`) → `difflib.SequenceMatcher.get_opcodes()`; `replace` — парами за видом; зайві клітинки студента належать попередньому завданню (розвʼязок, розбитий на кілька клітинок). Прибрана мітка `# ✍` не ламає зіставлення.
- **Завдання зроблено**: код — є рядки, яких нема в шаблоні й які не коментар; текст — після мітки ≥ 20 знаків. `checks` — рядки виводу `✅ | ❌ | ⬜ назва`; `image`, `error` — з виводів.
- **Виконання**: `ran = {count, of, ordered, fresh, errors}` з `execution_count`; `fresh` — лічильники 1…k підряд («перезапустити й виконати все»); marimo `.py` виводів не несе → `ran = None`.
- **Рядок відповідей** — останній рядок виводу `LAB<n> <варіант> …`; `vid` — з `VARIANT = "…"`.
- **Час** — перший і останній `executionInfo.timestamp` Colab (імен акаунтів не зберігаємо).
- **Для показу** виводи зводяться до `text` (stream, `text/plain`; без ANSI; ≤ 20 000 знаків), `image` (png / jpeg, base64 перевірено, ≤ 3 МБ), `latex`, `error` (назва, значення, хвіст трасування), `skipped` (усе інше, зокрема `text/html` — не показуємо).

FACTS = `{kind, tool, cells, vid, card, line, ran, tasks: [{key, role, case, title, done, plot, image, error, checks}], count: {tasks: [n, of], plots: [n, of], conclusions: [n, of], report, ai, stars: [n, of]}, times}`.

## 4. Підказка оцінки — `labs_grade.py`

Правило — таблиця рівнів із тексту кожної лаби (T228), однакова для всіх пʼяти.

| Рівень | Робота | Захист |
|:-:|:--|:--|
| 12 | усі відповіді ✅ (вердикт рядка) · ноутбук виконано без помилок | — |
| 14 | + усі кроки зроблено · графіки n із N · висновки всі · рапорт | записом |
| 13 | рівень 14 неповний: зроблено не менше половини його пунктів | записом |
| 16 / 18 / 19 / 20 | + зірочок 1 / 2 / 3 / усі | 16 — записом; 18–20 — наживо |

GRADE = `{steps: [{level, title, way, needs: [{key, ok, text}], ok}], work, way, cap, hint}`: `work` — рівень, якого сягає сама робота (`None` — ще не 12); `way` — `defended`, а якщо порожньо — намір студента; `cap` — 12 без захисту, 16 записом, 20 наживо (`None` — форму не названо); `hint = min(work, cap)`. Зірочки — `stars` викладача, а без нього — з файла. Пункт, про який файл мовчить (нема файла, marimo без виводів), — `ok: None`.

Підказка — не оцінка: `points` ставить лише викладач.

## 5. API — `/api/variants`

FILE = `{id, name, kind, size, at, by, line: bool, run: RUN | None}` · RUN = `{at, by, ok, same, line, right, total, seconds, errors: [{key, name, text}], engine, file}` (`same` — вердикт перезапущеного рядка збігся з вердиктом рядка студента; `file` — id виконаної копії).

MY (студентові) = що було (`lab, vid, card, ask, line, verdict, ok, total, attempts, checked_at, notebook, points, note`) + `way, video, defended, file, files: [FILE], facts, grade, live: {at, names} | None, formats: {jupyter, marimo, live}, due, late`. Ключа й типових помилок у MY нема.

| Метод | Шлях | Хто | Що |
|:--|:--|:--|:--|
| GET | `/{lab}/my` | студент | MY; картки нема — 404 зі словами; тримає номер n в іншій лабі й картка n вільна — бере її мовчки |
| GET | `/{lab}/free` | студент | `{group, free: [n…], same: n \| None}` — вільні номери його потоку |
| POST | `/{lab}/my/claim` | студент | `{n}` → MY; зайнято — 409 зі словами. Адмін і тестовий студент можуть узяти демо `n = 0` |
| PUT | `/{lab}/my` | студент | `{line?, notebook?, way?, video?}` → MY; відсутнє поле не міняється |
| POST | `/{lab}/my/file` | студент | multipart `file` → MY: версія, розбір, рядок із файла перевірено як спробу; картки ще нема — сайт бере варіант із файла |
| POST | `/{lab}/my/pull` | студент | стягнути `.ipynb` за збереженим посиланням Colab / Drive → як файл; доступ закрито — 422 зі словами |
| GET | `/{lab}/my/start?as=jupyter\|marimo` | студент | шаблон зі своєю карткою (і `TOKEN`, якщо лаба шле на сайт) файлом |
| GET | `/file/{id}` | власник · адмін · агент | NOTEBOOK = `{file, lab, vid, tool, cells: [{i, kind, source, role, key, task, given, h, count, out: […]}], facts}` |
| GET | `/file/{id}/raw` | власник · адмін · агент | оригінал |
| GET | `/{lab}/results` | адмін | рядки: `row()` + `who, grade: {work, cap, hint}, count, file, files` |
| GET | `/{lab}/results/{vid}` | адмін | рядок + `answers` (ключ), `values`, `files: [FILE]`, `facts`, `grade`, `shape: {tasks}`, `prev`, `next` |
| PUT | `/{lab}/results/{vid}` | адмін | `{points?, note?, defended?, stars?, student?}`; `student: ""` звільняє картку, email — передає |
| GET | `/{lab}/stats` | адмін | по кожній відповіді: скільки ✅, скільки ❌ і з якою типовою помилкою, хто |
| GET | `/{lab}/files?todo=1` | адмін · агент | остання версія кожного варіанта: `{id, vid, student, kind, name, size, at, sha, run: bool}` |
| PUT | `/file/{id}/run` | агент · адмін | `{ok, line, seconds, errors, engine, log, executed}` (`executed` — base64 zlib виконаного `.ipynb`) → RUN |
| POST | `/{lab}/live` | токен картки | `{vid, token, name, value}`; без cookie, `Access-Control-Allow-Origin: *`; сайт сам судить значення правилом рядка |

Рядок студента для «Зводу» (`routes/student_variants.py`, `students.TEACHER`) — додати `way, defended, stars, files, file_at, work, hint`.

Сповіщення бота `lab`: завантажено файл — «📎 ноутбук: 13/13 ✅ · графіків 3/3 · висновків 4/4 · ★ 1 · підказка 16».

## 7. Локальний перезапуск — `bin/nbrun`

- `bin/nbrun build` — образ `ods-nbrun` (`bin/nbrun.d/Dockerfile`: Python 3.12, numpy, scipy, sympy, matplotlib, pandas, nbclient, ipykernel, marimo — версії закріплено).
- `bin/nbrun <лаба> [-t ods] [--vid V] [--all]` — `GET /files?todo=1` → кожен файл у контейнер **через stdin**, результат — JSON зі stdout → `PUT /file/{id}/run`.
- Пісочниця: `docker run -i --rm --network none --read-only --tmpfs /tmp --memory 1g --cpus 1 --pids-limit 256 --cap-drop ALL --security-opt no-new-privileges --user 1000`, жодного `-v`; ліміт часу на ноутбук — 5 хв (`docker kill`), stdout читається не далі 60 МБ.
- `bin/nbrun file <шлях>` — те саме для файла з диска, без сайту.
- Модель загроз: витівка чи шкідливий код студента. Docker Desktop тримає контейнер у власній ВМ; мережі й дисків хоста контейнер не бачить.

## 8. marimo в браузері

Кнопка «У браузері» бере `GET /my/start?as=marimo`, стискає `lz-string` і відкриває `https://marimo.app/#code/<…>`: Python виконується в браузері студента (Pyodide), наш сервер — ні. Третій формат поруч із Colab і marimo локально; здача — той самий `.py` файлом. Що перевірити в браузері — у звіті.

## 9. `check()` → сайт (лаби 3–5)

Токен видає сайт, у файлі карток його нема: «Моя лаба» дописує до картки рядок `TOKEN = "…"`, коли будова лаби каже `live`. Службова клітинка після звірки шле `POST /api/variants/<n>/live`; без токена, без мережі чи після першої невдачі — мовчить. Картки не перегенеровуються, кількість клітинок і відповіді не міняються.

# T381 · Лекції ods на основному сайті: заливка з історією версій, шапка лекції, панель лаб, баги після першого погляду — план

`2026-11-20` · ⚙️ задача · продовження [T374](../T374--lectures-candy/report.md); відповіді Vitalik-а на [T378](../T378-Q--lectures-candy-choices.md) — у чаті 2026-11-20 (Q1 «так, давай заливати скоріше», Q6 «як зробив — зійде»)

## Що сказав Vitalik (диктовка 2026-11-20, після першого погляду)

- На основному дев-сайті не видно кольорів лектора, видів пошуку й сторінки «Зміни»; усе це було лише на стенді — «давай простіше… щоб не було окремого стенду». Завтра в нього кілька хвилин: глянути, виконати команди, показати студентам.
- «Історія» лекції: один запис і «крихти» на «Методичку». Хоче: перша версія — точнісінько як у лектора, далі правки окремими змінами.
- «Редагувати» → «Щось пішло не так».
- Кнопки-перемикачі («Кольори лектора», «Текст / Слайди») під мишкою виглядають як натиснуті — скрізь.
- Лаби: синій темніший, зелений трохи темніший (у тон темному фіолетовому); у перемикачі 1–5 не видно, що натиснуто, — колір лише активній або дуже світлі решті; розділи лаби (огляд, захист, справи…) — окремим рядком, як було, а під меню переїжджають лише при прокрутці; клік по всьому рядку прилиплого підрозділу — на його початок.
- Лекції: шапка, що прилипає, як у лаб — рядок лекції з кнопками праворуч, рядок розділу, рядок підрозділу; клік по рядку — на початок, без жовтого підсвічування; може, «попередня / наступна лекція».
- Питання: чи погано, що частково пофарбовані формули без кольору; приклади запитів для кожного виду пошуку; посилання на приклад таблиці-картинки (Q6); що з історією текстів і чи потрібен приватний репозиторій (Q2); чи пушити базу на сервер, чи досить команди контенту; де зосереджені всі зміни текстів і слайдів.

## Рішення

1. **Основний дев-сайт замість стенда.** Код там уже новий (API з `--reload`), бракувало даних: заливаю лекції в дев-базу `ods` через `bin/content` (слово Vitalik-а на Q1). Стенд T374 після цього зупиняю.
2. **Історія лекції на сайті = історія git лекцій.** `bin/content` шле лекцію не одним текстом, а кроками з git теки лекцій: перший — текст із презентації лектора до вичитки (тег `orig`), далі кожен коміт, що міняв текст, зі своєю нотаткою й часом. Сервер приймає час версії (`at`); сторінка без початку в історії дістає його перед першою зміною. Дописується лише те, чого сайт ще не бачив; правки, зроблені на сайті, не стираються.
3. **Історія правок на ods** — «крихти» за видом сторінки (Лекції › Лекція N), на сторінці лекції — посилання «зміни» на каталог.
4. **Перемикачі**: під мишкою — світлий відтінок, натиснута — залита; правило одне на всі сайти.
5. **Шапка лекції й панель лаб** — два агенти Opus за брифами (`.dev/.drafts/T381/`), кожен зі своїми файлами й своїм Chrome на наявних стендах; інтеграція, перевірка й коміти — мої.
6. **Колір усередині формул** (T378 Q4) — остання хвиля, лише коли решта закрита й перевірена.
7. Сервер: команди для Vitalik-а даю після прогону тих самих команд на скретч-цілі (памʼятка «команди для сервера — спершу відтворити»).

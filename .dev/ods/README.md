## Рішення

- **Один репо з python-labs**, деплой сайту — зі своєї гілки · [T164](../.rounds/.t/T164-R--ods-kickoff.md).
- **Окрема база** на сайт; користувачі з python-labs не спільні · T164.
- **Вхід** — Google OAuth, пошта NURE; бот привʼязується, як на python · T164.
- **Лекції й лаби в git не зберігаються — лише в Mongo** (Vitalik у чаті 2026-09-29: «ми не будемо зберігати лаби та лекції ods у git. Лише в базі Монго. Бо репозиторій можливо стане публічним»; замінює «контент у два етапи» з T164):
  - до бази — md-файли на диску поза git (`sites/ods/data/` у `.gitignore`), синк — Dropbox;
  - знімка контенту в git, як `data/guide/` методички python, не буде;
  - версії для викладача — теж лише в базі.
- **Репо може стати публічним:** у `.dev` нічого з розвʼязків і змісту лекцій та лаб.
- **Код базового варіанта** пише модель Opus 5.5, окремим запитом Vitalik.

## Де що лежить

```text
sites/ods/
├── data/                 # поза git, до переїзду в Mongo
│   ├── lectures/         # README.md, NOTES.md, lec01…lec15: lecNN.md + img/
│   └── labs/             # README.md, lab1…lab5: labN-student.md + img/
│                         # для викладача: NOTES.hid.md, labN-teacher.hid.md,
│                         #                lab4-correction.hid.md, img/*.hid.*
└── orig/                 # поза git: pptx/, docx/
```

- Коду сайту ще нема: `sites/ods/api/` і `sites/ods/vue/` зʼявляться з базовим варіантом.
- Опис формату md — у README поруч із даними: [лекції](../../sites/ods/data/lectures/README.md), [лаби](../../sites/ods/data/labs/README.md).

## Правила роботи з контентом

- Контент лекцій і лаб у git не комітиться — ні файлами, ні знімком, ні цитатами в `.dev`; імпорт у базу — скриптом, що читає файли з диска.
- Нове для викладача — одразу з `.hid.` у назві: так його легко відділити від студентської версії при імпорті в базу.
- Перед комітом — `git status`: нічого з `sites/ods/` крім коду.
- Авторський текст лекцій і лаб не виправлявся. Правки змісту — лише за рішенням Vitalik; підказки, де дивитися, — у `NOTES.md` і `NOTES.hid.md`.

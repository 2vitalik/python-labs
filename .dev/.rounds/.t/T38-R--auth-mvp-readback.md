## Що я почув

- **Перша кодова задача — мікро-MVP:** маленька, простенька, «пустенька» перша версія застосунку. Тільки мінімальна сторінка + авторизація; все інше — потім.
- **Інтерфейс:** мінімалістичний, «як у Bootstrap»; шапка-менюшка + головна сторінка.
- **Головна:** текст-заглушка «це майбутня система…; щоб отримати доступ — авторизуйтесь».
- **Вхід:** Google OAuth, дозволена лише пошта @nure.ua.
- **Модель доступу (на потім, не в цій задачі):** реальний доступ — лише студентам груп, яких навчаєш; інші — можливо, read-only перегляд; частина сторінок може бути публічною без авторизації взагалі; авторизація — насамперед для участі в курсі.
- **Стек — сумнів:** Django відпадає через привʼязку до реляційної БД; «дуже хочу MongoDB»; питання — чи Vue + FastAPI найкращий вибір у такому разі.
- **Код-стайл:** любить дуже зрозумілий, лаконічний код, «нібито сам писав» — просить це десь явно зафіксувати.
- **Запит до мене:** поставити необхідні питання для плану + подумати, що міг не врахувати навіть для цієї малої задачі; перша версія має вийти «майже ідеальною»: лаконічна, коротка, дуже зрозуміла.

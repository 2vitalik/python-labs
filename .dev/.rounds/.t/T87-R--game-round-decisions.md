## Пакет рішень

- **Обʼєктна модель прийнята повністю** (T84, всі «a»):
  - три шари «каталог → обʼєкти гри → заявки»; обʼєкт — якір заявок і скриншотів (Q1a);
  - v1 стартує з **вікна + меню**; сутності/рівні — наступною фазою (Q2a);
  - вікно — лише від типу з каталогу; нестандартне — через `custom-window` з ручною ціною (Q3a);
  - пункт меню — дія на вибір: `→ вікно` / `→ функція-заявка` / текст (Q4a) — граф переходів буде;
  - докази `none / screenshot / gif / link` — атрибут картки каталогу (Q5a);
  - GitHub — гібрид: поле опційне, обовʼязкове для ⭐/золота, нормалізація в коміт-пін (Q6a);
  - старт без монетної математики: ціни довідково, [T08](../../grading/.t/T08-Q--grading-open-questions.md) не блокує (Q7a);
  - сид чернеток «елементи налаштувань» + типи вікон — так, ревізія в адмінці (Q8a).
- **Механіки** (T86):
  - **Q1c — драбина формальності потребує глибшого обговорення: окрема сесія-розмова** до впровадження рівнів 1–2; напрям «без DSL» не відкинуто, але й не затверджено;
  - таблиця взаємодій як перша структура — так, після сутностей у «Моїй грі» (Q2a); конкретика — в сесію з Q1c;
  - слоти параметрів: спершу формат на 2–3 картках-прикладах, «топ-20» — після «ок» (Q3a); приклади готую до/в межах тієї ж сесії механік;
  - сімʼї редактора/магазину — засіяти чернетками зараз, разом із налаштуваннями (Q4a).
- **Процес:** пілот робимо етапами по сесіях (розклад — нижче); уточнення — питати обовʼязково.

## План етапів пілота

1. **A — каталог-підготовка** (ця сесія): чернетки — сімʼя «елементи налаштувань» + функції, типи вікон, діти редактора/магазину; задача — [T88](../../tasks/.t/T88--catalog-objects-seed/plan.md).
2. **B — «Моя гра» v1, дизайн + бекенд:** P-тікет (моделі гри/обʼєктів/заявок, API, завантаження скриншотів) → «ок» → код. Концептуальні питання до дизайну — [T89](../../platform/.t/T89-Q--my-game-questions.md).
3. **C — фронт:** сторінка «Моя гра» — вікна (тип + назва + скриншот + чіпи елементів + автопідказки функцій), меню з пунктами й діями.
4. **D — паспорт гри:** галерея вікон, довідковий монетний підсумок, граф переходів; твій клік-тест.
5. **E — сесія-обговорення механік** (T86 Q1c): драбина глибше, приклади слотів, словник наслідків таблиці взаємодій.
6. **Далі:** заявки-гаманець і черга перевірки (потрібні відповіді [T10](../../reports/.t/T10-Q--reports-open-questions.md) Q1–Q2) → докази gif/лінки → механіки за підсумками E.

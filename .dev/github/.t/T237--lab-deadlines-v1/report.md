## Зроблено

- **Моделі ядра** `core/api/core/models/deadline.py` (`Deadline`, `LabMark` — унікальна пара user+lab), `models/repo.py` (`Commit`, `Repo` з журналом комітів, `Review`); у `db.MODELS`.
- **Логіка** `core/labs.py`: `due_for` (група перемагає «для всіх»), `effective` (подовження перемагає базовий), `facts` (до / у вікні лаби / після, останній до дедлайну), `state` (слово викладача → звіт → факти), `cell`, `Index` (усе для матриці одним читанням). `stale` звіту — за префіксом sha: короткий з `cut` і повний — один коміт. Наївний UTC з Mongo й aware з запиту зводяться `utc()`/`naive()`, щоб `history` бачила лише справжні зміни.
- **Слово викладача** `core/lab_marks.py`: `set_mark` — upsert, `history`, алерт 📅 `due` лише коли щось змінилось (повторне те саме — тиша); `parse_due` — `5.11`, `05.11.26`, `2026-11-05`, `2026-11-05 18:35` → Київ, кінець дня без часу.
- **Git** `core/repos.py` (stdlib): `pull` (clone або fetch + `set-head` + `checkout --detach origin/HEAD`, `set-url` при зміні посилання, SSH `BatchMode`), `head`, `log` (committer/author час, перший рядок, `--shortstat`), `cut` (`rev-list --before`), `checkout` (`worktree add`); помилки GitHub — короткими словами для викладача.
- **API** `routes/labs.py`, `routes/student_labs.py` (усе — `editor_user`: адмін і агент): `GET /api/labs`, `PUT /api/labs/{n}/deadline` (та сама множина груп = той самий документ), `DELETE /api/labs/deadlines/{id}`, `GET /api/students/{nick}/labs`, `PUT …/labs/{n}` (надіслані поля = задані, `until: null` чистить), `GET|PUT …/labs/{n}/review` (той самий звіт повторно — без історії), `PUT /api/repos` (пачкою, перезапис без історії). `deps.lister` — `GET /api/students` відповідає агентові як адміну. `LABS` у `config.py` (5).
- **Бот** `core/bot/due.py` — `/due` у трьох місцях, ефемерна в меню команд; `notes.vanish` винесено з `/hide` і спільне для обох; вид `due` у `notify.KINDS` після `week`.
- **`bin/repos`**: `sync` (діф з минулого разу) · `pull` (6 паралельно, `.seen/<нік>.json` — коли коміт побачили вперше, `.state.json` — помилки) · `status` · `push` · `cut <N> [--checkout]` · `reviews` (шапка `key: value` між `---`). `data/repos/`, `data/reviews/` — у `.gitignore`.
- **Фронт ядра**: `labs.js` (стани, дати, опис клітинки), `pages/DeadlinesPage.vue` (чіпи груп і станів у `?group=`/`?state=`, форма дедлайну, на всю ширину), `components/LabMatrix.vue` (групи згортаються, 🐙, редактор під рядком, Σ без «—»), `LabCell.vue`, `LabEdit.vue` (подовження · вердикт · нотатка · звіт), `LabReport.vue` (Markdown через `renderMd`), `DeadlineForm.vue` (список дедлайнів лаби, чіпи груп), `StudentLabs.vue` (картка «Лаби» на `/students/<нік>/edit`). Сайт python: маршрут `/deadlines` (admin, wide, filters), пункт меню «Дедлайни».

## Хвости

- Факти `window` рахуються від ефективного дедлайну попередньої лаби того ж студента — подовження лаби 1 зсуває вікно лаби 2; свідомо.
- Клітинка з подовженням показує «→ дата» замість останнього коміту — факти в підказці й редакторі.
- `cut` бере committer-дату, як і `facts` на сайті; `authored` зберігається, але сайт поки не підсвічує зсув.
- Якщо Vitalik захоче бачити подовження в стрічці `/activity` — рядки `history` для `lab_marks` є, назва колекції для стрічки не підписана (`site.colls`).

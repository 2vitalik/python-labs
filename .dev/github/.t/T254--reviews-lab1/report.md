## Як повторити для лаби N

1. `bin/repos auto` (клони свіжі, факти на сайті) → `bin/repos cut N --checkout` → `bin/repos facts N`.
2. Субагент на пару за [prompt.md](prompt.md); у виклику — нік, група, дедлайн, короткий sha зрізу, комітів після, шляхи CUT/HEAD/facts/результатів; пачками ≤ 20, список недосланих тримати окремо.
3. `bin/repos digest N` → виправити розбіжності → `bin/repos reviews --dry` → погляд Vitalik → `bin/repos reviews`.

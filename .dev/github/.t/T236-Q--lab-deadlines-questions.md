**Q3 — Чи бачить студент свої стани й подовження.** Прозорість «зроби й набереш» каже «так»; поки лише адмін.
- a) так, блок «Лаби» в «Моїй грі» зі станом по лабах і подовженням, без звітів агента (рекомендую, окремим кроком);
- b) так, і короткий підсумок звіту агента теж;
- c) ні, лише викладач.

**Q4 — Дата коміту як доказ.** Git-дату студент може виставити будь-яку; GitHub час пушу не віддає. Щоденний `bin/repos pull` на твоєму ноутбуці (launchd) записує, коли коміт зʼявився у нас — верхня межа чесності.
- a) так, поставити щоденний `pull` (напр. 23:30) — додам plist за зразком mongodb-backup;
- b) поки руками, коли треба;
- c) чекати перенесення на сервер.

**Q6 — Що робити зі студентами без репозиторію чи без доступу.** Клітинки ⚠️/🚫 видно в матриці; дайджест вранці вже рахує тих, хто без GitHub.

## Хвилі

Кожна хвиля закінчується комітом, після якого збірка й смоуки цілі.

1. **Збір** — знімок сервера через API (лише читання), розбір справжніх даних по дедлайнах 1 і 2: що є, чому можна вірити, чого бракує.
2. **Модель** — джерела → факти → «випадок» (чітке так · чітке ні · пограничне, з кодом причини) → слово викладача; критерії й поблажка — пропозиція з виборами.
3. **Код** — обчислення випадку в ядрі, колонки у «Зводі», види «Дедлайн N · вердикт»; де зберігається слово й поблажка.
4. **Дані локально** — дев-база повторює сервер (дедлайни, подовження, опитування, репозиторії), щоб дивитись у дев-сайті.
5. **Чого бракує** — як спитати пограничних: тексти в чат по групах випадків, команда бота, кнопки — проєкт; код — за словом.
6. **Доки** — звіт, README вузла й кореня, CHANGELOG, STATUS, Q-тікет.

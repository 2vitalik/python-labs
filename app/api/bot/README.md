# Telegram-бот Python Labs — як користуватись

Бот `@python_nure_bot` — другий інтерфейс до тієї ж бази, що й сайт. Студенту він поки потрібен для одного кроку — привʼязати акаунт. Викладачу — це канал алертів про все, що відбувається на сайті, з налаштуванням прямо в Telegram.

## Запуск

- `TG_BOT_TOKEN` (від BotFather) і `TG_BOT_NAME` у `app/api/.env`; `SITE_URL` — публічна адреса сайту для посилань у повідомленнях.
- `cd app/api && uv run python -m bot` — long polling, вебхук не потрібен.
- Без запущеного бота теж працює: алерти шле сам API тим самим токеном. Потрібен запущений бот для: `/start`, `/here`, `/mute`, дзеркала ніка, ранкового дайджесту, алертів про помилки самого бота.

## Студент

| Що робить студент | Що робить бот |
| --- | --- |
| «Привʼязати бота» в профілі → `/start <токен>` | записує чат і `@username` у профіль, вітає на імʼя: «👋 Привіт, Василь! / ✔️ Дякую, записав тебе)» |
| той самий `/start` ще раз | «✔️ Тебе вже було записано раніше, дякую)» |
| те саме посилання з іншого Telegram | перепривʼязує на новий чат: «🔁 Раніше був інший Telegram — тепер писатиму сюди» |
| застаріле посилання (після «відвʼязати» на сайті) | «❌ Не впізнаю це посилання» + два кроки, як узяти нове |
| привʼязався без `@username` | «☝️ додай юзернейм» — інакше написати напряму не можна |
| будь-яке інше повідомлення | привʼязаному — «далі буде», чужому — інтро з посиланням на профіль |
| змінив або прибрав `@username` у Telegram | нік у профілі оновлюється з наступного повідомлення боту |

Відвʼязка — лише на сайті (кнопка «відвʼязати» в профілі): старе посилання одразу мертве.

## Викладач (адмін)

Спочатку — те саме «Привʼязати бота» у власному профілі. Відтоді всі алерти приходять особисто в чат із ботом; це вже робочий стан. Далі за бажанням — окремий чат або гілки форуму:

| Команда | Що робить |
| --- | --- |
| `/here` | куди зараз іде кожен вид алертів (з ключами видів) |
| `/here change` · `/here fill change` | названі види йдуть у чат або гілку, де написана команда |
| `/here all` | усі види сюди |
| `/here off` | цей чат чи гілка більше нічого не отримує; види повертаються в «особисто адмінам» |
| `/mute game` · `/mute claim game` | вид вимкнено зовсім («🔇 вимкнено»); увімкнути — `/here game` у будь-якому чаті |

- Команди слухає лише адмін із привʼязаним ботом; решта їх не бачить.
- Бота треба додати в групу; privacy mode вимикати не треба, у групах бот мовчить на все, крім команд.
- Вид привʼязаний до одного місця: повторний `/here` в іншій гілці перетягує його.
- Не вдалося доставити (бота вигнали, гілку закрили) — те саме повідомлення прийде особисто з рядком «⚠️ Не доставив у …».

## Види алертів

Шапка кожного алерту: емодзі рівня · що сталося · імʼя-лінк на сторінку студента · група. Рівень: 🟢 заповнено нове · 🟠 замінено наявне · 🔴 видалено; нижче — рядок на кожне змінене поле, «старе → нове», стерте — «→ ✖️».

| Вид | Коли приходить | Рядки |
| --- | --- | --- |
| `fill` 🟢 | студент заповнив порожні поля профілю, привʼязав бота | 🪪 ПІБ · 🐙 GitHub · ✈️ Telegram · 🤖 Бот |
| `change` 🟠🔴 | замінив або стер наявне, відвʼязав бота, перепривʼязав з іншого Telegram, змінив чи прибрав `@username` | ті самі |
| `login` 👋 | перший вхід на сайт; невідомий (не з імпорту) — з поштою і «статус «очікує»» | 📧 · ☝️ |
| `claim` 🎯 | заявка створена, відредагована, видалена | 🎯 картка · 🧩 обʼєкт · 📝 нотатка · 🔗 лінк · ⚙️ параметри |
| `game` 🧩 | картка гри створена або змінена; обʼєкт чи правило додано або видалено | 🏷 назва · 🕹 основа · 📄 опис · 🧩 обʼєкт · 📜 правило реченням |
| `error` 💥 | необроблена помилка API або бота (4xx — ні) | ❗ тип: текст · 📍 файл:рядок функція |
| `digest` 📊 | щодня о 09:00 (Київ): по групах, скільки без ПІБ, GitHub, бота; усе заповнено — тиша | 👥 група · 🪪 n · 🐙 n · 🤖 n |

```
🟢 Профіль · Пупкін Василь · ПЗПІ-25-1
🪪 ПІБ: Пупкін Василь Іванович
🐙 GitHub: github.com/vasya/labs
```
```
🔴 Профіль · Пупкін Василь · ПЗПІ-25-1
🤖 Бот: відвʼязано
✈️ Telegram: @vasya_tg → ✖️
```
```
🟢 Гра · Пупкін Василь · ПЗПІ-25-1
📜 КОЛИ «Гравець» × «Ворог» → ТО шкода 3 · спавн «Гравець»
```
```
💥 API · PUT /api/profile · vasya
❗ ValueError: boom
📍 routes/profile.py:31 update_profile
```
```
📊 Профілі не заповнені · студентів: 58
👥 ПЗПІ-25-1 · 🪪 2 · 🐙 7 · 🤖 9
☝️ 🪪 ПІБ · 🐙 GitHub · 🤖 бот
```

Не алертиться: правки адміна (`/students/…`, імпорт), редагування обʼєктів і правил гри (лише створення й видалення), скриншоти, помилки 4xx.

## Де що в коді

- `texts.py` — відповіді студентам у стилі T109; `start.py` + `link.py` — `/start` і привʼязка.
- `notify.py` — `KINDS` (новий вид = один рядок) і `send()`; `here.py` — `/here`, `/mute`; маршрути — колекція `routes` у Mongo.
- `alerts.py` (профіль, перший вхід), `game_alerts.py` (заявки, гра), `errors.py`, `digest.py` — тексти й обробники; хуки у `routes/profile|me|auth|my_*.py`.
- Смоуки без Telegram: `DB_NAME=python_labs_smoke uv run python tests/smoke_bot.py` · `smoke_notify.py` · `smoke_events.py`.
- Тікети: T58 (привʼязка), T106 (пустишка), T109 (стиль), T111 (алерти, `/here`), T113 (заявки, гра, помилки, дайджест, `/mute`).

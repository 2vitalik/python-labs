## Куди додавати нове

- Нова гра відомого класу → свій файл + рядок у відповідну таблицю.
- Ідея механіки без гри → у «Можливості» найближчої гри або одразу в зону [tasks/](../tasks/README.md).
- Донори механік без власного файла (Chip's Challenge, Into the Breach, NecroDancer тощо) — див. ресерч-каталог `.dev/games/.t/T32-C--grid-games-catalog.md`; файл заводиться, коли гра стає кандидатом у приклади.

# wiki — база знань контенту курсу

Чернетковий простір «що студенти зможуть робити»: ігри та ігрові можливості до того, як вони стануть канонічним каталогом завдань. Вільний Markdown, редагують усі (Vitalik + агент), історію тримає git — папок-версій нема.

Межа з `.dev/`: те, що колись побачить студент у каталозі, — тут; те, як ми будуємо систему (рішення, тікети), — у `.dev/`. Походження структури: `.dev/.t/T51-P--kb-structure.md`, рішення — `.dev/.rounds/.t/T54-R--kb-round-decisions.md`.

## Гілки

- [games/](games/README.md) — ігри, класи, варіації: одна гра = один файл; карта класів і осей — [games/_classes.md](games/_classes.md).
- [tasks/](tasks/README.md) — ігрові можливості й завдання по зонах: одна зона = один файл; карта зон — [tasks/_map.md](tasks/_map.md); сировина зі старих систем — [tasks/_v3-raw.md](tasks/_v3-raw.md).

## Конвенції

- Імена файлів EN-kebab, вміст UA; `_`-префікс — службові карти гілки, не одиниці контенту.
- Файл виріс за ~200 рядків → розгортається в папку з підфайлами.
- Зведення джерел: тіло файла — єдиний зведений текст (веде агент); швидкі вкиди — у секцію «Сире» внизу файла або просто в чат, агент вплавляє і чистить буфер.
- Зрілість файла в індексі README гілки: 💭 чернетка · 🌿 зводиться · ✅ стабільне (готове до конвертації в каталог).
- Пункт-завдання скрізь однією граматикою: `- **коротка назва** — пояснення (лише якщо неочевидно)`; маркери в кінці рядка: ⭐ — алгоритмічне золото, `` `гра` ``/`` `клас` `` — застосовність; без маркерів = універсальне.

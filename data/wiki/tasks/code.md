# Код і платформа

Якість і влаштування коду — класонезалежна зона. Куроване ядро; беклог — [_v3-raw.md](_v3-raw.md) § code.

## Архітектура

- **розділення логіки і рендера** — двіжок не знає, консоль це чи GUI (вимога спільного двіжка)
- **два фронтенди на одному двіжку** — консоль + GUI перемикаються
- **стан гри як дані** — серіалізований стан (основа збережень і replay)
- **цикл tick/update/render** — явний ігровий цикл

## Python-фічі

- **типізація** — анотації + перевірка mypy
- **dataclass-сутності** — моделі елементів поля
- **генератори та ітератори** — обхід поля, хвилі
- **виключення** — власні класи помилок, охайна обробка
- **стандартні колекції** — deque для тіла змійки, heapq для A* `snake`

## Тести

- **юніт-тести логіки** — рух, взаємодії, перемога без рендера
- **тест на рівнях-фікстурах** — мапа з очікуваним результатом
- **property-тести** — генератор завжди видає розвʼязне ⭐ `puzzles`

## Git

- **історія комітів** — осмислені повідомлення, без сміття в репо
- **README проєкту** — як запустити, керування, скриншоти
- **теги версій** — зріз на кожну лабораторну

## Пакування і запуск

- **requirements/pyproject** — відтворюване середовище
- **запуск однією командою** — `python -m game` без танців
- **збірка в exe** — pyinstaller для демонстрації без Python

# Stomp! — покроковий роглайк-платформер: 300 ходів, щоб тупотом і каскадами розбити якомога більше

## Суть
PICO-8-гра st33d: чоловічок іде праворуч крізь нескінченну смугу зі стін, каменів, землі й шипів, і за **300 ходів** має набрати найбільший рахунок. Головна дія — **тупіт** (вниз): удар проходить крізь увесь стовпець суцільних блоків під ногами, стіни стають каменями, камені розлітаються, бур-стіни випускають бури, бомби — вогняні кулі. Тупіт дає **лише половину очок**, тож гра штовхає будувати непрямі руйнування: скинути камінь на шипи, обвалити шип на скарб, підірвати бомбу каскадом. Світ стоїть, доки ти не ходиш; кожен успішний хід — мінус одиниця часу.

## Поле і час
- Квадратна сітка 8-піксельних клітин, вид збоку; екран 16 стовпців × 16 рядків, рядок 0 — HUD. Під екраном (рядок 16) — суцільний ряд шипів: впасти вниз = смерть.
- Поле генерується смугами по 8 стовпців: кожна смуга — два шматки 8×8 (верхній і нижній). Камера й межа рухаються **лише праворуч**: назад можна відійти не далі 6 стовпців від найдальшої точки, стовпці позаду стираються.
- Хід = одна дія гравця, потім фаза світу: камені падають/котяться, шипи без опори обриваються, бури, кулі й черви роблять по кроку. Заблокована дія (у стіну, стрибок у повітрі) ходу не витрачає.
- Гравець не падає сам: у повітрі кожна дія веде вниз (вниз — прямо, вбік — по діагоналі вниз), тож падіння теж коштує ходів.

| Стіна (2 скіни) | static | 10 очок | тверда; від удару стає каменем |
| Стіна з самоцвітом | static | 10 очок | від удару стає каменем-самоцвітом |
| Бур-стіна | static | 50 очок, напрям ← / → (видно одразу) | від удару випускає бур |
| Бомба-стіна | static | 80 очок | від удару вибухає трьома вогняними кулями |
| Земля (2 скіни) | terrain | 0 очок | гравець прокопує її, заходячи в клітину; бур і кулі руйнують |
| Камінь (2 скіни) | object | 20 очок | падає по 1 клітині за хід; скочується з іншого каменя по діагоналі; штовхається ланцюгом |
| Камінь-самоцвіт | object | 500 очок | як камінь |
| Шип | hazard | — | вбиває того, хто входить у клітину згори (гравця, камінь); без опори обривається |
| Падаючий шип | projectile | 1 клітина/хід | влітає в клітину під собою, б'є її вміст, на твердому розбивається |
| Бур | enemy | напрям | їде вбік по 1 клітині; руйнує вміст клітини, куди в'їхав (гравця теж); у стіну — розворот; без опори — падає |
| Вогняна куля | projectile | напрям | летить по прямій 1 клітина/хід; б'є вміст клітини, на першому твердому гасне |
| Черв'як | neutral | 0 очок | лише падає, коли під ним порожньо |
| Золотий черв'як | neutral | 1000 очок | як черв'як; впав за нижній край → очки; з'являється, лише коли часу ≤ 150 |
| Ряд шипів під екраном | hazard | — | смерть усьому, що падає за поле |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(left|right)` → ЯКЩО `supported(player)` і `free(side)` → ТО `move(player, dir)`, `counter(time, -1)`.
- КОЛИ `input(left|right)` → ЯКЩО `not supported(player)` і `free(side)` і `free(side_below)` → ТО `move(player, diag_down)`, `counter(jump, =0)`.
- КОЛИ `input(dir)` → ЯКЩО `occupied(target, dirt)` → ТО `disappear(dirt)`, `move(player, dir)` — копання й крок за один хід (угору — лише не в падінні).
- КОЛИ `input(up)` → ЯКЩО `free(above)` і (`supported(player)` або `counter(jump, <, 3)`) → ТО `move(player, up)`, `counter(jump, +1)`; інакше `block` (хід не витрачено).
- КОЛИ `input(left|right)` → ЯКЩО `occupied(side, rock)` → ТО `push` — ланцюг каменів зсувається, якщо за останнім не стіна; інакше `block`.
- КОЛИ `input(down)` → ЯКЩО `occupied(below, wall|rock)` → ТО `custom: «тупіт: удар іде вниз по всіх суцільних клітинах підряд, кожну — hit; гравець лишається на місці»`, `shake`.
- Таблиця удару (`hit`): стіна → `transform(wall, rock)`, `score(10)` · стіна з самоцвітом → `transform(gem_wall, gem_rock)`, `score(10)` · камінь → `disappear(rock)`, `score(20)` · самоцвіт → `disappear`, `score(500)` · бур-стіна → `spawn(drill)`, `score(50)` · бомба-стіна → `explode(3 fireballs)`, `score(80)` · земля → `disappear`, 0 · гравець → `lose`.
- КОЛИ удар нанесено тупотом → ТО `custom: «очки ×½»`; будь-яке інше руйнування (шипи, бур, кулі, падіння) — повні очки.
- КОЛИ `turn_end` → ЯКЩО `not supported(rock)` → ТО `fall(rock)` на 1 клітину; ЯКЩО `occupied(below, rock)` і вільна діагональ → ТО `roll(rock)` у випадковий бік.
- КОЛИ `custom: «камінь падає на гравця»` → ТО `block` — камені не чавлять, лише зупиняються.
- КОЛИ `enter(player|rock, spike)` → ЯКЩО `moving(_, down)` → ТО гравець — `lose`; камінь — `disappear(rock)`, `score(20|500)`.
- КОЛИ `turn_end` → ЯКЩО `not supported(spike)` → ТО `transform(spike, falling_spike)`; далі щоходу `fall` + `hit` клітини, куди влетів; ЯКЩО `occupied(cell, wall|rock)` → ТО `disappear(falling_spike)`.
- КОЛИ `turn_end` → ТО бур: `hit` своєї клітини; ЯКЩО попереду земля → `disappear(dirt)`; ЯКЩО попереду стіна → `face(drill, opposite)`; ЯКЩО знову стіна → `fall(drill)`; інакше `move(drill, dir)` і `hit` нової клітини.
- КОЛИ `explode(bomb)` → ТО `spawn(fireball)` ×3 — в усі боки, крім напрямку назад до того, хто вдарив (від тупоту — ліворуч, праворуч, униз).
- КОЛИ `turn_end` → ТО куля: `move(fireball, dir)`, `hit` клітини; ЯКЩО `occupied(cell, wall|rock)` → ТО `disappear(fireball)` — бомба на шляху кулі вибухає ланцюгом.
- КОЛИ `turn_end` → ЯКЩО `not supported(worm)` → ТО `fall(worm)`; КОЛИ `edge(gold_worm)` (впав за нижній край) → ТО `score(1000)`.
- КОЛИ `custom: «гравець просунувся праворуч»` → ТО `custom: «стерти стовпці далі ніж 8 позаду, згенерувати нову смугу 8×16 попереду»`.
- КОЛИ `counter(time, =, 0)` → ТО `game_over` («time out»); КОЛИ `died(player)` → ТО `game_over` («death»).
- Перемога: нема — гра на рекорд. · Поразка: смерть або кінець 300 ходів (обидва завершують забіг з рахунком). · Рахунок: таблиця вище; рекорд зберігається між запусками.

## Керування і ввід
- ← / → — крок (у повітрі — по діагоналі вниз); ↑ або O (Z) — стрибок на клітину вгору (до 3 підряд); ↓ або X — тупіт / спуск / копання вниз.
- Титул: O — **careful mode** (одне натискання = один хід), X — **smooth mode** (затиснута клавіша повторює хід).
- Після смерті: O або X — новий забіг.

## Вікна, меню, HUD
- `splash-screen` / `mode-select`: логотип, «300 turns to score your best and die trying», «O: careful mode», «X: smooth mode».
- `game-screen`: поле; на старті — панель-підказка walk / jump / stomp з іконками кнопок; HUD — `score` (5 цифр, ліворуч), `turn-counter` (лишилось ходів, праворуч); рамка поля темно-червона при ≤ 100 ходах і червона (з червоними цифрами) при ≤ 50; `popup-text` очок над зруйнованим; трясіння екрана від тупоту й вибухів.
- `end-screen`: шторки закриваються; причина («death» / «time out»), «score: N» і «new best!» або «best: N», «press O or X to restart».
- Переходи: splash → (O/X) забіг → смерть/час → end-screen → (O/X) новий забіг.

## Фічі поза полем
- `leaderboard-local` з одним рядком: найкращий рахунок у cartdata, позначка «new best!».
- Два режими вводу (careful / smooth) — без зміни правил.
- Генерація: колода шматків 8×8 — порожній старт → стартові → 2 навчальні → по 3 з чотирьох рівнів складності ручної роботи → процедурні; з рівня складності «3+» у кожній руці 1 ручний шматок і 3 процедурні впереміш.
- Процедурний шматок: квоти стін, шипів, порожнечі, землі, черв'яка, золотого черв'яка (коли часу ≤ 150), самоцвітів, бур-стін (після 9-го шматка), бомб (після 15-го), решта — камені; гарантована «наскрізна лінія» порожніх клітин зліва направо з одним вертикальним коліном.
- Ерозія: кожен новий нижній шматок отримує ще одну вибиту клітину (до 64) — нижня половина поля з часом дірявіє, падіння в шипи ймовірніше.
- Санітарія генерації: шип, камінь чи черв'як без опори, а також камінь, що одразу скотився б, замінюються землею.
- Нема undo, паузи-меню, рівнів.

- Осі варіацій:
  - **руйнування**: удар по одній клітині / тупіт крізь стовпець (Stomp!) / вибух площею;
  - **очки**: за все однаково / штраф за пряме, бонус за непряме (Stomp!: ½ за тупіт);
  - **падіння гравця**: автоматичне / лише за вводом, коштує ходів (Stomp!);
  - **ліміт**: життя / ходи (300) / час.

## Цікавинки для курсу
- Тупіт крізь стовпець + таблиця реакцій «удар → що стає з клітиною» (стіна → камінь, бомба → кулі) — 📎: словник реакцій і цикл униз.
- Фаза світу після ходу: камені падають і скочуються з каменів, шипи обриваються й падають, бури й кулі крокують — порядок оновлення важливий — 🥉.
- Ланцюгові вибухи: куля б'є бомбу, бомба — нові кулі без зворотного напрямку — 🥉.
- Нескінченне поле з колоди шматків 8×8 (ручні + процедурні з квотами і гарантованим проходом) і поступова ерозія дна — 🥈.
- Стрибок як лічильник 0–3 і «падіння за вводом» по діагоналі — 🌱.
- Ліміт 300 ходів + рекорд у збереженні + бонус за непрямі руйнування — 🌱.

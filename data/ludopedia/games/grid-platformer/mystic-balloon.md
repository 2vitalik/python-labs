# Mystic Balloon — відьмочка піднімає магією кульки й батути, будує з них сходи до магічного кола

## Суть
Безкоштовна японська екшн-головоломка для Windows: відьма Містія застрягла в механічному особняку і на кожній стадії має дійти до **магічного кола**. Вона вміє дві речі — **стрибнути на одну клітину** і **підняти магією обʼєкт перед собою** (кульку чи батут), нести його й поставити попереду. Ворогів нема: виклик — порядок дій серед льоду, конвеєрів, хмар, що зникають, ґрат, що зачиняються за спиною, і дверей на ключі. Помилка робить стадію нерозвʼязною — тоді рестарт з меню.

## Поле і час
- Квадратна сітка клітин («マス»), вид збоку, одна стадія — один екран (?).
- Real-time без ліміту часу (гра йде на 40 FPS); є гравітація для Містії й обʼєктів, після приземлення — коротке заціпеніння, коли рухатись не можна.
- Шари: блоки й механізми поля + обʼєкти (кульки, батути) + предмети (ключі, магічні кулі) + персонаж.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Містія | player | несе 0/1 обʼєкт; ключі ≤ 99 | ходить, стрибає на 1 клітину (з місця чи по діагоналі), піднімає/ставить обʼєкт, лазить драбиною |
| Кулька (バルーン) | object | — | піднімається й переноситься; головне — бути сходинкою; падає без опори |
| Батут (ジャンプ台) | object | висота 3 / 2 з ношею | стати → стрибок до 3 клітин (з ношею — до 2); обʼєкт на ньому не підскакує; теж переноситься |
| Ключ | pickup | ≤ 99 у запасі | відкриває двері |
| Магічна куля | pickup | — | зібрано всі → ґрати назавжди відчинені, бар'єр-блоки зникають |
| Блок | static | — | звичайна опора |
| Лід | terrain | — | крок убік → проковзує ще на клітину; розвертатися на місці не можна; зупиняє перешкода або приземлення згори |
| Конвеєр | terrain | напрям стрілки | несе Містію, якщо попереду вільно; обʼєкти не везе (JA-вікі) |
| Бар'єр-блок | gate | — | як блок, зникає, коли зібрано всі магічні кулі |
| Блок «без стрибка» | terrain | — | стоячи на ньому, стрибати не можна (Містія блимає білим) |
| Драбина | static | — | лазіння ↑/↓; з ношею — не можна; ставити обʼєкт на драбину не можна |
| Хмара | terrain | — | зникає, коли зійти з неї (і при стрибку вгору з неї); розбивається ударом голови знизу |
| Двері | gate | — | відчиняються дотиком збоку з ключем (ключ витрачається); на них можна стати |

| Магічне коло | static | — | вхід з будь-якого боку, навіть з ношею → стадію пройдено; обʼєкт на нього не поставити |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(left|right)` → ЯКЩО `free(side)` → ТО `move(mistia, dir)`; на льоду → `slide` ще на 1 клітину, якщо вільно.
- КОЛИ `input(Z)` → ЯКЩО `not has(mistia, object)` і `free(above)` і `not cell(under, no_jump)` → ТО `custom: «стрибок на 1 клітину вгору»`; з напрямком під час замаху → `custom: «стрибок по діагоналі: 1 угору, 1 убік»`.
- КОЛИ `input(X)` → ЯКЩО `not has(mistia, object)` і `occupied(front, balloon|jumppad)` і `custom: «шлях підйому вільний»` → ТО `pickup`, `carry`.
- КОЛИ `input(X)` → ЯКЩО `has(mistia, object)` і `free(front)` і `not cell(front, ladder|goal)` → ТО `place(object, front)`, `fall(object)`.
- КОЛИ `custom: «під обʼєктом порожньо»` → ТО `fall(object)`; падаючий обʼєкт можна перехопити підйомом у повітрі (техніка гравців).
- КОЛИ `enter(mistia, jumppad)` → ЯКЩО `free(above)` → ТО `custom: «підкидає на 3 клітини, з ношею — на 2»`; ЯКЩО над головою перешкода → ТО батут «запечатаний», доки з нього не зійти.
- КОЛИ `enter(mistia, conveyor)` → ЯКЩО `free(next)` → ТО `move(mistia, arrow_dir)`; зійти — лише стрибком.
- КОЛИ `leave(mistia, cloud)` → ТО `disappear(cloud)`; КОЛИ `blocked(mistia)` при стрибку знизу в хмару → ТО `disappear(cloud)`.
- КОЛИ `contact(mistia, door)` збоку → ЯКЩО `has(mistia, key)` → ТО `take(mistia, key)`, `disappear(door)`; інакше `block`.
- КОЛИ `leave(mistia, cage)` → ТО `custom: «ґрати зачиняються»` → далі `block`; ЯКЩО `has(mistia, object)` → ТО прохід `block` завжди.
- КОЛИ `enter(mistia, key|ball)` → ТО `pickup`; ключів понад 99 не рахує.
- КОЛИ `all_gone(magic_ball)` → ТО `disappear(barrier)`, `custom: «ґрати назавжди відчинені»`.
- КОЛИ `input(up|down)` → ЯКЩО `cell(here, ladder)` і `not has(mistia, object)` → ТО `move(mistia, up|down)`.
- КОЛИ `enter(mistia, goal)` → ТО `win`, `next_level`.
- Перемога: дійти до магічного кола (збирати все не обовʼязково). · Поразки нема: нерозвʼязний стан → меню RESTART. · Рахунку нема; є позначки пройдених стадій.

## Керування і ввід
- ← / → — хід; ↑ / ↓ — драбина; Z — стрибок (з ← / → під час замаху — убік); X — підняти / поставити; Shift + ← / → — розворот на місці; Esc — меню.
- Меню: Z — вибір, X — скасування, ↑ / ↓ на виборі стадій — номер стадії ±.
- Службові: Ctrl — показ FPS, F — вікно / повний екран, C — звук вкл/викл; H на виборі стадій — підказка зі зірками складності.

## Вікна, меню, HUD
- `main-menu` (титул): NORMAL GAME · EDIT GAME (свої стадії й файли повторів) · END.
- `level-select`: STAGE (номер) або LOAD (файл стадії/повтору) · PLAY · TITLE · END; праворуч унизу — скільки стадій відкрито й скільки не пройдено, пройдені позначені монеткою.
- `game-screen`: стадія; HUD — кількість ключів (?).
- `pause-menu` (Esc): EXIT (продовжити) · RESTART · SELECT · TITLE · END.
- `hints-window` — підказка до стадії за H.
- Кінцівка після стадії 50; бонусна область 51–55 відкривається після неї.
- `editor-window` — окрема програма `mysbaledit.exe`.
- Переходи: титул → вибір стадії → стадія → коло → вибір стадії; Esc → меню.

## Фічі поза полем
- 50 офіційних стадій в областях по 4 (лід, конвеєри…); пройдена будь-яка одна стадія області відкриває наступну область — застряглу стадію можна пропустити.
- `autosave` прогресу (пройдені стадії) у файл `mysbal.rec`; переноситься між версіями копіюванням файла.
- `level-editor`: мишею — палітра частин, розстановка (протягуванням — серія), піпетка (ПКМ), стирання (подвійний клік); BGM, початковий напрямок, графіка частин; обовʼязкові персонаж і коло; кульок і батутів разом ≤ 20; файли `.krm`; позначка «пройдено».
- `level-sharing`: BBS автора для обміну стадіями — понад 2000 стадій гравців (2015).
- `replay`: відтворення файлів повторів у EDIT GAME (запис — у ver.Circus).
- Секрети: Shift+M — грати маскотом «ちび叉»; Shift+E — пропуск до кінцівки.
- Undo нема; таймера нема.

## Варіації й родичі
- **ver.Circus (2015)**: героїні Pecorro і Shan з дзвоником замість кола; блок «магічна печатка» (не можна піднімати й ставити, але стрибати можна); ON/OFF-блоки з перемикачами; мотузяні драбини на один раз; одноразові батути (буріють); панелі розвороту конвеєрів; ліфти (червоний розвертається від хибного вводу); стопори обʼєктів; парні варп-зони; ручки дистанційного керування; висхідні потоки; 40 досягнень; запис повторів.
- Родичі: Block Dude (несеш один блок над головою), Catrap, Boxboy (сам твориш сходинки), Solomon's Key (магія блоків), Fire 'n Ice (лід і стрибок на 1).
- Осі варіацій:
  - **що несеш**: блок-сходинку (Block Dude) / сходинку або батут (Mystic Balloon);
  - **стрибок**: 1 клітина / батут 3 / без стрибка з ношею;
  - **одноразові клітини**: хмара (зникає), ґрати (зачиняються), мотузяна драбина (Circus);
  - **глобальний ключ**: зібрати всі кулі → змінюється поле.

## Пропозиції до словників
- `+effect:jump(a, h)` — стрибок на висоту h (Mystic Balloon: 1 / батут 3 / з ношею 2); відмінне від `move`.
- `+trigger:land(a)` — приземлення після падіння (лід, заціпеніння, батут).
- `+feature:area-unlock` — розблокування області за будь-яку одну пройдену стадію.
- `+card:jump-pad`, `+card:close-behind-gate`, `+card:crumble-after-leave`, `+card:catch-falling-object` — див. вище.

## Непевне
- (?) Чи стадія завжди в один екран і розмір сітки — у джерелах нема.
- (?) Де саме Містія тримає обʼєкт (над головою — за Vector, «ймовірно») і що таке «шлях підйому» точно.
- (?) Чи кулька справді просто падає (назва «повітряна кулька» натякає на політ, але довідка й історія версій говорять про «падаючі обʼєкти»).
- (?) Ключі й магічні кулі: довідка каже «обʼєкти не накладаються», а техніки — що кульку чи батут можна поставити «на» предмет; як саме — не ясно.
- (?) HUD (лічильник ключів, номер стадії) — не описаний.
- (?) Мобільний порт (Vアプリ) — лише згадка в JA-вікі.

# Ligo — бічний Sokoban-платформер: зливай і розрізай білих істот, неси блоки й розчавлюй кальмарів вагою

## Суть
Покроковий бічний пазл-платформер Anthony Berleur (три роки розробки, «adventure Sokoban»): спершу ти керуєш однією маленькою білою істотою, далі кількома, що ходять **синхронно**. Головна дія — **розчавити кальмарів**, упавши на них чимось важчим, а ключ до цього — **вага**: одна істота легша за кальмара, дві злиті вже важчі, куб важчий за дві, три злиті — важчі за куб. Істоти **зливаються** при дотику в довше або вище тіло й **розрізаються** односторонніми деревʼяними платформами; блоки штовхають і носять, а пізніше **промені гравітації** перевертають «низ» для героя й блоків. Увесь світ — один нелінійний мегарівень з телепортами, секретами й мета-пазлами.

## Поле і час
- Бічний вид, квадратна сітка: кам'яні острівці, лози, деревʼяні містки на зоряному тлі; кожна секція світу при вході ізольована.
- Гравітація: усе без опори падає; напрям гравітації — властивість кожної сутності (промені його перевертають), тож перевернуті кальмари й блоки можуть «висіти» й давити одне одного в повітрі.
- Хід = дія гравця (крок, лазіння, взяти або покласти); падіння докручуються автоматично.
- Розвʼязана секція «оживає» кольором, а її лози й платформи лишаються для руху світом.

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(dir)` (← або →) → ЯКЩО `free(next_cell)` → ТО `move(body, dir)` — усі підконтрольні тіла роблять крок синхронно.
- КОЛИ `input(up|down)` → ЯКЩО `cell(body_cell, vine)` → ТО `move(body, up|down)`; на бруньці вгорі лози можна стояти.
- КОЛИ `turn_end` → ЯКЩО `not supported(a)` → ТО `fall(a)` у бік своєї гравітації — для тіл, кубів, кальмарів, статуй.
- КОЛИ `contact(body, cube)` → ЯКЩО `free(cell_behind)` → ТО `push`.
- КОЛИ `input(grab)` → ЯКЩО `occupied(next_cell, cube)` → ТО `carry(body, cube)`; повторно — покласти (?).
- КОЛИ `adjacent(creature_a, creature_b)` → ТО `attach(a, b)` — тіло вдвічі довше або вище, залежно від сторони дотику.
- КОЛИ `custom: «тіло частково проходить односторонню деревʼяну платформу»` → ТО `split(body)` — так «нарізають» вежу чи хробака потрібної довжини (?).
- КОЛИ `contact(falling_a, squid)` → ЯКЩО `custom: «вага A більша за вагу кальмара»` → ТО `disappear(squid)`; ваги: 1 істота < кальмар < 2 злиті < куб < 3 злиті.
- КОЛИ `enter(a, gravity_beam)` → ТО `set_state(a, gravity_flipped)` — «низ» сутності перевертається (герой і блоки).
- КОЛИ `all_gone(squid)` → ТО `win` (?) — секцію розвʼязано, світ розфарбовується.
- КОЛИ `enter(body, teleporter)` → ЯКЩО `not state(body, gravity_flipped)` → ТО `teleport(body, other_teleporter)`.
- КОЛИ `enter(body, teleporter)` → ЯКЩО `state(body, gravity_flipped)` → ТО `custom: «вийти в перевернуту частину світу»`.
- КОЛИ `custom: «фінальний пазл світу»` → ЯКЩО `custom: «з усіх кубів, істот і себе складено задану фігуру»` → ТО `message(lore)`.
- КОЛИ `input(undo)` → ТО `undo(1)`.
- КОЛИ `input(reset)` → ТО `restart`.
- Перемога: секцію розвʼязано (кальмарів розчавлено; іноді блок скинуто на гриб (?)). · Поразка: нема — глухий кут відкочується. · Рахунок: нема; прогрес — розфарбовані секції, лор, секретні світи.

## Фічі поза полем
- `undo` і `restart-level` (reset); кілька патчів лагодили швидкий undo й reset.
- `world-map`: нелінійний взаємопов'язаний світ, телепорти, «повернутися до телепорта» з меню; розвʼязані секції лишають лози й платформи.
- `skip-level`: важкі рівні можна оминути, але частина обовʼязкова для проходу.
- `save-progress`: збереження при вході в рівень (патч 1.1.1), Steam Cloud.
- Секрети: 4 приховані «misery»-світи (підказки на табличках), мета-пазл кожного світу; 8 досягнень; англійська й французька.

## Варіації й родичі
- Демо в Steam (2023–2024, виставка Cerebral) → реліз 4.03.2025 → патчі 1.0.x–1.1.1 (ненавмисні розвʼязки, undo, збереження).
- Осі варіацій «кілька тіл в одному пазлі»:
  - **керування**: усі синхронно (тут) / по черзі з перемиканням (`party-switch`, [Snakebird](../thinky/snakebird.md));
  - **злиття**: нема / зчеплення при дотику в довше тіло (тут) / ріст від їжі (Snakebird);
  - **розʼєднання**: нема / одностороння платформа ріже тіло (тут);
  - **вага**: важить лише «є опора» / порівняння ваг для розчавлення (тут).

- (?) Темні привиди («обійняти»), статуї, блоки-промені — лише згадки без правил.
- (?) Сімʼя: у черзі гра стояла в `push-slide`, але бічний вид із гравітацією й лазінням — це `grid-platformer`.

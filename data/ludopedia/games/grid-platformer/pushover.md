# Pushover — переклади доміно так, щоб один поштовх повалив усі, і тригер упав останнім

## Суть
Мураха G.I. Ant бігає платформами й драбинами бічного рівня і переносить доміно по одному, щоб зібрати ланцюг. Потім — **рівно один поштовх**: усі доміно мають упасти без зіткнень, тригер — останнім і пласко, тоді відчиняються двері виходу, до яких мураха ще мусить дійти. Ядро — планування ланцюгової реакції з ~10 типами доміно (стопер, розщеплювач, вибуховий, затримка, кувальник, міст, зникаючий, висхідний, тригер). Гравець не діє під час реакції — він лише будує початковий стан.

## Поле і час
- Один екран, бічний вигляд, невидима сітка: платформи (рядки-«полиці»), драбини між ними, двері входу й виходу. Доміно стоять у клітинах полиць.
- **Два шари глибини:** мураха ходить «перед» рядом доміно; щоб штовхнути, вона ступає в ряд (Domino-Chain: стрілка вгору → «увійти в ряд»). Підняти можна доміно «за спиною».
- Real-time з таймером рівня. Реакція — детермінована симуляція: хвиля падіння стандартних доміно швидша за біг мурахи; висхідний і кувальник повільніші (TAS-нотатки).
- Доміно можуть падати за край екрана — це дозволено; зіткнення — ні.

| Двері виходу | gate | closed/open | відкриваються після правильного падіння тригера; мураха входить → перемога |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(pickup)` → ЯКЩО `not has(ant, domino)` and `occupied(cell_behind, domino)` and `not same(domino, trigger)` → ТО `custom: «carry»` (доміно в руках).
- КОЛИ `input(drop)` → ЯКЩО `has(ant, domino)` and `free(cell)` and `not cell(x, door_front)` (крім зникаючого) → ТО `custom: «place»`.
- КОЛИ `input(push, dir)` → ЯКЩО `counter(pushes, ==, 0)` → ТО `custom: «topple(domino, dir)»`, `counter(pushes, +1)`; другий поштовх заборонений.
- КОЛИ `custom: «toppled(a, dir)»` → ЯКЩО `occupied(next(dir), domino)` → ТО `custom: «topple(next, dir)»` (каскад — `after`).
- КОЛИ падаюче вдаряє стопер → ТО `custom: «rebound»`: падає назад у зворотному напрямку, валить те, що позаду.
- КОЛИ вдарено затримку → ТО `set_state(delay, waiting, n)` (відбиває, як стопер) → після `n` → `custom: «topple»`.
- КОЛИ `contact(any_from_above, splitter)` → ТО `split(splitter)`: дві половини `topple` ліворуч і праворуч.
- КОЛИ вдарено вибухове → ТО `set_cell(ledge_under, gap)`, `custom: «explode»`; хто на ньому — `fall`.
- КОЛИ міст падає в проміжок → ЯКЩО `custom: «gap ≤ reach»` → ТО `set_cell(gap, bridge)`; інакше `fall`.
- КОЛИ зникаюче лягло → ТО `disappear_a`.
- КОЛИ кувальник ліг → ЯКЩО `not blocked(a)` → ТО `custom: «стати й знову topple»` (котиться полицею).
- КОЛИ штовхнули висхідне → ТО `move(a, up)` до стелі → `custom: «topple вздовж стелі»`; КОЛИ мураха сходить за край з висхідним у руках → ТО воно зависає під стелею до поштовху.
- КОЛИ доміно падає на інше лежаче / вдаряється в стояче не за правилами → ТО `custom: «crash»` → `spawn(rubbish)`, рівень провалено.
- КОЛИ `settled` (усе впало й заспокоїлось) → ЯКЩО тригер ліг пласко and `custom: «last_in_chain(trigger)»` and `count(standing - stoppers, ==, 0)` and нема зіткнень → ТО `set_state(exit, open)`.
- КОЛИ `contact(ant, exit)` → ЯКЩО `state(exit, open)` → ТО `win`, `next_level`.
- КОЛИ мураха падає з великої висоти / за низ екрана / її накриває доміно → ТО `lose` («You Failed, You Died»).
- КОЛИ `counter(time_left, ==, 0)` → ТО `custom: «грати можна далі»`; пауза після цього показує підказку.
- КОЛИ `level_end(win)` → ТО `give(token)` (?) ; КОЛИ провал → ЯКЩО `has(token)` → ТО `custom: «повернутись у стан перед поштовхом»`, `take(token)`.
- Перемога: тригер останнім і пласко + усі (крім стоперів) упали + без зіткнень + мураха дійшла до дверей. Поразка: зіткнення, щось стоїть, тригер не останній, смерть мурахи, вихід недосяжний (діра, лежить доміно перед дверима). Рахунку нема — є жетони й час.

## Керування і ввід
- Стрілки ←/→ — хід полицею; ↑/↓ на драбині — лізти; ↑ біля ряду — ступити в ряд доміно.
- Вогонь (Domino-Chain: Space) — підняти доміно позаду / поставити несене в поточну клітину; Вогонь + ←/→ у ряду — поштовх (один на рівень).
- Підняття й ставлення займають час (анімація); TAS-маршрути економлять, скидаючи доміно збоку.
- Чистий аватар, без курсора; нема undo, лише жетон-«відкат до поштовху».

## Вікна, меню, HUD
- `splash-screen` — титул Ocean / Red Rat; `dialogue-window` — інтро-історія (Colin Curly, пачки Quavers) і катсцени після кожного світу.
- `main-menu`: Start · Password → `level-password` · (SNES: опції) (?).
- `level-password` — ввід коду, щоб продовжити з рівня.
- `game-screen` — рівень на весь екран; HUD: `timer-countdown`, `level-number`, лічильник жетонів (`+ui:token-counter`) (?), доміно в руках видно на спрайті мурахи.
- `pause-menu` — після вичерпання часу показує `hint-text` до рівня.
- `end-screen` — провал із причиною («You Failed, You Died», зіткнення, тригер не останній…) і пропозиція використати жетон; перемога — мураха входить у двері, наступний рівень і пароль.
- Переходи: splash → main-menu → (Start | Password) → game-screen → end-screen → game-screen наступного рівня; кожні 11 рівнів → катсцена світу.

## Фічі поза полем
- `levels-sequential`: 100 рівнів, 9 тематичних світів × 11 + фінальний 100-й, де маркування доміно приховане (треба памʼятати типи).
- `level-password` — прогресія кодами; жетон повтору (`+feature:retry-token`) — накопичується за пройдені рівні й дозволяє переграти лише фазу реакції.
- Підказка після вичерпання часу (`hint`, але «заробляється» простроченням).
- Перші рівні — `tutorial` (по одному новому типу доміно).
- Domino-Chain: рівні — текстові файли (`level-from-txt`), вбудована довідка F1, автозапис replay при зіткненні, новий тип «квантове» доміно.

## Варіації й родичі
- Push-Over (SNES) — та сама механіка з іншою обгорткою; Pushover 2 / Domino-Chain (фан) — нові типи (квантове: однакові падають разом, інверсні — навпаки).
- Родичі: The Incredible Machine (запусти механізм, далі — симуляція), Lemmings (підготуй і спостерігай), Catrap/Lode Runner (платформа + драбини), Rube Goldberg-пазли.
- **Осі варіацій:** скільки поштовхів (1 / N / ∞) · чи важливий порядок (тригер останній / будь-який) · що можна рухати (усе / все крім тригера / зони заборони перед дверима) · що робить доміно при ударі (падає / відбиває / чекає / ділиться / рве підлогу / мостить / зникає / летить угору / котиться).

## Пропозиції до словників
- `+trigger:toppled(a, dir)` — доміно почало/завершило падіння в бік; основа каскаду.
- `+trigger:settled` (🔥 корпусу) — реакція завершилась, можна перевіряти умову перемоги.
- `+effect:topple(a, dir)` — перекинути з передачею поштовху сусідові; `+effect:rebound(a)` — падаюче відскакує назад (стопер, затримка).
- `+effect:carry` / `+effect:place` (🔥) — взяти в руки / поставити з рук.
- `+cond:last_in_chain(a)` — сутність останньою в каскаді; `+cond:supported(a)` — під мурахою/доміно є полиця.
- `+role:gate` (двері виходу), `+role:terrain` (драбина).
- `+ui:carried-item` — що несе аватар; `+ui:token-counter` — кількість жетонів повтору.
- `+feature:retry-token` — повтор лише фази запуску; `+window:level-password` — вікно паролів.
- `+card:domino-topple-chain` — див. вище.

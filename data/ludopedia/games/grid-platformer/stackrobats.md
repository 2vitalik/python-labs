# Stackrobats — циркова трупа: лідер дотиком «вмикає» акробатів, і вся звʼязна група ходить, лізе й летить разом до кубка

## Суть
Покроковий PICO-8-пазл з видом збоку. Гравець веде червоного **лідера** трупи; зелені акробати, яких лідер торкається (і ті, хто торкається вже активних), стають частиною групи й рухаються разом з ним. Група лізе драбиною, падає крізь канат, злітає батутом, штовхає бочки; кубок має взяти **саме лідер**. Головна хитрість — група не тверда в русі: хто вперся, той лишається, і звʼязок рветься, а від лідера відірвані акробати одразу «вимикаються» й падають.

## Поле і час
- Кожен номер («feat») — один екран 16×16 клітин PICO-8 (карта 128×64 ділиться на 8×4 екрани; 30 номерів, решта екранів — меню й фінал; з коду картриджа).
- Вид збоку, гравітація вниз; камера фіксована на екрані номера.
- Тік = одне натискання; після вводу гра доанімовує рух (2 px/кадр), потім перевіряє падіння й звʼязність, і лише тоді приймає наступний ввід.
- Шари: тайли карти (стіни, драбини, канат, батути) + сутності (акробати, бочки, кубок).

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Лідер (червоний) | player | завжди активний | рухає всю активну групу; лише він бере кубок |
| Акробат (зелений) | ally | активний / неактивний | активний, якщо звʼязаний з лідером ланцюгом сусідів по 4 сторонах; неактивний падає сам |
| Стіна / підлога | static | — | непрохідна, опора |
| Драбина | terrain | — | хтось із групи на драбині або під нею → ↑/↓ рухає всю групу; верх драбини — опора |
| Канат (highwire) | terrain | — | по ньому ходять як по підлозі; ↓ — група падає крізь нього до першої перешкоди |
| Батут угору | terrain | — | Z, якщо хтось із групи стоїть на ньому → група летить угору до упору |
| Батут убік (ліворуч / праворуч) | terrain | напрям | Z, якщо хтось із групи поруч із ним → група летить у протилежний бік до упору |
| Бочка | object | — | штовхається на 1, якщо за нею вільно (по одній); падає без опори; є опорою |
| Кубок | static | — | ціль; лідер у клітині кубка → номер пройдено |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `tick` (рух доанімовано) → ТО `set_state(acrobats, inactive)`; далі від лідера: КОЛИ `adjacent(active, acrobat)` → ТО `set_state(acrobat, active)` — ланцюгом, поки є нові (flood fill по 4 сусідах).
- КОЛИ `input(left|right)` → ТО `custom: «кожен активний по черзі від переднього до заднього»`: ЯКЩО `free(next)` → ТО `move(member, dir)`; інакше `block` лише для нього (група може розірватися або «нахилитися»).
- КОЛИ `contact(member, barrel)` при русі вбік → ЯКЩО `free(cell_behind_barrel)` → ТО `push`, `move(member, dir)`; дві бочки підряд не штовхаються.
- КОЛИ `input(up)` → ЯКЩО `custom: «хоч один активний на драбині або драбина над ним»` → ТО `move(active, up)` для кожного, кого не блокують стіна, бочка чи неактивний акробат (активні одне одному не заважають).
- КОЛИ `input(down)` → ЯКЩО `custom: «хоч один активний на драбині або драбина під ним»` → ТО `move(active, down)` з тими самими винятками.
- КОЛИ `input(down)` → ЯКЩО `custom: «хоч один активний стоїть на канаті»` → ТО `slide(active, down)` — кожен падає крізь канати й порожнечу до стіни, бочки чи акробата.
- КОЛИ `input(z)` → ЯКЩО `custom: «хоч один активний стоїть на батуті-вгору»` → ТО `slide(active, up)`; інакше ЯКЩО хтось поруч із бічним батутом → ТО `slide(active, left|right)` (пріоритет: угору → ліворуч → праворуч). Канати під час польоту не заважають.
- КОЛИ `tick` → ЯКЩО `not state(acrobat, active)` і `not supported(acrobat)` → ТО `fall(acrobat)` на 1 (опора: стіна, бочка, інший акробат).
- КОЛИ `tick` → ЯКЩО `custom: «жоден активний не має опори»` (опора для групи: стіна, бочка, драбина під ним або сам на драбині) → ТО `fall(active)` усією групою на 1 — група висить, доки тримається хоч один.
- КОЛИ `tick` → ЯКЩО `free(below)` → ТО `fall(barrel)`.
- КОЛИ `enter(leader, trophy)` → ТО `win`, `custom: «феєрверк і завіса»`, `next_level`; після останнього номера → `window(end-screen)`.
- КОЛИ `input(x)` → ТО `restart`.
- Перемога: лідер на кубку. · Поразки нема: глухий кут лікується рестартом (undo нема). · Рахунку нема.

## Керування і ввід
- ← / → — крок усієї активної групи (з поштовхом бочки).
- ↑ / ↓ — драбина; ↓ на канаті — падіння крізь канат.
- Z — злетіти з батута, до якого торкається група; X — рестарт номера; Enter — меню PICO-8.
- Undo нема — гравці просили в коментарях (itch).

## Вікна, меню, HUD
- `splash-screen` — лого «Beep Yeah! games», анімація акробата.
- `main-menu` — назва, «by tom brinton», пункт «feat N» зі стрілками (вибір серед відкритих номерів) і «how to play».
- `help-window` — чотири рядки з картинками: лідер; «activate other acrobats by touching them»; лідер має взяти кубок; канат і батути; «press z to return».
- `game-screen` — поле номера, згори `level-number` у вигляді «feat N: назва» (назви номерів: «the carry», «tower of power», «barrels of fun»…); тіні під акробатами, кліпання лідера.
- `pause-menu` (Enter, PICO-8): main menu · prev. level.
- `custom-window` — завіса-перехід між номерами (закривається після кубка, відкривається на старті).
- `end-screen` — фінальний екран після 30-го номера: промені прожекторів, феєрверк.
- Переходи: splash → main-menu ⇄ help-window; main-menu → (feat N) game-screen → (кубок) завіса → наступний номер → … → end-screen → main-menu.

## Фічі поза полем
- `levels-sequential` + `level-unlock` + `save-progress`: найдальший відкритий номер пишеться в `cartdata` і переживає перезапуск.
- `restart-level` (X), вибір будь-якого відкритого номера з меню, «prev. level» у паузі.
- `sound-toggle`/музика — стандартні PICO-8 (?); undo, підказок, редактора нема.

- Осі варіацій:

  - **рух групи**: тверде тіло / кожен член окремо від переднього (тут);
  - **опора групи**: кожен окремо / вистачає одного члена (тут);
  - **хто приймає ціль**: будь-хто / лише лідер (тут).

## Цікавинки для курсу
- Активація flood fill від лідера щотіку з «вимиканням» відірваних — 🥉 (BFS по сусідах + стани).
- Рух групи від переднього до заднього з індивідуальним упором (група рветься, вежа «нахиляється») — 🥉.
- Опора групи «хоч один член стоїть» + незалежне падіння неактивних — 📎.
- Драбина: один член на драбині піднімає всю групу; баг накладання (свої не блокують → двоє в одній клітині) як урок про порядок обробки — 📎.
- Батути й канат як `slide` групи до упору з прохідними для польоту клітинами — 📎.
- Розвʼязувач BFS по станах (позиції акробатів і бочок) — 🥇.

## Пропозиції до словників
- `+effect:move_group` — рух усіх активних членів групи по черзі від переднього, з індивідуальним `block` (Stackrobats; так само просили для інших групових ігор).
- `+cond:any_member` — «хоч один член групи задовольняє умову» (на драбині, на батуті, має опору).
- `+role:leader` — головна сутність групи: від неї рахується звʼязність, лише вона бере ціль.
- `+card:drop-through-platform`, `+card:leader-goal` — див. вище.
- `+card:connectivity-recompute` — звʼязність/активність перераховується щотіку, а не фіксується при першому дотику.

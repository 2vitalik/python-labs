# Nuts & Milk — рожева крапля збирає фрукти на мотузках над водою, тікаючи від суперника, щоб дістатися нареченої

## Суть
Ранній платформер Hudson Soft (у версії Famicom 1984 — один екран на рівень, вид збоку): Мілк ходить, стрибає й лазить мотузками, атакувати не вміє. Треба зібрати всі фрукти — тоді з будиночка виходить наречена Йогурт, і до неї треба встигнути до кінця таймера. Заважають Натс (1–3 переслідувачі, теж лазять мотузками), у режимі Game B — дирижаблі; внизу вода. Особливість — **оглушення від довгого падіння**: Мілк лежить, доки гравець не натисне стрибок, і пружини, на яких можна «закачатися» до запаморочення.

## Поле і час
- Один екран на рівень, вид збоку: цегла й труби (тверді), мотузки-мости, пружини, вода по низу, будиночок угорі ліворуч.
- Real-time; таймер рівня.
- Комп'ютерна версія PC-8801 (1983) — інша гра з видом згори (збирати фрукти, тікаючи від Натса); тут описано Famicom-лінію.

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(left|right)` → ЯКЩО `free(side)` → ТО `move(milk, dir)`.
- КОЛИ `input(jump)` → ЯКЩО `not cell(here|below, rope)` → ТО `custom: «стрибок»`; інакше `block`.
- КОЛИ `input(up|down)` → ЯКЩО `cell(here, rope)` → ТО `move(milk, up|down)`.
- КОЛИ `custom: «приземлення після довгого падіння»` → ТО `stun(milk)` — лежить, доки КОЛИ `input(jump)` → ТО `clear_state(milk, stunned)`.
- КОЛИ `enter(milk, spring)` → ТО `custom: «високий стрибок; точний таймінг»`; ЯКЩО `custom: «підстрибує надто довго»` → ТО `stun(milk)` (запаморочення).
- КОЛИ `enter(milk, fruit)` → ТО `pickup`; КОЛИ `all_gone(fruit)` → ТО `spawn_at(yogurt, house)`.
- КОЛИ `contact(milk, yogurt)` → ЯКЩО `timer(>, 0)` → ТО `win`, `next_level`.
- КОЛИ `contact(milk, nuts|blimp)` → ТО `lives(-1)`, `restart` — фрукти повертаються на місця.
- КОЛИ `enter(milk, water)` → ТО `lives(-1)`, `restart`.
- КОЛИ `counter(time, =, 0)` → ТО `lives(-1)`.
- КОЛИ `enter(nuts, water)` → ТО `disappear(nuts)`, далі `respawn(nuts)` за мить.
- КОЛИ `tick` → ТО `custom: «Натс іде до Мілка, лазить мотузками»`.
- КОЛИ `picked(milk, helicopter)` → ТО `score(bonus)` (Game B).
- Бонус-стадія (номер закінчується на 3 або 8): Йогурт у центрі, кулі з боків, фрукти не обовʼязкові; КОЛИ `contact(milk, yogurt)` → ТО `lives(+1)`, сценка; не встиг → `message(NO BONUS)`, життя не втрачається.
- КОЛИ `input(select)` → ТО `next_level` (пропуск); пройти без пропусків → коротке повідомлення.
- КОЛИ `counter(lives, =, 0)` → ТО `game_over`.
- Перемога: Йогурт після всіх фруктів. · Поразка: Натс/дирижабль, вода, таймер; 0 життів — кінець. · Рахунок: очки (за що саме, крім гелікоптерів, — (?)).

- Переходи: титул → рівень → (Йогурт) наступний → … 50 → Game B з рівня 1.

## Фічі поза полем
- 50 рівнів; після 50-го Game A гра переходить у Game B з рівня 1 (JA), справжньої кінцівки нема; за EN-вікі — цикл на рівень 1.
- `skip-level` без ліміту кнопкою Select.
- `level-editor` (Famicom і MSX): лише перший екран, не зберігається.
- `difficulty-presets`: Game A / Game B.
- Бонус-стадії кожні 5 рівнів (3, 8, 13…) з додатковим життям.

  - **смерть**: продовжити з місця / рівень скидається з фруктами (Nuts & Milk).

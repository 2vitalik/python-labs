# nuworm — черв'як із блоків-труб: повзе як змійка, а гравець перелітає крізь отвори й зʼєднує, розщеплює, вирощує шматки

## Суть
Безкоштовна PuzzleScript-головоломка noa (2023–2025, 59 рівнів у 9 розділах). На полі — блоки з **отворами** на боках: кінці, прямі й кутові «труби»; блоки, чиї отвори дивляться один на одного, зростаються в одну фігуру — черв'яка. Гравець сидить у кінцевому блоці фігури: натиск у **закритий** бік — черв'як повзе як змійка (голова крокує, тіло тягнеться, попереду все штовхається), натиск у **відкритий** бік — гравець вилітає крізь отвір, летить трубами фігури чи навпростець через поле й «вселяється» в інший блок або відскакує. Розділи вводять: рух, злиття, повороти, довгого черв'яка, розщеплення (відділяється лише голова), ріст і «замикання». Мета кімнати — залетіти у вихідну трубу в стіні.

## Поле і час
- Квадратна сітка; кімната = екран 15×11 (`flickscreen 15x11`), фінальна — кілька екранів, камера перегортає їх.
- Клітина: підлога · стіна · дірка (`~`); блоки — шар обʼєктів з «портами» на 4 боках: отвір вільний або зʼєднаний із сусідом.
- Вхід і вихід — однобокові блоки-труби, вбудовані в стіну; стрілки на стіні показують сусідні кімнати.
- Хід = один натиск; переліт і падіння в дірку розгортаються автоматичними кроками (`again_interval 0.08`).
- Палітра змінюється з розділом (базова + 8 тем).

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Гравець («око» черв'яка) | player | у якому блоці; напрям польоту | керує фігурою, у кінцевому блоці якої сидить; вилітає крізь отвори |
| Блок-кінець | object | 1 отвір N/E/S/W | штовхається; після руху отвір дивиться назад; одиночний — найменший черв'як |
| Глухий блок | object | без отворів | лише штовхається, у нього не залетиш |
| Пряма труба | object | 2 протилежні отвори | гравець пролітає наскрізь; зʼєднується з двох боків |
| Кутова труба | object | 2 суміжні отвори | переліт повертає на 90° |
| Фігура (черв'як) | object | ланцюг зʼєднаних блоків | штовхнута — їде цілою; з гравцем усередині — повзе як змійка |
| Стіна | static | — | непрохідна; гравець від неї відскакує |
| Дірка | hazard | — | фігура, що цілком над діркою, падає й зникає; гравець пролітає над діркою |
| Вхідна труба | spawner | у стіні, 1 отвір | гравець вилітає з неї на старті; залетів назад — вилітає знову |
| Вихідна труба | static | у стіні, 1 отвір | гравець залетів — кімнату пройдено |
| Значки клавіш | static | undo / restart / Esc | підказки, вмуровані в стіни перших кімнат |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `level_start` → ТО `spawn_at(player, entry)`, `slide(player, entry_opening)` — гравець вилітає з вхідної труби (у вступних кімнатах розділів — із затримкою).
- КОЛИ `input(dir)` → ЯКЩО `custom: «у блоці гравця з боку dir отвір чи звʼязок»` → ТО `slide(player, dir)` — політ.
- КОЛИ `contact(player, block)` → ЯКЩО `facing(block_opening, toward_player)` → ТО `move(player, into_block)`; інакше `bounce(player)` — летить назад тим самим шляхом.
- КОЛИ `blocked(player)` → ТО `bounce(player)` — удар об стіну.
- КОЛИ `custom: «блок гравця закритий у напрямку польоту»` → ЯКЩО `custom: «є звʼязок убік (кутова труба)»` → ТО `face(player, connection_dir)`; інакше `custom: «зупинка — тепер гравець керує цією фігурою з цього кінця»`.
- КОЛИ `input(dir)` → ЯКЩО `custom: «блок гравця закритий з боку dir»` → ТО `move(head, dir)`, `custom: «кожен сегмент стає на місце попереднього (тіло-черга)»`.
- КОЛИ `contact(head, block)` → ТО `push(block)` — разом з усіма блоками, зʼєднаними з ним, і з тим, що стоїть попереду (ланцюг).
- КОЛИ `blocked(block)` → ТО `block` — упор у стіну скасовує весь хід; показується удар, хід не пишеться в історію undo.
- КОЛИ `custom: «два рухи в одну клітину або один обʼєкт штовхають у два боки»` → ТО `block`.
- КОЛИ `custom: «сегмент зсунувся як голова чи тіло»` → ТО `face(free_opening, back)` — вільний отвір дивиться туди, звідки блок прийшов; звʼязки всередині черв'яка перебудовуються вздовж нового шляху.
- КОЛИ `adjacent(block_a, block_b)` → ЯКЩО `custom: «їхні отвори дивляться один на одного»` → ТО `attach(block_a, block_b)` — одна фігура; так черв'як росте.
- КОЛИ `custom: «голова штовхає власне тіло (U/C-форма) або щось, що впирається в її хвіст»` → ТО `detach(head, neck)` — штовхнута частина їде цілою, голова відривається; обидва місця розриву стають отворами. Ділиться лише голова й лише у фігурі гравця.
- КОЛИ `after(move)` → ЯКЩО `not supported(piece)` → ТО `fall(piece)`, `disappear(piece)` — фігура падає, лише коли жоден її блок не стоїть на підлозі; дірка не засипається.
- КОЛИ `after(move)` → ЯКЩО `not supported(player_piece)` → ТО `fall(player_piece)`, `undo(1)` — падіння показують і самі скасовують хід.
- КОЛИ `enter(player, exit_pipe)` → ТО `sound(sfx6)`, `win`, `next_level`.
- КОЛИ `enter(player, entry_pipe)` → ТО `respawn(player, entry)` — вилітає знову, стан кімнати лишається.
- Перемога: гравець у вихідній трубі. · Поразки нема (смертельний хід скасовується). · Рахунку нема.

## Керування і ввід
- Стрілки / WASD — повзти або летіти (залежить від того, чи відкритий блок з того боку); U / Z — undo; R — рестарт; Esc — вибір рівня; Enter / X — підтвердити.
- Телефон: свайп (утримання — повтор), спливне меню: undo, restart, level select.
- Повтор клавіші пришвидшено до 0,18 с; у меню вибору авторка ще зменшила його на 60 мс у експортованому HTML.

## Вікна, меню, HUD
- `title-screen` (custom): кімната «nuworm by noa» з одним блоком; X / Enter — гравець пірнає у вихід, гра починається.
- `chapter-intro` (custom): вступна кімната розділу ('move', 'fuse', 'turn', 'move, extended', 'split', 'split, extended', 'grow', 'grow, extended', 'close') — гравець сам пролітає крізь візерунок блоків від входу до виходу.
- `level-select` (Esc): секції «1.1», «1.2»… з позначкою ✓ для розвʼязаних; рівень можна пропустити й повернутись.
- `game-screen`: кімната з рамкою екрана; значки undo / restart / Esc у стінах перших кімнат; лічильників нема.
- Фінал: кімната 'ending' на кілька екранів — труби над морем дірок; гравець вилітає за край екрана.
- Переходи: title → кімнати, сполучені трубами (вихід однієї веде в наступну) → ending; Esc → level-select з будь-якої кімнати.

## Фічі поза полем
- `undo` ∞ (удар об стіну не пишеться в історію), `restart-level`, `level-select` з ✓ і пропуском рівнів.
- Палітра за розділом (`chapter-palette`), музика, звук на кожну подію: рух, розщеплення, зіткнення, поштовх, падіння, зʼєднання, поява, перемога.
- Підказок нема: авторка пише, що систему підказок на цьому рушії зробити важко.
- Один браузерний білд для клавіатури й тачу; код рівнів із коментарями авторки лежить просто в HTML.

## Цікавинки для курсу
- Блок із портами (4 біти) і злиття «отвір до отвору» з перерахунком компонент звʼязності — 📎.
- Змійка, що штовхає: тіло-черга + поширення поштовху на зʼєднані фігури + скасування всього ходу при упорі — 🥉.
- Політ гравця трубами: прямі, кути, відскок від стіни, вхід лише крізь отвір — 🥉.
- Розщеплення голови при самоштовху: хто «йде слідом», а хто «штовхнутий», і які звʼязки рвуться — 🥈 (конфлікти рухів — найтонша частина коду).
- Опора фігури над діркою через звʼязність + автоматичний undo смертельного ходу — 📎.
- Розвʼязувач по станах (фігури як множини блоків із портами + блок гравця) — 🥇.

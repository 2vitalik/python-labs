# Vertebrae — миша в черепі мертвої змії: веди скелет-змійку, штовхай ящики, ламай і зрощуй хребет

## Суть
Маленька миша на Пазл-островах знаходить череп давно мертвої змії й вдягає його як шолом. Відтоді кожен її крок рухає череп, а за ним тягнеться хребет. Мета рівня — довести мишу (у черепі) до клітини-цілі.

Скелет штовхає ящики й вільні кістки, тримає кнопки дверей і лежить на воді, куди миша не ступить. Укус власного хребта чи двері, що зачиняються на ньому, ламають скелет на шматки, а шматки можна знову приростити.

PuzzleScript-гра draxes (у сирці — автор Ali Nikkhah, подяка Joel Fox): 55 рівнів-островів (itch: «понад 50»), сюжет у репліках миші між рівнями.

## Поле і час
- Квадратна сітка: острови з землі, камʼяних стежок і земляних стін серед води; рівні від 14×13 до 70×63 клітин. Номер рівня намальовано цифрою у воді в кутку мапи.
- Шари: вода / земля → кнопки, проводи, ціль → двері, стіни, хребці й череп → ящики (поверх хребців) → миша (окремий шар, сидить у черепі).
- Проводи (Trigger) йдуть під землею, водою й стінами від кнопки до дверей.
- Хід = крок миші; перерахунок скелета (тягнення, поштовх, розлам, зрощення, двері) відбувається в межах того самого ходу. Без вводу нічого не рухається.
- Повна інформація, без випадковості.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Миша | player | поза черепом / у черепі | ходить по землі й стежках, не по воді; увійшла в череп — далі рухається тільки з ним |
| Череп (голова) | container | напрям; тіло є / нема | рухається разом з мишею; тягне хребет; штовхає ящики й кістки; тримає кнопку |
| Хребець | segment | зʼєднання з двох боків | повторює шлях голови; може лежати на воді; везе ящик, що на ньому стоїть |
| Хвіст | segment | — | кінець хребта; торкнувшись вільної кістки, приростає до неї |
| Вільна кістка | object | — | штовхається; приростає до черепа без тіла чи до кінця хребта |
| Ящик | object | на хребці / окремо | штовхається; на хребці їде з ним; хребець під ним відпав — ящик лишається й більше не приростає |
| Кнопка | switch | — | натиснута, поки на ній череп або ящик (хребці й кістки не тиснуть) |
| Провід | conduit | ланцюг клітин | передає сигнал від кнопки до суміжних дверей |
| Двері (вертикальні / горизонтальні) | gate | відчинені / зачинені | відчиняються сигналом; без сигналу зачиняються, нищать кістку в проході й чавлять мишу; ящик у проході їх тримає |
| Ціль | zone | — | миша на ній — перемога |
| Вода | terrain | — | миша й череп не заходять; кістки й ящики можуть у ній лежати |
| Камʼяна стежка | terrain | — | прохідна клітина посеред води |
| Земляна стіна | static | — | непрохідна для всіх |
| Кров | mark | — | лишається від розчавленої миші; з нею перемога неможлива |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(dir)` → ЯКЩО `cell(next, ground|step)` → ТО `move(mouse, dir)`; вода чи стіна → `block`.
- КОЛИ `contact(mouse, skull)` → ТО `custom: «миша вдягає череп»`, `checkpoint`; на першому рівні — серія реплік («A predator!…», «…a fine helmet to wear.»).
- КОЛИ `input(dir)` → ЯКЩО `state(mouse, in_skull)` → ТО `move(skull, dir)` разом з мишею; череп не може рушити — миша теж стоїть.
- КОЛИ `input(dir)` геть від шиї → ТО `custom: «хребет тягнеться: кожен хребець стає на місце попереднього»` (тіло-черга).
- КОЛИ `contact(skull, crate|loose_bone)` → ЯКЩО `free(cell_behind)` → ТО `push` ланцюгом усіх підряд; інакше `block`.
- КОЛИ `contact(skull, own_vertebra)` → ТО `split(spine)`: хребець у цій клітині зникає, частина за ним стає окремим шматком без голови («I wonder what would happen if a live snake bit itself»).
- Рух черепа назад у власну шию штовхає скелет цілком; частина, що вперлась у стіну, відламується (`split`) (?).
- КОЛИ `contact(tail|bare_skull, loose_bone)` → ТО `attach(a, b)`: кістка стає новим хвостом чи шиєю; кінці шматків зрощуються, але кінці одного шматка не замикаються в кільце.
- КОЛИ `input(dir)` → ЯКЩО `custom: «хребець під ящиком рухається»` → ТО `carry(crate)`.
- КОЛИ `custom: «хребець під ящиком відпав»` → ТО `disappear(bone)`, `custom: «ящик лишається на місці й більше не приростає»`.
- КОЛИ `enter(skull|crate, button)` → ТО `set_state(door, open)` для всіх дверей, суміжних з мережею проводів кнопки.
- КОЛИ `leave(skull|crate, button)` → ТО `clear_state(door, open)` для дверей мережі.
- КОЛИ `state_off(door, open)` → ЯКЩО `occupied(door_cell, crate)` → ТО `custom: «двері лишаються відчиненими»`.
- КОЛИ `state_off(door, open)` → ЯКЩО `occupied(door_cell, bone)` → ТО `disappear(bone)`, `split(spine)` («I wonder what happens if a door closes on my tail.»).
- КОЛИ `state_off(door, open)` → ЯКЩО `occupied(door_cell, mouse)` → ТО `lose` («Crushed!»), лишається кров.
- КОЛИ `edge(part)` → ТО `block`: рух, що виштовхнув би будь-яку частину за край мапи, скасовано.
- КОЛИ `enter(mouse, goal)` → ТО `win`, `next_level`.
- Перемога: миша на цілі й не розчавлена (`no Blood`). · Поразка: розчавлення дверима, далі лише undo / рестарт. · Рахунку нема.

## Керування і ввід
- Стрілки / WASD — крок миші (разом з черепом і скелетом); утримання повторює крок (0,12 с).
- Z — undo, R — рестарт рівня; клавіші дії нема (`noaction`); Esc — титул (стандарт PuzzleScript).

## Вікна, меню, HUD
- `splash-screen`: титул PuzzleScript «Vertebrae» (почати / продовжити — стандарт рушія).
- `dialogue-window`: текстові екрани між рівнями — вступ («It was a beautiful, quiet day on the Puzzle Islands…») і репліки миші, що підказують механіку: «Good thing the snake is not alive!», «I get the point already... this snake was very large!».
- `game-screen`: уся мапа-острів одразу, HUD нема; номер рівня — цифра у воді, частина мапи; розчавлення — повідомлення «Crushed!».
- Переходи: титул → репліки → рівень → (миша на цілі) → наступний рівень.

## Фічі поза полем
- `undo` без ліміту, `restart-level`, `checkpoint` після вдягання черепа на першому рівні.
- 55 рівнів послідовно (`levels-sequential`); вибору рівня на itch нема — гравці радять PuzzleScript+ (?).

## Цікавинки для курсу
- Аватар-пілот: сідає в обʼєкт і далі керує ним — 🌱.
- Тягнення хребта як черги + штовхання ящиків ланцюгом — 📎.
- Укус себе: прибрати хребець, розділити список сегментів на два шматки, позначити новий хвіст — 🥉.
- Зрощення кінців шматків при дотику з забороною кільця — 🥉.
- Кнопка → мережа проводів → двері; двері, що зачиняються, ріжуть хребет і чавлять мишу, ящик їх тримає — 🥉.
- Вантаж на сегменті, що лишається на місці після відриву й більше не підбирається — 📎.
- Розвʼязувач для рівнів зі скелетом (стан = граф сегментів + ящики + двері) — 🥇.

# Billy Bumbum — перекидай кубик-зад дракона по клітинках, пукай на лазери й блоки і сядь задом у куб друга

## Суть
Покрокова ізометрична головоломка: Біллі — кубик (зад дракона) з обличчям з одного боку й задом із протилежного. Кожен хід — **перекид через ребро** на сусідню клітинку, тож зад весь час змінює бік; мета рівня — опинитися на помаранчевому кубі-цілі **задом донизу**, щоб звільнити друга. Гази з заду — головний інструмент: штовхають куби, перекривають лазери, бустери перекидають Біллі через прогалини. 250+ рівнів від дизайнерів Thinky-спільноти, оверворлд із гілками, мультяшні сцени.

## Поле і час
- Квадратна сітка білих плиток-острівців на «тортах»; навколо — порожні слоти (контури клітинок на землі). Рендер ізометричний 3D, логіка — 2D-сітка + орієнтація куба.
- Стан Біллі: клітинка + орієнтація (6 варіантів сторони заду: вгору / вниз / 4 боки).
- Хід = один перекид; без вводу світ стоїть. Смерті нема — «You don't really need to worry about dying».

## Варіації й родичі
- Осі варіацій «перекочування куба»:
  - **що важливо в орієнтації**: нічого (Edge) / зайняті клітинки ([Bloxorz](bloxorz.md)) / яка грань знизу — ціль «задом донизу» (Billy Bumbum) / грані-стани ([Stephen's Sausage Roll](../thinky/stephens-sausage-roll.md));
  - **що дає орієнтація**: лише умову перемоги / ще й інструмент — газ із заду діє в бік, куди дивиться зад (тут);
  - **бустери**: нема / плитка переносить через прогалину (тут, Cuboid-подібні).
- Родичі: [Bloxorz](bloxorz.md), [Bloxpath](bloxpath.md), [Lost in Cheese](lost-in-cheese.md) (кіт-кубик котиться й штовхає сир), [Sokoban](sokoban.md).

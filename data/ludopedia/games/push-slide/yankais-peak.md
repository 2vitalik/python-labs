# Yankai's Peak — Sokoban на трикутній сітці: синя піраміда ковзає, перекидається навколо вершини й штовхає кольорових сусідів на їхні плитки

## Суть
Гравець — «свідома синя піраміда» на полі з трикутних плиток. Треба заштовхати кожну кольорову піраміду на плитку **свого кольору**, а потім завести власну піраміду на синю плитку-вихід. Рухів два: **ковзнути** через ребро в сусідній трикутник (3 напрямки, лише на землю) або **закріпитися за одну з трьох вершин і перекинутись** навколо неї в один із двох боків. Перекидання замітає дугу й штовхає піраміди на шляху, часто ланцюгом. 130+ рівнів у 7 частинах (PART), кожна вводить нову механіку.

## Поле і час
- Поле — острівець трикутних плиток у порожнечі; у кожного трикутника 3 сусіди через ребро і 12 через вершини (сусідство нестандартне → `field: graph`).
- Шари: порожнеча → плитки (звичайні / кольорові цілі / синій вихід / спецплитки) → піраміди.
- 3D-рендер під кутом, поле видно цілком; хід = одна дія гравця, усі поштовхи ланцюга розвʼязуються в межах ходу (`time: turn`). Рух детермінований.

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(dir)` → ЯКЩО `cell(next_tri, floor)` і `free(next_tri)` → ТО `move(player, dir)` (ковзання через ребро, 3 напрямки).
- КОЛИ `input(corner)` → ТО `set_state(player, anchored)` — якір на обраній вершині.
- КОЛИ `input(cw|ccw)` → ЯКЩО `state(player, anchored)` → ТО `rotate(player, 60)` навколо якоря (перекидання в сусідній трикутник при тій самій вершині).
- КОЛИ `contact(player, pyramid)` (ковзання або дуга перекидання) → ЯКЩО `custom: «для піраміди є клітина попереду»` → ТО `push(pyramid)`; інакше `block`.
- КОЛИ `contact(pyramid, pyramid)` → ТО `push` наступної — `custom: «ланцюг поштовхів, що може й повернути сусідів»`.
- КОЛИ `enter(pyramid, paint_tile)` → ТО `transform(pyramid, pyramid_of_tile_color)`.
- КОЛИ `leave(a, fragile_tri)` → ТО `set_cell(fragile_tri, void)`.
- КОЛИ `enter(a, sticky_tri)` → ТО `set_state(a, stuck)`.
- КОЛИ `contact(octahedron, pyramid)` → ТО `attach(octahedron, pyramid)` (?).
- КОЛИ `edge(pyramid)` → ТО `custom: «піраміда випадає з поля — рівень нерозвʼязний»` (?).
- КОЛИ `all_on(colored_pyramid, same_color_tile)` і `enter(player, blue_tile)` → ТО `win`, `next_level`.
- Перемога: усі кольорові на своїх плитках + гравець на синій. · Поразка: нема, лише глухий кут → undo. · Рахунку нема.

## Керування і ввід
- Клавіатура: напрямки ковзання (WASD / стрілки) — відгуки скаржаться, що 4 ортогональні клавіші погано лягають на трикутну сітку.
- Миша / тап: клік по вершині піраміди — закріпити якір; далі замах в один із двох боків.
- Undo без ліміту; підказок нема (Pocket Gamer).
- Мобільна версія — дотики по вершинах.

## Вікна, меню, HUD

## Фічі поза полем

- Розблокування за квотою: для наступного PART-у треба розвʼязати частину (≈2/3) рівнів поточного — `+feature:unlock-by-quota`.
- `undo` без ліміту; `cloud-save` (Steam Cloud), `achievements`.
- Редактора й підказок нема.

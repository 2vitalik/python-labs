# Blue Max — повітряний бій Першої світової: таємно обери маневр з розкладу свого літака, усі летять одночасно, стріляй лише прямо вперед

## Суть
Настільна гра GDW (Phil Hall, 1983) про дуелі біпланів: кожен гравець веде **один літак** на гексовій мапі. Щоходу гравець таємно записує номер маневру з **розкладу маневрів** свого типу літака (номер 1–36, напрямок L/R/S, швидкість 1–4), потім усі маневри відкривають і **виконують одночасно**. Стріляти можна лише по цілі **в гексах прямо попереду на відстані 0–3**, а пошкодження — це сині й червоні фішки, які тягнуть наосліп з чашки (крила, фюзеляж, хвіст, двигун, паливо, «пілот убитий», вогонь…). Хто сів на хвіст супернику, **дізнається напрямок його маневру** до свого вибору.

## Поле і час
- Дві мапи 17″ × 22″ складаються в поле 34″ × 22″; гексова сітка; літак має **напрямок** на одну з 6 граней. Висоти в базових правилах нема.
- Хід = 10 кроків: хвіст → вибір маневру → витрата палива → рух → вогонь → пошкодження → розклинювання → заклинювання → шкода від вогню → гасіння вогню й диму.
- Час — `wego`: вибір маневрів таємний, виконання одночасне; літаки проходять крізь гекси й ділять їх без зіткнень.
- Сторони — дві команди, бажано з однаковою кількістю гравців; кожен ставить літак за стартовою лінією своєї сторони з будь-яким напрямком.

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `phase_start(tailing)` → ЯКЩО `custom: «ціль у передній дузі хвостуючого, а він — у задній дузі цілі»` and `in_range(tailer, target, 3)` and `not state(tailer, smoking)` and `not state(tailer, burning)` → ТО `set_state(tailer, tailing)`; хвостувати можна не більше одного ворога за хід.
- КОЛИ `phase_start(maneuver_selection)` → ЯКЩО `state(target, tailed)` → ТО `custom: «ціль передає хвостуючому маркер напрямку L / R / S»`; хвостуючий обирає маневр після цього; у колі хвостувань першим каже той, у кого менший кидок.
- КОЛИ `phase_start(maneuver_selection)` → ТО `custom: «кожен таємно записує в аркуш один маневр зі свого розкладу»`.
- КОЛИ `custom: «вибір маневру»` → ЯКЩО `custom: «швидкість відрізняється від минулого ходу більше ніж на 1»` → ТО `block`.
- КОЛИ `custom: «вибір маневру 27–36 (обмежений)»` → ЯКЩО `custom: «минулий маневр — не прямий 2, 3, 4 чи 5 і не той самий обмежений»` → ТО `block`; маневри 1, 28, 31, 36 не повторюються два ходи поспіль.
- КОЛИ `custom: «вибір маневру»` → ЯКЩО `state(plane, gliding)` → ТО `custom: «лише маневр 2 або 9»`.
- КОЛИ `phase_start(fuel)` → ТО `counter(fuel, −speed)`; ЯКЩО `counter(fuel, =, 0)` → ТО `set_state(plane, gliding)`.
- КОЛИ `phase_start(movement)` → ТО `custom: «усі одночасно відкривають і виконують маневри»`; 1S — лишається на місці, 1L / 1R / 27 / 28 — розворот у своєму гексі.
- КОЛИ `phase_start(combat)` → ЯКЩО `custom: «ціль у гексах прямо попереду на 1–3»` або `custom: «ціль у тому ж гексі, той самий напрямок, атакер повільніший»` → ТО `custom: «бойова величина = база + модифікатори: черга (коротка / середня / довга), стабільність A/B/C, ціль у звалюванні (маневр 1), швидкість атакера 3–4, одна гармата, кут (deflection), повторна ціль, хвіст»`.
- КОЛИ `custom: «атака»` → ТО `custom: «кидок 1d6 × бойова величина за таблицею → N синіх і M червоних фішок»`; величина ≤ 0 — без ефекту; одна атака на літак за хід.
- КОЛИ `input(fire, target)` → ЯКЩО `custom: «ціль не прямо попереду або не летить прямо на / від атакера»` → ТО `custom: «модифікатор кута (deflection)»`.
- КОЛИ `phase_start(damage)` → ТО `custom: «тягнути фішки з чашки, спершу сині; повернути лише після всіх витягів»`.
- КОЛИ `custom: «влучання в хвіст»` → ЯКЩО `custom: «вогонь спереду»` → ТО `custom: «стає влучанням у двигун»`.
- КОЛИ `custom: «влучання в двигун»` → ЯКЩО `custom: «вогонь ззаду»` → ТО `custom: «стає влучанням у хвіст»`.
- КОЛИ `counter(wings, =, 0)` або `counter(fuselage, =, 0)` або `counter(tail, =, 0)` → ТО `disappear(plane)` (збито).
- КОЛИ `counter(engine, =, 0)` або `counter(fuel, =, 0)` → ТО `set_state(plane, gliding)`.
- КОЛИ `custom: «червона фішка: вибух бака або пілот убитий»` → ТО `disappear(plane)`; «пілот зачеплений» → `custom: «наступного ходу лише повільніше або прямо»`; «заклинило кермо» → `custom: «лише L або R на кілька ходів»`; «двигун» → `custom: «без швидкостей 3 і 4»`.
- КОЛИ `phase_start(jam_check)` → ЯКЩО `custom: «стріляв довгою чергою»` → ТО `custom: «1d6: 5–6»` → `set_state(gun, jammed)`.
- КОЛИ `phase_start(jam_clearing)` → ЯКЩО `state(gun, jammed)` and `custom: «цей хід — прямий необмежений маневр»` → ТО `custom: «1d6: 4–6»` → `clear_state(gun, jammed)`.
- КОЛИ `phase_start(fire_damage)` → ЯКЩО `state(plane, burning)` → ТО `custom: «1 синя фішка за кожен крок вогню»`.
- КОЛИ `phase_start(extinguish)` → ЯКЩО `state(plane, burning)` → ТО `custom: «1d6: 5–6 (4–6 після ковзання — маневр 8, 16 або 17)»` → `clear_state(plane, burning)`.
- КОЛИ `phase_start(extinguish)` → ЯКЩО `state(plane, smoking)` → ТО `custom: «1d6: 6 — дим зник, 1 — займання»` → `clear_state(plane, smoking)` / `set_state(plane, burning)`.
- КОЛИ `input(fire, lewis, burst)` → ТО `counter(magazine, −1|−2|−3)` за гармату; ЯКЩО `counter(magazine, =, 0)` → ТО `custom: «заміна лише після маневру 2, 3 чи 4, діє в кінці ходу»`.
- КОЛИ `edge(plane)` → ЯКЩО `custom: «свій край позаду стартової лінії»` → ТО `disappear(plane)` (втеча).
- КОЛИ `custom: «одна сторона вся збита або втекла»` → ТО `game_over`.
- Перемога: збити або вигнати всіх ворогів; окремих очок за партію нема. · Поразка: літак збито. · Рахунок (кампанія): 1 очко досвіду за хід над полем, 25 — за збитий.

## Керування і ввід
- Настільна: аркуш літака з боксами й записом маневрів по ходах; розклад маневрів — картка з номерами 1–36 і малюнком кінцевого положення відносно стартової стрілки.
- Порядок ходу: хвостовані передають маркер напрямку → кожен таємно пише номер → одночасне відкриття й рух → оголошення черг (коротка/середня/довга) → кидки й витяг фішок.
- Офіційної цифрової версії не знайшов; Canvas Eagles — безкоштовна переробка «в мережі» (формат не перевірено).

## Вікна, меню, HUD
- `game-screen` (цифрова версія): гексове поле з літаками й напрямками; `maneuver-schedule` свого літака з підсвіткою доступних маневрів (`legal-move-highlight`); `aircraft-record` — бокси двигуна, крил, фюзеляжу, хвоста, палива, гармат, магазину; `direction-marker` від хвостованої цілі; `threat-range` — 3 гекси прямо попереду.
- `match-setup` (цифрова версія): вибір літаків, сторін, стартові позиції за лінією.
- `help-window`: таблиці бойових величин і модифікаторів.
- `campaign-roster` (цифрова версія): пілоти, досвід, перемоги, здібності, дата кампанії.
- `end-screen` (цифрова версія): збиті й утеклі.

## Фічі поза полем
- **Кампанія**: від січня 1917 до листопада 1918, рекомендовано 2 бої на місяць; пілоти — новачки (< 50 очок) → досвідчені (50+); ас — 5+ перемог; «Blue Max» — 20 перемог.
- Здібності пілота на 100, 200, 350, 500 і 1000 очках і за кожні 5 перемог (до 5): кращий хвіст, маневр, стабільність (C → B → A), кидок, заклинювання, кут, вогонь, дальність, спостерігач.
- `mode-coop` / `local-multiplayer`: команди сторін на одному столі.
- Перевидання 2014 (Giochi Uniti / Stratelibri): механіка й характеристики «глибоко перероблені», типів літаків 19 → 6.

## Варіації й родичі
- Видання: GDW 1983 → коробкове перевидання 1992 → мініатюрна версія 1995 (без фішок і мапи) → Giochi Uniti 2014. Canvas Eagles (Eric Hotz) — безкоштовна вебпереробка.
- Родичі в корпусі: [Star Fleet Battles](star-fleet-battles.md) (одночасний рух за записом, сектори вогню), [Wooden Ships and Iron Men](wooden-ships-and-iron-men.md) (таємний запис руху, одночасне виконання), [Frozen Synapse](frozen-synapse.md) (план → одночасне виконання), [BattleTech](battletech.md) (аркуш з боксами пошкоджень).
- Осі варіацій:
  - **як задається рух**: очки руху / **номер з таблиці маневрів** (Blue Max) / наказ-рядок `L1R1` (WS&IM) / карти маневрів (Wings of Glory (?));
  - **інформація суперника**: усе таємно / **хвіст бачить напрямок цілі** / повна;
  - **пошкодження**: HP / **фішки з чашки з локаціями** / таблиця результатів;
  - **зброя**: сектор / **лише прямо вперед** / задня дуга спостерігача.

## Цікавинки для курсу
- Розклад маневрів як дані: номер → (зсув, кінцевий напрямок, швидкість) + обмеження ланцюжка (зміна швидкості ≤ 1, обмежені лише після прямих, неповторювані) — 📎.
- Хвіст: перевірка «я в задній дузі цілі, вона в моїй передній, ≤ 3 гекси» + асиметрія інформації під час вибору — 🥉.
- Одночасне виконання з проходом крізь гекси (без зіткнень) — 🌱.
- Мішок з 36 фішок: витяг без повернення до кінця кроку, підміна «хвіст ↔ двигун» за напрямком вогню — 📎.
- Заклинювання / дим / вогонь як ланцюжок станів з кидками — 🌱.
- Кампанія: досвід, пороги здібностей, календар 1917–1918 — 🥉.

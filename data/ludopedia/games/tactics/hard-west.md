# Hard West — XCOM без кубика: промах «зʼїдає» удачу цілі, тож кожен наступний постріл вірніший, а куля вміє рикошетити від металу

## Суть
Покрокова тактика на Дикому Заході з окультизмом: загін 1–4 стрільців, 2 очки дії, укриття половинне й повне — як у XCOM. Головна відмінність — **влучання не вирішує генератор випадковості**: кожен персонаж має запас **удачі**; постріл з шансом X % по ньому знімає X удачі, а коли удачі не вистачає — влучає; отримана рана удачу відновлює. Удача — ще й валюта для здібностей: рикошет від металевих поверхонь (стріляти «за ріг»), ухилення. Між боями — текстова мапа світу, а прогресія — **покерні карти**, комбінації яких дають бонуси.

## Поле і час
- Квадратна сітка з ізометричною камерою, укриття двох висот; 8 сценаріїв, у кожному 4–6 бойових мап (40 місій усього).
- Хід: увесь загін гравця, потім вороги. Під час ходу гравця вороги тримають **360°-бар'єр реакції**.
- Видимість: туман; персонажі на сонці відкидають **тінь**, яка видає позицію навіть без лінії огляду; звуки ворогів також видають їх.
- Деякі місії починаються зі **стелс-фази**: вартові мають конуси огляду, розмір яких залежить від «Heat» зброї загону.

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `turn_start(player)` → ТО кожен `custom: «2 AP»`; рух — 1 AP, постріл — `end_turn(a)` для більшості зброї.
- Шанс: `custom: «база зброї й навички − укриття цілі (половинне/повне)»`; КОЛИ `adjacent(shooter, target)` → ТО `custom: «шанс 100 % (впритул)»`.
- Удача: КОЛИ `input(shoot, s, t)` → ЯКЩО `custom: «удача цілі ≥ шанс влучання»` → ТО `custom: «промах; удача цілі −шанс»`; інакше → ТО `damage(n)` (менше за укриттям).
- КОЛИ `custom: «персонаж отримав шкоду»` → ТО `custom: «удача відновлюється на велику величину»`.
- КОЛИ `custom: «удача = 0»` → ТО `custom: «будь-який постріл по персонажу влучає»`.
- Рикошет: КОЛИ `input(ricochet, s, surface, t)` → ЯКЩО `custom: «металева поверхня і шлях surface→t вільний»` and `custom: «вистачає удачі»` → ТО `custom: «постріл в обхід укриття/поза лінією огляду; удача −вартість»`.
- Тінь: КОЛИ `custom: «ворог на сонці кидає тінь у поле зору загону»` → ТО `reveal(enemy)`; ЯКЩО `custom: «стріляти по тіні»` → ТО `custom: «постріл без лінії огляду»`.
- Shadowkill: КОЛИ `input(shadowkill, s, t)` → ЯКЩО not `custom: «ціль на сонці»` → ТО `damage`.
- Golden Bullet: КОЛИ `input(golden_bullet, s, t)` → ЯКЩО `custom: «удача ≥ 50 % і нема перезарядки здібності»` → ТО `custom: «100 % влучання крізь укриття»`, `custom: «удача −50 %»`, `timer(start)` кулдауна.
- Реакція: КОЛИ `custom: «персонаж гравця перетнув 360°-бар'єр ворога»` → ЯКЩО `custom: «ворог бачив персонажа на початку ходу»` → ТО `custom: «гарантований постріл на повну шкоду»` (здібність лише ШІ).
- Стелс: КОЛИ `level_start` → ЯКЩО `mode(infiltration)` → ТО `custom: «вартові з конусами розміру Heat»`; КОЛИ `enter(s, cone)` → ТО `custom: «тривога, бій»`; КОЛИ `input(subdue, s, guard)` → ТО `custom: «конус вимкнено на час, що залежить від Heat»`.
- Disguise: КОЛИ `state(s, disguised)` → ТО `custom: «вороги ігнорують у стелсі»`.
- Карти: КОЛИ `custom: «ціль сценарію / подія виконана»` → ТО `give(card)`; КОЛИ `custom: «карти персонажа складають покерну комбінацію»` → ТО `custom: «додатковий бонус комбінації»`.
- Поранення (модифікатор Combat Injuries): КОЛИ `custom: «сильна шкода»` → ТО `set_state(a, injury)` → згодом `transform(scar)` зі змішаним ефектом; лікар у сценарії лікує за гроші.
- Ironman: КОЛИ `died(plot_character)` → ТО `lose` (місію провалено); рестарти вимкнено.
- Перемога: ціль місії (знищити всіх / вижити / забрати обʼєкт). Поразка: загін загинув або ціль провалено.

## Керування і ввід
- Миша: вибір стрільця → підсвітка руху; наведення на ворога → шанс і шкода; окремі кнопки здібностей (рикошет показує лінію відбиття від поверхні).
- Вибір цілі по тіні — клік по силуету (?).

## Пропозиції до словників
- `+cond:luck_ge(a, n)` — удача A ≥ N (ключова умова промаху/здібностей).

# Cyborg Earthworm — Snake без керування: напиши шаблони «що бачу навколо голови → куди повзти» і дивись, як черв заповнює поле

## Суть
Класична змійка, але гравець не тисне стрілок: він складає **програму з візуальних шаблонів**. Кожен шаблон описує можливу ситуацію в маленькій околиці голови черва і каже, що робити. Черв повзе сам за першим шаблоном, що збігся; мета — досягти максимальної довжини, заповнивши тілом увесь вільний простір. Інструменти поверх шаблонів — фарба (мітки в ґрунті, на які черв потім реагує) і внутрішня памʼять черва; рішення перевіряється на процедурно згенерованих рівнях, тож воно має бути загальним алгоритмом, а не підгонкою.

## Поле і час
- Квадратна сітка рівня з вільними клітинами-ґрунтом і перешкодами; рівні кожної «зони» (20+) генеруються процедурно — «практично необмежена кількість».
- Черв бачить лише невелику ділянку навколо голови; розмір вікна шаблону задається сіткою в редакторі (є зміна розміру сітки) (?).
- Час `programmed`: на тік програма вибирає напрям, черв робить один крок; тіло — черга, що повторює шлях голови.
- Шар клітини: тип (ґрунт / зайнято тілом / перешкода) + мітка фарби.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Голова черва | player | напрям, памʼять | щотік крок за першим шаблоном, що збігся |
| Тіло черва | object | довжина | повторює шлях голови; довжина — метрика успіху |
| Ґрунт (вільна клітина) | terrain | — | куди черв може повзти; заповнити все — ідеальний забіг |
| Перешкода / край | static | — | непрохідно |
| Мітка фарби | mark | колір (?) | лишає черв за наказом шаблону; шаблони можуть її вимагати |
| Памʼять черва | — | значення (?) | читається умовою шаблону, оновлюється дією шаблону |
| Шаблон | mark | клітини околиці + напрям + дії | правило програми; список упорядкований |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `tick` → ЯКЩО `custom: «околиця голови збігається з шаблоном i (перший у списку)»` → ТО `move(head, dir_i)`; тіло — `custom: «хвіст іде слідом»`.
- КОЛИ `tick` → ЯКЩО `custom: «збігся конкретніший шаблон, що стоїть вище»` → ТО `custom: «загальний шаблон нижче не діє»` (перевизначення порядком).
- КОЛИ `tick` → ЯКЩО `custom: «шаблон вимагає мітку фарби в клітині»` and `custom: «мітка є»` → ТО шаблон збігається; інакше — наступний.
- КОЛИ `tick` → ЯКЩО `custom: «шаблон каже фарбувати»` → ТО `paint(cell, color)` (мітка в ґрунті).
- КОЛИ `tick` → ЯКЩО `custom: «памʼять черва = m»` → ТО шаблон з умовою m збігається; дія шаблону — `set_state(head, memory, m′)`.
- КОЛИ `enter(head, soil)` → ТО `grow(worm, 1)` (?) — черв росте, просуваючись ґрунтом.
- КОЛИ `contact(head, body)` → ТО `custom: «забіг закінчено; рахується довжина»`.
- КОЛИ `blocked(head)` → ТО `custom: «черв застряг; забіг закінчено»`.
- КОЛИ `custom: «жоден шаблон не збігся»` → ТО `custom: «черв зупиняється»` (?).
- КОЛИ `custom: «вільних клітин не лишилось»` → ТО `win` (100 % заповнення).
- КОЛИ `input(stats)` → ТО `custom: «прогнати програму на багатьох згенерованих рівнях зони»`, `window(test_stats)`.
- Перемога: заповнити весь вільний простір · Поразка: нема (поганий забіг — лише коротка довжина) · Рахунок: довжина черва / частка заповнення, середня по тестах (?).

## Керування і ввід
- Редактор шаблонів: сітка-околиця, клацанням задаєш тип клітини (ґрунт, тіло, мітка…) і напрям; шаблони складаються в упорядкований список.
- Запуск, крок (один тік), кнопка `>|` (?); «очистити всі шаблони» (сітка + кошик).
- `stats` — тест програми на наборі рівнів.

## Вікна, меню, HUD
- `game-screen`: велике поле з червом, список шаблонів, кнопки запуску/кроку.
- `code-editor-window` (редактор шаблонів на сітці).
- `stats-window` (custom «test-stats»): результати прогону на згенерованих рівнях (довжини, погані забіги).
- `level-select`: зони й нумеровані рівні.
- `tutorial-window`: текстові пояснення в перших рівнях.
- `confirm-dialog`: вихід.
- Переходи: level-select → game-screen ↔ редактор шаблонів → stats → наступна зона.

## Фічі поза полем
- `step-mode`, `restart-level`.
- 20+ зон з процедурними рівнями — програма має бути загальною; метрика — довжина (оптимізація замість змагання).
- Ранній доступ з 2020; повний реліз — 12.09.2026; є демо.

## Варіації й родичі
- Предок: **Snake Battle** (Gamos, 1995) — програмування змійки шаблонами для боїв; тут натомість соло-оптимізація. Ранній прототип автора — Tetris, де шаблони кладуть тетроміно (стовпці шаблонів на кожну фігуру).
- У сімʼї: `battlesnake` (змійка-бот кодом на сервері), `kara` (автомат: сенсори × стан → дія), `the-farmer-was-replaced` (режим змійки-динозавра).
- **Tail Recursion** (DEV505, 2026) — та сама ідея «змійка без стрілок», але програма — **граф блоків**: Move Forward, Turn Left, Repeat N, If/Else, Wall Ahead?, Store/Recall, сенсори Food ahead? / Door ahead?. Блоки витрачають бюджет тіку (цикли, умови й сенсори — безкоштовні); тіло складається з сегментів-здібностей (сенсор, памʼять, процесор = більший бюджет), і кожна здібність коштує довжини. Граф підсвічує блок, що спрацював; при смерті — причина (стіна чи сам себе). 70 рукотворних пазлів, Free Play з нескінченним полем, свої рівні `.level`, блоки на Lua з гарячим перезавантаженням.
- Осі варіацій: **мова** (шаблони околиці / граф блоків / текстовий код); **памʼять** (нема / біти памʼяті / фарба на полі = стигмергія); **мета** (виживання / довжина / заповнення); **рівні** (рукотворні / процедурні).

## Цікавинки для курсу
- Програма як упорядкований список шаблонів околиці 3×3/5×5 → напрям; перший збіг виграє — 🥉.
- Шаблони з поворотом під напрям голови (щоб не думати про орієнтацію) — 📎.
- Фарба в ґрунті як зовнішня памʼять (стигмергія) + внутрішня памʼять = скінченний автомат — 🥈.
- Прогін програми на N згенерованих рівнях і статистика довжини — 🥉.
- Евристика заповнення поля змійкою (гамільтонів обхід) — 🥇.
- Tail Recursion: тіло = здібності, кожна коштує довжини — 🥈.

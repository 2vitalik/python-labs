# Logic Bombs — постав стіни так, щоб кожна бомба зачепила рівно стільки котів, скільки написано

## Суть
Пазл на квадратній сітці від Matthewmatosis (автор відеооглядів ігор). Гравець ставить стіни: у кожному рядку й стовпці має бути задане число стін, а кожна бомба з числом N має «бачити» рівно N котів. Вибух іде чотирма променями — вгору, вниз, ліворуч, праворуч — крізь порожні клітини й котів, доки не впреться в стіну або край поля.

Правила однакові для всіх 160 пазлів і вводяться по одному в навчальних пазлах («Rule Four … Nothing more. Nothing less.»). Коли все зійшлося, бомби вибухають як підтвердження розвʼязку. До гри додано ROM для Game Boy з тими самими пазлами.

## Поле і час
- Квадратна сітка; на всіх бачених скриншотах і кадрах трейлера — 10×10. Числа ліворуч від рядків і над стовпцями — скільки стін у лінії.
- Клітина: невідома / стіна (чорна) / маркер «×» / дана сутність — бомба з числом, кіт, синя «крапля».
- Промені бомби не мають дальності: лише стіна або край поля їх зупиняють.
- Статичний пазл без таймера (категорія Steam «Playable without Timed Input»).
- Теми: піксельні Original і Green (сіра й зелена «під Game Boy» палітри; котра з них котра — (?)), Sketchbook (намальована: червоні коти, сині іскри замість крапель) і червона палітра зеленого тайлсету.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Стіна | mark | ставить гравець | чорна клітина; зупиняє промені; рахується в числі свого рядка й стовпця |
| Маркер «×» | mark | ставить гравець | «тут не стіна»; з першого патча стіна й маркер не перезаписують одне одного |
| Невідома клітина | mark | — | стартовий стан порожніх клітин |
| Бомба | static | число N | 4 промені до першої стіни або краю; має зачепити рівно N котів |
| Кіт (ціль) | static | стан: не зачеплений / зачеплений / зачеплений кількома | рахується кожною бомбою, що його бачить; промінь іде крізь нього далі |
| «Синя штука» (крапля; у Sketchbook — іскра) | static | — | бомба не має її зачепити (?) |
| Число рядка / стовпця | static | n | рівно n стін у лінії; сіріє, коли виконано, світиться знову, коли стін більше |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(wall, c)` → ЯКЩО `free(c)` → ТО `mark(c, wall)`; повторний ввід — `unmark(c)` (?).
- КОЛИ `input(marker, c)` → ЯКЩО `free(c)` → ТО `mark(c, cross)`.
- Число n рядка чи стовпця: ЯКЩО `count(wall_in_line, ==, n)` — обмеження виконано.
- КОЛИ `counter(wall_in_line, >, n)` → ТО `custom: «число лінії знову світиться»`; лінія з числом 0 світиться, щойно в ній зʼявилась стіна.
- КОЛИ `line_of_sight(bomb, cat)` → ТО `set_state(cat, hit)`; два й більше променів на одного кота — `set_state(cat, overhit)` (третій стан, у Game Boy-версії блимає).
- Бомба з числом N: ЯКЩО `count(cat_in_sight_of_bomb, ==, N)` — обмеження виконано («Nothing more. Nothing less.»).
- КОЛИ `constraint_broken(bomb)` → ТО `custom: «бомба знову світиться»` — котів на променях більше, ніж N.
- КОЛИ `line_of_sight(bomb, drop)` → ТО `custom: «бомба світиться, крапля міняє стан»` (?).
- КОЛИ `input(hover, drop)` → ТО `flash(markers_in_sight)` — блимають маркери, які «бачить» крапля.
- КОЛИ `all_constraints_met` → ТО `explode(rays, to_wall)`, `custom: «заливка поля, бомби й коти зникають»`, `win`.
- КОЛИ `input(hold_marker, puzzle)` на екрані вибору → ТО `restart` — повне скидання розвʼязку пазла.
- Перемога: виконано всі числа ліній і всі бомби. · Поразки нема. · Рахунку нема, лише позначка розвʼязаного пазла.

## Керування і ввід
- Миша: клік по клітині ставить стіну або маркер; для гри однією кнопкою (категорія «Mouse Only Option») кнопка в правому нижньому куті перемикає, що ставить клік — стіну чи маркер.
- Клавіатура й геймпад (повна підтримка, вібрація): курсор по клітинах і окремі кнопки «стіна» та «маркер»; Enter у меню, Escape на екрані вибору відкриває налаштування.
- Миша приймає клік і на рамці завширшки в клітину навколо поля (патч 17.10.2025).
- Наведення на «синю штуку» підсвічує маркери на її лініях (патч 4.11.2025).
- Скидання: на екрані вибору навести на пазл і утримувати кнопку маркера. Undo нема (скарги у відгуках).

## Вікна, меню, HUD
- `level-select` = титульний екран «LOGIC BOMBS»: сітка 16×10 квадратиків = 160 пазлів, підпис «A realm of pure logic.»; пазли мають ID виду «3-8», «9-15»; квадратики трьох видів — порожні, заповнені, з хрестиком.
- `game-screen`: рамка «консолі», поле з числами рядків і стовпців; кути екрана — повноекранний режим (вгорі ліворуч), «×» вихід (вгорі праворуч; на титулі там меню «≡»), тема (внизу ліворуч), перемикач вводу (внизу праворуч).
- `tutorial-window`-пазли: текст правила ліворуч від поля («Rule Four / Bombs hit exactly the stated amount of [кіт].»), ілюстрація «(5) × 5 котів» і підсумок під полем («Nothing more. Nothing less.»); пізніше — «If necessary, review earlier puzzles to see rules again. Rules are rules.»
- `settings-window` (options): керування для миші, клавіатури й геймпада, номер теми.
- HUD: числа ліній (`+ui:clue-greyed`), стрілки біля рядка й стовпця під курсором (`+ui:row-column-guide`), кольори станів котів; «<3» у куті поля після розвʼязку (кадри трейлера).
- Уздовж ліній з числом 0 за межами поля видно ряд хрестиків (скриншот і кадр трейлера).
- Переходи: титул-вибір → пазл → (розвʼязано: вибух, заливка) → титул-вибір; Escape на виборі → налаштування.

## Фічі поза полем
- `levels-sequential` + `level-unlock`: пазли відкриваються поступово (патч 22.07.2025 закрив доступ до закритих рівнів).
- `autosave`: «кожен пазл має свій слот збереження»; `cloud-save` через Steam Cloud.
- `theme-select`: чотири теми; рамка мерехтить від вигоряння екрана, вимикається через readme.
- `colorblind-palette` (категорія Steam «Color Alternatives»), `gamepad-support`, Steam Deck Verified.
- ROM для Game Boy у теці гри: ті самі пазли; виправлення пазлів потребують завантажити ROM наново.
- Нема: undo, музики, таймера, очок, редактора, секретів і мета-пазлів (опис: «No Nonsense»).

## Непевне
- (?) Крапля: патчі кажуть, що бомба світиться, коли «connected to a blue thing», а відгук — що клітина між бомбою й краплею мусить бути стіною; «connected» = «на промені» — моє тлумачення.
- (?) Чи може кіт бути зачеплений двома бомбами: третій стан блимає (радше помилка), але тексту такого правила не бачив.
- (?) Патч «Connected bombs relight…» — можливо, бомби не мають бачити одна одну.
- (?) «Sigma» з відгуків — пізній тип підказки, значення не знаю.
- (?) Підказки: зведення відгуків згадує систему підказок і «серце» як знак правильного шляху; на кадрах «<3» видно лише після розвʼязку.
- (?) Чи всі пазли 10×10; котрою кнопкою миші ставиться стіна, котрою — маркер; що означають три види квадратиків на екрані вибору.
- (?) «10 наборів по 16» — висновок із сітки 16×10 і номерів 3-8 … 9-15.

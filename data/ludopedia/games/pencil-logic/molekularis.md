# Molekularis — збери з літер-атомів одну молекулу: H, O, N, C мають рівно 1, 2, 3, 4 звʼязки

## Суть
На стільниковому візерунку у вершинах стоять літери H, O, N, C — атоми. Між сусідніми атомами (по пунктиру) гравець ставить від 0 до 3 звʼязків-рисок так, щоб у кожного атома їх було рівно стільки, скільки його валентність (H 1, O 2, N 3, C 4), а всі атоми злилися в одну молекулу. Хімії знати не треба: це «Hashi на стільниках» з літерами замість чисел (автор: «правило октету» + «одна молекула»). Автор — Alexander Thomas; пазли виходили в студентському журналі Tartine (ENS Lyon) з 2013/2014 навчального року.

## Поле і час
- Поле — шестикутне «Wabenmuster»: атоми у вершинах стільників, можливі звʼязки — пунктирні ребра; у кожного атома ≤ 3 сусіди (дуально — трикутна сітка). Приклад Janko — 5 стільників, 20 атомів, у розвʼязку є одинарні, подвійні й потрійні звʼязки.
- Звʼязок — 1, 2 або 3 риски на ребрі, лише між сусідами по пунктиру.
- Варіант «Zwischenräume» додає атоми в проміжки, і сусідство задає лише пунктир — тому `field: graph`, а класика — його окремий випадок.
- Шари: атоми-літери (незмінні) · кратності звʼязків на ребрах.
- Час статичний; хід = змінити кратність одного ребра.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| H (водень) | static | валентність 1 | рівно 1 звʼязок |
| O (кисень) | static | валентність 2 | рівно 2 |
| N (азот) | static | валентність 3 | рівно 3 |
| C (вуглець) | static | валентність 4 | рівно 4 |
| Пунктирне ребро | static | — | єдине дозволене місце звʼязку |
| Звʼязок | mark | кратність 0–3 | сума кратностей біля атома = валентність |
| Молекула | zone | — | у розвʼязку одна звʼязна компонента |
| P (фосфор, варіант) | static | валентність 3 або 5 | одна з двох валентностей |
| Q («Qulturium», варіант) | static | ≥ 1 | будь-яка кількість звʼязків |

| Атом-привид (варіант) | static | — | насправді інший атом; кількість привидів дана |
| Номер на краю (варіант) | static | — | «тунель» до діаметрально протилежного атома |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(click, edge)` → ТО `set_value(bond, n + 1)` по колу 0 → 1 → 2 → 3 → 0 (цифрова версія) (?).
- КОЛИ `input(click, edge)` → ЯКЩО `custom: «ребро не пунктирне — атоми не сусіди»` → ТО `block` (цифрова версія).
- КОЛИ `constraint_broken(valence)` → ЯКЩО `custom: «сума кратностей звʼязків атома ≠ валентність»` (`+cond:degree`) → ТО `set_state(atom, error)`.
- КОЛИ `constraint_broken(molecule)` → ЯКЩО `not connected(atom)` → ТО `set_state(molecule, error)`.
- КОЛИ `all_constraints_met` → ТО `win`.
- Перемога: усі валентності точні, молекула одна. Поразки й рахунку нема.
- Іонізований варіант: КОЛИ `constraint_broken(valence)` → ЯКЩО `state(atom, charged)` і `custom: «сума кратностей ≠ валентність − 1»` → ТО `set_state(atom, error)`.
- Іонізований варіант: КОЛИ `constraint_broken(ions)` → ЯКЩО `custom: «два заряджені атоми — сусіди»` → ТО `set_state(atom, error)`; так само, ЯКЩО заряджений атом звʼязаний більш ніж з одним сусідом.
- Проєктивна площина: КОЛИ `edge(bond)` → ТО `custom: «звʼязок продовжується з діаметрально протилежного атома (за номером на краю)»` (`+card:antipodal-wrap`).
- Дедукції: у C ≤ 3 сусіди, а валентність 4 ⇒ біля кожного C є подвійний чи потрійний звʼязок; звʼязок, що насичує обидва атоми (H–H, O=O, N≡N), замкнув би молекулу з двох атомів ⇒ заборонений, якщо атомів більше; сума валентностей завжди парна — кожен звʼязок рахується двічі.

## Керування і ввід
- Папір: між літерами малюють одну, дві чи три паралельні риски — як структурні формули з хімії.
- Цифрова версія: клік по пунктирному ребру — кратність по колу, правий клік — назад; перевірка за кнопкою; undo.
- Варіант «Herausgebrochenes Stück»: вирізаний шматок поля треба повернути й віддзеркалити, а тоді вставити; «Pertamution» — спершу знайти, яка літера який атом.

## Вікна, меню, HUD
- `game-screen` (цифрова версія): пунктирні стільники, атоми-літери, звʼязки рисками; `conflict-highlight` на атомі з хибною сумою і на відірваній частині молекули.
- `help-window`: 2 правила + приклад з розвʼязком (як на Janko й сайті автора).
- `puzzle-select`: класика за складністю (Baby, Mini, einfach, mittel, schwer), рубрики варіантів, архів Tartine за роками (цифрова версія).
- `mode-select` — вибір варіанта правил (цифрова версія).
- Переходи: puzzle-select → game-screen → перевірка → розвʼязано.

## Фічі поза полем
- `puzzle-bank`: сайт автора — класика (Baby 1–5, Mini 1–8, einfach 1–10, mittel 1–14, schwer 1–5), 11 рубрик варіантів, архів Tartine (до «Molekularis 94»); Janko — 6 пазлів з розвʼязками.
- `custom-rules`: варіанти — набори правил; «Gemischte Varianten» поєднують кілька (напр. іонізований на проєктивній площині).

## Варіації й родичі
- Варіанти автора: **Löcher** — частину атомів «зʼїдено», спершу відновити літери · **Projektive Ebene** — край зшито через діаметрально протилежні атоми, малі номери на краю показують, куди «стрибає» звʼязок · **Herausgebrochenes Stück** — вирізаний шматок повернути, віддзеркалити й вставити · **Ionisiert** — атом може мати заряд −1 (на звʼязок менше), заряджені не сусідять, заряджений звʼязаний лише з одним сусідом · **Hyperionisiert** — заряд до −3, двоє сусідів не можуть бути обидва гіперіонізовані · **Zwischenräume** — чотири атоми «з четвертого виміру», сусідство за пунктиром · **Liaisoskop** — число в стільнику = кількість звʼязків навколо нього · **P- і Q-атоми** — P має 3 або 5 звʼязків, Q — будь-яку кількість · **Geisteratome** — дана кількість атомів «прикидається» іншими · **Pertamution / Chessy** — літери переставлено (однакові символи — однакові атоми), у Chessy замість літер шахові фігури · **Gemischte** — суміші.
- [Hashiwokakero](hashiwokakero.md) — число = мости, кратність ≤ 2, одна мережа, квадратна сітка з прямими мостами на відстань.
- [Ichimaga](ichimaga.md) — число = лінії з кружка, одна мережа, лінії з одним поворотом.
- [Sokobond](../thinky/sokobond.md) — ті самі валентності H1 O2 N3 C4, але звʼязок виникає сам, коли штовхнутий атом опиняється поруч; [Atomino](../connect-rotate/atomino.md) — атоми з валентністю 1–4 ставлять курсором у реальному часі, завершена молекула зникає.
- **Осі варіацій**: решітка (квадрат / стільники / довільний граф із пунктиру) · кратність (≤ 2 / ≤ 3) · підказка (число / літера-валентність / діапазон P / будь-яка Q / брехлива) · топологія (площина / проєктивна площина) · заряди (нема / −1 / до −3).

## Цікавинки для курсу
- Валентності як таблиця `{H: 1, O: 2, N: 3, C: 4}` і перевірка суми кратностей біля кожного атома — 🌱.
- Звʼязність молекули (BFS по ребрах з кратністю > 0) — 📎.
- Стільникове поле: координати вершин, сусіди «вгору / вниз» за парністю, малювання пунктиру — 📎.
- Проєктивна площина: відповідність країв «діаметрально протилежно» — 🥉.
- Розвʼязувач: кратності 0–3 на ребрах з відсіканням за валентностями й звʼязністю; загадка автора — скільки звʼязків максимум може мати Q-атом у пазлі з єдиним розвʼязком — 🥇.

## Мапа на каталог
- Є: `satisfy-constraints`, `completion-detection`, `markup-validity` · `edge-marking` ↔ кратність на пунктирному ребрі · `connectivity-check` ↔ одна молекула · `piece-rotate-flip` ↔ вирізаний шматок (варіант).

- **Нема** → пропозиції карток:
  - `+antipodal-wrap` «Проєктивна площина: вихід за край веде до діаметрально протилежної точки» · entities/move · 🥉 — родич `wrap-edges` (тор).
  - `+ion-charge` «Заряд вузла зменшує валентність; заряджені не сусідять; заряджений звʼязаний з одним сусідом» · game-logic/constraints · 📎 · слот {max_charge: 1|3}.

## Пропозиції до словників
- `+cond:degree` — повтор: сума кратностей звʼязків біля вузла = N.
- `+card:valence-bonds` — повтор (Sokobond, Atomino; тут — пазл без руху).
- `+card:bridge-connect` — повтор (Hashi) зі слотом `max: 3` і сусідством за пунктиром.
- `+card:antipodal-wrap`, `+card:ion-charge` — див. мапу.

# Bank Heist — грабуй банки в місті-лабіринті: кожен пограбований банк кличе копа, кожен підірваний коп — новий банк

## Суть
Гравець веде машину-втікачку вулицями міста-лабіринту (як Pac-Man) і грабує банки, проїжджаючи крізь них. Кожне пограбування випускає поліцейську машину (до 3 одночасно) і ставить новий банк; кожен коп, підірваний динамітом із вихлопної труби, теж народжує банк — виходить замкнений цикл «банк ↔ коп». Пальне витікає з часом і від динаміту; поповнює його лише виїзд у наступне місто, звідки нема вороття, тож гравець щоразу вирішує: ще один банк чи тікати, поки є бензин.

## Поле і час
- Місто — один екран-лабіринт вулиць між кварталами; клітинність руху — як у maze-аркад Atari (?).
- Три проходи на краях обгортають екран: напр., виїзд у нижній лівий прохід → поява з нижнього правого. Верхній правий прохід веде в **наступне місто**; назад повернутись не можна.
- 4 міста на рівень (Bankersfield, Flat Broke, Silver Dollar, Heistown), 8 рівнів; після 4-го міста — наступний рівень, де копи швидші, а пальне згоряє швидше.
- Real-time; гра стартує з першого руху (ALE) або Game Reset / кнопкою (мануал).

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(dir)` → ЯКЩО `free(next_cell)` → ТО `move(car, dir)`.
- КОЛИ `tick` → ТО `counter(fuel, -1)`; темп росте з рівнем.
- КОЛИ `contact(car, bank)` → ТО `disappear(bank)`, `counter(banks_in_town, +1)`, `score(10 × banks_in_town)` ($10 за 1-й … $90 за 9-й), `spawn_at(bank, random|preset)`.
- КОЛИ `picked(car, bank)` → ЯКЩО `count(cop, <, 3)` → ТО `spawn(cop)` — коп рушає в погоню (місце появи (?)).
- КОЛИ `input(fire)` → ТО `place(car, dynamite)` позаду машини, `counter(fuel, -n)`.
- КОЛИ `custom: «динаміт вибухає»` → ЯКЩО `occupied(blast, cop)` → ТО `disappear(cop)`, `score(10|30|50)` залежно від кількості копів у погоні (1/2/3) (?), `spawn_at(bank, random|preset)`.
- КОЛИ `custom: «динаміт вибухає»` → ЯКЩО `occupied(blast, car)` → ТО `lives(-1)` — свій динаміт теж убиває.
- КОЛИ `contact(car, cop)` → ТО `lives(-1)`.
- КОЛИ `counter(fuel, ==, 0)` → ТО `lives(-1)`.
- КОЛИ `counter(fuel, <, low)` → ТО `custom: «машина блимає»` (попередження).
- КОЛИ `enter(car, side_passage)` → ТО `teleport(car, paired_passage)` — `wrap` по визначених проходах; найкращий спосіб відірватися від копів.
- Коп щотік: Left A — `custom: «погоня, завжди знаходить машину»`; Left B — `custom: «фіксований маршрут»`; КОЛИ `custom: «розвилка»` → ЯКЩО `custom: «напрям = назад»` → ТО `block` (без розворотів, тож за копом можна їхати без ризику лобового зіткнення).
- КОЛИ `reach(car, upper_right_exit)` → ТО `next_level` (місто), `counter(banks_in_town, =0)`, `custom: «пальне до позначки, якщо стрілка біла; червона — без змін»`.
- КОЛИ `reach(car, upper_right_exit)` → ЯКЩО `counter(banks_in_town, >=, 9)` → ТО `custom: «повний бак»`, `lives(+1)`, `score(city_bonus)` ($93 / $279 / $186 / $372 на 1-му рівні, далі +$372 за рівень).
- КОЛИ `custom: «покинуто 4-те місто»` → ТО `speed(cop, +n)`, `custom: «пальне згоряє швидше»`.
- КОЛИ `counter(lives, ==, 0)` → ТО `game_over`.
- Перемога: нема (рахунок). · Поразка: скінчились запасні машини — від копа, свого динаміту чи порожнього бака. · Рахунок: банки зростаючою ціною, підірвані копи, бонус міста за ≥9 банків.

## Керування і ввід
- Джойстик — 4 напрямки руху вулицями (ALE дає 18 дій, тобто й діагоналі з кнопкою; значення діагоналей у грі (?)).
- Кнопка — скинути динаміт із вихлопу; прийом із мануалу — підпустити копа впритул позаду і тоді скинути.
- Консоль: Game Select — рівень старту (8 рівнів); Game Reset — старт; Difficulty Left — розум копів; Difficulty Right — банки випадково / у заданому порядку; Color/B-W.

## Вікна, меню, HUD
- Меню нема (Atari 2600): налаштування — фізичні перемикачі консолі.
- `game-screen` — місто на весь екран; HUD: `score` (у доларах), бензобак угорі ліворуч як `energy-bar` + позначка дозаправки (`custom: «refill-marker»`, стрілка біла/червона), `lives` — запасні машини (?), номер міста/рівня (?).
- Переходи: Game Select (рівень) → Game Reset → місто 1 → верхній правий вихід → місто 2 … → 4-те місто → наступний рівень → … → 0 машин → кінець (рахунок лишається на екрані (?)).

## Фічі поза полем
- `difficulty-presets` — два перемикачі незалежно: розум копів (A/B) × розклад банків (A/B); ALE називає це складностями 0–3.
- Вибір стартового рівня Game Select — `level-select` (ALE: режими 0, 4, … 28 — вісім стартів).
- `levels-sequential`: 8 рівнів × 4 міста з наростанням швидкості.
- Нема збереження, рекордів, паролів, мультиплеєра.

## Варіації й родичі
- `rally-x` — машина в лабіринті, пальне як таймер, димова завіса проти переслідувачів; тут замість диму динаміт, а пальне поповнюється лише виїздом.
- `pac-man` — лабіринт, проходи-обгортки; але збирання не «все», а «скільки наважишся».
- `lock-n-chase` — грабіжник у лабіринті проти копів, що збирає монети; двері замість динаміту.
- `bomberman` — бомби, що ранять і самого гравця.
- **Осі варіацій:** звідки беруться вороги (фіксовано / кожен підібраний предмет породжує ворога); що поповнює ресурс (предмет на полі / вихід із рівня); чи можна повернутися в пройдену зону (так / ні); чи ранить своя зброя (ні / так).

## Цікавинки для курсу
- Цикл «підібрав банк → зʼявився коп; знищив копа → зʼявився банк» з лімітом 3 копи — саморегульована складність — 🥉.
- Пальне як таймер, що витрачається ще й на зброю, і дозаправка лише на виході зі шкалою-прогнозом — 📎.
- Динаміт, що вбиває і свого: бомба-пастка позаду машини з перевіркою радіуса для всіх — 📎.
- Ціна банку = порядковий номер у місті + поріг 9 банків (машина, повний бак, бонус) — ризик/нагорода «ще один?» — 🌱.
- Копи без розворотів (`no-reverse-turn`) і два режими AI за перемикачем — 📎.
- Гра — середовище ALE (Gymnasium): навчити RL-агента грабувати банки — 👑.

- (?) Запал динаміту (миттєво чи з затримкою) і радіус вибуху — не описані.
- (?) Ціни копів $10 / $30 / $50 — мануал прив'язує їх до кількості машин у погоні; чи це ціна одного копа, чи серії — неясно. Ціна 10-го банку й далі — не дано.

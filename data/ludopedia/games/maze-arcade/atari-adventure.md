# Adventure (Atari 2600) — квадратик-лицар носить по одному предмету крізь лабіринти трьох замків, щоб повернути Чашу додому, ухиляючись від драконів і кажана-злодія

## Суть
Гравець — маленький квадрат, що ходить екранами-кімнатами королівства (30 кімнат), відчиняє ворота замків ключами відповідних кольорів і шукає Зачаровану Чашу, щоб принести її в Золотий замок. Нести можна лише **один** предмет: меч, ключ, міст, магніт чи Чашу — і кожен вибір відкриває одне й закриває інше. Три дракони охороняють свої предмети й ковтають героя, кажан краде і міняє предмети навіть поза екраном. Перша графічна пригодницька гра і перша відома пасхалка — схована кімната з іменем автора.

## Поле і час
- Королівство — граф кімнат-екранів; вихід за край екрана через отвір веде в сусідню кімнату. Деякі переходи односторонні («погана магія»).
- Лабіринти в замках і навколо: більшість екранів дзеркальні ліво-право, що плутає; кілька екранів симетрію порушують.
- Катакомби — туман: видно лише найближче оточення героя (`info: partial`).
- Рух вільний (піксельний), 8 напрямків; real-time; світ «живе» поза екраном: кажан і дракони рухаються й там.
- Рівень 1 — спрощена мапа (без Білого замку, кажана, червоного дракона, невидимих лабіринтів); рівні 2–3 — повна мапа; рівень 3 — випадкові стартові позиції предметів і драконів.

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(dir)` → ЯКЩО `free(ahead)` → ТО `move(hero, dir)`; інакше `block`.
- КОЛИ `edge(hero)` → ТО `custom: «перехід у сусідню кімнату з того боку»` (`+trigger:room_exit`).
- КОЛИ `contact(hero, item)` → ТО `custom: «підняти; той, що ніс, лишається на місці»` (`carry`) — `count(carried, ==, 1)` завжди.
- КОЛИ `input(button)` → ЯКЩО `has(hero, item)` → ТО `custom: «кинути предмет тут»` (`+effect:drop`).
- КОЛИ `contact(hero, gate[c])` → ЯКЩО `has(hero, key[c])` → ТО `set_state(gate, open)`; інакше `block`.
- КОЛИ `leave(key[c], castle)` → ЯКЩО `not has(hero, key[c])` → ТО `custom: «ворота можуть зачинитись — ключ лишився всередині»` (?).
- КОЛИ `contact(dragon, sword)` → ТО `transform(dragon_dead)`.
- КОЛИ `contact(dragon, hero)` → ЯКЩО `not has(hero, sword)` або `custom: «меч не торкнувся дракона першим»` → ТО `custom: «дракон кусає й ковтає героя»`, `lose`.
- Дракон: КОЛИ `tick` → ТО `custom: «рух до героя або до свого предмета (охорона)»` (`chase-player`); Йоргл — `custom: «тікає від Золотого ключа й кімнати з ним»`.
- КОЛИ `tick` → ЯКЩО `mode(switch_right_a)` `and has(hero, sword)` → ТО дракони: `custom: «тікають від меча»`.
- КОЛИ `contact(dragon, hero)` → ЯКЩО `mode(switch_left_b)` → ТО `custom: «дракон вагається перед укусом — шанс втекти»`.
- КОЛИ `input(button)` → ЯКЩО `has(hero, bridge)` `and custom: «обидва кінці по різні боки стіни»` → ТО `custom: «міст лягає через стіну; крізь нього можна пройти»`; торкнутись бокових балок зсередини — `block` (пастка).
- КОЛИ `tick` → ЯКЩО `occupied(room, magnet)` → ТО `custom: «неживі предмети тягнуться до магніту»`; діє і на сусідню кімнату, якщо магніт винесли перед собою.
- Кажан: КОЛИ `tick` → ЯКЩО `state(bat, agitated)` → ТО `swap(bat_item, room_item)` або `custom: «хапає предмет у героя»`, `set_state(bat, calm)`; діє і поза екраном.
- КОЛИ `contact(hero, bat)` → ТО `custom: «можна зловити й нести кажана разом з його предметом; може вирватись»`.
- КОЛИ `enter(hero, catacombs)` → ТО `hide(cells)` поза малим радіусом героя.
- КОЛИ `custom: «у кімнаті ≥ 4 обʼєкти»` → ТО `custom: «магія діє ненадійно — спрайти блимають, дракону важче проковтнути»`.
- КОЛИ `enter(chalice, golden_castle)` → ТО `win`.
- КОЛИ `input(reset)` → ЯКЩО `state(hero, swallowed)` → ТО `respawn(hero, golden_castle_gate)`; убиті дракони теж оживають (`respawn(dragon)`), предмети лишаються, де були.
- Пасхалка: КОЛИ `contact(hero, barrier)` → ЯКЩО `has(room, dot)` `and count(objects_in_room, >=, 3)` `and level(op, >=, 2)` → ТО `custom: «бар'єр блимає, крізь нього можна пройти»` → схована кімната з написом «Created by Warren Robinett».
- Перемога: Чаша в Золотому замку. Поразка: дракон проковтнув (Reset — перевтілення без штрафу). Рахунку нема.

## Керування і ввід
- Джойстик — рух у 8 напрямках; червона кнопка — кинути предмет. Підбирання — дотиком.
- Консоль: Game Select — рівень 1–3, Game Reset — старт / перевтілення; лівий Difficulty — швидкість укусу драконів, правий — дракони тікають від меча.
- Тактика «нести перед собою»: предмет тримається з того боку, де взяли, — ним можна «штовхнути» дракона мечем або винести магніт у сусідню кімнату.

## Вікна, меню, HUD
- `game-screen` — кімната на весь екран; HUD нема (ні очок, ні життів, ні таймера); колір кімнати — підказка, де ти.
- `mode-select` — номер рівня 1–3 перемикачем Game Select, показується на екрані.
- Фінал — `custom: «екран блимає кольорами»` (?).
- Схована кімната пасхалки — `custom-window` з написом автора.
- Переходи: Select (рівень) → Reset → гра → (проковтнули) Reset → перед Золотим замком → … → (Чаша вдома) перемога.

## Фічі поза полем
- `skill-levels` 1–3: розмір мапи, наявність кажана й Ріндла, фіксовані / випадкові стартові позиції (рівень 3 — `seed` не показується).
- Перемикачі складності як окремі правила драконів (вагання, страх меча) — `custom-rules`.
- Перевтілення без ліміту — `continue` без втрати стану світу.
- Без збереження, рахунку і рекордів.

## Пропозиції до словників
- `+trigger:room_exit` — герой вийшов за край кімнати-екрана (Adventure, Berzerk, Venture).

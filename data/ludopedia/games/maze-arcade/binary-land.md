# Binary Land — два пінгвіни в дзеркальному лабіринті: ліво-право навпаки, зійтись біля серця одночасно

## Суть
Гравець одним джойстиком керує двома пінгвінами — Гріном і Мароном, які стоять по різні боки вертикальної стіни. Вгору-вниз вони йдуть однаково, а ліворуч-праворуч — **дзеркально**, тож вирівнювати їх доводиться, упираючи одного в стіну свого лабіринту, поки другий іде. Мета раунду — щоб обидва **одночасно** дісталися клітини з серцем у клітці вгорі посередині. Павутиння зупиняє одного пінгвіна, і тоді рухається лише другий; спрей знімає павутиння і вбиває павуків.

## Поле і час
- Сітка 10×15 клітин (EN-вікі), поділена вертикальною стіною на дві половини; у кожній — свій лабіринт, навмисно несиметричний.
- Єдина клітина, доступна обом, — верхня центральна, з кліткою-серцем.
- Real-time з таймером раунду; залишок часу додається до очок.
- 99 стадій, після 99-ї — знову з першої без фіналу (JA-вікі; EN-вікі каже про цикл після 17-ї — див. «Непевне»).

| Марон (дівчинка) | player | обраний або другий | другий іде вгору/вниз так само, ліворуч/праворуч — навпаки |

| Клітка з серцем | static | верх посередині | обидва одночасно → раунд пройдено |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(up|down)` → ТО `move(selected, dir)` і `move(other, dir)`, кожен ЯКЩО `free(next_cell)` — інакше `block` лише для того, хто вперся.
- КОЛИ `input(left|right)` → ТО `move(selected, dir)` і `mirror_input` для другого: `move(other, opposite dir)`; упор одного не зупиняє другого.
- КОЛИ `contact(penguin, web)` → ТО `set_state(penguin, stuck)`; далі рухається лише другий пінгвін.
- КОЛИ `contact(spray, web)` → ТО `disappear(web)`, `score(100)`; ЯКЩО `state(penguin, stuck)` у цій клітині → ТО `clear_state(penguin, stuck)` — керування знову парне.
- КОЛИ `contact(spray, spider)` → ТО `disappear(spider)`, `score(200)`.
- КОЛИ `contact(spray, fireball)` або `contact(spray, bird)` → ТО `custom: «без ефекту»`.
- КОЛИ `state_on(penguin, stuck)` → ЯКЩО `state(gurin, stuck)` and `state(malon, stuck)` → ТО `lives(-1)` (міс).
- КОЛИ `contact(penguin, spider)` або `contact(penguin, fireball)` → ЯКЩО `not state(penguin, invincible)` → ТО `lives(-1)`.
- КОЛИ `contact(penguin, bird)` → ТО `swap(gurin, malon)`.
- КОЛИ `contact(penguin, bonus)` → ТО `disappear(bonus)`, `score(n)` (500 / 1000 / 2000 / 5000).
- КОЛИ `contact(penguin, whale_card)` → ТО `set_state(penguin, invincible, dur)`, `speed(penguin, +1)`.
- КОЛИ `contact(penguin, fireball)` → ЯКЩО `state(penguin, invincible)` → ТО `disappear(fireball)`.
- КОЛИ `contact(spray, special_obstacle)` → ТО `transform(special_obstacle, panel)`; КОЛИ `contact(penguin, panel)` → ТО `score(n)` або `lives(+1)`.
- КОЛИ `custom: «умова виклику курчати»` → ТО `spawn(chick)`; КОЛИ `contact(chick, bird|fireball)` → ТО `disappear(bird|fireball)`.
- КОЛИ `rng(p)` → ТО `move(spider|fireball, rng_dir)` (вороги блукають випадково).
- КОЛИ `all_on(penguin, heart_cage)` (одночасно) → ТО `score(time_left)`, `next_level`.
- КОЛИ `counter(time_left, ==, 0)` → ЯКЩО `not mode(bonus_round)` → ТО `lives(-1)`.
- КОЛИ `counter(lives, ==, 0)` (міс при останньому) → ТО `game_over`, ЯКЩО рекорд — `window(name-entry)`.
- Бонусний раунд (кожні кілька раундів): КОЛИ `level_start` → ТО `set_state(one_penguin, stuck)`; КОЛИ `picked(penguin, bonus_item)` → ТО `score(800)`; КОЛИ `all_on(penguin, heart_cage)` → ЯКЩО `all_gone(bonus_item)` → ТО `score(50000)`; КОЛИ `counter(time_left, ==, 0)` → ТО `next_level` без міса.
- Перемога: окремого фіналу нема — стадії по колу. Поразка: обидва в павутинні, дотик павука чи кулі, кінець часу; життя скінчились → кінець. Рахунок: павутиння 100, павук 200, бонуси 500–5000, спецпанелі 1000–5000, залишок часу, бонусний раунд 800 за предмет і 50000 за все.

## Керування і ввід
- Хрестовина — рух (обраний пінгвін — як натиснуто, другий — дзеркально по горизонталі); A або B — спрей; Start — пауза.
- На титулі гравець обирає, ким керувати «прямо» — Гріном чи Мароном.
- Коли один пінгвін застряг, хрестовина рухає лише другого.

## Вікна, меню, HUD
- `main-menu` (титул) → `character-select` — вибір Гріна або Марона.
- `game-screen` — два лабіринти поруч; HUD: `score`, залишок часу (`timer-countdown`), номер раунду (`level-number`), запас життів (`lives`).
- `bonus-round` — раунд з одним пінгвіном у павутинні від старту, предметами по 800 і без міса за час.
- `pause-menu` — пауза кнопкою Start.
- `name-entry` (Best 5) — після кінця гри, якщо очки в топ-5: курсор, перебір літер угору/вниз, реєстрація; за бездіяльності реєструється сам; таблиця стирається з вимкненням живлення.
- Переходи: титул → вибір персонажа → раунд → (обидва біля серця) наступний раунд, кожні кілька — бонусний → (життя скінчились) топ-5 → титул.

## Варіації й родичі
- PC-версії (1983) і MSX (1984): замість пінгвінів — хлопчик і дівчинка, механіка та сама; Famicom (1985) — пінгвіни, 99 стадій; мобільні римейки 2001–2005, GBA-збірка 2005, Virtual Console 2011/2013.
- [Libble Rabble](libble-rabble.md) — два підконтрольні разом, але двома джойстиками і з мотузкою; [Kwirk](../push-slide/kwirk.md) — кілька аватарів з перемиканням; [Pac-Man](pac-man.md) — однекранний лабіринт із ворогами.
- **Осі варіацій** звʼязку двох аватарів: незалежні з перемиканням (Kwirk) / одночасні однакові / **дзеркальні по одній осі** (Binary Land) / звʼязані мотузкою (Libble Rabble); мета пари — кожен до своєї цілі / зустрітись в одній клітині одночасно; пастка — вбиває / вимикає одного, керування переходить до другого.

## Цікавинки для курсу
- Дзеркальне керування двома аватарами з незалежним упором у стіни — 🥉 (один ввід → два ходи з окремою перевіркою `free`).
- Мета «обидва в цілі одночасно» — 📎.
- Павутиння вимикає одного аватара, і керування переходить до другого, доки той не визволить — 📎.
- Птах міняє аватарів місцями — 🌱.
- Спрей перетворює певні перешкоди на бонус-панелі — 🌱.
- Розвʼязувач раунду: BFS по парах позицій (до (10×15)² станів) з урахуванням дзеркала й упорів — 🥇.

## Непевне
- (?) Як саме визволяють застряглого: EN-вікі — вільний пінгвін переходить через спільну клітину в чужу половину і знімає павутиння спреєм; мануал каже лише «визволиш — усе як було».
- (?) Чи вільний пінгвін, поки другий застряг, рухається «прямо» чи дзеркально, якщо застряг обраний.
- (?) Цикл стадій: JA-вікі — після 99-ї на першу; EN-вікі — «після 17-ї знову з першої».
- (?) Умова появи курчати; які саме перешкоди дають спецпанелі; тривалість невразливості від карти-кита.
- (?) Бонуси: мануал — торт 500, JA-вікі — перстень 500; «є й інші бонуси» — список неповний.
- (?) Початкова кількість життів і тривалість таймера раунду; як часто бонусний раунд («кожні кілька раундів»).
- (?) Примітка мануалу «дві останні цифри відкидаються» стосується показу очок чи залишку часу.

# RimWorld (кімнати) — кімната виникає сама з замкнених стін, її роль визначає вміст, а одна температура і «враження» на всю кімнату впливають на настрій

## Суть
Описано **лише шар кімнат і температури** RimWorld. Гравець не малює кімнат: він будує стіни, двері, дах і меблі, а гра сама знаходить **кімнати як замкнені області** (flood fill по клітинах, обмежених непрохідним). Кожна кімната отримує **роль за вмістом** (спальня, їдальня, лікарня, майстерня… — найбільший бал), **Impressiveness** зі статистик Wealth/Beauty/Space/Cleanliness (найслабша має ~половину ваги) і **одну температуру**, що вирівнюється з сусідами крізь стіни, двері й відсутній дах. Колоністи (pawns) діють самі: користуються кімнатами й отримують думки-модифікатори настрою.

## Поле і час
- Квадратна сітка зверху; мапа процедурна (`random: both` — генерація + події). Під капотом — **регіони 12×12**, які ріжуть непрохідні будови; регіони зливаються; кімната — обʼєднання регіонів, максимум 36 регіонів (найбільша можлива 72×72 = 5184 клітин; безпечно — 50×50).
- Шари клітини: місцевість (ґрунт, камінь, болото…) · підлога (впливає на чистоту, красу, вартість) · будова (стіна, двері, вентиляція, кондиціонер, меблі) · **дах** (немає / збудований / тонкий камінь / товстий камінь) · бруд і предмети.
- Real-time з годинником доби й сезонами; рівняння температури кожні 120 тіків; пауза й 3 швидкості (?).
- Кімнатні значення — **одне на кімнату**, не на клітину (на відміну від ONI / Theme Hospital).

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Стіна | static | матеріал, ціна, краса | непрохідна; обмежує кімнату; матеріал на тепло не впливає |
| Колона в куті | static | — | кути заповнювати не треба (4-сусідство); колона в зовнішньому куті лише додає Wealth/Beauty |
| Двері (одинарні / подвійні) | gate | відкриті / закриті | замикають кімнату навіть відкриті; відкриті — швидко вирівнюють тепло; регіон дверей окремий |
| Вентиляція | gate | відкрита / закрита | замикає кімнату, але дуже швидко передає тепло |
| Кондиціонер (cooler) | conduit | ціль °C, холодна/гаряча сторона | стоїть у стіні; качає тепло з одного боку в інший; гарячий бік — назовні |
| Обігрівач (heater) | source | ціль 21 °C, струм | додає тепло кожен крок вирівнювання, доки не досягнуто цілі |
| Пасивний охолоджувач | sink | 17 °C, 5 днів на дровах | охолоджує, морозити не може |
| Багаття | source | ≤30 °C, паливо | гріє без струму |
| Дах | terrain | тип | ≥25 % клітин без даху → кімната бере температуру надворі; товстий камінь — не обмінюється з надвором |
| Кімната | zone | роль, Wealth, Beauty, Space, Cleanliness, Impressiveness, температура | автоматично з flood fill; перераховується після змін стін/дверей |
| Меблі ролі (ліжко, стіл, верстат, плита, медичне ліжко, полиця…) | object | розмір, вартість, краса | визначають роль кімнати за балами; займають Space |
| Підлога | terrain | чистота (−20…+1), краса, вартість | чистота кімнати = середнє по клітинах |
| Бруд (кров, блювота, сміття…) | hazard | чистота −5…−20 | знижує Cleanliness; прибирає колоніст |
| Колоніст (pawn) | ally | потреби, настрій, комфорт 16–26 °C | діє сам за пріоритетами; користується кімнатами; ловить думки |
| Їжа / тіла | object | свіжість | псуються швидше в теплі, не псуються при ≤0 °C |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `custom: «збудовано/знесено стіну, двері, вентиляцію, кондиціонер»` (`+trigger:room_changed`) → ТО `fill(region)` — `custom: «перерахувати регіони 12×12 і кімнати: 4-звʼязні області, обмежені непрохідним»`.
- КОЛИ `custom: «межу кімнати змінено»` → ЯКЩО `custom: «область торкається краю мапи»` → ТО `custom: «це надвір, не кімната»`.
- КОЛИ `custom: «межу кімнати змінено»` → ЯКЩО `custom: «більше 36 регіонів»` → ТО `custom: «непризначений внутрішній простір, не кімната»`.
- КОЛИ `custom: «межу кімнати змінено»` → ТО `custom: «для кожної ролі бал за вмістом: спальня 100000 (одне вільне людське ліжко), лікарня 100000 (медичні ліжка без тюремних), барак 100100 за ліжко, їдальня 12 за стіл, кімната відпочинку 7 за розвагу, лабораторія 60, кухня 28 за плиту, майстерня 27 за верстат, склад 1 за полицю, звичайна 0,99»` → `set_state(room, role=max)`; рівність — роль, що вище в таблиці.
- КОЛИ `custom: «межу кімнати змінено»` → ТО `set_value(room.space, 1.4 × клітини − 0.9 × клітини під меблями, що не дають стати)`; стільці не рахуються.
- КОЛИ `custom: «межу кімнати змінено»` → ТО `set_value(room.wealth, сума вартості будов, меблів, підлог + стіни й двері навколо)`.
- КОЛИ `custom: «межу кімнати змінено»` → ТО `set_value(room.beauty, сума краси клітин усередині й поруч / weighted_size)`, де `weighted_size = size, якщо size > 40, інакше 20 + size/2` — малі кімнати штрафуються.
- КОЛИ `tick` → ТО `set_value(room.cleanliness, середнє чистоти клітин)` (підлога під дверима не рахується, бруд під дверима — так).
- КОЛИ `custom: «перерахунок статистик»` → ТО `set_value(room.impressiveness, 65 × середнє(m) + 35 × мінімум(m))`, де `m = f(Wealth/1500, Beauty/3, Space/125, 1 + Cleanliness/2.5)` з логарифмом поза (−1, 1); ЯКЩО `custom: «I > 500 × m_space»` → ТО `custom: «I = 0.25·I + 0.75·500·m_space»` (м'яка стеля від розміру).
- КОЛИ `custom: «колоніст скористався кімнатою за роллю»` (сон у спальні, їжа за столом) → ТО `custom: «думка за рівнем Impressiveness: <20 Awful −2 (лише спальні) … 50–64 +3 … ≥240 Wondrously +8»` (`+effect:mood`).
- КОЛИ `timer(120 ticks)` → ЯКЩО `custom: «≥25 % клітин без даху»` → ТО `set_value(room.temp, outdoor)`.
- КОЛИ `timer(120 ticks)` → ЯКЩО `custom: «дах збудований/тонкий камінь»` → ТО `custom: «температура рухається до надвірної, швидкість ~ периметр/площа»` (`+effect:equalize`); товстий камінь — ні.
- КОЛИ `timer(120 ticks)` → ТО `custom: «обмін з сусідніми кімнатами крізь стіни лише в 4 напрямках; подвійна стіна — удвічі повільніше, далі без ефекту»`; відкриті двері/вентиляція — швидко.
- КОЛИ `timer(120 ticks)` → ЯКЩО `state(heater, powered)` and `counter(room.temp, <, target)` → ТО `custom: «додати тепло»`; кондиціонер — `custom: «перенести тепло з холодного боку на гарячий»`; заблокований вхід/вихід — не працює.
- КОЛИ `tick` → ЯКЩО `custom: «тіло ≤40 °C»` → ТО `custom: «колоніст гріє кімнату ≈1,25 × розмір тіла»`.
- КОЛИ `custom: «колоніст спить при > 26 / < 16 °C»` → ТО `custom: «думка “Slept in the heat/cold”»`; на 10° за межею комфорту — тепловий удар / гіпотермія, тяжкість росте; 100 % — смерть.
- КОЛИ `tick` → ЯКЩО `custom: «їжа при 1–10 °C»` → ТО `custom: «псування × T/10»`; ЯКЩО `custom: «≤ 0 °C»` → ТО `custom: «не псується»` — морозильна кімната.
- КОЛИ `tick` → ЯКЩО `custom: «верстат поза 10–35 °C»` → ТО `speed(work, ×0.7)`; ЯКЩО `custom: «верстат поза кімнатою з правильною роллю»` → ТО `speed(work, ×0.2)` (?) (з 1.6).
- КОЛИ `counter(room.temp, >=, 235)` → ТО `custom: «предмети й люди самозаймаються»`.
- Поразка — усі колоністи мертві/зникли (?); перемога — корабель/кінцівки DLC (Wikipedia). Рахунку нема; настрій і виживання — мета.

## Керування і ввід
- Курсор: меню Architect → Structure (стіни, двері, колони), Furniture, Temperature (обігрівач, кондиціонер, вентиляція), Floors; drag-лінія для стін, drag-прямокутник для підлоги й даху (Build roof / Remove roof area).
- Поворот предмета перед установкою (Q/E (?)); кондиціонер — вибір боку.
- Призначення ліжка власнику (спальня стає «Колоніст X's bedroom»).
- Колоністами напряму не керують: пріоритети робіт (таблиця), розклад, draft для бою.

## Варіації й родичі
- У корпусі: `prison-architect-rooms` (кімната — явна позначка + flood fill секторів), `theme-hospital` (креслення прямокутника; тепло на тайл), `oxygen-not-included-cells` (газ і температура на клітину; кімнати з вимогами), `frostpunk` (тепло радіусом); Dwarf Fortress — у черзі.
- **Осі варіацій «кімната»**: явна позначка (PA) / креслення прямокутника (Theme Hospital) / автоматично flood fill (RimWorld, ONI) · **«роль»**: задає гравець / бали за вмістом (RimWorld) · **«якість»**: сума предметів (Two Point престиж) / формула з мінімумом (RimWorld) · **«тепло»**: на клітину з дифузією / одне на кімнату з обміном через межі / радіус.

## Цікавинки для курсу
- Кімнати як 4-звʼязні компоненти, обмежені непрохідним; край мапи = надвір; ліміт розміру — 📎 (flood fill/BFS).
- Регіони 12×12 як прискорення: перераховувати лише змінені — 🥈.
- Роль кімнати як argmax балів за вмістом з таблиці — 🌱.
- Impressiveness: нормування, логарифм, «середнє + мінімум», мʼяка стеля від Space — 📎.
- Температура кімнати: обмін із сусідами пропорційно периметру/площі, дах ≥25 %, подвійна стіна — 🥉.
- Обігрівач/кондиціонер як термостат з ціллю й теплообміном між кімнатами — 📎.
- Псування їжі від температури (морозильник) — 🌱.

## Пропозиції до словників

- `+ui:room-stats-panel` — статистики кімнати під курсором; `+ui:temperature-readout`.

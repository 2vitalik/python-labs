# Мураха Ленгтона — один агент фарбує клітину під собою й повертає; з хаосу виростає «шосе»

## Суть
Нуль гравців: на білому полі стоїть мураха; на білій клітині вона повертає праворуч, на чорній — ліворуч, перефарбовує клітину й робить крок уперед. Із двох рядків правила виростають три фази: кілька сотень кроків симетричних візерунків, хаос до кроку 9 977 і нескінченне «шосе» з періодом 104 кроки. Гравець лише ставить мураху(-х), задає правило-рядок і початковий малюнок, далі дивиться. Узагальнення — **турміт**: мураха з внутрішнім станом, тобто машина Тюрінга з 2D-стрічкою.

## Поле і час
- Квадратна сітка, клітина має колір (2 у класиці, N у RL-варіантах); мураха — окремий шар зверху: позиція + напрям (N/E/S/W) + (для турмітів) стан.
- Як клітинний автомат: клітина під мурахою кодується 8 «кольорами» (колір × напрям), але зручніше моделювати мураху як агента.
- Поле теоретично нескінченне (траєкторія завжди необмежена — теорема Коена–Конга); реалізації: обмежене (мураха «падає» за край і стоп), тор (краї склеєні), розріджене нескінченне.
- Тік = один крок мурахи; при кількох мурахах — усі в одному тіку (порядок — параметр реалізації).
- Темп задає людина: крок, запуск, швидкість, «стрибок» на N кроків.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Мураха | player | позиція, напрям, (стан) | читає колір під собою → повертає → перефарбовує → крок уперед; гравцем не керується |
| Біла клітина | terrain | колір 0 | мураха повертає на 90° за годинниковою (R) |
| Чорна клітина | terrain | колір 1 | мураха повертає на 90° проти годинникової (L) |
| Клітина кольору k (RL-рядок) | terrain | k ∈ 0..N−1, буква L/R | поворот за k-ю буквою, колір → k+1 mod N |
| Турміт | player | стан s, таблиця переходів | (s, колір) → (новий колір, поворот L/R/N/U, новий стан) |
| «Шосе» | object | період 104 кроки | емерджентна смуга, що росте по діагоналі нескінченно |
| Межа поля | static | dead / wrap | зупинка симуляції або перехід на протилежний край |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `tick` → ЯКЩО `cell(under_ant, white)` → ТО `face(ant, right)`, `paint(cell, black)`, `move(ant, forward)`.
- КОЛИ `tick` → ЯКЩО `cell(under_ant, black)` → ТО `face(ant, left)`, `paint(cell, white)`, `move(ant, forward)`.
- RL-рядок (Turk, Propp): КОЛИ `tick` → ЯКЩО `cell(under_ant, k)` → ТО `face(ant, rule[k])` (L або R), `paint(cell, (k+1) mod N)`, `move(ant, forward)`. Класика = `RL`.
- Відомі рядки: `RLR` — хаотичне зростання (невідомо, чи буде шосе); `LLRR` — симетричне зростання; `LRRRRRLLR` — заповнює квадрат навколо себе; `LLRRRLRLRLLR` — заплутане шосе; `RRLLLRLLLRRR` — заповнений трикутник, що росте й рухається.
- Достатня умова симетричного зростання: рядок складається з послідовних однакових пар (`LL`/`RR`) — доведено через плитки Трюше.
- Гекс-варіант: КОЛИ `tick` → ТО `rotate(ant, 0|60|120|180|-120|-60)` за буквою N/R1/R2/U/L2/L1, далі `paint` і `move`. `L2NNL1L2L1` — кругове зростання, `L1L2NUL2L1R2` — спіраль.
- Турміт: КОЛИ `tick` → ЯКЩО `state(ant, s)` and `cell(under_ant, c)` → ТО `paint(cell, table[s,c].color)`, `face(ant, table[s,c].turn)` (L/R/N/U), `set_state(ant, table[s,c].state)`, `move(ant, forward)`.
- Абсолютний турміт: `custom: «поворот задано сторонами світу (N/E/S/W), а не відносно мурахи»` — 2D-аналог звичайної машини Тюрінга.
- Кілька мурах: КОЛИ `tick` → кожна мураха робить свій крок; КОЛИ дві на одній клітині → `custom: «правило взаємодії задає реалізація (по черзі / сумарний поворот / анігіляція)»`.
- Варіант Еда Пегга: КОЛИ `tick` → ТО `split(ant)` (одна повертає L, друга R); КОЛИ `contact(ant, ant)` → ТО `disappear_both`.
- Межа: КОЛИ `edge(ant)` → ЯКЩО `mode(torus)` → ТО `wrap(ant)`; інакше `custom: «симуляція зупиняється»`.
- КОЛИ `repetition` (стан околу мурахи + зсув повторились через 104 кроки) → ТО `message(«шосе»)` — фіча детектора, не правило гри.
- КОЛИ `input(click, cell)` → ТО `set_cell(cell, next_color)`; КОЛИ `input(place_ant, cell)` → ТО `spawn_at(ant, cell)` з напрямом.
- Перемоги/поразки/рахунку нема; лічильник — номер кроку.

## Керування і ввід
- Типова реалізація (web-симулятори, Golly): клік — змінити колір клітини або поставити/повернути мураху; поле для RL-рядка або таблиці турміта; Run/Pause, Step, повзунок швидкості, «стрибок» на N кроків; зум і пан.
- Golly: правило-таблиця + RLE-патерн; за esolangs, Golly показує напрям мурахи **до** повороту — це впливає на те, як ставити мураху.
- Порядок «поворот → фарбування → крок» (Wikipedia) і «фарбування → крок → поворот» (esolangs) дають ту саму траєкторію з точністю до того, коли рахується напрям.

## Вікна, меню, HUD
- `game-screen` (типова цифрова версія): поле з мурахою(-ами), `zoom-control`, `grid-lines`; панель: Run/Pause, `step-button`, `speed-slider`, Clear, Randomize.
- HUD: `generation-counter` (номер кроку), позиція й напрям мурахи, кількість мурах.
- `settings-window`: `rule-input` (рядок `RL…`, гекс-рядок або таблиця турміта), розмір поля, топологія (обмежене/тор), палітра кольорів.
- `custom-window` «Пресети» — список відомих рядків/турмітів (спіраль, Фібоначчі, ромб, сніжинка).
- Переходи: game-screen ↔ settings (зміна правила зазвичай скидає поле) · пресет → game-screen.

## Фічі поза полем
- `custom-rules` — правило як рядок/таблиця; `step-mode`, `speed-control`; `export-import` (RLE у Golly).
- Мультимураха — кілька агентів з власними позиціями й напрямами.
- Детектор шосе/циклу — фіча аналізу (не в кожній реалізації).
- Збережень/рекордів нема; «контент» — бібліотека пресетів.

## Варіації й родичі
- **Осі варіацій:** кількість кольорів і рядок поворотів (`RL`, `RLR`, `LLRR`…) · внутрішні стани (мураха → турміт) · відносні/абсолютні повороти · сітка (квадрат / гекс / трикутник у Brady / 3D у Hutton) · кількість мурах і правило зустрічі · топологія межі.
- Paterson's worms — турміти на ребрах трикутної сітки; Brady «flippers» — 1D-турміти.
- Busy Beaver для турмітів: Brady знайшов 2-станову 2-кольорову машину, що зупиняється (37 одиниць, інша — 121 крок).
- Родичі в корпусі: [game-of-life](game-of-life.md) (усі клітини оновлюються, тут — лише одна), [cell-machine](cell-machine.md), [kara](../program-robots/kara.md) (FSM-сонечко на 2D-аркуші — турміт із сенсорами), Wireworld (мураху Ленгтона можна побудувати у Wireworld).
- Тюрінг-повнота: Gajardo та ін. — траєкторія однієї мурахи обчислює будь-яку булеву схему.

- Детектор шосе: хеш околу мурахи з урахуванням зсуву, знайти період 104 — 🥈 (порівняння станів з трансляцією).
- Гекс-мураха з 6 поворотами — 🥉 (координати гекс-сітки + рендер).
- Кілька мурах + правила зустрічі (порядок ходу, розщеплення, анігіляція) — 🥉 (конфлікти в одному тіку).
- Нескінченне поле через словник клітин + камера, що стежить за мурахою — 📎.

# The Settlers II — економіка як мережа доріг: прапорці на вузлах, один носій на кожен відрізок, товари передаються естафетою

## Суть
Гравець не керує жодним поселенцем: він ставить будівлі на вузли карти, зʼєднує їхні прапорці дорогами й налаштовує пріоритети, а ШІ сам призначає людей на роботи. Ядро — **транспорт естафетою**: кожен відрізок дороги між двома прапорцями обслуговує рівно один носій, тож пропускна здатність мережі залежить від того, як часто стоять прапорці. Ланцюги виробництва (колода → дошка, зерно → борошно → хліб, руда + вугілля → залізо → зброя) годують військо, а військові будівлі розширюють кордон. Від Factorio чи OpenTTD відрізняється тим, що «конвеєр» тут — це граф вузлів з носіями-агентами.

## Поле і час
- Карта — прямокутник W×H **вузлів**; у кожного вузла 6 сусідів (W, NW, NE, E, SE, SW) — топологічно гекс-сітка. Рядки зсунуті, а рельєф задано **двома трикутниками** на вузол («вершиною вгору» і другим, лівим верхнім кутом у вузлі), тож поле — трикутна сітка, де вузол = клітина гекса.
- Шари вузла (формат WLD/SWD): висота (у редакторі база 10, максимум 60, різниця між сусідами ≤ 5), дві текстури трикутників, дорога, обʼєкт (дерево, граніт 1–6, декор), тварина, якість будмайданчика, ресурс під землею, затінення, індекс прохідної зони.
- Будівлі, прапорці й люди стоять **на вузлах**; дороги проходять **ребрами** між сусідніми вузлами.
- Рельєф: луки/савана (будівельні, родючі), гори (лише шахти), пустеля (лише прапорець), вода, сніг, лава, болото (непрохідні; на воді — лише човни).
- Час — real-time: носії ходять, будівлі працюють за власними циклами. Туман: видно лише свою територію й околиці; оглядова вежа розширює огляд.

## Сутності
| Сутність | Роль | Параметри | Поведінка |

| Вузол | terrain | висота, 2 трикутники рельєфу, якість | визначає, що на ньому можна поставити й чи прохідний |
| Прапорець | container | черга товарів, власник | вузол мережі; товари чекають тут на носія; між прапорцями ≥ 2 вузли |
| Відрізок дороги | conduit | шлях з ребер, тип: звичайна / ослина / водна | зʼєднує два прапорці (або будівлю з її прапорцем); на ньому 1 носій + 1 осел |
| Носій | ally | відрізок | ходить лише своїм відрізком: бере товар з одного кінця, несе на інший |
| Осел | ally | — | другий носій на завантаженій дорозі; береться з ослиної ферми |
| Човен | ally | водний відрізок | один носій з човном на водний шлях — «вузьке горло» |
| Будмайданчик | object | розмір | сюди несуть дошки й камінь; будівельник зводить будівлю |
| Хатина (Hut) | static | 1 вузол | лісоруб, лісничий, каменяр, рибалка, мисливець, криниця, казарма, вартівня, оглядова вежа |
| Дім (House) | static | 1 вузол | лісопилка, млин, пекарня, бойня, броварня, монетний двір, плавильня, кузня, зброярня, верф, склад, сторожова вежа, катапульта |
| Замок (Castle) | static | 1 + 3 вузли (W, NW, NE) | ферма, свиноферма, ослина ферма, фортеця, штаб; на RttR — вуглепал |
| Шахта | static | гора | граніт / вугілля / залізо / золото; споживає їжу |
| Гавань | static | узбережжя | порт для кораблів |
| Штаб (HQ) | static | склад + оборона | перша будівля; не захоплюється — після вдалої атаки знищується |
| Склад | container | — | зберігає товари, генерує робітників, вербує солдатів |
| Військова будівля | zone | радіус кордону, місткість | розширює територію, поки є хоча б один солдат |
| Солдат | ally | ранг | гарнізон; атакує за наказом; ранг росте від золотих монет |
| Катапульта | static | дальність | стріляє камінням по ворожих будівлях, вбиває по одному солдату |
| Робітник з інструментом | ally | професія | працює в будівлі; без потрібного інструмента будівля стоїть |
| Дерево / граніт | resource | кількість | рубаються / розбиваються; лісничий садить нові дерева |
| Підземний ресурс | resource | вид, кількість | вода є завжди; риба, вугілля, залізо, золото, граніт вичерпуються |
| Ворог (інший народ) | enemy | — | будує власну мережу, атакує кордон |

## Правила (КОЛИ → ЯКЩО → ТО)
Будування на вузлах:
- КОЛИ `input(click, node)` → ЯКЩО `custom: «вузол на своїй території»` → ТО `window(custom-window)` — меню будівель лише того розміру, який дозволяє якість вузла (прапорець / хатина / дім / замок / шахта).
- КОЛИ `input(place, flag)` → ЯКЩО `no_adjacent(flag)` and `custom: «вузол прохідний»` → ТО `place(player, flag)`; інакше `block` (найкоротша відстань між прапорцями — 2 вузли).
- КОЛИ `input(place, building)` → ЯКЩО `fits(building, node)` → ТО `place(player, building_site)`; `custom: «прапорець будівлі — у сусідньому вузлі SouthEast; якщо його нема, він ставиться, і вхід зʼєднується з ним відрізком дороги»`.
- КОЛИ `spawned(castle_site)` → ТО `custom: «вузли W, NW, NE стають розширенням будівлі й недоступні»`.
- КОЛИ `custom: «на вузлі чи поруч зʼявилась будівля, прапорець або дорога»` → ТО `custom: «якість сусідніх вузлів знижується (замок → дім → хатина → лише прапорець)»` (?).

Дороги й носії:
- КОЛИ `input(path, flag_a → flag_b)` → ЯКЩО `custom: «кожен вузол шляху прохідний і не зайнятий іншою дорогою»` → ТО `spawn(road)`; є й авто-маршрут: гравець вказує два прапорці, гра сама прокладає шлях (`custom`).
- КОЛИ `spawned(road)` → ТО `custom: «склад висилає носія»`, `spawn_at(carrier, road)`.
- КОЛИ `input(place, flag)` на вузлі дороги → ЯКЩО `no_adjacent(flag)` → ТО `split(road)`: два відрізки, старий носій лишається на одному, на другий викликається новий; на ослиній дорозі новий прапорець теж «ослиний».
- КОЛИ `spawned(ware)` біля прапорця → ТО `custom: «вибрати наступний прапорець маршруту до споживача»`, `carry(carrier, ware)` до іншого кінця відрізка, `custom: «покласти на прапорець»` — і так естафетою до будівлі-споживача.
- КОЛИ `custom: «на прапорці кілька товарів»` → ТО першим `carry` товар з вищим пріоритетом (вікно пріоритетів; за замовчуванням вгорі військове — золото, зброя, пиво).
- КОЛИ `custom: «звичайна дорога стала ослиною»` → ЯКЩО `has(storehouse, donkey)` → ТО `spawn_at(donkey, road)` — другий носій на відрізку.
- КОЛИ `spawned(road)` на воді → ТО `custom: «один носій з човном»`; для дальніх перевезень — кораблі між гаванями (верф будує човни й кораблі).

Будівництво й виробництво:
- КОЛИ `spawned(building_site)` → ТО `custom: «дошки й камінь їдуть мережею; будівельник зводить будівлю»` (хатина — 2 дошки, дім — 2 дошки + 2 камені, замок — 3 + 3, шахта — 4 дошки).
- КОЛИ `custom: «будівлю зведено»` → ЯКЩО `has(storehouse, tool)` → ТО `transform(settler, worker)`, `custom: «робітник іде до будівлі»`; інакше будівля чекає — кузня робить інструменти за пріоритетом інструментів.
- КОЛИ `timer(work_cycle)` → ЯКЩО `has(building, inputs)` and `occupied(building, worker)` → ТО `take(building, inputs)`, `spawn_at(ware, building_flag)` (напр. лісопилка: колода → дошка; пекарня: борошно + вода → хліб).
- КОЛИ `timer(work_cycle)` у лісоруба → ЯКЩО `in_range(woodcutter, tree, n)` → ТО `disappear(tree)`, `spawn_at(log, flag)`; лісничий `spawn_at(tree, near)`.
- КОЛИ `input(place, farm)` → ЯКЩО `not cell(node, fertile)` → ТО `block` (пісок, гори, сніг, лава врожаю не дають).
- КОЛИ `timer(work_cycle)` у шахті → ЯКЩО `has(mine, food)` and `has(node, resource)` → ТО `counter(resource, -1)`, `spawn_at(ore, flag)`; найменше значення ресурсу = «вичерпано».
- КОЛИ `custom: «бракує товару в кількох споживачів»` → ТО `custom: «розподіл за налаштуванням: яку частку їжі, зерна, заліза, вугілля, дощок, води отримує кожен тип будівлі»`.

Військо й територія:
- КОЛИ `custom: «склад має меч, щит і пиво»` → ТО `transform(settler, soldier)`.
- КОЛИ `custom: «солдат зайняв нову військову будівлю біля кордону»` → ТО `set_side(nodes_in_radius, player)` — територія росте на радіус будівлі (казарма 7, вартівня 8, сторожова вежа 9, фортеця 10, штаб 9).
- КОЛИ `enter(gold_coin, military_building)` → ТО `custom: «ранг солдата +1»`.
- КОЛИ `input(attack, enemy_building, n, rank)` → ТО `custom: «n солдатів обраного рангу йдуть до цілі»`.
- КОЛИ `contact(attacker, defender)` → ТО `custom: «двобій»` (?).
- КОЛИ `custom: «захисників не лишилось»` → ЯКЩО `custom: «ціль — штаб»` → ТО `disappear(hq)`; інакше `set_side(building, attacker)`, `set_side(nodes_in_radius, attacker)`.
- КОЛИ `timer(shot)` у катапульти → ЯКЩО `in_range(catapult, enemy_building, n)` and `has(catapult, stone)` → ТО `custom: «влучання вбиває одного солдата гарнізону»`.
- КОЛИ `custom: «збудовано оглядову вежу»` → ТО `reveal(radius)` — огляд без території.
- Перемога: кампанія — ціль місії (?); вільна гра — умова, обрана на старті (?). · Поразка: (?) втрата штабу й усіх військових будівель. · Рахунку як такого нема.

## Керування і ввід
- Лише миша, point-and-click: клік по вузлу → меню (Activity window) з будівлями доступного розміру, прапорцем, дорогою.
- Дорога: від прапорця крок за кроком по сусідніх вузлах до іншого прапорця або авто-маршрут між двома прапорцями.
- Клік по будівлі → її вікно (стан, робітник, атака для ворожої військової будівлі: кількість і ранг солдатів).
- Split-screen для двох людей на одному ПК: другий гравець — другою мишею.
- NDS-порт — стилус і два екрани.

## Вікна, меню, HUD
- `main-menu`: кампанія (Roman Campaign / World Campaign у Gold), Free Game → Limitless (Unlimited) Play, вихід (?).
- `match-setup`: 2–4 народи, умови перемоги, стартові ресурси, розстановка, типи гри («Every man for himself», «Human vs. Computer», «People vs. People»).
- `game-screen`: карта з вузлами; накладка якості майданчиків (`+ui:map-overlay`: значки прапорець / хатина / дім / замок / шахта) (?).
- `custom-window` Activity — меню будівництва на вузлі.
- `custom-window` розподілу товарів (`+window:distribution-window`): частки шести товарів по споживачах; окремо — пріоритет інструментів і пріоритет транспорту.
- `custom-window` будівлі: робітник, запаси, для військових — гарнізон і кнопка атаки.
- Вікна стилізовано під Windows 95; `settings-window`, `map-window`, `stats-window` — (?).
- Переходи: main-menu → match-setup / вибір місії → game-screen ↔ вікна-оверлеї.

## Цікавинки для курсу
- Гекс-граф вузлів з 6 напрямками й «зсунутими» рядками, перетворення координат і сусідів — 🥉 (класика offset/axial).
- Мережа прапорців: прокладання дороги по вузлах, розщеплення відрізка новим прапорцем, правило «не ближче 2 вузлів» — 🥈 (граф, що змінюється під час гри).
- Носій-агент на відрізку й естафета товарів з чергою пріоритетів на прапорцях — 🥈 (симуляція агентів + маршрутизація).
- Маршрутизація товару до найближчого споживача по графу доріг (Дейкстра з вагами відрізків) — 🥇.
- Якість будмайданчика за рельєфом, висотою й зайнятістю сусідів, замок на 4 вузли — 🥉.
- Кордон як обʼєднання радіусів військових будівель, захоплення будівлі змінює власника вузлів — 🥉.
- Ланцюги виробництва зі споживанням і вікном розподілу — 🥈.

## Мапа на каталог
- Є: `cell-click` + `hover-highlight` ↔ клік по вузлу; `path-drawing` ↔ дорога по сусідніх вузлах; `chase-bfs` ↔ авто-маршрут дороги й маршрути товарів; `impassable-cells` + `floor-types` ↔ вода, сніг, лава, болото, пустеля; `multi-cell-size` ↔ замок на 4 вузли; `coverage-area` ↔ радіус кордону військової будівлі; `fog-of-war` ↔ огляд лише своєї території, оглядова вежа; `ai-opponent` ↔ Human vs. Computer; `simultaneous-versus` ↔ split-screen на двох; `sequential-levels` ↔ кампанія; `unit-xp-skills` ↔ ранг солдата від золотих монет (найближча картка).
- **Нема** → пропозиції карток:
  - `+flag-road-network` «Мережа доріг між прапорцями, 1 носій на відрізок» · entities/move · 🥈 · слоти {min_flag_gap: 2, carriers_per_segment: 1..2}.
  - `+road-split-flag` «Новий прапорець ділить дорогу на два відрізки» · entities/interact · 📎.
  - `+donkey-upgrade` «Завантажена дорога отримує другого носія» · entities/state · 📎.
  - `+build-quality-map` «Якість вузла визначає розмір будівлі» · game-logic/constraints · 🥉 · слоти {sizes: flag|hut|house|castle|mine}.
  - `+production-chain` «Будівля перетворює входи на вихід» · entities/state · 🥉.
  - `+goods-priority` «Черга товарів на вузлі за пріоритетом» · game-logic · 📎.
  - `+worker-economy`, `+territory-capture` — уже пропоновані в корпусі; `+soldier-from-goods`, `+ship-transport`, `+resource-depletion` — дрібні.

## Пропозиції до словників
- `+card:flag-road-network` — ядро гри, у каталозі немає жодної транспортної мережі з агентами.
- `+card:build-quality-map` — «що можна поставити тут» як властивість клітини (S2, Anno, Caesar).
- `+card:goods-priority` — порядок обробки черги на вузлі (S2, Factorio-фільтри).
- `+ui:map-overlay` — значки якості будмайданчика поверх карти (уже просив Caesar III).
- `+window:distribution-window` — частки ресурсу між типами споживачів.
- `+trigger:staffed(building)` — будівлю зайняв робітник / солдат (старт виробництва, розширення кордону).
- `+effect:set_territory(radius)` — переписати власника вузлів у радіусі (кордон).

## Непевне
- (?) Як саме знижується якість сусідніх вузлів біля будівлі/прапорця/схилу — правило з памʼяті, у джерелах лише значення якості.
- (?) Коли дорога стає ослиною (кількість товарів, час роботи носія) — код RttR має `UpgradeDonkeyRoad`/`NeedDonkey`, умову не прочитано.
- (?) Механіка двобою солдатів (випадковість, вплив рангу) — тому `random: runtime` під питанням.
- (?) Радіуси військових будівель узято з settlers2.net через переказ сторінки — перевірити числа.
- (?) Умови перемоги/поразки у вільній грі й місіях кампанії; що стається з будівлями, які опинились на чужій території.
- (?) Геологи, швидкість гри, збереження, мінікарта/статистика — не перевірено.

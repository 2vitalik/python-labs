# Factorio (логістичний шар) — предмети як частинки на дворядних конвеєрах, маніпулятори між клітинами

## Суть
Описано **лише клітинний шар логістики** Factorio: як предмети рухаються конвеєрами, як маніпулятори переносять їх між клітинами, як будівлі займають 1×1/2×2/3×3 клітин, як стовпи покривають зону живленням, труби — рідиною, сигнали — блоки колії. Гравець ставить орієнтовані сутності на сітку, і завод працює сам: це «клітинний автомат зі складних сутностей», де кожна клітина знає напрям, і сусідство визначає потік. Клас `hybrid`: `avatar` (інженер ходить і будує) + `cursor` (будування курсором, креслення). Бій, дослідження, крафт і планети поза описом.

## Поле і час
- Нескінченна процедурна мапа квадратних клітин (tile); ресурси (руда, вода, нафта) — частина рельєфу при генерації (`random: setup`), туман — недосліджене (`info: partial`).
- **Шари**: тайл підлоги (земля/вода/бетон) · сутність, що займає N×M клітин · предмети **на** конвеєрі (позиції всередині клітини, по 4 на доріжку) · мережі поверх (електрика, рідини, сигнали) як графи.
- Час — real-time 60 тіків/с; уся симуляція детермінована. Швидкість конвеєра в клітинах/с: жовтий 1.875, червоний 3.75, синій 5.625, turbo (Space Age) 7.5.
- Камера — над інженером, зум; мапа (`map-window`) показує мережі й заводи згори.

| Поворот конвеєра | terrain | автоматично | якщо в клітину заходить рівно один конвеєр збоку і ззаду нічого — клітина стає поворотом; зовнішня доріжка ≈1.15 довша |
| Підземний конвеєр (вхід/вихід) | terrain | пара, макс. 4/6/8 клітин під землею (жовтий/червоний/синій) | переносить обидві доріжки під будь-чим; бічний вхід приймає лише половина з конвеєром — блокує одну доріжку |
| Сплітер | object | 2×1 (ширина 2), пріоритет входу/виходу, фільтр | ділить 1:1 між двома виходами, зберігаючи доріжки; пріоритет — спершу один бік; фільтр — обраний предмет в один вихід, решта — в інший |
| Маніпулятор (inserter) | object | 1×1, напрям, швидкість, розмір руки | бере з клітини **позаду**, кладе в клітину **попереду**; на перпендикулярний конвеєр — на дальню доріжку |
| Довгорукий маніпулятор | object | досяг 2 клітини (?) | те саме, але через одну клітину |
| Швидкий / bulk / stack маніпулятор | object | швидкість, рука = стек | bulk — багато предметів за мах; stack (Space Age) — складає стопки на конвеєр |
| Скриня | container | 1×1, N слотів | приймає/віддає маніпуляторам; обмежувач — «червоний хрест» по слотах (?) |
| Збиральна машина (assembler) | object | 3×3, рецепт | бере лише інгредієнти рецепта; маніпулятор досипає на ~1 мах крафтів (мін. 2, макс. 100) |
| Піч | object | 2×2 (камʼяна) / 3×3 (електрична) | переплавка; паливо — до 5 одиниць |
| Бур (mining drill) | object | 2×2 (burner) / 3×3 (electric), зона копання | видобуває з ресурсу під собою, кладе в клітину перед собою (на конвеєр/в скриню) |
| Руда/ресурсне поле | resource | кількість | вичерпується бурами |
| Електростовп малий/середній/великий/підстанція | object | 1×1/1×1/2×2/2×2; зона живлення 5×5 (?)/7×7/4×4 (?)/18×18 (?); дріт 7.5 (?)/9/30 (?)/18 (?) | будівля живиться, якщо хоч одна її клітина в зоні; стовпи зʼєднуються дротом у межах меншого з досягів |
| Генератори, акумулятор | object | акумулятор 2×2, 5 MJ, 300 kW | акумулятор заряджається надлишком, віддає при нестачі; при дефіциті всі машини сповільнюються пропорційно |
| Труба | terrain | 1×1 | зʼєднується з сусідніми трубами й портами будівель; рідина тече мережею (?) |
| Труба під землею | terrain | пара, макс. 10 клітин | зʼєднує крізь 9-клітинний проміжок |
| Рейка, потяг | object | — | потяг займає блоки колії |
| Рейковий сигнал | switch | праворуч від колії | ділить колію на блоки; green — блок вільний, red — зайнятий/зарезервований, yellow — потяг не встигне зупинитись |
| Ланцюговий сигнал | switch | — | копіює стан наступного сигналу: потяг зупиняється раніше, не застрягає на перехресті |
| Інженер (гравець) | player | інвентар, досяг будування | ходить 8 напрямків, ставить/знімає, носить предмети |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `tick` → ЯКЩО `occupied(cell_ahead_on_lane, item)` → ТО `block` (предмет стоїть, черга); інакше `move(item, belt_dir)` на швидкість tier.
- КОЛИ `tick` → ЯКЩО `facing(belt_a, belt_b)` and `custom: «a входить у b ззаду»` → ТО предмети йдуть далі на ту саму доріжку.
- КОЛИ `custom: «конвеєр A входить у бік конвеєра B (не ззаду)»` → ТО **сайдлоад**: усі предмети A лягають на ближню до A доріжку B; якщо ззаду B інший вхід нема і це єдиний боковий — `transform(B, curve)` (поворот замість сайдлоада).
- КОЛИ `enter(item, underground_entry)` → ТО `teleport(item, paired_exit)` (з тією ж доріжкою); пара — найближчий вихід того ж tier у напрямку, у межах 4/6/8 клітин.
- КОЛИ `custom: «конвеєр входить у бік підземного входу»` → ТО приймає лише доріжка з боку конвеєра, інша — `block` (фільтр доріжки).
- КОЛИ `enter(item, splitter)` → ЯКЩО `custom: «фільтр = item»` → ТО у фільтровий вихід; інакше ЯКЩО пріоритет виходу → туди, доки `free`; інакше чергувати 1:1. Вхідний пріоритет — брати з пріоритетного, доки в ньому нема шпари.
- КОЛИ `tick` (мах маніпулятора) → ЯКЩО `has(source_behind, item)` and `custom: «ціль попереду прийме item»` → ТО `take(source, hand_size)`, `give(target, hand)`; ціль-машина приймає лише інгредієнти рецепта і до ліміту; паливо — до 5.
- КОЛИ маніпулятор кладе на конвеєр → ЯКЩО конвеєр перпендикулярний → дальня доріжка; ЯКЩО вздовж → права доріжка (з погляду конвеєра). Бере — з ближньої доріжки (перпендикулярно).
- КОЛИ `tick` → ЯКЩО машина має всі інгредієнти and живлення → ТО крафт; `custom: «швидкість × частка живлення»`; вихід лежить у машині, доки маніпулятор не забере.
- КОЛИ бур завершив цикл → ЯКЩО `free(output_cell)` → ТО `spawn_at(ore, output_cell)`; інакше `block` (бур стоїть).
- КОЛИ ставиться будівля N×M → ЯКЩО `free(all_cells)` and `not cell(x, water)` → ТО розміщення; інакше `block` (червоний привид).
- КОЛИ ставиться будівля → ЯКЩО `in_range(pole_supply, any_cell_of_building)` → ТО `set_state(building, powered)`.
- КОЛИ ставиться стовп → ТО `custom: «автоматично зʼєднується дротом з найближчими стовпами в межах min(reach_a, reach_b)»`.
- КОЛИ `tick` → ЯКЩО `custom: «попит > генерація»` → ТО `speed(all_consumers, ×supply/demand)`; акумулятори розряджаються останніми.
- КОЛИ ставиться труба поруч з трубою/портом → ТО `attach` у спільну рідинну мережу; `custom: «різні рідини в одній мережі заборонені»` (?).
- КОЛИ потяг підʼїжджає до сигналу → ЯКЩО блок за сигналом зайнятий/зарезервований → ТО `block` (стоїть); ланцюговий — дивиться далі до наступного звичайного сигналу.
- КОЛИ `contact(player, belt)` → ТО `move(player, belt_dir)` (конвеєр несе й гравця).
- Перемоги/поразки на цьому шарі нема; гра виграється запуском ракети (поза описом). «Рахунок» шару — **пропускна здатність** (предм/с) і відсутність заторів.

## Керування і ввід
- WASD — інженер (8 напрямків), ЛКМ — поставити предмет з руки, ПКМ (утримати) — зняти, `R` — повернути орієнтацію перед/після встановлення (підземний — розвернути вхід/вихід), `Q` — «піпетка» (взяти в руку такий самий предмет), `F` — підняти з землі/конвеєра.
- Drag під час будування: конвеєр тягнеться лінією, стовпи — з автокроком на максимальний досяг (?).
- Copy/paste налаштувань (Shift+ПКМ/ЛКМ) між машинами; креслення (blueprint) — виділити рамкою, вставити привидами, будують дрони.
- Hover над сутністю — підказка: рецепт, швидкість, живлення, зона; наведення стовпа показує зону живлення синім.
- Панель швидких слотів (quickbar) — цифри 1–0.

## Вікна, меню, HUD
- `game-screen`: поле + `minimap` (кут) + `inventory-bar` (quickbar) + тултип сутності + індикатори проблем (нема живлення, вихід заблокований, бракує інгредієнта) — `custom: «іконки стану над будівлею»`.
- `inventory-window`: інвентар гравця (сітка слотів) + крафт-меню вкладками.
- Вікно сутності (`custom-window`): машина — рецепт, вхідні/вихідні слоти, прогрес-бар, енергія; скриня — сітка слотів з обмежувачем; сплітер — пріоритети входу/виходу (лівий/правий), фільтр предмета; маніпулятор — фільтри, умови мережі.
- `map-window` (M): мапа з шарами (електромережі, ресурси, потяги).
- Blueprint library (`custom-window`): збережені креслення, експорт рядком.
- `main-menu`: Play (Campaign / Tutorial / New game / Load / Multiplayer) · Settings · Mods · Exit.
- `settings-window` з вкладками (графіка, звук, керування, інтерфейс); `pause-menu` (Esc): Continue, Save, Load, Settings, Quit.
- Генератор мапи (`custom-window`): seed, частота/розмір/багатство ресурсів, вороги, перемикачі.
- Переходи: main-menu → генератор мапи → game-screen; клік по сутності → її вікно; E → inventory-window; M → map-window.

## Варіації й родичі
- Mindustry, Satisfactory (3D), Shapez/Shapez 2 (конвеєри фігур, без доріжок), Dyson Sphere Program, Builderment, Oxygen Not Included (труби/газ), Opus Magnum (маніпулятори як програма → `program-robots`).
- Осі варіацій «конвеєр»: 1 доріжка / 2 доріжки · дискретні предмети на клітині / позиційні · злиття: сайдлоад / лише ззаду · перетин: тунель / міст / перехрестя (Mindustry junction).
- Осі «маніпулятор»: звідки→куди (позаду→попереду / довга рука / фільтр) · що бере (будь-що / лише потрібне цілі).
- Осі «покриття»: квадрат зони (стовп) / ромб / коло; «досить однієї клітини» vs «вся будівля в зоні».
- Родичі на сітці: Stardew-спринклери (покриття форми), Stardew-конвеєри нема; Minecraft-воронки (hopper).

## Цікавинки для курсу
- Конвеєр із черговим просуванням предметів (без доріжок, 1 предмет на клітину) — 📎; дві доріжки з позиціями в клітині — 🥉.
- Автоповорот vs сайдлоад за сусідами (клітина сама визначає форму з того, що в неї входить) — 🥉 (контекстна форма тайла, як «автотайли»).
- Маніпулятор позаду→попереду з правилом «бере лише те, що прийме ціль» — 📎.
- Сплітер 1:1 з пріоритетом і фільтром — 🥉 (стан чергування + блокування виходу).
- Підземна пара в межах N клітин (пошук пари вздовж напряму) — 📎.
- Зона живлення стовпів і злиття мереж (union-find по дротах) з пропорційним дефіцитом — 🥈.
- Блоки колії з сигналами і ланцюговими сигналами (резервування, без дедлоків) — 🥇.

# Animal Crossing: New Horizons (квіти) — поливаєш сусідні квіти, а вранці поруч проростає дитина з генами обох батьків

## Суть
Описано **лише шар квітів**: гравець садить квіти на клітинах острова, щодня поливає, і полита квітка з невеликим шансом «розмножується» — з сусідом свого виду (гібрид) або сама (клон). Кожна квітка має прихований **генотип** (3 гени, у троянд 4), колір — лише фенотип, тож дві однакові червоні троянди можуть мати різні гени. Гра — менделівська генетика на сітці: гравець будує грядки-розкладки, щоб відсіяти клони й дістати рідкісні кольори (чорна космея, синя троянда, золота троянда).

## Поле і час
- Острів — квадратна сітка клітин; квітка займає одну клітину. Важить сусідство 8 клітин (ортогональні й діагональні): розкладки гайдів рахують «торкання» і по діагоналі.
- Час — **реальний годинник** консолі; головний тік квітів — **ранок нового дня**: ріст стадій і поява нащадків.
- Шари: ґрунт/трава (можна садити) · рослина (стадія, генотип, стан «полито») · прапорець золотої лійки на чорній троянді.
- Видимість повна для фенотипу, **генотип прихований** — гра його ніде не показує.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Гравець | player | інструменти в інвентарі | ходить, біжить, садить, поливає, зриває, копає |
| Квітка (8 видів, що схрещуються) | object | вид · генотип (R, Y, W; троянда + S) · стадія · полито | щодня росте; полита — шанс схреститись або клонуватись |
| Космея · гіацинт · лілія · хризантема · братки · тюльпан · анемона | object | 3 гени → 27 генотипів | колір = таблиця виду від генотипу |
| Троянда | object | 4 гени (додатковий «яскравість/відтінок») → 81 генотип | синя — лише 1 генотип з 81 |
| Пакет насіння | pickup | вид, колір, фіксований генотип | садиться → паросток; «магазинні» генотипи відомі |
| Паросток · стебло · бутон · цвіт | — | стадії | щодня +1 стадія; цвіте на третій день після посадки |
| Цвіт (зірваний) | pickup | колір | дає предмет; рослина повертається до стебла |
| Нащадок | object | генотип з батьків | зʼявляється вранці на вільній сусідній клітині в стадії бутона |
| Клон | object | генотип = батька | те саме, коли поруч нема квітки свого виду |
| Лійка (звичайна / … / золота) | pickup | тип | поливає клітину; золота ставить прапорець на чорну троянду |
| Золота троянда | object | — | дитина чорної троянди з прапорцем |
| Конвалія | object | не схрещується, не зривається | зʼявляється сама за рейтингу острова 5★ понад день |
| Відвідувач | ally | гравець з іншого острова | його полив підіймає шанс розмноження |

Генотипи насіння (кількість домінантних копій R-Y-W[-S]): космея червона 200 / жовта 021 / біла 001; гіацинт 201 / 020 / 001; лілія 201 / 020 / 002; хризантема 200 / 020 / 001; братки 200 / 020 / 001; тюльпан 201 / 020 / 001; анемона червона 200 / **помаранчева** 020 / біла 001 (жовтих анемон нема); троянда 2001 / 0200 / 0010.

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(plant, cell)` → ЯКЩО `free(cell)` and `has(player, seed_bag)` → ТО `place(seed_bag)`, `set_state(plant, sprout)`.
- КОЛИ `timer(day)` → ЯКЩО `state(plant, sprout)` → ТО `set_state(plant, stem)`; далі стебло → бутон → цвіт тим самим правилом.
- КОЛИ `input(water, flower)` → ТО `set_state(flower, watered)`; відвідувач, що полив, — `counter(visitor_waterings, +1)`.
- КОЛИ `timer(day)` → ЯКЩО `state(flower, watered)` and `prob(p)` → ТО `custom: «квітка пробує розмножитись»`; p = 5% без відвідувачів, 25 / 35 / 50 / 65 / 80% за 1 / 2 / 3 / 4 / ≥5 відвідувачів, що поливали.
- КОЛИ `timer(day)` → ЯКЩО `custom: «спроба вдалася»` and `adjacent_count(flower, same_species, >=, 1)` → ТО `custom: «обрати партнера серед сусідів свого виду»`, `spawn_at(child, free_neighbor)`.
- КОЛИ `spawned(child)` → ТО `custom: «кожен ген дитини = 1 випадкова копія від батька A + 1 від батька B»`, `set_state(child, bud)`.
- КОЛИ `spawned(child)` → ТО `custom: «колір = таблиця виду[генотип]»` — фенотип видно, генотип ні.
- КОЛИ `timer(day)` → ЯКЩО `custom: «спроба вдалася»` and `not adjacent_count(flower, same_species, >=, 1)` → ТО `clone(flower)`, `spawn_at(clone, free_neighbor)`; шанс клону = шансу схрещення.
- КОЛИ `timer(day)` → ЯКЩО `custom: «спроба вдалася»` and `not free(neighbors)` → ТО `custom: «нащадку нема місця — спроба пропадає»`.
- КОЛИ `input(pick, flower)` → ЯКЩО `state(flower, bloom)` → ТО `give(player, blossom)`, `set_state(flower, stem)`; конвалію — `block`.
- КОЛИ `contact(running_player, flower)` → ЯКЩО `state(flower, bloom)` and `prob(p)` → ТО `set_state(flower, bud)` (витоптав цвіт).
- КОЛИ `input(dig, flower)` → ТО `give(player, flower)`, `clear_state(flower, watered)` — бонус поливу втрачено.
- КОЛИ `input(golden_can, black_rose)` → ТО `set_state(rose, gold_flag)`.
- КОЛИ `spawned(child)` → ЯКЩО `state(parent, gold_flag)` → ТО `transform(child, gold_rose)`, `clear_state(parent, gold_flag)`.
- КОЛИ `timer(day)` → ЯКЩО `custom: «рейтинг острова 5★ понад 1 день»` → ТО `spawn_at(lily_of_the_valley, random)`.
- Приклади ймовірностей: помаранчева × помаранчева космея → чорна 6,25%; червона × біла лілія → рожева 50%; біла × біла троянда → фіолетова 25%; жовта × жовта хризантема → зелена 6,25%; фінальна стадія методу «Folklore» → синя троянда 25%.
- Перемоги/поразки нема; мета — зібрати всі кольори (каталог), рідкісні — через ланцюг поколінь.

## Керування і ввід
- Стік — рух, утримання B — біг (ризик витоптати). A з інструментом у руках — дія у клітину попереду: садити, полити (лійка), копати (лопата), зірвати цвіт.
- Колесо інструментів і кишені (інвентар) — вибір лійки/лопати/насіння.
- Генотип не має інтерфейсу: гравець веде облік сам (гайди, калькулятори) або ставить розкладки, де походження дитини однозначне.

## Вікна, меню, HUD
- `game-screen`: острів від третьої особи; HUD мінімальний (час/дата при поверненні з меню, підказки дій A/B) (?).
- `inventory-window` — кишені: пакети насіння, цвіт, викопані рослини, лійки.
- `shop-window` — крамниця острова продає насіння базових кольорів; квіти іншим гравцям — лише цвіт поштою, рослини поштою не шлються.
- `custom-window` — Nook Phone (DIY-рецепти, де є золота лійка; рейтинг острова) (?).
- `lobby-window` — Dodo Airlines: прийом відвідувачів (вони поливають).
- Переходи: game-screen ↔ inventory-window (X); game-screen → крамниця (вхід у будівлю) → shop-window.

## Фічі поза полем
- `autosave` — гра зберігається сама; час реальний, «перемотка» лише зміною годинника консолі (?).
- `online-multiplayer` до 8 гостей: відвідувачі-поливальники підіймають шанс з 5% до 80% — соціальна механіка всередині генетики.
- `unlockables`: золота лійка — рецепт від Isabelle за рейтинг 5★; конвалія — за 5★ понад день.
- Нема undo, нема показу генотипу, нема статистики схрещень — уся «наука» поза грою.

## Варіації й родичі
- Попередники серії (Wild World, City Folk, New Leaf) — та сама генотипова система, інша механіка поливу й в'янення (у NH квіти більше не в'януть).
- Родичі в корпусі: `stardew-farm` (щоденний тік ґрунту, але без генетики), `game-of-life` (народження залежить від сусідів), `luck-be-a-landlord` (сусідство дає ефект).
- Осі варіацій:
  - **сусідство для пари:** 4 / 8 клітин / радіус;
  - **хто розмножується:** кожна полита / лише пара / клон, коли пари нема;
  - **спадковість:** колір напряму / прихований генотип / генотип з домінуванням;
  - **шанс:** фіксований / від соціальної дії (відвідувачі) / від предмета (золота лійка = прапорець).

## Цікавинки для курсу
- Менделівське схрещування: генотип 3–4 гени × 2 копії, фенотип — таблиця; дитина бере по копії від кожного — 📎 (рахунок 1/16 = 6,25% — гарна перевірка юніт-тестом).
- Нащадок на вільній сусідній клітині, клон, коли пари нема, «нема місця — нема дитини» — 🥉 (порядок обробки квіток і вибір партнера визначають результат).
- Прихований стан, видимий лише через фенотип: гравець дедукує генотип за нащадками (тест-кросинг) — 🥈.
- Розкладки грядок, що гарантують відсутність клонів (ізольовані пари), — 🥈 як задача на розміщення.
- Прапорець, що «успадковується» один раз (золота лійка) — 🌱.
- Шанс від кількості відвідувачів (5 → 80%) — 🌱 як таблиця множника.

## Пропозиції до словників
- `+effect:inherit` — дитина отримує властивості від двох батьків за правилом (гени); зараз — `custom` у правилі.
- `+trigger:day_start` — тік «ранок нового дня» (тут замінено на `timer(day)`).
- `+cond:visitors_watered` — скільки різних гравців полили сутність (таблиця шансу).
- `+card:mendel-genes`, `+card:hidden-genotype`, `+card:breed-adjacent`, `+card:clone-isolated` — див. вище.
- `+feature:visitor-boost` — чужі гравці підсилюють твою механіку (полив).

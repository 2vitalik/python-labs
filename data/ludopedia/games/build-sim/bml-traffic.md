# BML — червоні авто їдуть праворуч, сині вниз, по черзі; за густини ~32 % вільний потік різко стає глобальним затором

## Суть
Самоорганізований клітинний автомат Біхама, Міддлтона й Левіна (1992): на торі випадково стоять авто двох кольорів, червоні рухаються лише праворуч, сині — лише вниз. Кольори ходять по черзі; авто робить крок, якщо клітина попереду вільна. Найпростіше двовимірне правило дає фазовий перехід: за малої густини рух сам впорядковується у вільний потік, за великої все стає намертво. Гравець задає густину й розмір поля і дивиться, яка фаза виросте; BML — двовимірний родич Rule 184.

## Поле і час
- Квадратна (або прямокутна) решітка; межі склеєні в тор: вихід праворуч → зліва, вихід знизу → згори.
- Клітина: порожня / червоне авто / синє авто; одне авто на клітину.
- Тік = хід одного кольору; усі авто цього кольору рухаються одночасно за старим станом.
- Відношення сторін важить: при взаємно простих розмірах проміжні стани — періодичні смуги затору й вільного руху, при невзаємно простих — зазвичай невпорядковані.
- Варіанти поверхні: пляшка Клейна, дійсна проєктивна площина (краї склеюються з перевертанням).

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Червоне авто | object | напрям → | у свою фазу крокує праворуч, якщо попереду вільно |
| Синє авто | object | напрям ↓ | у свою фазу крокує вниз, якщо попереду вільно |
| Порожня клітина | terrain | — | приймає авто; кількість задає густина ρ |
| Межа-тор | static | склейка країв | переносить авто на протилежний край |
| Затор | object | емерджентний | кластер, де жодне авто не рухається; у фазі jam — усе поле |
| Смуга (проміжна фаза) | object | періодична / невпорядкована | співіснування заторів і вільного руху |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `phase_start(red)` → ЯКЩО `free(cell_right)` → ТО `move(red_car, right)`; інакше `block`.
- КОЛИ `phase_start(blue)` → ЯКЩО `free(cell_down)` → ТО `move(blue_car, down)`; інакше `block`.
- Фази чергуються: червоні, сині, червоні… Усі авто одного кольору перевіряють «вільно?» за станом до свого ходу — `custom: «рішення рахуються з копії поля, потім застосовуються разом»`.
- КОЛИ `edge(car)` → ТО `wrap(car)`.
- КОЛИ `level_start` → ТО `spawn_at(car, random_free)` з густиною ρ, колір — червоний або синій.
- КОЛИ `counter(moved_cars, ==, 0)` → ТО `message(«global jam»)` — глобальний затор, стан більше не зміниться.
- Вільний потік: КОЛИ `counter(moved_cars, ==, all)` → ТО `message(«free flow»)`.
- BML-R (рандомізований): КОЛИ `tick` → ТО `custom: «L² разів вибрати випадкову клітину; якщо там авто й попереду вільно — крок»`; проміжної фази нема, перехід різкий.
- Відкриті межі (BML-R): КОЛИ `rng(α)` → ТО `spawn_at(car, entry_edge)`; КОЛИ `reach(car, exit_edge)` → ЯКЩО `prob(β)` → ТО `disappear(car)`.
- Неорієнтовні поверхні: КОЛИ `edge(car)` → ЯКЩО `mode(klein|projective)` → ТО `custom: «вихід на протилежний край з віддзеркаленням координати»`; на проєктивній площині локальні затори бувають у кутах, а решта тече.
- Ввід: КОЛИ `input(reset)` → ТО `restart` з новою випадковою розстановкою; КОЛИ `input(density, ρ)` → ТО `custom: «нова густина діє з наступного Reset»` (?).
- Перемоги, поразки, рахунку нема; спостережувана величина — частка авто, що рушили за тік (середня швидкість).

## Керування і ввід
- Jason Davies: поля Density, Speed, Size (ширина × висота, підказка «coprime»), кнопка Reset; приклад-лінки з готовими ρ (0.20, 0.38, 0.40, 0.60).
- Типова цифрова версія: Run/Pause, Step (одна фаза або пара фаз), повзунки густини й швидкості, розмір поля, Reset.
- Гравець не керує авто — лише параметрами й початковим станом.

## Вікна, меню, HUD
- `game-screen`: поле з червоними й синіми клітинами, рядок параметрів (Density, Speed, Size, Reset).
- HUD (Jason Davies): «Frame rate: N/s», «Iterations: N»; у типовій версії — частка рухомих авто.
- `stats-plot` (пропозиція): середня швидкість у часі; графік «швидкість від густини» для сканування параметра.
- `settings-window` (цифрова версія): густина, розміри, межі (тор / Клейн / проєктивна / відкриті), BML / BML-R.
- Переходи: зміна параметрів → Reset → game-screen.

## Фічі поза полем
- `seed-input` / `share-code` — Jason Davies зберігає параметри в лінку (готові приклади фаз).
- `step-mode`, `speed-control`, `pause`.
- Сканування параметра: прогін густини ρ від 0 до 1 і графік середньої швидкості — головний «експеримент» моделі.
- Збережень, режимів, рекордів нема.

## Варіації й родичі
- **Осі варіацій:** порядок оновлення (почергово кольорами / випадкові одиничні оновлення BML-R) · поверхня (тор / пляшка Клейна / проєктивна площина / відкриті межі з α, β) · співвідношення сторін (взаємно прості чи ні) · кількість видів авто й напрямків.
- Rule 184 — одновимірний аналог (див. [elementary-cellular-automata](elementary-cellular-automata.md)); [nagel-schreckenberg](nagel-schreckenberg.md) — 1D-модель зі швидкостями.
- Строгі результати: Angel–Holroyd–Martin (2005) — за густини, близької до 1, жодне авто не рухається нескінченно часто; Austin–Benjamini (2006) — на N×N менше ніж N/2 авто завжди дають вільний потік.
- Проміжну фазу виявила D'Souza (2005); періодичні проміжні фази на квадратних решітках бачили у 2008.
- Ігрові родичі в корпусі: [mini-motorways](mini-motorways.md) (затори як механіка), [openttd-rails](openttd-rails.md).

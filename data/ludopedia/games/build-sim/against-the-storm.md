# Against the Storm — місто в лісі на квадратній сітці: рубаєш дерева, відкриваєш приховані галявини й платиш за це ворожістю лісу, поки синя смуга репутації не обжене червону смугу нетерпіння

## Суть
Роґлайт-містобудування: кожне поселення — окремий забіг на процедурній мапі лісу з ядром-вогнищем у центрі. Мапа — **квадратна сітка клітин** (вхід будівлі — клітина), майже вся вкрита деревами; дроворуби вирубують ліс, а в ньому сховані **галявини** — галявину відкриває прорубаний до неї шлях, і всередині чекають ресурси, події-загадки та загрози. Кожна відкрита галявина, кожен дроворуб, кожен рік і кожен поселенець піднімають **ворожість лісу**, яка штрафує мешканців. Перемога — заповнити **Репутацію** раніше, ніж заповниться **Нетерпіння Королеви**; між забігами — мета-прогрес Smoldering City.

## Поле і час
- Квадратна сітка клітин; ліс = дерева на клітинах (рубаються); вільні клітини навколо вогнища на старті; галявини — області клітин, приховані туманом, поки їх не відкрито (?).
- Будівлі N×M з поворотом і клітиною-входом; дороги/стежки зменшують час ходіння; ходити можна й крізь дерева та будівлі, але з великим штрафом.
- Real-time з паузою; рік = три сезони: Drizzle (садити) → Clearance (збирати) → Storm (негативні умови, ×ворожість, неприбраний урожай гине, торговців нема).
- Світова мапа між забігами — поле вибору місця поселення з біомами й модифікаторами (6 біомів); її геометрія (гекси?) (?).

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Дерево | terrain | вид деревини | непрохідне для будівництва; дроворуб рубає → клітина вільна, +деревина |
| Вільна клітина | terrain | — | можна будувати, ходити |
| Дорога / стежка | terrain | — | швидше ходіння |
| Галявина (мала / небезпечна / заборонена) | zone | вміст, рівень загрози (?) | прихована, поки не відкрито; відкриття → ворожість +, показ вмісту |
| Загадка/подія галявини | object | потрібні товари, таймер (?) | вирішити товарами → нагорода або зняти загрозу; інакше штраф |
| Родовище / джерело / гриби, гейзер | resource | запас | збирається таборами; деякі можна прибрати, звільняючи місце |
| Вогнище (hearth) | source | паливо, рівень, хранитель | відпочинок і споживання товарів мешканцями поруч; додаткові вогнища знижують ворожість |
| Будинок | object | раса | закриває потребу в житлі |
| Виробнича будівля / табір збирачів | object | вхід-клітина, робітники, рецепти | працює з робітниками; табір часто треба крутити під рельєф |
| Табір дроворубів | object | налаштування «уникати галявин» | дроворуби рубають ліс; кожен — +ворожість |
| Склад | container | — | центральне сховище; вироби повертаються сюди при знесенні |
| Кіста Blightrot | hazard | — | розквітає в бурю/подіях → порча; повна смуга порчі → гинуть 3 мешканці; гасити Purging Fire з Blight Post |
| Поселенець (люди, бобри, ящірки, лисиці, гарпії, жаби, кажани) | ally | раса, resolve, потреби, спеціалізація | працює; resolve ≤ 0 → іде геть; задоволений — дає репутацію |
| Торговець | neutral | товари року | купівля cornerstones і креслень за бурштин; не приходить у бурю |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(place, building)` → ЯКЩО `fits(building, cells)` і `free(cells)` → ТО `place(blueprint)`; будують робітники з матеріалів складу.
- КОЛИ `custom: «дроворуб зрубав дерево»` → ТО `set_cell(cell, clear)`, `give(warehouse, wood)`.
- КОЛИ `custom: «прорубано прохід до межі галявини»` → ТО `reveal(glade)`, `counter(hostility, +n)` (?); налаштування табору «уникати галявин» не дає рубати в їх бік.
- КОЛИ `tick` → ТО `custom: «ворожість = f(рік, відкриті галявини, кількість мешканців, дроворуби, загадки) × складність − (вогнища, cornerstones, предмети)»`.
- КОЛИ `counter(hostility, >=, level)` → ТО `custom: «глобальний штраф до resolve; активуються загадки лісу з порогом ворожості»`.
- КОЛИ `custom: «почався сезон Storm»` → ТО `custom: «негативні умови × ворожість; неприбраний урожай знищено; торговець не прибуває»`; Drizzle — позитивні умови.
- КОЛИ `input(solve, glade_event, goods)` → ЯКЩО `has(warehouse, goods)` → ТО `take(warehouse, goods)`, `custom: «нагорода / зняття загрози»`; товар-вимогу можна замінити кліком.
- КОЛИ `tick` → ТО `custom: «resolve мешканця падає зі швидкістю раси»`; ЯКЩО `custom: «закрито житло, складну їжу, сервіси, товари раси»` → ТО `custom: «resolve +»`.
- КОЛИ `counter(resolve, <=, 0)` → ТО `custom: «мешканець іде»`, `counter(impatience, +n)`.
- КОЛИ `counter(resolve, >=, threshold)` → ТО `counter(reputation, +1)`; поріг зростає після кожного пункту (Decadence).
- КОЛИ `input(complete, order)` → ТО `counter(reputation, +n)`, `choose(rewards)`.
- КОЛИ `timer(every)` → ТО `counter(impatience, +n)`; КОЛИ `counter(reputation, +1)` → ТО `counter(impatience, -n)`.
- КОЛИ `counter(reputation, =, max)` → ТО `win`; КОЛИ `counter(impatience, =, max)` → ТО `lose` (відкликання Королевою).
- КОЛИ `custom: «бура / подія»` → ТО `spawn_at(cyst, buildings)` (?); КОЛИ `counter(corruption, =, max)` → ТО `custom: «гинуть 3 випадкові мешканці»`, `set_value(corruption, 0)`.
- КОЛИ `custom: «мешканець іде на відпочинок»` → ТО `move(villager, rest_spot)` — `custom: «випадкове місце довкола вогнища; крізь дерева й будівлі — великий штраф часу»`.
- КОЛИ `custom: «збіг спеціалізації раси з будівлею»` → ТО `custom: «10 % шанс подвоєного виходу або +5 resolve»`.
- КОЛИ `custom: «новий рік / подія»` → ТО `choose(cornerstones)` — постійний бонус до кінця забігу.

## Керування і ввід
- Миша: меню креслень (набір обирається перед забігом) → привид будівлі → поворот → клік; дороги — drag.
- Клік по будівлі — призначити робітників (раси), рецепти, налаштування табору (уникати галявин).
- Вікна загадок галявин — вибрати товари для вирішення; вікна наказів Королеви — обрати нагороду.

## Вікна, меню, HUD
- `main-menu` → Smoldering City (мета-хаб: апгрейди за ресурси) → `map-window` (світова мапа: вибір місця, біом, модифікатори) → підготовка забігу (раси, креслення, ембаркація) → `game-screen`.
- `game-screen`: поле, ліворуч унизу синя смуга Репутації, праворуч унизу червона смуга Нетерпіння (`+ui:dual-bar`), угорі праворуч — ворожість лісу; сезон і таймер року.
- `upgrade-window`: вибір cornerstone / нагороди ордера (`choose`).
- `custom-window`: подія галявини (потрібні товари, наслідки), торговець (`shop-window`).
- Вікно раси: resolve, потреби, пороги репутації.
- `end-screen`: перемога/поразка поселення → назад у місто.

## Фічі поза полем
- Роґлайт-сесії: забіг = поселення; ресурси, апгрейди й досвід переходять у Smoldering City (`meta-progression`).
- Печатки: збір уламків відкриває спеціальну мапу; перша печатка послаблює бурю.
- Prestige-рівні складності з наростаючими модифікаторами (кісти частіше, буря довша).
- DLC: Keepers of the Stone (2024, нова раса), раси жаб і кажанів у DLC.
- `pause`, `save-game` (?).

## Цікавинки для курсу
- Вирубка лісу на сітці з прихованими галявинами: відкриття області, коли прохід торкнувся її межі — 📎 (flood + reveal).
- Ворожість як глобальний лічильник із зважених джерел і порогами — 🌱.
- Дві смуги-перегони: репутація зменшує нетерпіння, мешканці, що пішли, — збільшують — 🌱.
- Сезонний цикл з різними правилами в кожному сезоні — 📎.
- Ходіння з різною вартістю клітин (дорога / порожньо / дерево / будівля) — Дейкстра — 📎.
- Resolve з порогами, що ростуть після кожного пункту репутації — 🌱.

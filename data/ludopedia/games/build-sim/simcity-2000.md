# SimCity 2000 — той самий SimCity, але земля має 32 висоти, під нею — шар водогону й метро, а станції старіють за 50 років

## Суть
Ядро — як у `simcity-1989`: мер розмічає зони R/C/I, тягне дороги й лінії, а місто росте саме. Тут описано **лише відмінності**. Головні: рельєф із 32 рівнями висоти (похилі клітини, тунелі, водоспади для ГЕС), окремий **підземний шар** (водогін, метро), зони будь-якого прямокутника й двох щільностей, транспорт через станції й депо, 9 типів електростанцій із роком появи й 50-річним строком служби. Вікно оцінки замінили газети, зʼявились сусідні міста, постанови міськради, облігації й аркології.

## Поле і час
- Квадратна сітка в ізометричній проєкції (City window): 3 рівні зуму, поворот усієї мапи на 90°; клітина ≈ 200×200 футів, межі міста ≈ 5×5 миль.
- **Висота:** 32 рівні; клітина може бути похилою; нижче рівня моря — вода. Гори, долини, озера, річки, струмки, водоспади.
- **Шари:** поверхня + підземний вигляд (труби водогону, метро, станції, контури зон); перемикач Show Underground.
- Час real-time; рік заснування 1900 / 1950 / 2000 / 2050 визначає доступні технології; клімат — щомісяця новий погодний тренд.

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(zone_tool, rect)` → ТО `place(player, zone)`, `currency(-5 або -10 за клітину)`; перезонування платне лише при зміні типу чи щільності; дороги й будівлі міста дезонують клітину під собою.
- КОЛИ `input(terraform, cell)` → ЯКЩО `mode(city)` → ТО `custom: «висота ±1»`, `currency(-25)`; у редакторі нової мапи — безкоштовно; нижче рівня моря — `set_cell(cell, water)`.
- КОЛИ `input(tunnel, cell)` → ЯКЩО `custom: «вхід — похила клітина, прямий шлях, стабільний ґрунт, без перетину тунелів»` → ТО `message(engineers_report)`, `place(player, tunnel)`; інакше `block`.
- КОЛИ `input(place, depot)` → ЯКЩО `custom: «рівна клітина поруч з колією / лінією метро»` → ТО `place(player, depot)`.
- КОЛИ `tick` → ЯКЩО `connected(building, power_plant)` → ТО `set_state(building, powered)`; струм іде лініями та будівлями в сусідні зони, але **не** через порожні зони.
- КОЛИ `counter(plant_age, >=, 50)` → ЯКЩО `custom: «No Disasters увімкнено»` and `has(city, funds)` → ТО `custom: «автоперебудова»`, `currency(-cost)`; інакше `custom: «станція руйнується без пожежі й радіації»`; газети попереджають заздалегідь.
- КОЛИ `input(place, hydro_plant)` → ЯКЩО `custom: «клітина водоспаду»` → ТО `place(player, hydro_plant)`.
- КОЛИ `tick` → ЯКЩО `connected(building, water_source)` and `custom: «води вистачає на населення»` → ТО `set_state(building, watered)`; без води `custom: «щільність зон обмежена»`.
- КОЛИ `tick` → ЯКЩО `adjacent_count(pump, fresh_water, >=, 1)` → ТО `custom: «вихід ×2–3 від колодязя»`; насос без живлення не працює.
- КОЛИ `timer(month)` → ТО `custom: «новий тренд погоди (12 видів) з поточного тренду й сезону + зважений випадок»`; спека — менше води й більше пожеж і бунтів, вітер — вітряки, хмари — сонячні.
- КОЛИ `custom: «пасажир їде громадським транспортом»` → ЯКЩО `custom: «є станції/депо на обох кінцях»` → ТО `custom: «поїздка без авто; менше заторів і забруднення»`.
- КОЛИ `counter(population, >=, 2000)` → ТО `give(player, mayor_house)`, `message(newspaper)`; 10 000 — ратуша, 30 000 — «щось круте».
- КОЛИ `counter(population, >=, 60000)` → ТО `choose(yes, no)`; ЯКЩО так → ТО `spawn_at(military_base, government_choice)`: берег → флот, рівнина → ВПС, пагорби → армія, дуже гориста → силоси.
- КОЛИ `counter(population, >=, 120000)` → ЯКЩО `custom: «рік ≥ року дизайну аркології»` → ТО `unlock(arcology)`.
- КОЛИ `counter(launch_arcologies, >=, 300)` → ЯКЩО `custom: «рік ≥ 2051»` → ТО `custom: «наступного січня аркології злітають у космос»`, `currency(+construction_cost)`.
- КОЛИ `custom: «настав рік винаходу»` → ТО `unlock(tool)`, `message(newspaper)`.
- КОЛИ `input(ordinance, on)` → ТО `custom: «щомісячний дохід (1 % податок з продажу чи доходу, азартні ігри, штрафи за паркування) або витрата з ефектом (сусідська варта ↓злочин, безкоштовні клініки ↑здоровʼя…)»`; без «No Disasters» рада може ухвалити постанову сама.
- КОЛИ `input(issue_bond)` → ТО `currency(+n)`, `custom: «відсотки щороку до погашення»`; ставки податку окремо для R, C, I і для типів промисловості.
- КОЛИ `custom: «надмірний дефіцит»` → ТО `game_over`.
- КОЛИ `custom: «є шосе до сусіднього міста»` → ТО `custom: «більше торгівлі й населення»`.
- Перемога: нема (у сценаріях — мета: населення, гроші, відновити промисловість, знизити злочин/забруднення/трафік) · Поразка: дефіцит · Рахунок: газети замість оцінки мера.

## Керування і ввід
- Миша: інструменти з підменю (довге натискання), протягування для доріг, труб, рейок; прямокутник для зон і портів; Shift перед відпусканням — скасувати.
- Shift+клік по будь-якій кнопці — довідка; Query показує назву, тип, висоту, вартість землі (станція — % спожитої потужності, дорога — трафік).
- Вікна відкриваються «на мить» (тримати кнопку) або «відірвати» (перетягнути кнопку).

## Вікна, меню, HUD
- `game-screen` (City window): ізометрична мапа, тулбар, `+ui:layer-toggle` (поверхня / підземний вигляд), кнопки Show (будівлі, зони, інфраструктура), зум, поворот, індикатор попиту R/C/I.
- `map-window`: оверлеї, зокрема висоти (світліше = вище), водогін, вартість землі.
- `+window:budget-window` (з `simcity-1989`): податки, `+window:ordinance-window`, облігації, служби, освіта, транспорт.
- `+window:newspaper` — газети замість оцінки: думка жителів, погода, винаходи, катастрофи; підписка на рік.
- Population (вік, тривалість життя, освіта) · Industries (типи, національний попит, податки) · Graphs · `+window:neighbors-window` (населення сусідніх міст і SimNation).
- `editor-window` — редактор рельєфу вбудовано (Edit New Map): підняти/опустити, вирівняти, рівень моря ±1, річки, ліси.
- Меню Disasters (викликати / No Disasters); `level-select` сценаріїв.

## Фічі поза полем
- `difficulty-presets`: старт $20 000 / $10 000 / −$10 000 з облігацією; економіка SimNation — бум / стабільна / рецесія; попит на промисловість; шанс катастроф.
- `+feature:founding-year`: 1900 / 1950 / 2000 / 2050 — від року залежать технології.
- `mode-puzzle` — сценарії на реальних містах і подіях (Oakland 1991); доповнення Great Disasters (НЛО, аварії АЕС, повені, землетруси); Urban Renewal Kit; Network Edition — до 4 гравців.
- `+feature:disaster-toggle` (з `simcity-1989`), `save-slots`.

## Варіації й родичі
- Базовий файл — `simcity-1989`; наступник — SimCity 3000.
- Порти: SNES (6 мап на один слот, імена до 8 символів; дари на 1 / 2 / 3 млн), Saturn (статуя на 30 000), GBA — без водогону.
- Родичі в корпусі: `openttd-rails` (станції й колія), `cities-skylines-zoning`, `dwarf-fortress-tiles` (кілька рівнів), `oxygen-not-included-cells`, `timberborn` (висоти й вода).
- Осі варіацій «поверх SimCity»:
  - **рельєф:** пласка мапа / висоти з похилами (SC2000);
  - **мережі:** одна (струм) / дві (струм + вода) / окремий підземний шар;
  - **технології:** усе з початку / за роком (SC2000).

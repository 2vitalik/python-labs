# Nagel–Schreckenberg — 1D-дорога: розгін, гальмування до просвіту, випадкове гальмування; затори виникають з нічого

## Суть
Модель Кая Нагеля й Міхаеля Шрекенберга (1992, Journal de Physique I): дорога — рядок клітин, у кожній не більше одного авто, швидкість авто — ціле число від 0 до vmax. Щотіку всі авто розганяються на 1, гальмують до просвіту перед собою, з імовірністю p ще раз пригальмовують і їдуть. Через випадкове «ловлення ґав» (dawdling) і надмірне гальмування виникають затори без жодної перешкоди, що повзуть назад проти руху. Мінімальна модель, на якій виросли TRANSIMS і прогноз заторів на автобанах NRW.

## Поле і час
- Одновимірна смуга клітин, кінці склеєні в кільце (періодичні межі в оригіналі).
- Клітина — порожня або одне авто; у DE-Wikipedia клітина = 7,5 м (авто + проміжок), тік = 1 с (час реакції водія).
- Швидкість 1 клітина/тік = 7,5 м/с (27 км/год); звичний vmax = 5 → 135 км/год.
- Тік = чотири фази, кожна застосовується до всіх авто паралельно; спершу всі визначають рух, потім рухаються разом.
- Класичний вивід — просторово-часова діаграма: рядок дороги за рядком тіку, затори — темні діагональні смуги.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Авто | object | позиція, швидкість v ∈ 0..vmax | розгін → гальмування до просвіту → випадкове гальмування → рух на v |
| Порожня клітина | terrain | — | просвіт між авто; кількість задає густина |
| Кільце | static | довжина L | вихід з кінця → початок |
| Затор (кластер) | object | емерджентний | авто «бампер до бампера», повільні; кластер зсувається назад |
| Точка вимірювання | zone | — | рахує авто, що проїхали (потік) |

## Правила (КОЛИ → ЯКЩО → ТО)
- Розгін: КОЛИ `phase_start(accelerate)` → ЯКЩО `custom: «v < vmax»` → ТО `speed(car, +1)`.
- Гальмування: КОЛИ `phase_start(slow_down)` → ЯКЩО `custom: «порожніх клітин до наступного авто менше за v»` → ТО `set_value(car, v = gap)`.
- Випадкове гальмування: КОЛИ `phase_start(randomize)` → ЯКЩО `custom: «v ≥ 1»` and `prob(p)` → ТО `speed(car, -1)`.
- Рух: КОЛИ `phase_start(move)` → ТО `move(car, x + v)`.
- Кожна фаза діє на всі авто паралельно, у порядку 1 → 2 → 3 → 4.
- КОЛИ `edge(car)` → ТО `wrap(car)` (кільце).
- Інваріант: `custom: «після фази гальмування v ≤ просвіт, тож зіткнень і обгонів нема»`.
- КОЛИ `level_start` → ТО `spawn_at(car, random_free)` з густиною ρ (Wikipedia: 100 клітин, ρ = 0.35; DE: 15 авто на 50 клітинах).
- Потік: КОЛИ `reach(car, detector)` → ТО `counter(flow, +1)`.
- Окремий випадок: ЯКЩО `mode(vmax = 1, p = 0)` → модель = Rule 184 Вольфрама = детермінований TASEP з паралельним оновленням.
- VDR (velocity-dependent randomization): КОЛИ `phase_start(randomize)` → ЯКЩО `custom: «авто стояло»` → ТО `custom: «ймовірність гальмування вища, ніж у русі»` — краще відтворює структуру заторів.
- Круїз-контроль (США): КОЛИ `phase_start(randomize)` → ЯКЩО `custom: «v = vmax»` → ТО `custom: «випадкового гальмування нема»`.
- Перемоги, поразки, рахунку нема; метрики — середня швидкість і потік (авто за тік).

## Керування і ввід
- Типова цифрова версія: повзунки густини (або кількості авто), vmax, p, довжини дороги; Run/Pause, Step, Reset.
- Вигляд: кільце-дорога з авто, кольоровими за швидкістю, і просторово-часова діаграма поруч.
- Гравець не керує авто; експеримент — змінювати густину й p і шукати, коли виникають затори.

## Вікна, меню, HUD
- `game-screen` (цифрова версія): дорога (рядок або кільце), просторово-часова діаграма, кнопки Run/Pause, `step-button`, Reset.
- HUD: `turn-counter` (тік), середня швидкість, потік.
- `stats-plot` (пропозиція): фундаментальна діаграма — потік або швидкість від густини.
- `settings-window`: довжина дороги, густина, vmax, p, варіант (класика / VDR / круїз-контроль).
- Переходи: settings → Reset → game-screen.

## Фічі поза полем
- `step-mode`, `speed-control`, `pause`; `seed-input` для відтворення випадкових гальмувань.
- Сканування параметра: прогін густини від 0 до 1 → фундаментальна діаграма.
- Розширення в реальних застосуваннях: паралельна версія для кластерів (TRANSIMS: увесь трафік Швейцарії, ~10 млн авто) і OLSIM — прогноз заторів на автобанах NRW.
- Збережень і рекордів нема.

## Варіації й родичі
- **Осі варіацій:** межа (кільце / відкрита дорога) · vmax (1 → Rule 184) · правило випадкового гальмування (стале p / VDR / без гальмування на vmax) · кількість смуг і правила обгону · стоп-сигнали.
- Фундаментальна діаграма: при p = 0 швидкість максимальна до густини 1/(vmax+1) ≈ 0.167, потім падає до 0 при повному заповненні; при p = 0.3 злам близько 0.15 і заокруглений. Реальний трафік має гістерезис і вигнуту гілку вільного руху, яких базова модель не дає — звідси розширення.
- Родичі в корпусі: [elementary-cellular-automata](elementary-cellular-automata.md) (Rule 184), [bml-traffic](bml-traffic.md) (2D, без швидкостей), [mini-motorways](mini-motorways.md) (затори як ігрова механіка).

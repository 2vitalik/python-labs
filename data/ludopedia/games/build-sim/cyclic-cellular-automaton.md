# Cyclic cellular automaton — κ кольорів по колу: клітина «зʼїдається» сусідом наступного кольору, і з шуму виростають спіралі

## Суть
Кожна клітина має один з κ кольорів 0…κ−1, розставлених на «колірному колі». Клітина не змінюється, доки серед сусідів не зʼявиться колір, **рівно на 1 більший** (за модулем κ, після κ−1 іде 0), — тоді вона бере цей колір. З випадкового старту поле проходить фази: шум → блоки, що поїдають шум, → «демони» — маленькі цикли з усіма кольорами по колу, які крутяться вічно й випускають спіральні хвилі. Правило належить Девіду Гріффіту і його учням (Fisch, Gravner); популяризував Дьюдні в Scientific American. Гравець лише задає параметри й стартовий шум.

## Поле і час
- Квадратна сітка, на екрані — скінченна з загортанням країв (тор) (FGG: «typically with wrap-around»).
- Сусідство радіуса ρ: **diamond** ρD (ℓ¹; 1D = 4 сусіди фон Неймана) або **box** ρB (ℓ∞; 1B = 8 сусідів Мура). Поріг θ — скільки сусідів наступного кольору треба.
- Тік: синхронне оновлення всіх клітин зі старого стану.
- Старт: кожна клітина незалежно отримує колір з імовірністю 1/κ.
- Тристадійна еволюція (2D, θ = 1): випадкова → «поїдання» блоками → домінування демонів; зрештою кожна клітина циклічно проходить усі кольори.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Клітина кольору k | tile | k ∈ 0…κ−1 | стає k+1 mod κ, якщо ≥ θ сусідів у радіусі ρ мають k+1 mod κ |
| Блок / крапля кольору | zone | розмір | емерджентний: однокольорова область, що наступає на шум |
| Хвильовий фронт | object | ширина ρ (CCA) | смуги кольорів, що біжать по полю й анігілюють при зіткненні |
| Демон (clock) | spawner | цикл із κ клітин | цикл сусідніх клітин з усіма кольорами по порядку: оновлюється щотіку незалежно від оточення, випускає спіралі |
| SPO (stable periodic object) | spawner | (ρ, θ, κ) | скінченна конфігурація, де кожна клітина кольору k має ≥ θ сусідів кольору k+1 — узагальнений демон, «організаційний центр» |
| Ріг барана (ram's horn) | object | — | пара спіралей навколо SPO; при ρ = 3B, θ = 6 відтворює себе й випускає концентричні хвилі |
| «Макарони» | object | — | метастабільний хаос обривків хвиль (GH, 2B/4/5), доки не зʼявиться SPO |
| Сміття (debris) | object | — | рештки розваленої вихорової спроби, напр. (1B, 3, 5) |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `level_start` → ТО `custom: «кожна клітина — випадковий колір 0…κ−1, рівноймовірно»`.
- КОЛИ `tick` → ЯКЩО `state(x, k)` and `adjacent_count(x, (k+1) mod κ, ≥, θ)` → ТО `set_value(x, (k+1) mod κ)`; інакше клітина лишається.
- Базовий CCA: ρ = 1D (4 сусіди), θ = 1 — правило з Вікіпедії «клітина бере колір сусіда, рівно на 1 більший».
- КОЛИ `edge(nbr)` → ТО `wrap(nbr)` — сусід береться з протилежного краю.
- Варіант Greenberg–Hastings (GH): КОЛИ `tick` → ЯКЩО `state(x, k)` and `custom: «k ≥ 1»` → ТО `set_value(x, k+1 mod κ)` (збуджені й рефрактерні кольори йдуть самі); колір 0 — лише через контакт з θ сусідами кольору 1.
- Тест смуги (FGG): горизонтальні смуги кольорів шириною ρ на тлі 0 у CCA з box-сусідством дають хвилю вгору, якщо θ < (2ρ+1)ρ; якщо θ > (2ρ+1)ρ, стан **ніколи не змінюється**.
- КОЛИ `settled` → ТО `custom: «фіксація: високий поріг, блоки застигли без спіралей»`.
- θ = 1, будь-яке ρ, κ ≥ 3: автомат локально періодичний з періодом κ — у випадковому старті завжди є демон, і він «підганяє» все поле.
- Демон: КОЛИ `custom: «цикл сусідніх клітин містить усі κ кольорів по порядку»` → ТО `custom: «цикл щотіку повертається на крок незалежно від решти поля»`; коротші демони поглинають довші.
- Режими за порогом (великі ρ): низький θ → спіралі; високий θ → застиглі блоки; середній → «турбулентність» (блоки + уривки спіралей).
- Перемоги, поразки й рахунку нема.

## Варіації й родичі
- **Осі варіацій:** κ (3, 4, ≥5…) · ρ і форма сусідства (D/B) · θ · хто оновлюється контактом (усі — CCA / лише 0 — GH) · детермінований чи випадковий (асинхронний) · вимірність (1D / 2D).
- Набори з FGG (ρ, θ, κ): (1B, 3, 3), (1B, 3, 4), (3B, 9, 3), (3B, 8, 4) — великі спіралі; (1B, 3, 5) — сміття; (1B, 2, 6) — центр із двома переплетеними нитками спіралей; (3B, 6, 8) — роги барана; GH (2B, 3, 8) — роги барана з рідких вогнищ; GH (2B, 4, 5) — макарони.
- **1D-версія** (Fisch): κ = 3 або 4 — зростаючі кластери, межі між кольорами — частинки з балістичною анігіляцією (звʼязок із Rule 184 з [elementary-cellular-automata](elementary-cellular-automata.md)); κ ≥ 5 — швидка фіксація («Bob's dilemma»).
- Випадковий асинхронний предок: Bramson і Griffeath (1980), 1D; кластеризація при κ ≤ 4, фіксація при κ ≥ 5.
- Родичі: Greenberg–Hastings (у черзі хвилі 3), [brians-brain-seeds](brians-brain-seeds.md) (збудливе середовище з рефрактерним станом), [forest-fire-model](forest-fire-model.md) (випадкові GH-моделі дають «forest fire»-рівноваги), реакція Бєлоусова — Жаботинського (схожі спіралі), [game-of-life](game-of-life.md); камінь-ножиці-папір на сітці — та сама циклічна перевага при κ = 3 (?).

# TypeShift — крути колонки літер, доки центральний ряд не прочитає слово; мета — «використати» кожну літеру

## Суть
Поле — кілька вертикальних колонок різної довжини з літерами; колонку можна зсувати вгору-вниз. Слово читається в одному горизонтальному ряду, через усі колонки; кожне справжнє слово, що склалося, фарбує свої літери в зелений. Пазл розвʼязано, коли зеленою стала кожна літера поля. Ядро — анаграма × пошук слова у форматі «sliding block»: шукаєш не одне слово, а покриття множини літер мінімальним набором слів.

## Поле і час
- Поле: N колонок поруч (N = довжина слова); у кожній колонці свій стовпчик літер, колонки різної висоти й зміщені одна відносно одної.
- Рядок читання — одна горизонтальна лінія поперек колонок; що в ній, те й «спроба».
- Часу нема (статичний пазл); у поданні — анімація зсуву і «вспалах» зеленим на знайденому слові.
- Пізніші рівні: більші поля й закріплені літери (за PocketGamer) (?).

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Колонка | object | список літер, зсув | ковзає вертикально по одній позиції; кінці не зациклені (?) |
| Літера | tile | символ, стан unused/used | used (зелена) — після участі хоча б в одному слові; стан не відкочується |
| Рядок читання | zone | N клітин, по одній з кожної колонки | після кожного зсуву перевіряється як слово |
| Словник | static | список слів | джерело `in_dictionary` |
| Список знайдених слів | static (UI) | слова | поповнюється; повтор нічого не дає |
| Підказка (clue-стадії) | mark | текст-визначення, відповідь | закреслюється, коли знайдено слово-відповідь |
| Ключові слова | static (приховане) | мінімальний набір слів, що покриває всі літери | показуються після розвʼязку |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(drag column, up|down)` → ЯКЩО `custom: «у колонці є літера в цьому напрямку»` → ТО `shift(col, dir)`; інакше `block`.
- КОЛИ `after(shift)` → ЯКЩО `in_dictionary(reading_row)` and `custom: «слова ще нема в знайдених»` → ТО `set_state(letters_in_row, used)`, `custom: «слово в список знайдених»`, `flash`.
- КОЛИ `after(shift)` → ЯКЩО `in_dictionary(reading_row)` and `custom: «слово вже знайдено»` → ТО `custom: «нічого не міняється»`.
- КОЛИ `counter(unused_letters, ==, 0)` → ТО `win`, `custom: «показати ключові слова»`, `window(end-screen)`.
- Clue-стадія: КОЛИ `after(shift)` → ЯКЩО `custom: «слово в рядку = відповідь на одну з підказок»` → ТО `custom: «підказку закреслено/прибрано»`.
- Clue-стадія: КОЛИ `custom: «усі підказки розвʼязано»` → ТО `win`.
- Закріплена літера (пізні рівні) (?): `custom: «колонка/літера не зсувається»` → `block`.
- Перемога: усі літери зелені (звичайна стадія) або всі підказки розвʼязано (clue-стадія) · Поразки нема · Рахунок: у звичайній стадії «ефективність» — що менше ходів/слів, то краще (за PocketGamer) (?).

## Керування і ввід
- Тач/миша: затиснути колонку й тягнути вгору-вниз; колонка «клацає» на позиції літер.
- Клавіатури нема: спроба — завжди поточний вміст рядка читання; перевірка автоматична після кожного зсуву.
- Clue-стадія: тап по підказці (за Wikipedia «правильна підказка зникає при тапі») (?).

## Вікна, меню, HUD
- `game-screen`: колонки, рядок читання (підсвічений), лічильник/список знайдених слів, кнопка підказки (?); у clue-стадії — `clue-list` над/під полем.
- `puzzle-select`: паки пазлів сітками з позначкою «розвʼязано».
- `daily-window` (?): щоденний пазл і щоденний clue-пазл.
- `shop-window`: покупка паків (IAP).
- `end-screen`: «Solved», ключові слова пазла, кількість знайдених.
- Переходи: `main-menu` → паки → `puzzle-select` → `game-screen` → `end-screen` → наступний.

## Фічі поза полем
- `puzzle-bank` паками; частина безкоштовна, решта — IAP (PocketGamer); реклама в безкоштовній версії (Wikipedia).
- `daily-puzzle` (?): щоденний пазл; з 2023 TypeShift — гра на порталі Puzzmo (щоденний формат).
- `key-words-reveal`: після розвʼязку гра показує «ключові» слова — критики вважали це спойлером.
- Браузерна версія на сайті Merriam-Webster (станом на 2021 — недоступна).

## Варіації й родичі
- Інші ігри Gage: SpellTower (`spelltower.md`), Knotwords (`knotwords.md`) — та сама «мінімалістична словесна» школа.
- Родичі за механікою: криптекс/кодовий замок (барабани з літерами), Wordle-подібні (перевірка слова словником, `wordle.md`).
- **Осі варіацій:** мета (покрити всі літери / знайти слова за підказками) · кінці колонок (упор / тор) · закріплені літери · кількість рядків читання (1 / кілька) (?).

## Цікавинки для курсу
- Колонки-барабани з рядком читання — 🌱: масив зсувів, рядок = `col[i][offset[i]]`.
- Стан «used» на літері з довільної кількості слів + умова «усі зелені» — 🌱.
- Пошук усіх слів, досяжних зсувами (декартів добуток колонок ∩ словник, через trie) — 📎.
- Мінімальне покриття літер словами (ключові слова) — set cover; точний розвʼязок — 🥇: NP-повна задача, на малих полях — перебір/ILP.
- Генерація пазла з набору ключових слів (вирівнювання колонок, щоб не було «зайвих» легких слів) — 🥈.

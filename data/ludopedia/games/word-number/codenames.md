# Codenames — дві команди, 25 слів і ключ-карта: ведучий одним словом і числом наводить своїх на «агентів»

## Суть
На столі сітка 5×5 карток-слів; кожна потай належить червоним, синім, нейтральним «перехожим» або асасину. Розподіл бачать лише два ведучі-«спаймастери» на ключ-карті. Ведучий дає підказку з одного слова й числа («Ocean: 3»), його команда торкається карток, вгадуючи, до яких слів вона веде. Ядро — асоціативна комунікація з прихованою інформацією: одна підказка має покрити якомога більше своїх слів і оминути асасина й чужих.

## Поле і час
- Поле 5×5 = 25 карток-слів, лицем догори; ключ-карта 5×5 у підставці між ведучими (на ній чотири вогники по краях — хто ходить першим).
- Шари: слово (видно всім) + приховане призначення (видно ведучим) + накладена картка агента/перехожого/асасина після відкриття.
- Хід = одна підказка ведучого + серія вгадувань команди. Команди чергуються.
- Темп: необовʼязковий пісочний годинник — підганяє того, хто думає задовго.
- Розміри варіантів: Pictures — 5×4 картинок; Disney Family — 4×4 без асасина; Duet — 5×5, кооператив.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Картка-слово | tile | слово, приховане призначення, стан open/closed | відкривається торканням оперативника; відкрита накривається карткою кольору |
| Агент команди | mark | red / blue; 9 у стартової, 8 у другої | накриває своє слово; команда, що накрила всіх своїх, виграє |
| Подвійний агент | mark | 1, перевертається кольором стартової команди | дає стартовій команді девʼятого агента |
| Перехожий | mark | 7 | відкриття закінчує хід |
| Асасин | hazard | 1, чорний | відкриття — миттєва поразка команди, що вгадувала |
| Ключ-карта | static (прихована) | сітка 5×5 кольорів + стартова сторона | бачать лише ведучі; обирається випадково |
| Спаймастер | player | 1 на команду | дає підказки «слово + число»; мовчить під час вгадувань |
| Оперативники | player | ≥1 на команду | обговорюють і торкаються карток |
| Підказка | mark | слово, число N (або 0 / ∞) | задає ліміт вгадувань N+1 |
| Пісочний годинник | static | — | будь-хто перевертає, щоб змусити рішення |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `game_start` → ТО `custom: «випадкова ключ-карта; вогники визначають стартову команду»`, `custom: «подвійний агент — кольору стартової»`.
- КОЛИ `turn_start(team)` → ТО `custom: «ведучий каже одне слово й одне число»`.
- КОЛИ `input(clue)` → ЯКЩО `custom: «підказка — слово або частина складеного слова, що лежить відкритим на столі»` → ТО `end_turn`, `custom: «суперник накриває одного свого агента»`.
- КОЛИ `input(clue)` → ЯКЩО `custom: «підказка за літерами/звучанням/позицією, не за сенсом»` → ТО так само `end_turn` + бонус супернику (якщо помітили; не помітили — підказка дійсна).
- КОЛИ `input(touch card)` → ЯКЩО `turn_of(team)` and `custom: «вгадувань ≤ N+1»` → ТО `reveal(card)`.
- КОЛИ `after(reveal)` → ЯКЩО `custom: «агент своєї команди»` → ТО `mark(card, team)`; команда може вгадувати далі або зупинитися.
- КОЛИ `after(reveal)` → ЯКЩО `custom: «перехожий»` → ТО `mark(card, bystander)`, `end_turn`.
- КОЛИ `after(reveal)` → ЯКЩО `custom: «агент суперника»` → ТО `mark(card, other_team)`, `end_turn` — хід допоміг супернику.
- КОЛИ `after(reveal)` → ЯКЩО `custom: «асасин»` → ТО `lose` (для команди, що вгадувала), `game_over`.
- КОЛИ `counter(guesses, ==, N+1)` → ТО `end_turn`.
- КОЛИ `input(stop)` → ЯКЩО `counter(guesses, >=, 1)` → ТО `end_turn` (мінімум одне вгадування на хід обовʼязкове).
- КОЛИ `counter(team_agents_left, ==, 0)` → ТО `win` для цієї команди — навіть якщо останнього агента відкрив суперник у свій хід.
- Підказка 0: «жодне моє слово не повʼязане» — вгадувань без ліміту, але ≥1. Підказка ∞ (unlimited): без числа, для «боргів» з попередніх підказок.
- Легальність підказки: лише сенс слова; заборонені форми слів зі столу; число не може бути частиною підказки («Citrus: 8» для LEMON і OCTOPUS); омоніми з різним написанням — різні слова; спеллінг уголос дозволено.
- КОЛИ `timer(hourglass)` → ЯКЩО `custom: «ведучий не встиг»` → ТО `custom: «дає підказку до найважчого слова»`.
- Перемога: накрити всіх своїх агентів · Поразка: відкрити асасина (або суперник накрив своїх першим) · Рахунку нема.
- Duet: КОЛИ `counter(turns, ==, limit)` → ЯКЩО `custom: «не знайдено всі 15 агентів»` → ТО `lose` (кооператив; ліміт ходів задає режим).

## Керування і ввід
- Настолка: ведучий говорить підказку; оперативник торкається картки; ведучий накриває її карткою кольору з ключ-карти.
- Цифрова версія (codenames.game): ввести нікнейм → кімната → налаштування → поділитися URL кімнати; голос — сторонні дзвінки. Підказку ведучий вводить текстом і числом, оперативники клікають картки (?).
- Ролі розділені за інформацією: ведучий бачить кольори, оперативники — ні; «чесність» в офлайні тримається на гравцях.

## Вікна, меню, HUD
- `lobby-window` (цифрова версія): нікнейм, «Enter Game», посилання на кімнату.
- `match-setup`: мова слів, режим (класика / Duet), таймер (?), набір слів (?).
- `role-select` (?): вибір команди й ролі (ведучий / оперативник).
- `game-screen` для оперативників: сітка 5×5, `clue-display` (поточна підказка й число), `guesses-left`, `remaining-counter` агентів кожної команди, `turn-indicator`, кнопка «End guessing».
- `game-screen` для ведучого: те саме + `key-card-view` (кольори всіх карток), поле вводу підказки.
- `end-screen`: переможна команда, повна ключ-карта.
- `help-window`: правила і правила легальних підказок.
- Переходи: `lobby-window` → `match-setup` → `game-screen` → `end-screen` → нова партія з тими самими командами.

## Пропозиції до словників
- `+trigger:clue_given` — ведучий оголосив підказку (Codenames, Dixit-подібні); зараз через `input(clue)`.
- `+cond:clue_valid` — підказка легальна за правилами (не слово зі столу, за сенсом).
- `+effect:cover` — накрити картку маркером сторони (відмінно від `mark`: впливає на перемогу й закриває слово).
- `+role:card` — картка на полі з прихованим призначенням.
- `+ui:clue-display` — поточна підказка й число; `+ui:guesses-left` — лишилось вгадувань; `+ui:key-card-view` — розкладка, видима лише ролі.
- `+window:role-select` — вибір команди й ролі перед партією.
- `+feature:custom-word-list` — свої слова для партії (?).
- `+axis:turn-structure` — `sequential` з фазами «підказка → вгадування».
- `+card:hidden-key-card`, `+card:clue-word-number` — див. «Мапа на каталог».

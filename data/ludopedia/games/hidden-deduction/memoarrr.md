# Memoarrr! — острів 5×5 долілиць: відкрита карта мусить ділити тварину або пейзаж з попередньою, хто схибив — вилітає з раунду

## Суть
Карткова memory-гра на виліт: 24 карти-локації лежать сіткою 5×5 без центра, на кожній — одна з 5 тварин і один з 5 пейзажів (усі 25 поєднань різні, одна прибрана наосліп). Гравці по черзі відкривають по одній карті, і вона мусить **збігтися з останньою відкритою** за твариною або пейзажем — інакше гравець бере вулкан і вибуває до кінця раунду. Останній, хто не вибув, бере скарб із прихованою кількістю рубінів; після 7 раундів перемагає той, у кого рубінів більше. Ключ — ланцюжок: ціль задає не пара, а попередній хід суперника.

## Поле і час
- Сітка 5×5 «сорочкою» (хмари) догори; центральна карта прибрана, на її місці — стос скарбів із вулканами зверху (кількість вулканів = гравців − 1).
- 5 тварин × 5 пейзажів = 25 унікальних карт; одна випадкова невідома нікому — тому не можна вирахувати останню.
- Кожен гравець «володіє» одним боком острова: на старті таємно дивиться 3 середні карти свого краю.
- Хід = одне відкриття; раунд триває, доки не скінчаться вулкани; між раундами карти перевертаються назад **без переміщення** — памʼять переноситься в наступний раунд. Гра — 7 раундів.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Карта-локація | tile | тварина, пейзаж; закрита / відкрита | відкрита стає «останньою» — ціллю для наступного |
| Вулкан | supply | 1 / 3 / 7 птахів | бере той, хто схибив; власник пропускає ходи до кінця раунду; найбільше птахів → старт наступного раунду |
| Скарб | pickup | 1–4 рубіни (прихована цінність) | бере переможець раунду, не дивлячись; рахунок — наприкінці |
| Стос у центрі | container | вулкани зверху, скарби під ними | порожній від вулканів → кінець раунду |
| Пінгвін (експерт) | mark | здібність | таємно подивитись будь-яку закриту карту |
| Восьминіг (експерт) | mark | здібність | поміняти свою карту з ортогональним сусідом |
| Морж (експерт) | mark | здібність | заборонити наступному гравцеві одну закриту карту |
| Краб (експерт) | mark | здібність | додатковий хід (кожен вдалий краб — ще один) |
| Черепаха (експерт) | mark | — | нічого |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `game_start` → ТО `custom: «25 локацій 5×5 долілиць; центральну прибрати не дивлячись; у центр — 7 скарбів, зверху (гравців − 1) вулканів у випадковому порядку»`.
- КОЛИ `game_start` → ТО `custom: «кожен гравець таємно дивиться 3 середні карти свого боку острова й кладе назад»`.
- КОЛИ `input(flip, card)` → ЯКЩО `same(card, last_revealed, animal)` або `same(card, last_revealed, landscape)` → ТО `reveal(card)`, `end_turn` (успіх; карта стає новою ціллю).
- КОЛИ `input(flip, card)` → ЯКЩО не збігається ні за чим → ТО `reveal(card)`, `give(player, top_volcano)`, `set_state(player, out)`; наступний мусить збігтися вже з цією карткою.
- КОЛИ `turn_start(player)` → ЯКЩО `has(player, volcano)` → ТО `pass_turn` (вибулий пропускається).
- КОЛИ `input(flip, card)` → ЯКЩО `first_time` (перший хід стартового гравця в раунді) → ТО `reveal(card)` — завжди успіх.
- КОЛИ `input(flip, card)` → ЯКЩО `level(==, 1)` і `custom: «це одна з 3 карт, які стартовий гравець бачив на старті»` → ТО `block`.
- КОЛИ `turn_start(player)` → ЯКЩО `counter(revealed, ==, 24)` → ТО `give(player, top_volcano)`, `set_state(player, out)` (відкривати нічого).
- КОЛИ `turn_start(player)` → ЯКЩО `count(volcano_in_stack, ==, 0)` → ТО `give(player, top_treasure)` (наосліп), `level_end`.
- КОЛИ `level_end` → ТО `hide(all_cards)` без переміщення, `custom: «вулкани назад на стос у випадковому порядку; власник вулкана з найбільшою кількістю птахів починає»`.
- КОЛИ `counter(treasures_taken, ==, 7)` → ТО `game_over`; перемагає більше рубінів; нічия → більше карт скарбів → найдорожчий скарб.
- Експерт: КОЛИ успішне `reveal(card)` → ЯКЩО `same(card, penguin, animal)` → ТО `custom: «таємно подивитись будь-яку закриту карту»`; восьминіг → `swap(card, orth_neighbor)`; морж → `custom: «одна закрита карта заборонена наступному гравцеві»`; краб → `extra_move`; черепаха → нічого.
- Варіант Ordered Stack: `custom: «скарби складено за зростанням: 1, 1, 2, 2, 2, 3, 4»` — пізні раунди дорожчі.
- Перемога: найбільше рубінів після 7 раундів · Поразка в раунді: схибити (взяти вулкан) · Рахунок: рубіни на скарбах.

## Керування і ввід
- Настолка: перевернути одну закриту карту на місці; вулкан і скарб — з центрального стосу.
- Цифрова версія: клік по закритій карті; остання відкрита підсвічена як ціль; заборонена моржем — затінена; здібність тварини — окремий запит (вибір карти для пінгвіна/восьминога/моржа).

## Вікна, меню, HUD
- `main-menu` (цифрова версія): кількість гравців 2–4, Звичайні / Експертні правила, Ordered Stack.
- `custom-window` «таємний погляд» (цифрова версія): кожен по черзі бачить 3 карти свого краю (`pass-device` для hotseat).
- `game-screen` (цифрова версія): острів 5×5, `last-revealed-marker`, `volcano-stack` (скільки вулканів лишилось), іконки вибулих, `turn-indicator`, кількість скарбів у кожного (без цінності).
- `end-screen` (цифрова версія): відкриття скарбів, рубіни, тайбрейк.
- Переходи: main-menu → таємний погляд → game-screen (раунди 1–7) → end-screen.

## Фічі поза полем
- `hotseat` 2–4 гравці, 10–20 хв, вік 8+.
- `custom-rules`: Ordered Stack, експертні здібності тварин.
- Нагороди: Empfehlungsliste Spiel des Jahres 2018, Deutscher Kinderspielepreis 2018.

## Варіації й родичі
- [Memory / Concentration](memory-concentration.md) — пара однакових; тут збіг за **однією з двох ознак** з попередньою картою.
- [Zicke Zacke Hühnerkacke](zicke-zacke-huehnerkacke.md) — ціль задає клітина перед куркою; успіх = крок, промах = кінець ходу без вильоту.
- [Voltorb Flip](voltorb-flip.md), [Mini Cactpot](mini-cactpot.md) — відкриття з ризиком, але з підказками, а не з памʼяттю.
- **Осі варіацій**: правило збігу «однаковий малюнок / спільна ознака з двох / ціль на полі»; провал «кінець ходу / виліт з раунду»; памʼять між раундами «переноситься (карти не рухаються) / скидається»; здібності «нема / тварина відкритої карти діє».

## Цікавинки для курсу
- Генерація 5×5 з 25 унікальних пар (тварина, пейзаж) і прибраною центральною — 🌱.
- Перевірка ходу «спільна ознака з останньою відкритою» + виліт і пропуск вибулих — 🌱.
- Раунд на виліт з «останній живий бере приз» і передачею старту за кількістю птахів — 📎.
- Експертні здібності як окремі правила (peek, swap з сусідом, заборона для наступного, extra_move) — 📎.
- AI: обирати карту, що гарантовано збігається, і водночас лишити наступному якомога менше безпечних збігів — 🥉 (памʼять + підрахунок ризику).

## Пропозиції до словників
- `+cond:shares_any(a, b, props)` — A і B мають спільне значення хоча б однієї з ознак (зараз — два `same` через «або»).
- `+effect:peek(player, cell)` — показати приховане лише одному гравцеві (пінгвін, стартовий погляд).
- `+effect:forbid_cell(cell, who)` — заборонити клітину конкретному гравцеві на наступний хід (морж).
- `+ui:last-revealed-marker` — позначка поточної цілі збігу; `+ui:volcano-stack` — скільки вибуттів лишилось до кінця раунду.

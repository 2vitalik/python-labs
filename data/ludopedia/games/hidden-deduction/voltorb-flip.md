# Voltorb Flip — 5×5 закритих карток 1/2/3/Вольторб: перегортай, множ монети, не зірви бомбу

## Суть
Мінігра Game Corner у Pokémon HeartGold/SoulSilver (міжнародні версії). 25 карток лицем донизу; під кожною — 1, 2, 3 або Вольторб. Для кожного рядка й стовпця відомі **сума чисел** і **кількість Вольторбів**. Кожна відкрита картка множить виграш раунду; Вольторб забирає все. Мета — відкрити всі двійки й трійки; одиниці нічого не дають. Гібрид сапера (бомби) і нонограми (лінійні суми), з неминучими вгадуваннями і ризик-менеджментом (можна забрати виграш і вийти).

## Поле і час
- Поле 5×5; справа від кожного рядка й під кожним стовпцем — панель-підказка: зверху сума чисел, знизу кількість Вольторбів.
- Статичний покроковий: один хід = перевернути одну картку.
- Генерація раунду залежить від поточного рівня гри (1…8 (?)): скільки двійок, трійок і Вольторбів.
- Шари: прихований номінал + відкрита картка + memo-позначки гравця.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Закрита картка | static | номінал прихований | перевертається кліком |
| Картка 1 | tile | ×1 | безпечна, виграш не змінює |
| Картка 2 | tile | ×2 | множить виграш раунду на 2 |
| Картка 3 | tile | ×3 | множить виграш раунду на 3 |
| Вольторб | hazard | — | вибух: раунд програно, виграш раунду = 0 |
| Підказка рядка/стовпця | zone | сума, кількість Вольторбів | обмеження на 5 карток лінії |
| Memo-позначка | mark | Вольторб / 1 / 2 / 3 (кілька на картку) | нотатка гравця «можливі значення» |
| Виграш раунду | resource | добуток відкритих чисел | забирається при перемозі або виході |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(flip, c)` → ЯКЩО `cell(c, n)` → ТО `reveal(c)`, `custom: «виграш раунду ×= n»` (перша картка задає виграш = n).
- КОЛИ `input(flip, c)` → ЯКЩО `cell(c, voltorb)` → ТО `reveal(c)`, `lose` раунду, виграш раунду = 0, `reveal(all)`, далі зміна рівня.
- КОЛИ `custom: «усі 2 і 3 відкриті»` → ТО `win` раунду, `currency(+виграш)`, `reveal(all)`, `level(+1)`.
- КОЛИ раунд програно → ЯКЩО `counter(flipped, <, level)` → ТО `custom: «рівень = max(1, кількість перевернутих)»`; інакше рівень лишається.
- КОЛИ `input(quit)` → ТО `confirm-dialog`; так → `currency(+поточний виграш)`, раунд вважається програним для правила рівня.
- КОЛИ `input(memo, c, v)` → ТО `mark(c, v)` / `unmark(c, v)` — нотатка без впливу на гру.
- Підказки лінії: сума = Σ чисел (Вольторб = 0); рядок з «0 Вольторбів» — увесь безпечний; рядок з сумою + Вольторби = 5 — лише одиниці й Вольторби.
- Перемога раунду: відкрити всі 2 і 3. · Поразка раунду: Вольторб. · Рахунок: добуток номіналів відкритих карток → монети Game Corner (обмінюються на призи).

## Керування і ввід
- Стилус/D-pad + A: перевернути картку.
- Кнопка Memo (або X): режим нотаток; у ньому торкання картки ставить/знімає обрану позначку (Вольторб, 1, 2, 3).
- Quit — забрати виграш і вийти з раунду.
- Дедуктивні прийоми: лінія з 0 Вольторбів — відкривати сміливо; лінія з сумою 5 − кількість Вольторбів = кількість чисел → лише одиниці (пропускати).

## Вікна, меню, HUD
- `game-screen` (нижній екран DS): 5×5 поле, `line-clue` праворуч і знизу (сума + іконка Вольторба з числом), кнопки Memo і Quit, `memo-panel` (вибір позначки).
- Верхній екран: `level-number` (поточний рівень), `score` «coins collected in current game», загальні монети (?).
- `help-window`: пояснення правил і прийомів (вбудований туторіал при першому вході (?)).
- `confirm-dialog`: «Quit?» з попередженням про рівень; повідомлення «Received N coins!», «Advanced to Game Lv. N!» / «Dropped to Game Lv. N.».
- Переходи: game-screen → (Вольторб / всі 2 і 3 / quit) повідомлення → нова роздача на новому рівні.

## Фічі поза полем
- Адаптивна складність: рівень гри росте з перемогами й падає з ранніми поразками.
- `cash-out` — вихід з поточним виграшем як ставка-ризик.
- Монети йдуть у Game Corner (призи — TM, покемони).
- Заміна слот-машин в міжнародних версіях HGSS (японські зберегли слоти).

## Варіації й родичі
- Сапер (бомби + дедукція), нонограма/Picross (лінійні підказки), Sumplete, Kakuro (суми по лініях), Hexcells (лінійні суми).
- Фан-клони і солвери в браузері (ймовірність Вольторба на кожну картку).
- Осі варіацій: **підказка** — сума і кількість бомб на лінію / кількість сусідів; **рахунок** — добуток / сума / без рахунку; **помилка** — втрата раунду / HP / смерть; **рівень** — фіксований / адаптивний з падінням.

## Цікавинки для курсу
- Лінійні підказки (сума + кількість бомб) на 5×5 — 🌱 генерація, 📎 перевірка.
- Добуток як рахунок і «одиниці не важливі» — 🌱.
- Адаптивний рівень з падінням до кількості перевернутих — 🌱.
- Memo з множиною кандидатів на картку — 📎 (`pencil-marks`).
- Ймовірнісний солвер: перебір усіх розкладок рядків/стовпців, імовірність Вольторба на картку, порада «найбезпечніша корисна картка» — 🥈.
- Генерація за таблицею рівнів (кількість 2/3/Вольторбів) — 🌱 після того, як є таблиця.

## Пропозиції до словників
- `+cond:all_kind_revealed` — усі сутності виду відкриті (2 і 3); `all_gone` не підходить, бо картки лишаються.
- `+effect:multiply_score` — помножити рахунок раунду (`multiplier` — це множник подальших очок, не те).
- `+effect:level_set` — встановити рівень гри у значення (падіння до кількості перевернутих).
- `+ui:line-clue` — підказка за краєм поля (див. Hexcells); `+ui:memo-panel` — панель вибору позначки.
- `+feature:cash-out` — вийти зі ставкою; `+feature:adaptive-level` — рівень складності слідкує за результатами.

# 14 Minesweeper Variants — сапер, у якого змінюються правила: 7 правил розстановки мін і 7 правил підказок

## Суть
Кожен пазл — маленьке поле (5×5…8×8) сапера без вгадувань, але з активним **правилом-модифікатором**: або воно обмежує, як лежать міни (усі міни звʼязні, у кожному 2×2 є міна…), або змінює зміст числа (бреше на 1, рахує хрестом, рахує довжини серій…). Гравець позначає клітини як міну/безпечну, відкриваючи нові числа, доки поле не розвʼязано. Гра — «каталог осей варіації» сапера: те саме ядро, 14 різних логік.

## Поле і час
- Квадратне поле від 5×5 до 8×8 (розмір росте зі складністю); загальна кількість мін відома (фан-вікі: використовується в дедукції), показ на екрані — (?).
- Частина клітин може бути **кольоровою** (для правил M і N); решта — звичайні.
- Статичний пазл без таймера-тиску; генерується процедурно, кожен розвʼязний логікою.
- Шари: прихований вміст (міна / безпечна з підказкою) + розмітка гравця + нотатки малювання.

## Правила (КОЛИ → ЯКЩО → ТО)
- Базове (V, Vanilla): число = кількість мін серед 8 сусідів; загальна кількість мін задана.
- КОЛИ `input(mark_mine|mark_safe, c)` → ЯКЩО `custom: «відповідає розвʼязку»` → ТО `mark(c)`; безпечна → `reveal(c)` з підказкою за активним правилом; інакше `custom: «помилка»` (?).
- КОЛИ `all_constraints_met` → ТО `win`, наступний пазл / рівень.
- Ліві правила — **обмеження розстановки мін** (`constraint_broken` для розвʼязку):
  - **Q — Quad**: у кожному квадраті 2×2 є щонайменше одна міна.
  - **C — Connected**: усі міни звʼязні по 8 напрямках.
  - **T — Triplet**: жодних трьох мін поспіль по горизонталі, вертикалі чи діагоналі.
  - **O — Outside**: безпечні клітини звʼязні по 4 напрямках, а кожна міна звʼязана по 4 напрямках з краєм поля.
  - **D — Dual**: міни утворюють доміно 1×2 / 2×1, і доміно не торкаються одне одного.
  - **S — Snake**: міни утворюють одну «змійку» (шлях), тіло якої не торкається саме себе ортогонально.
  - **B — Balance**: у кожному рядку й стовпці однакова кількість мін.
- Праві правила — **зміст підказки**:
  - **M — Multiple**: міна в кольоровій клітині рахується в підказках за дві (загальна кількість мін не змінюється).
  - **L — Liar**: кожна підказка хибить рівно на 1 (на 1 більше або на 1 менше за правду).
  - **W — Wall**: підказка дає довжини серій мін підряд серед 8 сусідів (як у нонограмі, кілька чисел).
  - **N — Negation**: підказка = різниця між мінами в кольорових і некольорових сусідніх клітинах.
  - **X — Cross**: підказка рахує міни в хресті на 2 клітини в кожен бік (не в 3×3).
  - **P — Partition**: підказка = кількість окремих звʼязних груп мін серед 8 сусідів.
  - **E — Eyesight**: підказка = кількість безпечних клітин, видимих у 4 напрямках, включно з собою; міни перекривають огляд.
- Перемога: поле повністю визначене. · Поразка: нема (?) — лише лічильник помилок/відмова ходу. · Рахунок: нема; прогрес — розвʼязані рівні та досягнення.

## Керування і ввід
- Мишею: одна кнопка позначає міну, інша — безпечну клітину (?).
- Інструменти малювання для нотаток (лінії/позначки поверх поля) — замінник pencil marks.
- Кнопка підказки: показує, **куди дивитися** (область/клітини), але не дає відповіді.

## Фічі поза полем

- Комбінації двох правил (C+D, C+Q, Q+T, L+M, M+X, N+X…) — пазли поверх основних 14 (фан-вікі); сайт автора гайду ділить на «Main (14)», «Extra (+')», «Gallery (+)».

## Варіації й родичі
- Саме по собі — **каталог осей** сапера:
  - вісь «форма множини мін»: вільна / звʼязна (C) / доміно (D) / змійка (S) / звʼязна з краєм (O);
  - вісь «локальна щільність»: ≥1 у 2×2 (Q) / ≤2 поспіль (T) / рівно в рядках (B);
  - вісь «окіл підказки»: 3×3 / хрест радіуса 2 (X) / промені до міни (E);
  - вісь «функція по околу»: кількість / зважена сума (M) / різниця кольорів (N) / кількість груп (P) / довжини серій (W) / зашумлене ±1 (L).
- Родичі: Hexcells (лінійні підказки, {n}/-n-), Tametsi (граф клітин), Bombe (гравець пише правила виведення), Sudoku-варіанти (той самий принцип «одне правило змінює логіку»), Nikoli-пазли Statue Park / Nurikabe (звʼязність як обмеження).

## Цікавинки для курсу
- Правило як **плагін**: одна функція `clue(cell, board)` і один `check(board)` на варіант — архітектура «стратегія» — 🥉.
- Перевірки форми множини мін (звʼязність C/O через BFS, доміно D, змійка S) — 📎 кожна, разом 🥈.
- Підказки P (кількість груп серед 8 сусідів, кільцева звʼязність) і W (серії по кільцю) — 📎.
- L (брехун ±1): розвʼязок через перебір двох гіпотез на клітину — 🥉.
- Генератор без вгадувань під довільне правило (пошук розвʼязку SAT/перебором малої дошки 8×8, перевірка єдиності) — 🥇.
- Підказка «куди дивитися» (знайти мінімальну множину підказок, що форсує клітину) — 🥇.

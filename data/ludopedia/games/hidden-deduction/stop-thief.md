# Stop Thief — невидимий злодій ходить кварталом, а електронний сканер лише звуком каже, на яку клітину він ступив: підлога, двері, вікно, вулиця чи новий злочин

## Суть
Детективи (2–4 гравці) ганяються по сітчастому плану кварталу за злодієм, якого немає на дошці: його веде електронний Crime Scanner (з 2017 — застосунок). Щоходу сканер програє звук дії злодія — кроки в будівлі, скрип дверей, бите скло вікна, біг вулицею, тривога нового злочину — і гравці з типу клітини та сусідства виводять, де він. Хто стоїть на клітині злодія або поруч, може ввести її трицифровий код і спробувати арешт; правильний — нагорода, хибний — штраф. Перший, хто збере потрібну суму, виграє.

## Поле і час
- План кварталу — квадратна сітка: 4 пронумеровані будівлі (Furs 1, Jewelry 2, Antiques 3, Bank 4) і 4 вулиці (5–8), 5 станцій метро; стіни непрохідні.
- Кожна клітина злодія має код з 3 цифр: цифра будівлі/вулиці + двоцифровий номер клітини (напр. 333); у версії 2017 є ще ненумеровані кружки лише для детективів.
- Типи клітин злодія: підлога, двері, вікно, вулиця, місце злочину, газетний кіоск (червона клітина на вулиці), метро.
- Хід гравця = (кнопка Clue → злодій робить одну дію) + рух детектива; злодій ходить лише тоді, коли просять підказку.
- Видно все, крім злодія; уся інформація — звук і коротка індикація.

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `game_start` → ТО `sound(alarm)`, `message(будівля злочину)` — злодій стартує на місці злочину.
- КОЛИ `input(clue)` → ТО `custom: «злодій робить одну приховану дію»`, `sound(тип клітини)`; оригінал також показує будівлю/вулицю й код дії (Cr, Fl, dr, GL, St).
- Рух злодія: `custom: «випадково на сусідню нумеровану клітину, крім щойно покинутої; може стояти (окремий звук)»`.
- КОЛИ `enter(thief, door|window)` → ТО `custom: «наступна дія — пройти крізь»`.
- КОЛИ `enter(thief, crime_scene)` → ТО `sound(alarm)`, `set_cell(crime_scene, floor)`, `custom: «+$100 до нагороди (2017 — +$1,000 Crime Spree)»`.
- КОЛИ `enter(thief, newsstand)` → ТО `sound(alarm)`, `set_cell(newsstand, street)` до арешту.
- КОЛИ `input(roll)` → ТО `custom: «кинути 2 кубики»`, `move(detective, dir)` на ≤ кидка в 8 напрямках (можна менше).
- КОЛИ `enter(detective, subway)` → ТО `teleport(detective, any_subway)`, `end_turn` (решта кроків пропадає).
- КОЛИ `input(move, detective)` → ЯКЩО `cell(next, wall|window)` → ТО `block`.
- КОЛИ `input(sleuth_card)` → ЯКЩО `custom: «≤1 картка за хід»` → ТО ефект картки (`take(other, money)` / `skip_turn(other)` / зайві Clue / Tip / рух); картка — під низ колоди, добрати нову.
- КОЛИ `input(tip)` → ТО `reveal(thief)` — точний код клітини.
- КОЛИ `input(arrest, code)` → ЯКЩО `custom: «детектив на цій клітині або поруч»` і `custom: «код = позиція злодія»` → ТО `currency(+reward)`, `custom: «новий Wanted Poster; оригінал — усі фішки до агенції, 2017 — лишаються»`.
- … ЯКЩО код правильний, але `custom: «злодій вислизнув»` → ТО `sound(taunt)`, `custom: «5–6 швидких дій злодія, можливо з новими злочинами й метро»` (оригінал).
- … ЯКЩО код хибний → ТО оригінал: `custom: «втрата ліцензії; наступного ходу заплатити $100 замість дій»`; 2017: `currency(-1000)` і хід далі.
- КОЛИ `input(replay, n)` → ТО `sound(n-та з останніх 10 дій)` — без штрафу.
- КОЛИ `counter(money, >=, target)` → ТО `win` (оригінал — $2,500; 2017 — $45,000 / $35,000 / $25,000 для 2 / 3 / 4 гравців).
- Перемога: перший до цільової суми · Поразки нема · Рахунок: гроші — нагороди за арешти мінус штрафи й крадіжки картками.

## Керування і ввід
- Оригінал: Crime Scanner з LED-дисплеєм і кнопками 0–9, T (Tip), A (Arrest), C (Clue); арешт — A + 3 цифри коду; цифрові кнопки — повтор останніх 10 дій.
- Хід: натиснути Clue → послухати → кинути кубики → пересунути фішку → (картка) → (арешт).
- 2017: застосунок програє звук публічно, кнопка повтору; арешт — ввести номер клітини в застосунку; рух — картка з руки (значення = кроки), картки лишаються на столі, доки ефект не поверне руку.
- Черга — за годинниковою стрілкою; уся дедукція — на памʼяті й дошці (без нотаток у правилах).

## Вікна, меню, HUD
- `game-screen` (Crime Scanner): номер будівлі/вулиці + двобуквений код дії; звуки; клавіатура 0–9, T, A, C.
- `game-screen` (застосунок 2017): кнопка Clue / повтор звуку, поточна картка злодія, введення арешту.
- `mode-select` (застосунок 2017): список режимів гри, що поповнюється оновленнями.
- `arrest-entry` (цифрова версія): введення коду клітини, відповідь «арешт / втеча / хибний».
- Поза пристроєм: Wanted Poster / картка злодія з нагородою, ліцензії, гроші банку.
- Переходи: старт → цикл ходів → арешт → новий злодій → … → гравець із цільовою сумою.

## Фічі поза полем
- `hotseat`/`local-multiplayer` 2–4 (2017 — до 6 детективів (?)); банкір серед гравців (оригінал).
- `replay`-подібне: повтор останніх 10 дій злодія без штрафу.
- 2017: застосунок замість електроніки, колода злодіїв з власними ефектами (напр. Selina Kane: +$2,000 за кожне вікно), режими через оновлення застосунку.

## Варіації й родичі
- Stop Thief! (Restoration Games, 2017): застосунок замість сканера; картки руху замість кубиків; гроші ×10; Crime Spree +$1,000; хибний арешт −$1,000; злодій не їздить метро; фішки лишаються на місцях після арешту; звуки «hubbub» для вулиці, «muffled speaker» для метро, «hold music» — стоїть.
- [Scotland Yard](scotland-yard.md), [Fury of Dracula](fury-of-dracula.md) — прихований рух, але ворога веде людина й видно лише тип транспорту / слід; [Cluedo](cluedo.md) — дедуктивний детектив з кубиками; [Hunt the Wumpus](hunt-the-wumpus.md) — чутливі підказки від сусідніх клітин.
- **Осі варіацій**: хто веде втікача «машина / людина»; підказка «тип клітини звуком / тип транспорту / точне місце за розкладом»; ціна помилкового звинувачення «штраф / втрата ходу / вибування»; рух детективів «кубики / картки / фіксований».

## Цікавинки для курсу
- Злодій як випадкове блукання по графу нумерованих клітин з забороною розвороту й «двері/вікно — крізь» — 📎.
- Звукова підказка = тип клітини: множина можливих позицій як фільтр (сусіди × тип) — 🥈.
- Арешт за кодом клітини + перевірка «поруч» + три результати (арешт / втеча / хибний) — 🌱.
- Втеча: серія 5–6 прихованих дій з новими злочинами — 📎.
- Повтор останніх 10 дій (кільцевий буфер історії) — 🌱.
- Метро як телепорт між станціями з кінцем ходу — 🌱.
- AI-детектив, що ходить до центру множини можливих позицій злодія — 🥇.

## Непевне
- (?) Що вирішує між «арештом» і «втечею» при правильному коді в оригіналі — Wikipedia не каже (вірогідно, випадковість сканера).
- (?) Рух детектива: сума двох кубиків чи інше — Wikipedia каже лише «кидає кубики й рухається».
- (?) Значення карток руху 2017 і пороги для 5–6 гравців — у джерелах нема; кількість детективів 2017 — 6 фішок, але гравців до 4 у таблиці порогів.
- (?) Розмір сітки плану й кількість клітин — не знайдено.
- (?) Чи сканер показує номер будівлі на кожну дію (Wikipedia: «показує будівлю або вулицю»), чи лише на Tip — розбіжність у формулюваннях.

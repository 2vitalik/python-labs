# Tametsi — сапер без вгадувань на довільних розбиттях: сусідні числа + лічильники рядків/стовпців + лічильники мін за кольором

## Суть
Гравець шукає всі міни на полі з плиток, які не обовʼязково квадратні: восьмикутники, мозаїки, довільні фігури, де «сусід» — це ребро графа. Відкрита безпечна плитка показує, скільки мін серед її сусідів; поза полем стоять підказки «скільки мін у цьому рядку/стовпці»; а плитки розфарбовані групами, і для кожного кольору відомо, скільки мін у ньому всього. Пазли ручні, кожен розвʼязний чистою логікою — часто довгим ланцюгом «від супротивного». Гра — чистий пазл: без сюжету, музики й таймера.

## Поле і час
- Поле — граф: плитки довільної форми (квадрати, восьмикутники, «all sorts of tessellations»), суміжність задає рівень; UI показує, що з чим зʼєднано.
- Три рівні інформації (Electron Dance): **локальна** — число сусідніх мін; **агрегатна** — кількість мін на зрізі поля (рядок/стовпець, підказка за краєм); **глобальна** — загальна кількість мін, розбита за кольорами груп.
- Кожен рівень вмикає свою комбінацію типів підказок; часто для старту досить двох із трьох (Buried Treasure).
- Статичний пазл: нічого не відбувається без кліку; таймера нема.
- Шари: прихований стан (міна / безпечна) + колір групи + відкрите число + малюнки гравця поверх.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Закрита плитка | static | форма, колір групи, сусіди | відкривається як безпечна з числом або позначається міною |
| Безпечна відкрита плитка | mark | n = міни серед сусідів | підказка; з опцією auto count-down число зменшується на позначені сусідні міни |
| Плитка без числа (?) | mark | — | відкрита, але без підказки (?) |
| Міна | hazard | колір групи | ціль: позначити всі |
| Позначена міна | mark | — | ставиться ПКМ; входить у лічильники |
| Колірна група | zone | колір, n мін | усі плитки одного кольору; відомо, скільки мін у групі |
| Підказка рядка/стовпця | zone | n | кількість мін (виділених) у рядку/стовпці поза полем |
| Малюнок гравця | mark | колір, товщина пензля | нотатка поверх поля, на гру не впливає |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(open, c)` → ЯКЩО `not occupied(c, mine)` → ТО `reveal(c)` з числом `adjacent_count(c, mine, ==, n)` по ребрах графа.
- КОЛИ `input(open, c)` → ЯКЩО `occupied(c, mine)` → ТО `custom: «помилка: міну показано»` — гра відкриває інформацію замість поразки (?).
- КОЛИ `input(flag, c)` → ЯКЩО `occupied(c, mine)` → ТО `mark(c, mine)`; хибна позначка — `custom: «помилка»` (?).
- Підказка рядка/стовпця: `custom: «кількість мін на лінії = n»` (лінія — ряд плиток, позначений за краєм поля).
- Колірна група: `custom: «сума мін серед плиток одного кольору = n»` — та сама перевірка, що й `count`, але над зоною-групою.
- КОЛИ `after(mark)` → ЯКЩО `mode(auto-countdown)` → ТО `custom: «числа сусідів і лічильники зменшуються на 1»`.
- КОЛИ `all_constraints_met` → ТО `win`, наступний рівень `unlock(next)`.
- Гарантія дизайну: у кожному стані є плитка, яку можна вивести логікою; вгадування не потрібне.
- Перемога: усі міни позначені, усі безпечні відкриті. · Поразка: нема (?). · Рахунок: нема; є «пройдено» на рівні (?).

## Керування і ввід
- Ліва кнопка — відкрити плитку як безпечну; права — позначити міною (Critical Play).
- Наведення — підсвітка сусідів плитки / ліній підказки (UI «shows what's connected»).
- Інструмент малювання: вільний колір і товщина пензля, малювати по полю для гіпотез (нотатки на кшталт «1/n»); на логіку гри не впливає.
- Кожен клік — короткий звук.

## Вікна, меню, HUD
- `game-screen`: поле-граф, підказки рядків/стовпців за краєм, `color-group-counters` (міни за кольором), `remaining-counter` загальний (?), `draw-overlay`.
- `puzzle-select`: сітка рівнів; розвʼязаний відкриває наступний; 60 бонусних — окремий набір, що відмикається.
- `settings-window` / лаунчер: опція auto count-down (зменшення чисел при позначенні мін).
- `end-screen` рівня — мінімальний, перехід до наступного (?).
- Переходи: `puzzle-select` → `game-screen` → (розвʼязано) → `puzzle-select` з новим відкритим рівнем.

## Фічі поза полем
- `puzzle-bank`: 100 ручних рівнів зі зростаючою складністю + 60 бонусних, важчих (Buried Treasure рахує 101 основний).
- `level-unlock`: розвʼязок рівня відкриває наступний.
- `autosave`: прогрес усередині рівня зберігається автоматично.
- `auto-countdown` — опція лаунчера.
- Steam Achievements, Steam Cloud; музики нема (свідомо).

## Цікавинки для курсу
- Поле як граф (плитки-вершини, суміжність-ребра) замість масиву; рендер довільних полігонів і hit-test кліку — 🥉.
- Три типи обмежень над однією множиною клітин (сусіди / лінія / колір) — уніфікація як «множина клітин + кількість» — 📎.
- Солвер: множини-обмеження, віднімання підмножин, перебір до суперечності; перевірка «без вгадувань» — 🥇.
- Auto count-down: число показує «лишилось мін серед сусідів» — 🌱.
- Вільне малювання поверх поля (шар нотаток із кольором/пензлем) — 📎.
- Формат рівня з довільною геометрією й групами — 🥉.

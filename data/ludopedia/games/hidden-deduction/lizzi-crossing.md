# Lizzi Crossing — сапер з героєм: іди по полю, читаючи числа сапера й нонограмні підказки, і знайди сходи вниз

## Суть
Героїня Lizzi стоїть на згенерованому полі з прихованими мінами; ходиш нею по клітинах, і кожен крок відкриває клітину під ногами. Два види підказок: числа сапера (міни серед 8 сусідів) і нонограмні числа зверху та зліва — довжини груп мін у рядку/стовпці. Мета поверху — дійти до виходу, не наступивши на міну; прапорець «!» не пускає героїню на клітину. Клас `hybrid`: аватар (avatar) + дедукція пазла (puzzle).

## Поле і час
- Квадратна сітка-поверх; підказки нонограми — над стовпцями і ліворуч від рядків.
- Покроковий рух (хід = крок героїні); таймера нема (?).
- Шари: прихований вміст (міна / безпечна) + відкриті числа (трава = 0, лише візуально різна) + прапорці + вихід.
- Поверхи генеруються випадково; з 1.0.11 стартова зона навколо героїні відкривається сама.

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(move, dir)` → ЯКЩО `state(target, flag_!)` → ТО `block`; інакше `move(lizzi, dir)`.
- КОЛИ `enter(lizzi, hidden)` → ЯКЩО `occupied(cell, mine)` → ТО `lives(-1)` (одна міна шкодить лише раз, фікс 1.0.7); інакше `reveal(cell)` з числом.
- Число сапера: `adjacent_count(cell, mine, ==, n)` за 8 сусідами.
- Підказка лінії: `run_lengths(row|col)` — групи мін у рядку/стовпці.
- КОЛИ `input(right, c)` → ЯКЩО `not state(c, revealed)` → ТО `mark(c, !)` → `mark(c, ?)` → `unmark(c)` по колу (?); клавіші 1 / 2 ставлять «!» / «?» напряму.
- КОЛИ `enter(lizzi, exit)` → ТО `next_level` (новий згенерований поверх).
- КОЛИ `counter(lives, ==, 0)` → ТО `custom: «серія переривається, починається новий поверх»` (?).
- КОЛИ `counter(floors_in_row, %2==0)` → ТО `counter(sparkles, +1)`; кожні 10 поверхів підряд — ще `+1`.
- КОЛИ `level_start` → ТО `reveal(зона навколо старту)` (1.0.11).
- Перемога: нема фінальної — нескінченні поверхи. · Поразка: втрата всіх життів (?). · Рахунок: блискітки (зберігаються між сесіями).
- Генератор не гарантує розвʼязності без вгадувань («not intentional … the generator isn't perfect»).

## Керування і ввід
- WASD / стрілки — крок; ліва кнопка миші — рух (клік по клітині (?)).
- Права кнопка — поставити прапорець на закриту клітину або перемкнути тип; 1 — «!», 2 — «?» (з 1.0.10; перепризначувані).
- Звуку нема.

## Вікна, меню, HUD
- `game-screen`: поле, нонограмні числа на кольоровому тлі (відрізняються від чисел сапера, 1.0.1), життя, іконка блискіток з рахунком.
- `settings-window` (з 1.0.4): high-contrast палітра, масштаб під екран, перепризначення клавіш руху й прапорців, скидання; налаштування запамʼятовуються (1.0.5).
- HUD: `lives`, `tooltip` для іконок (1.0.11), лічильник блискіток.
- Переходи: поверх → сходи → наступний поверх; меню й кінцевий екран — (?).

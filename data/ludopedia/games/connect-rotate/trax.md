# Trax — двоколірні плитки-колії без дошки; вимушені ходи каскадом, перемога — своя петля або лінія на 8

## Суть
Двоє гравців по черзі кладуть однакові двосторонні плитки на безмежну площину; на кожній плитці — відрізок білої і відрізок червоної колії (?), і кольори на стиках мусять збігатися. Кожен грає за свій колір і хоче замкнути петлю свого кольору або протягти свою лінію через 8 рядів/стовпців. Ядро — **правило вимушеного ходу**: коли порожня клітина має два входи одного кольору, туди можна покласти лише одну плитку, і той самий гравець мусить її покласти; це породжує ланцюг вимушених ходів, через який один хід може змінити пів поля. Плитки спільні — кожна колія належить обом гравцям одночасно.

## Поле і час
- Дошки нема: поле — необмежена квадратна сітка, що росте від першої плитки; координати рахуються відносно лівого верхнього кута зайнятої області (зсуваються, коли гра росте вліво/вгору).
- Варіант «Limited Tiles» (оригінальний): поле обмежене 8×8 (64 плитки в наборі); Mini Trax — 3×3; SuperTrax — без ліміту (домінує в онлайн-грі).
- Хід = одна вільна плитка + усі вимушені, що з неї випливають. Час не обмежений.
- Кожне ребро клітини має рівно один колір (бо кожен бік плитки — кінець однієї колії), тож порожня клітина «знає» кольори входів від сусідів.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Плитка «хрест» (straight) | tile | сторона А; 2 орієнтації | дві прямі колії різних кольорів перетинаються (одна над одною), не зʼєднуючись |
| Плитка «криві» (curve) | tile | сторона Б; 4 орієнтації | дві дуги різних кольорів, кожна зʼєднує сусідні сторони, у протилежних кутах |
| Запас плиток | supply (custom) | 64 у наборі / ∞ | спільний для обох; плитки ідентичні |
| Порожня клітина-кандидат | static | кольори входів 1–4 | легальна, якщо торкається плитки; вимушена, якщо ≥2 входи одного кольору |
| Колія кольору c | mark | колір, звʼязний шлях | належить гравцю кольору c; петля або проліт ≥8 — перемога |
| Гравець | — | колір: білий / червоний (?) | білий ходить першим |

## Правила (КОЛИ → ЯКЩО → ТО)
- Перший хід: КОЛИ `turn_start(white)` і поле порожнє → ТО `place(curve|cross)` — фіксує орієнтацію поля.
- КОЛИ `input(place, cell, tile, orient)` → ЯКЩО `custom: «клітина торкається наявної плитки»` and `custom: «кольори всіх стиків збігаються»` → ТО `place`; інакше `block`.
- КОЛИ `after(place)` → ЯКЩО `edge_colors(cell, c, ==2)` для порожньої сусідньої клітини → ТО `forced_place(cell)` тим самим гравцем (плитка визначена однозначно: зʼєднує два входи кольору c).
- КОЛИ `after(forced_place)` → ТО перевірити сусідів знову (каскад) — `custom: «повторювати, доки всі порожні клітини мають ≤1 вхід або 2 входи різних кольорів»`.
- КОЛИ `after(place|forced_place)` → ЯКЩО `edge_colors(cell, c, ==3)` для будь-якої порожньої клітини → ТО `custom: «хід нелегальний»`, `replay_turn` (увесь хід переграється з першої плитки).
- КОЛИ `turn_end` → ЯКЩО `pattern(loop_closed, c)` → ТО `win(c)`.
- КОЛИ `turn_end` → ЯКЩО `pattern(span(8), c)` — колія кольору c тягнеться від краю до протилежного краю через ≥8 рядів або стовпців → ТО `win(c)`.
- КОЛИ `turn_end` → ЯКЩО обидва кольори мають перемогу в одному ході (включно з вимушеними) → ТО `win(той, хто ходив)`.
- Limited Tiles: КОЛИ `custom: «плитка виходить за 8×8»` → ТО `block`.
- Loop Trax: перемагає лише петля; лінія не рахується.
- Перемога: петля або лінія свого кольору · Поразка: суперник раніше · Нічия: на практиці майже неможлива (?) · Рахунку нема.

## Керування і ввід
- Фізично: взяти плитку, обрати сторону (хрест/криві) й поворот, прикласти до краю поля.
- Цифрова версія: клік по клітині-кандидату → вибір одного з (≤6) варіантів плитки, що пасують за кольорами; вимушені плитки ставляться автоматично з анімацією каскаду.
- Нотація: стовпці `@, A, B … Z, AA …`, рядки `0, 1, 2 …` згори; хід — 3 символи: стовпець, рядок, тип (`+` хрест, `/` або `\` крива); орієнтація й вимушені плитки не записуються — вони виводяться.

## Варіації й родичі
- Варіанти: Loop Trax (лише петлі), 8×8 Limited Tiles, Mini Trax 3×3, SuperTrax (безмежне поле).
- Предок — Chess Cards того ж автора (David Smith, Нова Зеландія, 1980); правило вимушеного ходу додане, бо без нього гра «застрягала».
- Родичі: Tantrix (гекс-плитки з трьома кольоровими кривими), Psyche-Paths/Kaliko (1970, гекс-serpentiles), Tsuro (плитки-шляхи, але фішки їздять), Hex/Bridg-It (зʼєднати протилежні краї).
- Осі варіацій: **поле: обмежене / росте** · **мета: петля / лінія / обидві** · **хто кладе вимушені: той самий / суперник / автомат** · **плитка: 2 кольори на квадраті / 3 на гексі (Tantrix)**.

- Виявлення замкненої петлі кольору (обхід колії по стиках плиток) — 📎.
- Перевірка «лінія через 8 рядів/стовпців» (габарити звʼязної колії) — 🥉.
- Поле, що росте в усі боки, зі зсувом початку координат (словник `(x, y) → плитка` замість масиву) — 🥉.
- Нотація ходів із виведенням орієнтації та вимушених плиток — 🥈.
- AI на minimax для Trax — 🥇 (велике розгалуження, каскад ускладнює оцінку).

## Пропозиції до словників
- `+role:supply` — спільний запас плиток поза полем (вже ×3 у корпусі).
- `+trigger:pattern(loop_closed)` ⏳ підтверджується; `+trigger:pattern(span(n))` — нове значення шаблону: звʼязний обʼєкт перетнув N рядів/стовпців від краю до краю.
- `+trigger:after` ⏳ — каскад: вимушена плитка після будь-якої іншої.
- `+cond:edge_colors(cell, color, n)` — порожня клітина має N входів кольору c (2 → вимушений, 3 → нелегально).
- `+effect:place` ⏳ (×10 у корпусі) — покласти плитку з запасу; `+effect:forced_place` — автоматично визначене розміщення в межах того самого ходу; `+effect:replay_turn` — скасувати весь хід і переграти.
- `+ui:tile-orientation-picker` — вибір сторони/повороту плитки біля курсора.
- `+feature:move-notation` — текстовий запис ходів, з якого стан відновлюється.

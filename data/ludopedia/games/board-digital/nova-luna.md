# Nova Luna — плитка коштує час, ціль на плитці виконують ланцюги кольорів довкола неї; хто першим накрив усі диски — переміг

## Суть
Кожен гравець викладає власну розкладку з квадратних плиток чотирьох кольорів. Плитку беруть з колеса місяця — одну з трьох наступних за маркером, — і вона коштує час на треку: ходить той, хто найдальше позаду (система Patchwork). На плитці — до трьох цілей у вигляді кольорових точок; ціль виконана, коли навколо плитки стоять потрібні кольори, причому сусід **тягне за собою весь одноколірний ланцюг**. Виконану ціль накривають своїм диском; хто першим накрив усі 20 — переміг.

## Поле і час
- Особисте поле без меж: перша плитка будь-де, кожна наступна — ортогонально до вже покладеної; діагональ не рахується ні для розміщення, ні для цілей.
- Спільне колесо місяця: 12 гнізд по колу — маркер-місяць і 11 відкритих плиток; решта плиток — закриті стоси добору.
- Трек місяця навколо колеса: на ньому по одному диску кожного гравця; диски, що стали на одну клітину, складаються в стос.
- Хід не чергується: ходить найзадніший диск, при рівності — верхній у стосі. Плитка негайно кладеться — відкласти не можна.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Плитка | tile | колір (синій / червоний / бірюзовий / жовтий); вартість часу 1–7; 0–3 цілі | береться з колеса, кладеться ортогонально до своєї розкладки |
| Ціль на плитці | mark | 1–4 кольорові точки (кольори й кількості, без розташування) | перевіряється за ланцюгами сусідів; виконана → диск |
| Колесо місяця | supply | 12 гнізд: маркер + 11 плиток | вікно з 3 наступних за годинниковою стрілкою, порожні гнізда пропускаються |
| Маркер (місяць) | object | гніздо на колесі | переходить у гніздо взятої плитки |
| Трек місяця | zone | клітини навколо колеса | черга ходів |
| Диск на треку | piece | 1 на гравця | рухається на вартість плитки; на зайнятій клітині — згори стосу |
| Диски-цілі | resource | 20 на гравця (21 − 1 на треку); для новачків 17 / 15 | накривають виконані цілі |
| Розкладка гравця | zone | без меж | плитки не перекриваються |
| Стоси добору | supply | закриті | поповнюють колесо |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `turn_start` → ТО ходить гравець, чий диск на треку найдальше позаду; ЯКЩО `custom: «кілька дисків на одній клітині»` → ТО `custom: «ходить верхній у стосі»`.
- КОЛИ `turn_start(side)` → ЯКЩО `count(tile_on_wheel, <=, 2)` і `count(tile_on_wheel, >=, 1)` → ТО `choose(refill | skip)`; поповнення — від гнізда біля маркера за годинниковою стрілкою.
- КОЛИ `turn_start(side)` → ЯКЩО `count(tile_on_wheel, ==, 0)` → ТО `custom: «обовʼязково заповнити всі порожні гнізда; стоси скінчились — скільки вистачить»`.
- КОЛИ `input(take(tile))` → ЯКЩО `custom: «плитка — одна з 3 наступних за маркером, порожні гнізда не рахуються»` → ТО `move(marker, tile_slot)`, `move(disc, +tile.cost)`; інакше `block`. Пропустити вибір не можна.
- КОЛИ `enter(disc, track_cell)` → ЯКЩО `occupied(track_cell, disc)` → ТО `custom: «покласти диск згори стосу»`.
- КОЛИ `input(place(tile, cell))` → ЯКЩО `free(cell)` і `adjacent_count(cell, tile, >=, 1)` (лише ортогонально; перша плитка — будь-де) → ТО `place(tile, cell)`; інакше `block`.
- КОЛИ `after(place)` → ТО для кожної ненакритої цілі розкладки (не лише на новій плитці): ЯКЩО `custom: «для кожного кольору цілі — кількість плиток цього кольору в ортогональних одноколірних ланцюгах, що мають хоч одну плитку поруч із плиткою-ціллю, не менша за потрібну»` (`+cond:chain_count`) → ТО `mark(goal, disc)`, `counter(discs, -1)`.
- Колір самої плитки-цілі для її цілей не рахується ніколи; діагональні плитки не рахуються; одна плитка може служити багатьом цілям.
- КОЛИ `counter(discs, ==, 0)` → ТО `win`, `game_over`.
- КОЛИ `custom: «гравець не може взяти плитку — усі вибрано»` → ТО `game_over`; виграє той, у кого лишилось найменше дисків.
- Тай-брейк: з рівною кількістю дисків виграє той, хто ходив би наступним.
- Варіант для новачків: КОЛИ `level_start` → ЯКЩО `mode(beginner)` → ТО `custom: «18 дисків на 3 гравців, 16 на 4 (17 / 15 для цілей)»`.
- Перемога: перший, хто накрив усі диски-цілі · Поразка: — · Рахунок: очок нема, лише лічильник дисків.

## Керування і ввід
- Настільна: на початку ходу — вирішити, чи поповнювати колесо (коли там 1–2 плитки); взяти одну з трьох; посунути диск; прикласти плитку; накрити виконані цілі.
- (цифрова версія) Клік по одній із 3 підсвічених плиток колеса → drag на розкладку з підсвіткою вільних ортогональних клітин; цілі, що виконаються, підсвічуються ще до розміщення; диск на треку рухається сам.
- Кнопка «Поповнити колесо» активна лише при 1–2 плитках; при 0 — поповнення автоматичне.

## Вікна, меню, HUD
(цифрова версія)

- `match-setup`: 1–4 гравці, варіант для новачків (кількість дисків).

- `tooltip` над ціллю: які кольори ще бракує і скільки.

- `help-window`: як рахуються ланцюги (картинка з прикладом).
- Переходи: main-menu → match-setup → game-screen → end-screen.

## Фічі поза полем
- `hotseat` 2–4 гравці; соло-режим (DE-вікі: 1–4 гравці; правила соло не відкривав).
- `custom-difficulty` — варіант для новачків зі зменшеною кількістю дисків.
- Нема: збереження, рейтингу (настільна).

## Варіації й родичі
- Походження: Habitats (Corné van Moorsel) → Uwe Rosenberg спростив і додав вибір із Patchwork; рецензенти порівнюють з Sagani (Rosenberg, 2010).
- **Осі варіацій**: черга ходів (по колу / трек часу) · ринок (відкритий / вікно 3 за маркером / драфт) · де мета (спільні цілі / цілі на кожній плитці) · як рахуються сусіди (лише прямі / ланцюги одного кольору) · кінець (раунди / перший, хто виклав усі диски / скінчився запас).
- Родичі: Patchwork (`patchwork.md`, трек часу і кільцевий ринок), Cascadia + Calico (`cascadia-calico.md`, шаблони сусідства), Kingdomino (`kingdomino.md`, звʼязні області одного типу), Qwirkle/Ingenious (`qwirkle-ingenious.md`, рахунок за лініями кольорів).

## Цікавинки для курсу
- Перевірка цілі через ланцюги: для кожного кольору — BFS по одноколірних ортогональних сусідах від клітин поруч із плиткою-ціллю, саму плитку-ціль виключити — 🥉.
- Після кожної плитки перевіряти всі ненакриті цілі розкладки, бо нова плитка може подовжити чужий ланцюг (інкрементально — лише цілі, чиїх ланцюгів торкнулась) — 🥈.
- Трек часу зі стосами: «ходить найзадніший, при рівності — верхній» (стек на клітині) — 📎.
- Колесо з маркером, вікном 3 і правилом «поповнити можна при 1–2, треба при 0» — 📎 (кільцевий масив з пропуском порожніх).
- Кінець при вичерпанні плиток з тай-брейком «хто ходив би наступним» — 🌱.
- AI: вибір плитки за співвідношенням «виконані цілі / витрачений час» з перебором клітин — 🥈.

## Пропозиції до словників
- `+cond:chain_count(goal_tile, color, op, n)` — кількість плиток кольору в одноколірних ланцюгах, що торкаються плитки (без неї самої). Ширше за `adjacent_count`: рахує всю компоненту, а не лише сусідів.
- `+ui:time-track` — трек часу зі стосами фішок (є в Patchwork); `+ui:market-ring` — кільце товарів з маркером і підсвіченим вікном (є в Patchwork).

# Bosk — висадити дерева на перехрестях стежок, а восени вітром рознести листя на регіони парку

## Суть
Гра з двох з'єднаних частин на одному полі. Навесні гравці по черзі ставлять 8 своїх дерев (значення 1–4) на **перехрестя** стежок; улітку кожна стежка-рядок і стежка-стовпець дає очки за більшість (суму значень дерев). Восени дерева по одному «скидають» листя: гравець обирає дерево й плитку 2–8, і листя лягає ланцюжком на **клітини** між стежками в напрямку вітру — кожен наступний листок прямо або по діагоналі вперед. Узимку рахують більшість верхніх листків у 8 регіонах парку. Випадковості нема зовсім.

## Поле і час
- **Подвійна сітка**: стежки утворюють ґрати; дерева стоять на вершинах (перехрестях), листя — на клітинах рельєфу між ними. Деревам заборонені крайові перехрестя, кути й зовнішня межа ігрової зони.
- Дошка двобічна: для 2 гравців — бік з більшими клітинами; для 3 — бік з дрібнішими клітинами в межах світлої рамки; для 4 — увесь цей бік. Розміри сітки — (?).
- 8 регіонів = клітини одного типу рельєфу (колір і фактура); розрізнені клітини одного типу — один регіон; вода — звичайна клітина.
- Час: весна (почергова висадка до 8 дерев у кожного) → літо (підрахунок) → осінь (8 раундів, у кожному кожен гравець скидає листя з одного свого дерева) → зима (підрахунок).
- Купки листя ростуть у висоту; для зими важить лише **верхній** жетон купки.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Перехрестя | zone | не край, не кут, у межах зони | вміщує одне дерево |
| Стежка (рядок / стовпець) | zone | список перехресть | улітку дає очки за більшість суми значень |
| Клітина рельєфу | terrain | тип рельєфу (регіон) | купка листя; верхній жетон або білка = контроль |
| Регіон | zone | 8 типів рельєфу | узимку очки за більшість контрольованих клітин |
| Дерево | piece | значення 1–4, по 2 кожного; 8 на гравця | ставиться навесні; восени — джерело листя, потім знімається |
| Плитка листя | object | 2, 3, 4, 5, 6, 7, 8 + білка (=1); 8 на гравця | одноразова; задає кількість активних листків і чергу ходу |
| Жетон листя | object | 36 на гравця | лягає на клітину шляху; перекриває чужі за плату |
| Білка | piece | 1 на гравця | замість листя: на клітину до 3 кроків уперед; перекриває будь-яку купку; її перекрити не можна |
| Дошка вітру + маркер | switch | 8 позицій: стрілка напряму + значення дерева (раунди 1–4) або «*» (5–8) | після раунду маркер зсувається праворуч → новий напрям і вимога |
| Турист (hiker) | object | — | позначає першого гравця |
| Трек рахунку | mark | маркер-листок на гравця | очки літа + зими |

## Правила (КОЛИ → ЯКЩО → ТО)
- Весна: КОЛИ `input(place_tree, intersection)` → ЯКЩО `free(intersection)` і `custom: «не край, не кут, не за межею ігрової зони»` → ТО `place(player, tree)`; дерево більше не рухається; по колу, доки кожен не поставить 8.
- Літо: КОЛИ `phase_start(summer)` → ТО для кожної стежки: `custom: «сума значень дерев кожного гравця на стежці»` → `custom: «1-ше одноосібно 2, 2-ге одноосібно 1; нічия за 2-ге — по 0; 1-ше без 2-го — 3; нічия за 1-ше — по 1, 2-ге — 0»` (`+effect:score_majority`); дерева лишаються.
- КОЛИ `custom: «літній підрахунок завершено»` (`+trigger:season_change`) → ТО `custom: «першим стає гравець з найменшими очками (нічия — найближчий за годинниковою від попереднього)»`, `give(player, hiker)`.
- КОЛИ `phase_start(autumn)` → ТО `choose(side)` — перший гравець кладе дошку вітру до однієї з 4 сторін поля; це задає початковий напрям і весь візерунок вітру; маркер — на позицію «1».
- КОЛИ `turn_start(player)` → ЯКЩО `counter(round, <=, 4)` → ТО `choose(tree)` з `same(tree.value, wind_spot.value)`; ЯКЩО `counter(round, >=, 5)` → ТО `choose(tree)` будь-яке своє.
- КОЛИ `after(choose)` → ТО `choose(leaf_tile)` → `custom: «взяти з запасу N активних листків, N = значення плитки (не дерева)»`.
- Перший листок: КОЛИ `custom: «скидання почалось»` → ТО `place(player, leaf)` на одну з 2 клітин біля дерева в напрямку вітру.
- Наступні: КОЛИ `after(place)` → ЯКЩО `counter(active_leaves, >, 0)` → ТО `place(player, leaf)` на одну з 3 клітин уперед від попередньої (прямо або по діагоналі за вітром).
- КОЛИ `edge(path)` → ТО `custom: «шлях обривається; поза зону листя не кладуть»`.
- Своє зверху: КОЛИ `enter(leaf, cell)` → ЯКЩО `custom: «верхній жетон — свій»` (`+cond:top_of_stack`) → ТО `place(player, leaf)` без плати.
- Чуже зверху: КОЛИ `enter(leaf, cell)` → ЯКЩО `custom: «верхній жетон — чужий»` → ТО `custom: «повернути в запас по 1 активному листку за кожен жетон купки, потім покласти 1 зверху»`; ЯКЩО `custom: «активних листків не вистачає на плату»` → ТО `block`.
- Білка: КОЛИ `custom: «зіграно плитку-білку»` → ТО `place(player, squirrel)` на клітину до 3 кроків від дерева за правилами шляху; КОЛИ `enter(leaf, cell)` → ЯКЩО `occupied(cell, squirrel)` → ТО `block`.
- КОЛИ `after(place)` (останній листок або білка) → ТО `disappear(tree)`, `custom: «плитка листя — у скид, більше не використовується»`.
- КОЛИ `custom: «усі гравці зіграли в раунді»` (`+trigger:round_end`) → ТО `set_state(wind_marker, next_spot)` (новий напрям і вимога до дерева), `custom: «першим у наступному раунді стає той, хто зіграв найменшу плитку (білка = 1; нічия — найближчий за годинниковою)»`.
- Зима: КОЛИ `phase_start(winter)` → ТО для кожного з 8 регіонів: `custom: «скільки клітин контролює кожен (верхній листок або білка; висота купки не важить)»` → `custom: «1-ше одноосібно 5, 2-ге 3; нічия за 2-ге — по 1; 1-ше без 2-го — 8; нічия за 1-ше — по 4, 2-ге — 0»`.
- Перемога: найбільша сума літа й зими · тай-брейк: найближчий до першого гравця останнього раунду · Поразка: — · Рахунок: більшості на стежках і в регіонах.

## Керування і ввід
- Весна: вибрати вільне перехрестя → поставити дерево (обираєш і значення).
- Осінь: вибрати дерево (за вимогою дошки вітру) → плитку листя → вести шлях: на кожному кроці вибір з 2 (перший) або 3 (далі) клітин; плата за чужі купки знімає листки з активних.
- (цифрова версія) Шлях — `path-drawing`: протягнути від дерева, допустимі наступні клітини підсвічені, ціна перекриття показана над купкою; `path-preview` рахує, скільки листків лишиться.

## Цікавинки для курсу
- Подвійна сітка: дерева на вершинах, листя на клітинах, «сусідні клітини в напрямку вітру» для вершини — 📎.
- Шлях листя: перший крок з 2, далі з 3 (прямо/діагональ), обрив на краю, плата висотою чужої купки — 🥉 (пошук найкращого шляху — DFS з бюджетом).
- Таблиця більшості з нічиїми (2/1/0, 3 за самотнє 1-ше, нічия за 1-ше) як одна функція для стежок і регіонів — 📎.
- Регіони як групування клітин за типом (не за звʼязністю) — 🌱.
- Черга ходу за найменшою плиткою й дошка вітру, що змінює напрям і вимогу — 🌱.
- AI осені: перебір дерево × плитка × шлях з оцінкою зміни контролю регіонів — 🥈 (гра з повною інформацією, але велике дерево варіантів).

## Пропозиції до словників
- `+trigger:round_end` — раунд закінчився (зсув вітру, нова черга; уже пропоноване корпусом).

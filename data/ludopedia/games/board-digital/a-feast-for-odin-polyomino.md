# A Feast for Odin і поліоміно-заповнення — вкрий дошку товарами-фігурами, відкрий дохід, не лишай −1

## Суть
У A Feast for Odin вікінги (робітники) добувають товари, а **поліоміно-тайли товарів** гравець викладає на домашню дошку й острови: кожна непокрита клітина в кінці дає −1, покриття діагоналі доходу піднімає щораундовий дохід, а оточена з 8 боків бонус-клітина дає товар щораунду. Зелені тайли не можуть торкатися ортогонально, синім можна — це обмеження сусідства на рівні кольору фігури. Файл — «парасолька» для ігор, де ядро = заповнення своєї сітки фігурами: Patchwork (є окремо), Bärenpark, The Isle of Cats, Project L, NMBR 9.

## Поле і час
- **Кілька особистих полів**: домашня дошка (сітка клітин з −1, діагоналлю доходу й бонус-клітинами), острови-дослідження (Шетланди, Фарери, Ісландія, Гренландія — двосторонні, з власною сіткою, позитивною цінністю 4–38 і своїми −клітинами), будинки (сарай, кам'яний, довгий), бенкетний стіл (смуга клітин).
- **Спільна зона**: дошка дій (~60 полів для робітників (?)), запас тайлів товарів 4 кольорів, запас мисливських/рибальських кубиків, карти професій.
- Раунд = 12 фаз (дохід, розміщення вікінгів по черзі, бенкет, бонуси, розмноження тварин…); 7 раундів (коротка гра — 6); з кожним раундом вікінгів на 1 більше.
- Час: покроковий; викладання тайлів на дошки — «будь-коли дія» у свій хід (?), бенкет — у своїй фазі.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Тайл товару | piece | колір ∈ {orange, red, green, blue}, форма-поліоміно (до 12 клітин) | кладеться на дошку/стіл за правилами кольору; апгрейд = заміна на наступний колір |
| Помаранчевий (їжа рослинна) | object | — | лише на бенкетний стіл; не торкається іншого помаранчевого |
| Червоний (їжа тваринна, тварини) | object | вівці/корови з вагітним боком | лише на стіл; не торкається іншого червоного |
| Зелений (ремесло) | object | — | на домашню дошку/острови; **не торкається іншого зеленого ортогонально**, діагонально можна |
| Синій (розкіш, спецтайли) | object | спецтайли унікальні | на дошки без обмеження сусідства |
| Срібло | resource | монета 1×1 | валюта; може лягати на дошку/стіл як 1×1 |
| Руда | resource | жетон 1×1 | на дошку, не на стіл |
| Клітина −1 | static | штраф на кінець | непокрита в кінці → −1 (на островах/будинках — свої значення) |
| Діагональ доходу | zone | значення по зростанню | покривати по порядку; дохід = найменше непокрите значення |
| Бонус-клітина | switch | надрукований товар | рахується покритою; якщо 8 сусідів покриті (на краю 5), а вона ні → товар щораунду |
| Острів | zone | сітка, цінність 4–38, срібло на ньому | береться кораблем; додає поле для викладання |
| Будинок (сарай/камʼяний/довгий) | zone | 8/10/17 очок | ще одне поле для тайлів; у кінці приймає залишки дерева/каменю |
| Бенкетний стіл | zone | смуга клітин | щораунду заповнити їжею/сріблом; порожня клітина → Thing-штраф −3 |
| Вікінг | worker | 1 + номер раунду | займає поле дії; повертається у фазі повернення |
| Кубики (d8, d12) | object | — | полювання, рибальство, набіги: результат − витрачене ≥ поріг (?) |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(place(tile, board, cells))` → ЯКЩО `fits(tile, board)` (без перекриття, без виходу за край) and `custom: «колір дозволений на цьому полі: дошки — зелений/синій/срібло/руда; стіл — помаранчевий/червоний/срібло»` → ТО `place`; інакше `block`.
- КОЛИ `input(place(green_tile))` → ЯКЩО `custom: «ортогонально торкається іншого зеленого тайла»` → ТО `block`; діагональний дотик дозволений. Синій/срібло/руда — без обмежень.
- КОЛИ `input(place(tile, banquet))` → ЯКЩО `same(tile, neighbour, colour)` для помаранчевого або червоного → ТО `block`; срібло торкається будь-чого.
- Бенкет: `custom: «по одному тайлу кожного типу можна покласти горизонтально, решта — вертикально; кожен тайл покриває ≥1 клітину столу й не звисає»`.
- КОЛИ `custom: «тайл покладено»` → ТО назавжди (не знімається).
- КОЛИ `custom: «покрито значення діагоналі доходу»` → ЯКЩО `custom: «покрито в порядку зростання»` → ТО дохід = найменше непокрите значення.
- КОЛИ `round_end` (фаза доходу) → ТО `currency(+income)` з домашньої дошки і кожного острова окремо.
- КОЛИ `pattern(surround8(bonus_cell))` (на краю — 5 сусідів) → ЯКЩО `not occupied(bonus_cell)` → ТО `give(player, bonus_good)` щораунду (фаза бонусів).
- КОЛИ `input(upgrade(tile))` → ТО `transform(tile → next_colour)`: orange → red → green → blue (?).
- КОЛИ `input(ship_action(island))` → ТО острів переходить гравцю з усім сріблом на ньому; невзяті острови щораунду отримують +2 срібла.
- КОЛИ `custom: «фаза бенкету»` → ТО заповнити всі клітини столу; кожна порожня → Thing-штраф (−3 у кінці).
- КОЛИ `custom: «останній раунд»` → ТО `game_over`: `score(+кораблі, еміграції, острови, будинки, тварини, професії, срібло)` `score(−Σ непокритих −клітин на всіх полях)` `score(−3 × Thing-штраф)`; при рівності — кілька переможців.
- Родичі (той самий цикл «форма → поле → очки»):
  - **Patchwork**: дошка 9×9, −2 за порожню клітину, перший повний 7×7 → +7.
  - **Bärenpark**: дошка з 4×4-квадратів; символ під тайлом → взяти новий тайл; заповнений квадрат 4×4 → статуя ведмедя (перший — більше); кінець, коли хтось заповнив парк.
  - **The Isle of Cats** (?): човен-сітка з кімнатами й щурами; родина = ≥3 котів одного кольору поруч (більше — більше очок); незаповнена кімната −5, непокритий щур −1.
  - **Project L** (?): тайли-поліоміно кладуться не на дошку, а на карти-пазли з дірками; заповнена карта дає очки і нову фігуру (апгрейд 1 → 2 → … клітин).
  - **NMBR 9** (?): тайли-цифри 0–9 кладуться шарами; вищий шар мусить спиратися на ≥2 тайли без звисання; очки = цифра × номер шару (нижній шар — 0).

## Керування і ввід
- Обрати тайл зі свого запасу (`piece-tray`), обрати поле (вкладки: домашня дошка / острів / будинок / стіл), drag, поворот 90° і дзеркало, підтвердити; нелегальні клітини (дотик зелених, звисання, перекриття) підсвічуються червоним.
- Окремо — розміщення вікінгів на дошці дій (клік по полю дії, якщо вистачає вікінгів у групі на 1–4 вікінги (?)).
- Апгрейд/обмін товарів — кнопки на тайлі в запасі.
- Кубики полювання/рибальства/набігу — кидок автоматичний, гравець обирає, скільки ресурсу докласти (?).

## Варіації й родичі
- Сімʼя Розенберга: Patchwork (2014) → A Feast for Odin (2016) → Indian Summer / Spring Meadow / New York Zoo (поліоміно в «puzzle trilogy») (?).
- Bärenpark (2017), The Isle of Cats (2019), Project L (2020), NMBR 9 (2017), Blokus (є в корпусі), Cartographers (поліоміно олівцем).
- **Осі варіацій**:
  - поле: одна дошка (Patchwork) / кілька дощок і островів (Odin) / дошка, що росте квадратами (Bärenpark) / шари (NMBR 9) / дошка = картка-ціль (Project L);
  - сусідство: без обмежень / той самий колір не торкається (Odin зелений, бенкет) / той самий колір **мусить** торкатися (Isle of Cats родини);
  - нагорода за покриття: прибрати −клітини / відкрити дохід по порядку / оточити бонус / заповнити квадрат або кімнату / символ під тайлом дає новий тайл;
  - ціна фігури: ґудзики+час / дії робітника / драфт / безкоштовно (NMBR 9).

## Цікавинки для курсу
- Валідатор розміщення поліоміно з правилом «зелений не торкається зеленого ортогонально» — 📎 (`fits` + перевірка сусідів за кольором).
- Дохід «найменше непокрите значення на діагоналі» — 🌱; «бонус-клітина оточена 8 сусідами, але сама вільна» — 🌱.
- Кілька дощок як вкладки з одним рушієм розміщення — 🥉 (поле як параметр, штраф −N — дані клітини).
- Бенкет: заповнити смугу тайлами двох типів без однакових сусідів і з квотою орієнтацій — 🥉, а «знайти заповнення з мінімумом штрафів» — 🥇 (пошук з поверненням).
- Isle of Cats-родини (компоненти одного кольору ≥3 з таблицею очок) — 📎; NMBR 9 шари з опорою ≥2 тайли — 🥈.
- Підказка «куди вміститься найбільше» (перебір позицій × 8 орієнтацій × правила кольору) — 🥈.

## Непевне
- (?) Розмір домашньої дошки, кількість −клітин і бонус-клітин — джерела не дають; «−1 на клітині» — з памʼяті, rulespal каже лише «штраф надруковано на дошці».
- (?) Ланцюг апгрейду orange → red → green → blue — з памʼяті.
- (?) «Бонус за повний ряд/стовпець», згаданий у завданні, у правилах Odin не знайдено — тут не включено; подібне — заповнений квадрат (Bärenpark, Patchwork 7×7).
- (?) Isle of Cats (кімнати −5, щури −1, родини ≥3), Project L, NMBR 9 — з памʼяті, сторінок не відкрито (Wikipedia-статей нема).
- (?) Офіційної цифрової версії Odin не знайдено (Steam-пошук порожній); розділ вікон — гіпотетична цифрова версія.
- (?) Кубики d8/d12 у полюванні/набігах і групи вікінгів 1–4 на полі дії — з памʼяті.

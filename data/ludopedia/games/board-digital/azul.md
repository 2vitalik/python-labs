# Azul — драфт плиток з фабрик: збери всі одного кольору, заповни лінію, виклади стіну 5×5

## Суть
Гравці по черзі беруть з «фабрик» **усі** плитки одного кольору і кладуть їх у свої лінії-шаблони (місткість 1–5). Наприкінці раунду з кожної повної лінії одна плитка переїжджає на стіну 5×5 і одразу дає очки за довжину зʼєднаних рядів і стовпців, у які вона стала. Надлишок падає на «підлогу» зі штрафами. Ядро — драфт з обмеженнями: кожен твій вибір вирішує, що лишиться суперникам і що змушено впаде комусь на підлогу.

## Поле і час
- **Спільна зона**: N фабрик-дисплеїв по колу (2 гравці → 5, 3 → 7, 4 → 9), по 4 плитки на кожній, і центр столу. Мішок з 100 плиток (5 кольорів × 20) і кришка-скид.
- **Особиста дошка** гравця: 5 ліній-шаблонів (сходинка 1, 2, 3, 4, 5 клітин) зліва → стіна 5×5 справа (кожен колір має фіксоване місце в кожному рядку, діагональний зсув) → лінія підлоги знизу (заповнюється зліва направо) → трек очок.
- Раунд = три фази: **Пропозиція фабрик** (драфт по черзі, доки всі плитки не розібрані) → **Облицювання стіни** (одночасно, лінії зверху вниз) → **Підготовка** (поповнення фабрик з мішка).
- Хід = одне взяття. Раунди тривають, доки в когось не заповниться горизонтальний ряд стіни.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Плитка | tile | колір (5) | береться з фабрики/центру; лягає в лінію → стіну або на підлогу/скид |
| Фабрика | supply | 4 плитки на початку раунду | беруть усі плитки одного кольору; решта → центр |
| Центр столу | supply | змінна кількість | беруть усі одного кольору; перший, хто бере, отримує маркер першого гравця |
| Маркер першого гравця | object | один | лежить у центрі; перший, хто бере з центру, кладе його на свою підлогу (рахується як плитка, зі штрафом клітини) і ходить першим у наступному раунді |
| Мішок | spawner | вміст прихований | заповнює фабрики по 4; порожній → пересипається скид; скид теж порожній → раунд іде з неповними фабриками |
| Кришка (скид) | supply | — | сюди йдуть зайві плитки з ліній і підлоги |
| Лінія-шаблон i | zone | місткість i (1–5), один колір | заповнюється справа наліво; повна → 1 плитка на стіну, решта в скид |
| Стіна 5×5 | zone | фіксовані місця кольорів (сірий варіант — вільні) | плитка дає очки за суміжні ряди; не знімається |
| Лінія підлоги | hazard | 7 клітин, штраф росте вправо (значення — у «Непевне») | збирає надлишок; штраф у кінці раунду, потім очищення |
| Трек очок | static | — | рахунок не падає нижче 0 |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(take(source, color))` → ЯКЩО `turn_of(player)` → ТО `custom: «draft(source, color)»`: усі плитки кольору — гравцю; якщо source = фабрика → `move(rest, centre)`.
- КОЛИ `input(take(centre, color))` → ЯКЩО `has(centre, first_player_marker)` → ТО `move(marker, floor)` (займає першу вільну клітину підлоги, штрафується як плитка).
- КОЛИ `input(put(line_i))` → ЯКЩО `same(line_i.color, color)` or `custom: «лінія порожня»` → ЯКЩО `not custom: «колір уже на стіні в ряду i»` → ТО заповнити лінію справа наліво; надлишок → `move(excess, floor)`; інакше `block`.
- Гравець може свідомо скинути всі взяті плитки одразу на підлогу.
- КОЛИ `custom: «підлога повна»` → ТО зайві плитки → `move(excess, lid)` без штрафу.
- КОЛИ `all_gone(tile_on_factories_and_centre)` → ТО `custom: «round_end»` → фаза облицювання.
- КОЛИ `after(custom: «round_end»)` → для кожної лінії зверху вниз: ЯКЩО `pattern(row_full)` → ТО `move(rightmost_tile, wall[i][color])`, `move(rest, lid)`, `score(run)`; неповна лінія лишається на наступний раунд.
- Рахунок плитки на стіні: нема сусідів → `score(+1)`; інакше `score(+довжина горизонтального ряду, що включає плитку)` + `score(+довжина вертикального)` (рахується лише напрям, де є сусід).
- Після облицювання: `score(−сума штрафів підлоги)` (мін. 0); підлога → `move(floor_tiles, lid)`, маркер лишається гравцю, він починає наступний раунд.
- КОЛИ `custom: «у будь-кого заповнено горизонтальний ряд стіни»` → ТО `game_over` одразу після цієї фази облицювання; інакше фабрики `spawn_at(tile×4, factory)` з мішка, мішок порожній → `custom: «скид у мішок»`.
- Фінальні бонуси: `score(+2)` за кожен повний ряд, `score(+7)` за повний стовпець, `score(+10)` за колір, усі 5 плиток якого на стіні.
- Перемога — найбільший рахунок; нічия → більше повних рядів; далі — спільна перемога.
- Сірий варіант: плитка йде в будь-яку клітину свого ряду, але колір не може повторитись у стовпці.

## Керування і ввід
- Клік по групі плиток кольору на фабриці або в центрі (підсвічуються всі плитки цього кольору) → клік по лінії-шаблону або підлозі.
- Неприйнятні лінії (інший колір / колір уже на стіні) не підсвічуються; гра підказує, скільки впаде на підлогу.
- Фаза облицювання автоматична; у сірому варіанті гравець клікає клітину стіни для кожної повної лінії.
- Черга: по колу від власника маркера першого гравця.

## Вікна, меню, HUD
(цифрова версія — BGA та мобільні застосунки)
- `lobby-window` / `match-setup` (кандидат): кількість гравців 2–4, сірий варіант стіни, таймер ходу, AI-суперники.
- `game-screen`: коло фабрик із центром; своя дошка (лінії, стіна, підлога) крупно; `opponent-boards` — дошки суперників зменшено; `score` кожного; `turn-indicator`; `selection-highlight` вибраного кольору; `legal-move-highlight` допустимих ліній; `score-preview` — скільки дасть плитка на стіні й скільки коштує підлога (у застосунках / BGA-підказка); `remaining-counter` плиток у мішку (?).
- `round-summary` (кандидат): анімація облицювання по лініях з `popup-text` (+3, −2).
- `end-screen`: бонуси рядів/стовпців/кольорів, фінальна таблиця.
- `help-window` / `tutorial-window`: правила з прикладами підрахунку.
- `log-window` (BGA): журнал «гравець узяв 3 червоні з фабрики 4».
- Переходи: lobby → game-screen ⇄ round-summary (кожен раунд) → end-screen.

## Цікавинки для курсу
- Драфт «усі одного кольору, решта в центр» + маркер першого гравця — 📎 (чисто, але повно правил).
- Рахунок плитки на стіні: довжини суміжних рядів у двох напрямках з особливим випадком «ізольована = 1» — 📎 (класична вправа на обхід сусідів).
- Лінії-шаблони як «буфер перед полем» з обмеженнями (один колір, колір не на стіні) — 🥉.
- Мішок + скид з перемішуванням і частковим поповненням — 🌱 (модель колоди/мішка).
- AI-підказка «найкращий хід»: перебір (джерело, колір, лінія) з оцінкою очок мінус підлога — 🥉; зважування того, що лишиться суперникам — 🥇.
- Сірий варіант (обмеження «колір раз у стовпці» як латинський квадрат) — 🥈 (перевірка досяжності розстановки).

## Пропозиції до словників
- `+trigger:round_end` — кінець раунду (коли спільний запас вичерпано); запускає фазу підрахунку.
- `+effect:draft(source, kind)` — забрати всі сутності виду з джерела; `+effect:discard` — відправити у скид.
- Вжито наявні `same` (колір лінії = колір плиток), роль `supply` (фабрика, центр, кришка), `opponent-boards`.
- `+ui:score-preview` — передбачення очок/штрафу до підтвердження ходу.
- `+window:round-summary` — проміжний екран/анімація підрахунку раунду.
- `+axis:turn-structure` — `alternate` + одночасна фаза облицювання.

## Непевне
- (?) Значення штрафів підлоги −1 −1 −2 −2 −2 −3 −3 (7 клітин) — з памʼяті; UltraBoardGames дає їх лише картинкою, BGA-довідка — «втрачаєш очки відповідно».

- (?) Деталі UI BGA/застосунків (score-preview, лічильник мішка, undo до підтвердження) — з памʼяті, не перевірено на сторінці.

# Encore! (Noch mal!) — кубик «колір + число»: закресли стільки клітин кольору одним звʼязним шматком і першим закрий колонку

## Суть
Roll-and-write Інки й Маркуса Брандів (Schmidt Spiele, 2016). Кожен має власний аркуш-сітку з кольоровими блоками; активний гравець кидає 3 кубики кольору й 3 кубики числа, і всі (активний — першим) беруть пару «колір + число» та закреслюють стільки клітин цього кольору. Хрестики ростуть від середньої колонки H назовні: кожна нова клітина мусить торкатися вже закресленої. Очки — за перегони: хто першим закрив колонку чи весь колір, бере більший бонус, решта — менший.

## Поле і час
- Аркуш: колонки A–O (15), стартова — середня H; клітини розфарбовані в 5 кольорів, утворюють блоки (є блоки по 6 клітин). Кількість рядків — (?).
- Шари аркуша: клітини з кольором (частина — із зіркою), над колонками — літери (облік ходів у соло), під колонками — по два значення очок (більше / менше), справа вгорі — бонуси кольорів, окремо — 8 полів «!» (джокери).
- Хід = кидок активного гравця; усі інші одночасно обирають свою пару з решти кубиків — `time: turn` з паралельними діями. Кубики передаються за годинниковою стрілкою.
- Інформація повна: усі бачать кубики й аркуші суперників; випадковість — у кожному кидку.

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Аркуш гравця | zone | 15 колонок A–O, 5 кольорів у блоках | власне поле кожного, перетину між гравцями нема |
| Клітина | mark | колір, зірка/без | закреслюється хрестиком; не стирається |
| Клітина колонки H | mark | — | лише звідси можна почати першу групу |
| Зірка | mark | −2, якщо не закреслена | 15 зірок → максимум −30 |
| Блок кольору | zone | 1..6 клітин одного кольору | за хід хрестики числа — лише в одному блоці, не розщеплюються |
| Кубик кольору | object | 3 шт.: 5 кольорів + чорний X (джокер) | задає колір |
| Кубик числа | object | 3 шт.: 1–5 + «?» (джокер) | задає, скільки клітин закреслити; 6 не буває |
| Поле «!» | supply | 8 на аркуші | кожен використаний джокер закреслює одне «!»; невикористане — +1 |
| Бонус колонки | resource | два значення: більше / менше | перший, хто закрив колонку, бере більше, інші його закреслюють |
| Бонус кольору | resource | 5 (перший) / 3 (решта) | закриті всі клітини кольору |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `turn_start(active)` → ТО `custom: «кинути всі 6 кубиків»` (`+effect:roll_dice`).
- КОЛИ `input(choose(color_die, number_die))` → ЯКЩО `turn_of(active)` → ТО `custom: «обрані два кубики вилучаються для інших»`.
- КОЛИ `input(choose(color_die, number_die))` → ЯКЩО `not turn_of(me)` і `custom: «кидок уже не з перших трьох»` → ТО `custom: «вибір лише з 4 решти; кілька гравців можуть взяти ту саму пару»`; у перших 3 кидках — усі з 6.
- КОЛИ `input(pass)` → ТО `pass_turn`; ЯКЩО `turn_of(active)` → ТО `custom: «іншим доступні всі 6 кубиків»`.
- КОЛИ `input(mark(cells))` → ЯКЩО `custom: «кількість клітин = число на кубику, ≤5»` і `same(cells, color_die, color)` і `connected(cells)` → ТО `mark(cells, x)` (`+effect:cross_box`); інакше `block`.
- КОЛИ `input(mark(cells))` → ЯКЩО `custom: «клітини лежать у кількох окремих блоках того самого кольору»` → ТО `block` — число не ділиться між блоками.
- КОЛИ `input(mark(cell))` → ЯКЩО `adjacent_count(cell, crossed, >=, 1)` (лише ортогонально) або `cell(cell, column_H)` → ТО можна; інакше `block`. Перший хрестик гри — лише в H.
- КОЛИ `input(use(joker))` → ЯКЩО `has(sheet, free_exclamation)` → ТО `mark(exclamation, x)`, `choose(колір будь-який | число 1–5)`; два джокери в один хід — два «!»; без «!» — `block`.
- КОЛИ `custom: «усі клітини колонки закреслені»` → ЯКЩО `custom: «ніхто ще не закрив цю колонку»` (`+cond:first_among_players`) → ТО `score(top_value)`, `message(«закресліть верхнє значення»)`; інакше `score(bottom_value)`. Кілька гравців в один кидок — усі беруть більше.
- КОЛИ `custom: «усі клітини кольору закреслені»` → ЯКЩО `custom: «перший за столом»` → ТО `score(5)`; інакше `score(3)`. Не більше 2 бонусів кольору на гравця.
- КОЛИ `counter(color_bonuses@any, ==, 2)` → ТО `custom: «дограти поточний кидок для решти гравців»`, `game_over`.
- КОЛИ `game_over` → ТО `custom: «сума: бонуси кольорів + бонуси колонок + 1 за кожне вільне "!" − 2 за кожну незакреслену зірку»`.
- КОЛИ `game_over` → ЯКЩО `custom: «рівний рахунок»` → ТО `custom: «перемагає той, у кого більше вільних "!"»`; інакше `draw` (перемога ділиться).
- Соло: КОЛИ `turn_start(solo)` → ТО `custom: «кинути 2 кубики кольору і 2 числа, обрати одну пару»`; КОЛИ `turn_end(solo)` → ТО `mark(letter_box, half_cross)`; КОЛИ `counter(turns, ==, 30)` → ТО `game_over`.
- Перемога: найбільше очок · Поразка: — · Рахунок: перегони за бонусами колонок і кольорів + запас «!» − незакреслені зірки.

## Керування і ввід
- Настільна: активний кидає, оголошує свою пару; інші одночасно обирають з решти й закреслюють ручкою. Пас дозволений.
- (цифрова версія) Тап по парі кубиків у лотку → підсвітка легальних клітин (колір, звʼязність, сусідство) → тапами закреслити рівно n клітин; кнопка «Пас»; кнопка джокера списує «!».

## Цікавинки для курсу
- Легальність запису: n клітин одного кольору, одна звʼязна група в одному блоці, торкається закресленого або колонки H — 📎 (BFS + перевірка блока).
- Генерація всіх легальних варіантів для пари кубиків (перебір звʼязних підмножин розміру n) для підсвітки — 🥉.
- Перегони «перший/решта» на спільних бонусах з одночасними діями в одному кидку — 🌱.
- Обмежені джокери як ресурс і як тай-брейк — 🌱.
- Соло-бот: жадібний вибір пари за очікуваними очками колонок — 🥉; оцінка з повним перебором кидків — 🥇.

## Пропозиції до словників
- `+effect:roll_dice` — кинути набір кубиків (6 у грі, 4 у соло).
- `+effect:cross_box` — закреслити клітину аркуша (roll/flip-and-write).
- `+cond:first_among_players` — гравець перший за столом виконав спільну ціль (колонка, колір, пара сіл у Tucana); відрізняється від `first_time` (вперше для себе).
- `+role:die` — кубик як сутність гри з гранями.
- `+ui:dice-tray` — лоток кинутих кубиків з позначкою взятих.
- `+ui:score-sheet` — таблиця підрахунку за рядками.
- `+ui:bonus-track` — ряд бонусів «більше/менше» з закресленими вже взятими.
- `+card:single-block-per-turn` · `+card:race-shared-goals` · `+card:limited-jokers` — див. «Мапа на каталог».

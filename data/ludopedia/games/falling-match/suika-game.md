# Suika Game — кидаєш фрукти у фізичну банку; два однакові зливаються в наступний, мета — кавун

## Суть
Гравець обирає, де над банкою відпустити фрукт; той падає й котиться за фізикою. Два однакові фрукти при дотику зливаються в наступний за розміром у сходинці з 11 фруктів (вишня → … → кавун). Кидати можна лише 5 найменших, тож великі виникають тільки злиттям, а злиття може запустити ланцюг. Програш — фрукт перетнув лінію вгорі або злиття «вистрілило» фрукт із банки.

## Поле і час
- Вільні координати (2D-фізика, Unity): банка з дном і стінками, лінія зверху. Фрукти — круглі тіла різного радіуса, відскакують, котяться, тиснуть одне на одне.
- Часу немає як тиску (нема таймера), але фізика йде в реальному часі; хід = один кинутий фрукт.
- Видно поточний фрукт над банкою й наступний (на крок уперед).

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Поточний фрукт | player | рівень 1–5 | рухається вздовж верху; відпущений — падає |
| Фрукт у банці | tile | рівень 1–11, радіус | фізичне тіло; дотик з таким самим → злиття в рівень+1 |
| Вишня (1) | tile | найменший | єдиний, що не утворюється злиттям |
| Полуниця, виноград, декопон, хурма (2–5) | tile | — | можуть випасти до кидка й утворюватися злиттям |
| Яблуко, груша, персик, ананас, диня (6–10) | tile | — | лише злиттям |
| Кавун (11) | tile | найбільший | два кавуни при злитті зникають |
| Банка | static | дно, стінки | тримає фрукти |
| Лінія зверху | static | — | фрукт за нею → кінець гри |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(move)` → ТО `move(current, x)` уздовж верху банки.
- КОЛИ `input(drop)` → ТО `place(current, x)`, `fall(current)`; `custom: «наступний стає поточним; новий наступний — випадковий з рівнів 1–5»`.
- КОЛИ `tick` → ТО `custom: «фізика: гравітація, зіткнення, тертя, котіння»`.
- КОЛИ `contact(fruit_a, fruit_b)` → ЯКЩО `same(a, b, level)` and `custom: «рівень < 11»` → ТО `merge(a, b → level+1)`, `score(n)` — більший фрукт дає більше очок.
- КОЛИ `contact(watermelon, watermelon)` → ТО `disappear_both`, `score(n)`.
- КОЛИ `after(merge)` → ТО `custom: «новий більший фрукт розштовхує сусідів»`; може торкнутися ще одного такого самого → нове злиття (ланцюг).
- КОЛИ `custom: «фрукт за лінією зверху»` → ТО `lose` (точна умова — див. «Непевне»).
- КОЛИ `custom: «злиття викинуло фрукт за межі банки»` → ТО `lose`.
- Мета — найбільший рахунок; рекорди — онлайн-таблиця.

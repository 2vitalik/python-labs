# BLOCKSUM — зливай сусідні числа в суму; N блоків із числом N зникають, а стек тим часом росте знизу

## Суть
Знизу поля безперервно піднімаються блоки з числами. Гравець курсором **зливає два сусідні блоки в один**: новий блок займає обидві клітини й несе суму їхніх чисел. Група блоків з однаковим числом N ≥ 2 зникає, коли в ній **щонайменше N блоків** (три «3», чотири «4»…), тож кожне злиття водночас наближає й віддаляє збіг: блоків стає менше, а поріг росте. Студентська гра (CESA Student Game Award, 2005), пізніше — безкоштовний ремейк Circle infotech і мобільна версія.

## Поле і час
- Поле 8 стовпців × 13 рядів (窓の杜); блоки — квадрати з числами, злиті — багатоклітинні фігури-обʼєднання з одним числом.
- Real-time: стек повільно сунеться вгору, знизу вʼїжджає новий ряд; X прискорює підйом, поки затиснута.
- Набір чисел у новому ряду залежить від рівня; рівень +1 за кожні 100 знищених блоків, старт — рівень 0.
- Коли група зникає, підйом **зупиняється**, група блимає, і лише після паузи зникає (часова «фаза розвʼязання», як у Panel de Pon).

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Курсор | player | квадрат на полі | рух стрілками; із затиснутою Z перетин межі між блоками зливає їх |
| Числовий блок | tile | число 1…, форма (1 клітина або обʼєднання) | піднімається зі стеком; зливається з сусідом у суму; у групі ≥ N однакових N зникає |
| Блок «1» | tile | 1 | сам не зникає ніколи — лише після злиття в число ≥ 2 |
| 魔晶石 (магічний кристал) | tile | круглий, без числа | злиття з числовим блоком стирає з поля всі блоки з тим самим числом (без очок) |
| Новий ряд | spawner | числа за рівнем | вʼїжджає знизу з підйомом стеку |
| Верхній ряд | static | — | дістався блок → тривога, маркери |
| Червоні маркери | hazard | по обидва боки поля | піднімаються знизу, поки стек у верхньому ряду; дійшли до верху → кінець гри |
| Бонусна стадія | zone | — | відкривається, якщо рівень досягнуто швидко; блоки прибирати легше |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(arrow)` → ТО `move(cursor, dir)`.
- КОЛИ `input(hold_z_and_cross_border)` → ЯКЩО `custom: «по обидва боки межі — два різні сусідні блоки»` → ТО `merge(a, b → a+b)`: новий блок займає клітини обох, `set_value(new, a+b)`.
- КОЛИ `pattern(group(n))` → ЯКЩО `same(blocks, value)` and `custom: «число N ≥ 2 і блоків у групі ≥ N»` → ТО `custom: «зупинити підйом»`, `set_state(group, flashing)`, далі `clear(group)`, `score(S)`.
- Блок «1» до збігу не допускається: КОЛИ `pattern(group(n))` → ЯКЩО `custom: «число = 1»` → ТО `custom: «нічого»` (4Gamer: «1» прибрати не можна).
- КОЛИ `input(x)` → ЯКЩО `state(group, flashing)` → ТО `clear(group)` одразу, без очікування.
- КОЛИ `input(hold_x)` → ЯКЩО `custom: «нема блимання»` → ТО `speed(stack, ×k)` — стек піднімається швидше, поки X затиснута.
- КОЛИ `timer(rise)` → ТО `shift(all, up)`, `spawn_at(row, bottom)` з числами за рівнем.
- КОЛИ `after(clear)` → ТО `fall(blocks_above)` (?) — і можливий новий збіг.
- КОЛИ `input(join)` → ЯКЩО `custom: «один із двох — 魔晶石»` → ТО `custom: «clear_kind — стерти всі блоки з числом другого блока»`, `score(0)`.
- КОЛИ `input(join)` → ЯКЩО `custom: «обидва — 魔晶石»` → ТО `disappear_both` (JA-вікі) або бонус-очки (窓の杜) (?).
- КОЛИ `counter(cleared_blocks, ≥, 100)` → ТО `counter(level, +1)`, `counter(cleared_blocks, -100)`; новий рівень змінює набір чисел у рядах.
- КОЛИ `reach(block, top_row)` → ТО `sound(warning)`, `custom: «червоні маркери з боків починають підніматися знизу»`.
- КОЛИ `reach(marker, top)` → ЯКЩО `custom: «блоки досі у верхньому ряду»` → ТО `game_over`.
- КОЛИ `counter(level, ==, L)` → ЯКЩО `timer(elapsed, ≤, limit)` → ТО `custom: «бонусна стадія з легшими блоками»`.
- Рахунок: лише за зникнення, `S = [A^1.5 × B + 0.2] × B`, де A — число групи, B — блоків знищено одночасно, `[x]` — ціла частина (JA-вікі); 魔晶石 очок не дає.
- Перемога: нема, гра на рекорд. · Поразка: маркери дійшли до верху, поки стек упирається в стелю.

## Керування і ввід
- Стрілки — курсор; Z (геймпад 1) затиснути й «перетягнути» курсор через межу двох блоків — злити їх.
- X (геймпад 2) — затиснути: прискорити підйом; натиснути під час блимання — прибрати групу одразу.
- Ремейк Circle infotech: курсор ставиться на «голову» блоків, що зливаються, кнопка A зливає (Vector) (?).

## Цікавинки для курсу
- Злиття двох сусідніх блоків у фігуру-обʼєднання з сумою (union-find клітин + одне число на компоненту) — 🥉.
- Поріг групи = значення плитки: BFS по однакових числах, порівняння розміру з N, «1» ніколи не зникає — 📎.
- Стек, що піднімається, зупинка підйому на час блимання, X — прискорити або «прибрати зараз» — 📎.
- 魔晶石: стерти всі блоки з числом партнера — 🌱.
- Пільговий відлік до поразки (маркери ростуть, поки стек у стелі) — 🌱.
- Формула очок `[A^1.5 × B + 0.2] × B` і рівень за кожні 100 блоків — 🌱.

## Непевне
- (?) Чи падають блоки після зникнення групи (дірки в стеку) — джерела не кажуть; правило `fall` — припущення.
- (?) Чи рахує група «блоки» (злиті фігури як одну одиницю) чи клітини — JA-вікі каже «个数» блоків; поведінку з багатоклітинними фігурами не перевірено.
- (?) Два 魔晶石 разом: JA-вікі — знищують одне одного; 窓の杜 — бонус-очки. Можливо, різні версії.
- (?) Vector (2007) згадує щось на кшталт бомби, що знищує зʼєднані з нею блоки, — текст зламаний, ймовірно ранній варіант 魔晶石.
- (?) Чи росте швидкість підйому з рівнем, рівень і ліміт часу для бонусної стадії, розмір курсора — у джерелах нема.
- (?) Набір меню, мережевий рейтинг і мобільна версія — лише згадки.

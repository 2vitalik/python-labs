# Baku Baku Animal — тварина зʼїдає всю звʼязану «свою» їжу; пари блоків асиметричні: їжа сама не зникає

## Суть
Зверху падають пари блоків: здебільшого їжа (морква, кістка, банан, бамбук), зрідка — голова тварини (кролик, пес, мавпа, панда). Їжа однакового виду, складена поруч, сама не зникає; коли тварина опиняється поруч зі своєю їжею, вона зʼїдає всю звʼязану групу цієї їжі. Чим більша група за один «укус», тим більше очок і тим більше блоків летить на поле суперника. Мета — завалити суперника так, щоб він не міг поставити нові блоки.

## Поле і час
- Два поля поруч (versus), квадратна сітка; точний розмір у джерелах не бачив.
- Real-time падіння пари; після приземлення — розвʼязання: окреме падіння блоків, поїдання, осідання, повтор (ланцюг).
- Нерівність видів: їжа зустрічається втричі частіше за тварин (3:1), тому тварина — дефіцитний «ключ».

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(shift)` → ЯКЩО `free(target)` → ТО `move(pair, dir)`; КОЛИ `input(rotate)` → ТО `rotate(pair, 90)`.
- КОЛИ `tick` → ТО `fall(pair)`; ↓ — швидше.
- КОЛИ `locked(pair)` → ТО `fall(each_block)` до опори.
- КОЛИ `adjacent(animal, food)` → ЯКЩО `custom: «їжа — саме цієї тварини (кролик→морква, пес→кістка, мавпа→банан, панда→бамбук)»` → ТО `clear(group)` — уся звʼязана група цієї їжі; `disappear(animal)` (?).
- КОЛИ `adjacent(animal, food)` → ЯКЩО `custom: «їжа чужа»` → ТО `custom: «нічого — блоки лежать»`.
- КОЛИ `after(clear)` → ТО `fall(all_unsupported)`; новий контакт тварини зі своєю їжею → `combo(+1)` (ланцюг) (?).
- Рахунок: `score(n)` росте з кількістю зʼїдених звʼязаних блоків за один укус.
- КОЛИ `custom: «укус»` → ТО `send_garbage(n)` — випадкові блоки падають супернику одразу після його поточної пари.
- КОЛИ `schedule(coin_interval)` → ТО `spawn(coin)` у парі; КОЛИ `contact(coin, block)` → ТО `custom: «clear_color — усі блоки кольору клітини приземлення»`.
- КОЛИ `spawned(pair)` → ЯКЩО `occupied(spawn_cell)` → ТО `lose`; суперник — `win`.
- Перемога: суперник не може поставити блоки · Поразка: те саме у тебе · Рахунок: за укуси.

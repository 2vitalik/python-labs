# Го — став камені на перетини, оточуй групи без дихань і ділянки порожнечі

## Суть
Двоє по черзі ставлять камені свого кольору на перетини сітки 19×19; камені не рухаються, але група, у якої не лишилось жодного «дихання» (сусіднього порожнього пункту), знімається з дошки. Мета — наприкінці мати більше території (обгородженої порожнечі) і/або каменів, ніж суперник, з урахуванням комі. Правил кілька рядків, але глибина величезна; різні набори правил (японські, китайські, AGA, Тромп–Тейлор) відрізняються в деталях підрахунку, ко й самогубства — готовий урок «одна гра, кілька специфікацій».

## Поле і час
- Сітка ліній 19×19 (361 пункт); популярні 13×13 і 9×9 для швидких партій; навчальні — від 5×5. Камені стоять на **перетинах**; суміжність — 4 ортогональні сусіди.
- Хоші (точки-зірки) — орієнтири й місця фіксованих каменів гандикапу.
- Хід = поставити камінь на порожній пункт **або** пас. Чорні ходять першими (у гандикапі першими ходять білі після розстановки).
- Годинник: абсолютний · Fischer · **байо-йомі** (після основного часу N періодів по ~30 с; хід у межах періоду зберігає його; останній вичерпано — поразка) · **канадський** (N ходів за T хвилин, напр. 20 за 5 хв).

## Сутності
| Сутність | Роль | Параметри | Поведінка |
|---|---|---|---|
| Камінь чорний/білий | piece | колір | ставиться на порожній перетин, не рухається; знімається, коли його група без дихань |
| Група (ланцюг) | zone | множина каменів | ортогонально звʼязані камені одного кольору; дихання = порожні сусіди всіх каменів |
| Дихання (liberty) | — | лічильник групи | 1 дихання → атарі; 0 → захоплення |
| Полонені (prisoners) | resource | лічильник сторони | зняті камені суперника; входять у територіальний підрахунок |
| Пункт ко | zone | живе 1 хід | заборонений для негайного перезахоплення |
| Територія | zone | власник | порожні пункти, оточені одним кольором (після зняття мертвих) |
| Хоші | static | 9 на 19×19 | маркер; місця фіксованого гандикапу |
| Комі | — | 6.5 (яп.) / 7.5 (кит., AGA) / 7 (NZ) | очки білим за другий хід; 0.5 у гандикапі |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `input(place(cell))` → ЯКЩО `turn_of(side)` and `free(cell)` and `legal(move)` → ТО `place(stone, cell)`, `end_turn`.
- КОЛИ `after(place)` → для кожної ворожої групи-сусіда: ЯКЩО `liberties(group, ==, 0)` → ТО `capture_group(group)`, `counter(prisoners[side], +size)`. Захоплення суперника перевіряється **до** самогубства.
- **Самогубство** — ЯКЩО після захоплень своя група має 0 дихань → `block` (японські, китайські, AGA); New Zealand / Ing — дозволено, група знімається.
- **Ко** — ЯКЩО хід відновлює позицію одразу після власного попереднього ходу → `block` (просте ко, японські). **Суперко**: позиційне — заборонено повторити будь-яку попередню позицію; ситуаційне — з урахуванням черги (китайські, AGA, NZ, Тромп–Тейлор).
- КОЛИ `input(pass)` → ТО `pass_turn`; AGA: суперник отримує «пас-камінь» у полонені.
- КОЛИ `passes(2)` поспіль → ТО кінець гри (AGA: білі мають пасувати останніми, іноді третій пас).
- КОЛИ `game_over` → ТО фаза **мертвих каменів**: гравці позначають мертві групи → `capture_group`; незгода — китайські: дограти; японські: гіпотетична гра/арбітр.
- КОЛИ підрахунок → **територіальний** (японські, корейські): `територія + полонені (+ мертві)`; **за площею** (китайські, Ing, NZ, Тромп–Тейлор): `камені на дошці + територія`; білі + `komi`. Більше → `win`; дробове комі виключає нічию.
- **Секі** — спільні дихання двох груп, ніхто не може зайти першим: обидві живуть; порожні пункти в секі — нейтральні (яп.) або рахуються (кит., AGA).
- **Гандикап** — КОЛИ `game_start` → ЯКЩО handicap = N ≥ 2 → ТО чорні ставлять N каменів (фіксовано на хоші — яп., AGA; вільно — кит., NZ), першими ходять білі, `komi = 0.5`. Одна аматорська ступінь ≈ один камінь.
- КОЛИ `counter(clock, ==, 0)` (основний час + усі байо-йомі) → ТО `lose`.
- Перемога: більше очок · здача · тайм-аут. Нічия: лише при цілому комі.

## Керування і ввід
- Клік по перетину → камінь; `hover-highlight` — напівпрозорий «привид» каменя під курсором; на мобільних — підтвердження ходу (дотик-перевірка) проти помилкових тапів.
- Кнопка Pass, Resign; запит Undo (за згодою суперника); у фазі підрахунку — клік по групі перемикає «мертва/жива».
- В аналізі — розгалуження варіантів, позначки (трикутник, квадрат, літери), режим «редагувати» (ставити будь-який колір).

## Вікна, меню, HUD
- (цифрова версія — OGS / KGS)
- `game-screen`: дошка з `cell-coordinates` (A–T без I, 1–19), останній камінь з маркером, `prisoners` обох сторін, `player-clock` з `byoyomi-clock` («5 × 30s»), комі, кнопки Pass / Resign / Undo; `chat-box`.
- `stone-removal` (фаза підрахунку): позначені мертві групи напівпрозорі, `territory-overlay` (квадратики власника на пунктах), попередній рахунок, кнопки Accept / Cancel → назад до гри.
- `end-screen`: «B+3.5» або «W+R» (resign) / «W+T» (time), зміна рейтингу.
- `lobby-window` / виклик: розмір дошки (9/13/19/custom), правила (Japanese/Chinese/AGA/Korean/NZ/Ing), гандикап і комі (`handicap-select`), система часу, rated/unrated.
- `analysis-board` / review: дерево варіантів, AI-оцінка ймовірності перемоги, підсвітка помилок; SGF-завантаження.
- `puzzle-window` (цумего / life-and-death задачі), `profile-window` з рангом (30k…1d…9d) і графіком.
- Переходи: lobby → game-screen → (2 паси) stone-removal → (accept) end-screen → review; stone-removal → (cancel/resume) game-screen.

## Варіації й родичі
- Розміри: 9×9 / 13×13 / 19×19 / нестандартні; варіанти: Atari Go (перше захоплення виграє — навчальний), Phantom Go (приховане), Toroidal Go (тор), Rengo (пари).
- Родичі: Gomoku (камені в ряд, без захоплень), Hex, Othello (перевертання замість зняття).
- **Осі варіацій** (самі набори правил!): самогубство (заборонено / дозволено) · ко (просте / позиційне суперко / ситуаційне) · підрахунок (територія / площа) · секі-пункти (нейтральні / рахуються) · гандикап (фіксований / вільний) · комі (5.5 / 6.5 / 7 / 7.5) · мертві камені (угода / дограти / автоматично).

## Цікавинки для курсу
- Групи й дихання: flood fill від поставленого каменя, зняття груп без дихань у правильному порядку (спершу чужі, потім свої) — 🥉.
- Ко і суперко: хеш позиції (Zobrist) в історії, позиційне vs ситуаційне — 🥈.
- Підрахунок за площею: flood fill порожніх регіонів, власник = єдиний колір межі (Тромп–Тейлор) — 🥉; територіальний з полоненими — 📎 поверх.
- Фаза мертвих каменів (позначити кліками, переобчислити територію, обидва підтверджують) — 🥈 (окреме вікно зі станами).
- Байо-йомі і канадський годинник як окремі системи часу — 📎 кожна.
- Оцінка рахунку/живості груп без рушія — 👑 (визначення життя й смерті — дослідницька задача); з готовим рушієм — 🥇.

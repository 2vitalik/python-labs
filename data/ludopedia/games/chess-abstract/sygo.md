# Sygo — го, де оточена група не знімається, а перефарбовується, а хід — або новий камінь, або ріст усіх своїх груп

## Суть
Варіант го від Christian Freeling (2010) на дошці 19×19. Хід — **або** поставити один камінь окремо від своїх груп (нова група), **або** «виростити» будь-які чи всі свої групи — кожну на один камінь. Оточена група без дихань не знімається, а **перефарбовується** в колір захоплювача (як у Reversi), тож ко й snapback не виникають, а захоплення не дає «очей». Автор називає гру «Go on speed»: ріст груп закінчує партію значно швидше, ніж го.

## Поле і час
- Сітка ліній 19×19 (у правилах — «стандартна base-19»); камені на перетинах; суміжність — 4 ортогональні сусіди. Старт — порожня дошка.
- Хід за ходом, **першими ходять білі**. Хід може класти **кілька каменів** (по одному на кожну групу, що росте) — кількість змінюється з числом груп.
- Пас дозволено будь-коли, хід не обовʼязковий; пас не забирає наступного ходу.
- Камені двобічні (чорні/білі) — щоб перевертати при захопленні.

## Сутності
| Сутність | Роль | Параметри | Поведінка |

| Камінь | piece | колір (двобічний) | ставиться на порожній пункт; не рухається; при захопленні перевертається на колір захоплювача |
| Група | zone | множина ортогонально звʼязаних каменів одного кольору | одиничний камінь — теж група; росте максимум на 1 камінь за хід |
| Дихання (liberty) | — | порожні ортогональні сусіди групи | 0 дихань → група захоплена (перефарбування) |
| Порожній пункт | terrain | — | місце для розміщення / росту; наприкінці — територія того, хто оточує його повністю |
| Територія | zone | власник | камені + порожні пункти, оточені лише своїми; у секі рахуються лише пункти, повністю оточені одним гравцем |

## Правила (КОЛИ → ЯКЩО → ТО)
- КОЛИ `game_start` → ТО `custom: «порожня дошка 19×19, перший хід — білих»`.
- КОЛИ `input(place(point))` → ЯКЩО `turn_of(side)` and `free(point)` and `adjacent_count(point, own_stone, =, 0)` → ТО `place(stone, point)` (нова група з одного каменя), `end_turn`.
- КОЛИ `input(grow(groups))` → ЯКЩО `turn_of(side)` and `custom: «кожен новий камінь ортогонально торкається своєї групи»` and `custom: «кожна група отримує не більше одного каменя»` → ТО `place(stone, point)` для кожного, `end_turn`; рости можна будь-якою підмножиною груп.
- КОЛИ `input(grow)` → ЯКЩО `custom: «новий камінь торкається двох і більше своїх груп»` → ТО `custom: «зараховується як ріст усіх цих груп»`; групи зливаються.
- КОЛИ `input(grow)` → ЯКЩО `custom: «дві групи ростуть назустріч і торкаються лише нові камені»` → ТО `custom: «хід легальний, це не подвійний ріст»`.
- КОЛИ `turn_start(black)` → ЯКЩО `custom: «ще жоден гравець не ріс»` → ТО `custom: «можна виростити всі групи І поставити один окремий камінь в тому ж ході»` (баланс за перший хід білих, протокол Symple).
- КОЛИ `after(place)` → ЯКЩО `custom: «у ворожої групи-сусіда 0 дихань»` → ТО `set_side(group, mover)` негайно; хід-розміщення на цьому завершується (`end_turn`).
- КОЛИ `after(grow)` → ЯКЩО `custom: «у ворожої групи 0 дихань»` → ТО `set_side(group, mover)` негайно; `custom: «захоплювачі зливаються в одну групу, яка цього ходу більше не росте»`.
- КОЛИ `after(place)` → ЯКЩО `custom: «у каменя/групи гравця 0 дихань»` and `custom: «захоплення робить захоплювачів однією живою групою»` → ТО хід легальний (тимчасово нуль дихань дозволено).
- КОЛИ `turn_end(side)` → ЯКЩО `custom: «у своєї групи 0 дихань після всіх захоплень»` → ТО `block` (самогубство заборонене — і для розміщення без захоплення, і для захоплення, що лишає захоплювача без дихань).
- Ко і snapback: `custom: «захоплення не звільняє пунктів — повторення позиції через захоплення неможливе»`; окремого правила повторень нема.
- КОЛИ `input(pass)` → ТО `pass_turn`.
- КОЛИ `custom: «два паси поспіль»` → ТО `game_over`.
- КОЛИ `input(resign)` → ТО `lose`.
- КОЛИ `game_over` → ТО `custom: «рахунок = камені на дошці + порожні пункти, оточені лише своїми; у секі — лише пункти, повністю оточені одним гравцем»`; більше → `win`; рівно → `draw` (рідко, через секі).
- Перемога: більше площі · здача суперника. Нічия: рівний рахунок. Комі нема — баланс дає правило першого ходу чорних.

## Керування і ввід
- Розміщення: клік по порожньому перетину, не сусідньому з власними каменями.
- Ріст (цифрова версія): кліки по кількох порожніх пунктах поруч зі своїми групами з попереднім показом (по одному на групу), потім «Завершити хід»; повторний клік знімає камінь.
- Pass, Resign; у першому ході чорних — режим «ріст + один камінь».
- Дошка: гравець кладе камені руками; перевертання захопленої групи — фізично.

## Варіації й родичі
- **Go** ([go.md](go.md)) — предок: дихання, групи, підрахунок за площею; різниця — зняття → перефарбування, 1 камінь → ріст усіх груп.
- **Symple** (Freeling) — звідти протокол ходу «розміщення або ріст усіх груп» і баланс першого ходу.
- **Reversi** ([reversi.md](reversi.md)) — звідти ідея перевертання захопленого; [atari-go.md](atari-go.md), [nogo.md](nogo.md) — інші го-варіанти корпусу.
- «Отелоанські» го-варіанти Фрілінга з різними страховками життя: **Medusa** і **Lotus** (група з «розеткою» живе безумовно), **Goncrete** («eye opener»: захоплювач прибирає по каменю з кожної перевернутої групи), **Implo** («promotion to life»), **Loose** (справжні vs фальшиві дихання), **Rin** (групи біля краю недоторканні). У Sygo страховкою працює сам протокол росту.
- **Осі варіацій**: доля захопленої групи (знімається / перефарбовується / перефарбовується з видаленням каменя) · хід (1 камінь / ріст усіх груп / вибір) · баланс першого ходу (комі / подвійний перший хід) · «життя» (два ока / розетка / безпечний край / протокол росту).

## Цікавинки для курсу
- Захоплення перефарбуванням: flood fill групи без дихань → `set_side` — 🌱 поверх готового go-ядра; без нього — 📎.
- Валідація ходу-росту: множина нових каменів, кожна група ≤1, злиття рахується як ріст усіх, назустріч — легально — 🥉.
- Порядок перевірок у багатокаменному ході: захоплення «негайно», злиття захоплювачів, тимчасово нуль дихань, потім самогубство — 🥈 (правила тут тонкі).
- Баланс першого ходу як стан «ще ніхто не ріс» — 🌱.
- Підрахунок за площею з правилом секі — 🥉.
- AI: хід = підмножина груп × їхні сусідні пункти, розгалуження вибухає — 🥇.

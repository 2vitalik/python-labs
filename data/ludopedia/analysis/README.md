# Зведення корпусу

Періодичні жнива з `games/` (через `index/`): що повторюється, що просить нових слів, що бракує каталогу й системі опису. Файли нумеровані за часом; кожен — самодостатній, з датою й кількістю ігор у корпусі на момент зведення.

- `01-vocab-harvest.md` — жнива словників за правилом трьох (тригери/умови/ефекти/ролі): що переносимо в ✅, що лишаємо ⏳.
- `02-windows-ui-features.md` — каталог вікон, HUD-елементів, налаштувань і режимів, зібраний з ігор: частоти, типові набори по сімʼях.
- `00-curator-notes.md` — робочі нотатки куратора сесії (процес, таксономічні спори, ранні сигнали).
- `03-catalog-gaps.md` — прогалини каталогу завдань: пропоновані картки/сімʼї/слоти з прикладами ігор; **`03-cards-draft.yaml`** — 117 карток-чернеток у форматі `tasks.yaml` для злиття.
- `04-taxonomy-check.md` — як системи класифікації витримали корпус: гібриди, спірні теки, нові осі.
- `05-rules-system.md` — пропозиція системи зберігання правил для студентів (що з граматики витримало, що додати) — дублюється B-тікетом у `.dev/games`.
- `06-wave2-curator-notes.md` — хвиля 2 (275 → 955 ігор, T260): процес 20 паралельних Opus-агентів, джерела й режим «лише WebFetch», файли-огляди й межові ігри, слова правил поза словниками, помилки черг, що пропущено свідомо.
- `07-wave3-curator-notes.md` — хвиля 3 (956 → 1663 ігор, T265, **не завершена** — тижневий ліміт Opus): **точка продовження** (що описано, що лишилось, команди), пошук по сімʼях + дамп Thinky Games через Chrome, злиття черг, прогалина `maybe`, джерела й prompt-injection, помилки черг і корпусу, межові ігри й нові осі.

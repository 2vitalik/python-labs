# Нотатки куратора (Fable, сесія 2026-11-02)

Робочі спостереження по ходу наповнення — сировина для зведень 01–05 і Q-тікета. Дата · факт · що з ним робити.

## Процес

- Спільний ліміт WebSearch — 200 запитів на сесію для всіх агентів, поповнення ~100/год; вичерпався на першій хвилі (17 пошукових агентів). Агенти перейшли на WebFetch відомих URL (Wikipedia, Tatham, fandom, Steam-сторінки); факти без джерела позначені `(?)` у «Непевне». Наслідок: корпус чесний щодо непевності, але частина цифр (розміри полів, очки) — з памʼяті моделей. Для v2-проходу потрібен агент-верифікатор із свіжим бюджетом пошуку.
- Ліміт одночасних субагентів — 20; пачки запускаються на нотифікаціях.
- Описові агенти стабільно дотримуються шаблону: лінт 0 проблем на 30+ файлах; одне порушення (тег без `+`) виправлено руками.
- Агенти обмежують себя 25 тегами `mechanics` (бриф «5–25»): для багатих ігор (шахи, NetHack) мало — підняти до 40.
- `kind` лінків: трапляються `other` і `fandom` для StrategyWiki — додати `other` у шаблон, лінт `kind` не перевіряє (не критично).

## Словники — ранні сигнали (21 гра)

- Правило трьох уже спрацювало для: тригери `input`, `enter`; умови `free`, `has`, `facing`; ефекти `set_state`, `set_cell`, `slide`, `fall`, `explode`, `roll`, `counter`; ролі `terrain`, `hazard`, `gate`, `switch`, `container`, `spawner`; вікно `level-password`; UI `move-counter`; вісь `control`.
- Нове слово, якого не було в кандидатах: `explode(area, into)` (Bomberman, Boulder Dash, Supaplex, XOR) — вибух як ефект з формою й продуктом; `roll` (камінь скочується з округлого); `spread` (аміба/вогонь); `send_garbage`/`offset_garbage` (versus-пазли); `place` (фігурні: поставити з руки/резерву — 5 файлів).
- Каталог: **нема картки `undo-redo` для самої гри** (лише `editor-undo`) — просять 6+ ігор. Також повторюються `+destructible-blocks`, `+wall-follower`, `+turn-when-blocked`, `+level-password`, `+permit-item`, `+chain-reaction`, `+line-match-clear`, `+garbage-attack`, `+next-queue`, `+ladder-climb`, `+rewind`.

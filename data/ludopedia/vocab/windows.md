# Типи вікон

Картки каталогу з тегом `window` (interface/menus; `Part kind=window` посилається на них) — ✅. Решта — ⏳ кандидати; пропонувати через `+window:`. Вікно = окремий екран/модал; HUD-елементи — у `ui-elements.md`.

## ✅ У каталозі (13)

- `game-screen` — головний ігровий екран (поле + HUD).
- `main-menu` — головне меню.
- `pause-menu` — пауза.
- `settings-window` — налаштування.
- `level-select` — вибір рівня.
- `end-screen` — кінець раунду (перемога/поразка/результат).
- `leaderboard` — таблиця рекордів.
- `shop-window` — магазин.
- `help-window` — довідка/правила.
- `about-window` — про гру/автора.
- `splash-screen` — заставка/лого.
- `confirm-dialog` — підтвердження (вийти? перезапустити?).
- `custom-window` — своє вікно (ціна договірна).

## ⏳ Кандидати

- `inventory-window` — інвентар/спорядження (роглайки).
- `map-window` — карта світу/підземелля на весь екран (мінікарта — HUD).
- `stats-window` — статистика гравця (перемоги, час, серії).
- `achievements-window` — досягнення.
- `tutorial-window` — навчання/перша гра покроково.
- `credits-window` — титри.
- `hints-window` — підказки/розвʼязник (пазли).
- `editor-window` — редактор рівнів.
- `level-password` — вхід на рівень за паролем/кодом (Chip's Challenge, старі консолі).
- `mode-select` — вибір режиму (класика / на час / нескінченний).
- `difficulty-select` — вибір складності.
- `puzzle-select` — сітка пазлів з позначками «розвʼязано» (банк пазлів).
- `daily-window` — щоденне завдання/серія.
- `upgrade-window` — вибір апгрейда між хвилями/рівнями (Vampire Survivors, PvZ-карта).
- `character-select` — вибір персонажа/загону/фігур.
- `loading-screen` — завантаження.
- `dialogue-window` — діалог/катсцена.
- `codex-window` — бестіарій/енциклопедія елементів гри (!) — донор для «паспорта гри».
- `log-window` — журнал подій/ходів (роглайк, шахова нотація).
- `replay-window` — перегляд повтору/історії ходів.
- `lobby-window` — лобі мультиплеєра.
- `profile-window` — профіль/аватар гравця.
- `skin-select` — вибір теми/скіна/набору фігур.
- `game-over-continue` — «продовжити?» з лічильником/монетами (аркади).
- `save-slots` — вибір слота збереження.
- `options-audio` · `options-video` · `options-controls` · `options-accessibility` — підсторінки налаштувань (коли окремі екрани).

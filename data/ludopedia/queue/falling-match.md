## Межові випадки

- Mr. Driller (W:Mr._Driller) — копання крізь кольорові блоки, що падають → `dig-gravity`.
- Puzzle Strike (W:Puzzle_Strike) — колодобудівна настільна за мотивами Puzzle Fighter → `board-digital`.
- Titanium Court — частково `tower-lanes`; лишено тут, бо ядро — match-3.
- Shovel Knight Pocket Dungeon — гібрид з `roguelike`; тут, бо ядро — падаючий стакан.
- Beglitched — частина `hidden-deduction` (приховані плитки); тут через match-3.
- Tetravex — по суті `pencil-logic` (статична розмітка ребер), якщо не опишемо як «плитка-збіг».
- Memory / Pairs — радше `hidden-deduction` (памʼять, приховане).
- Block Blast! / 1010! / Woodoku — без падіння; межа з `board-digital` (поліоміно-розміщення, як Blokus/Patchwork).
- Water Sort / Ball Sort — радше `push-slide`-подібний пазл стану, якщо без випадковості.
- Two Dots / Dungeon Raid — малювання шляху; межа з `connect-rotate`.
- Gunpey — зʼєднання ліній; межа з `connect-rotate` (Pipe Mania).
- Polarium — у пазл-режимі це `pencil-logic` (одноштрихові задачі).
- Flip Wars (W:Flip_Wars) — перефарбування плиток у пати-грі → `maze-arcade`.
- Wetrix — частково `build-sim` (рельєф і вода).

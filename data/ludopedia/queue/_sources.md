# Хаби для пошуку ігор

Де шукати далі (пошукові агенти стартують звідси). Позначка ⭐ — найпродуктивніше джерело для сімʼї.

## Бази й списки
- ⭐ Thinky Games — https://thinkygames.com/games/ — сотні сучасних головоломок з тегами механік (sokoban-like, rule-manipulation, gravity…).
- ⭐ Simon Tatham's Portable Puzzle Collection — https://www.chiark.greenend.org.uk/~sgtatham/puzzles/ — 40 логічних ігор з правилами й генераторами.
- ⭐ puzz.link (pzprv3) список жанрів — https://puzz.link/list.html — ~100 паперових жанрів з канонічними назвами й правилами.
- Nikoli (офіційний) — https://www.nikoli.co.jp/en/puzzles/ — правила класичних жанрів.
- Wikipedia: List of chess variants · List of Nikoli puzzle types · List of roguelikes · Tile-matching video game · List of puzzle video games · Grid-based (Category) · Falling-block puzzle.
- Chess Variant Pages — https://www.chessvariants.com/ — тисячі варіантів з правилами.
- Ludii — https://ludii.games/library.php — 1000+ настільних ігор, описаних лудемами.
- BoardGameGeek mechanics — https://boardgamegeek.com/browse/boardgamemechanic — Grid Movement, Tile Placement, Polyomino, Hexagon Grid, Square Grid, Enclosure, Connection, Deduction.
- Steam tags — Grid-Based Movement · Sokoban · Turn-Based Tactics · Traditional Roguelike · Match 3 · Tower Defense · Programming · Logic · Minesweeper.
- itch.io tags — sokoban · puzzlescript · grid-based · roguelike.
- PuzzleScript gallery — https://www.puzzlescript.net/Gallery/index.html — сотні мікро-пазлів з відкритими правилами.
- Glitchwave grid-puzzle — https://glitchwave.com/games/genre/grid-puzzle/ — чарти жанру.
- StrategyWiki / Fandom-вікі окремих ігор — списки елементів і їх поведінки (найкраще джерело для таблиці сутностей).
- MobyGames — платформи, роки, скриншоти вікон.
- Advent of Code — https://adventofcode.com/ — щороку 10+ задач на сітках (Sokoban-склад 2024/15, промені 2023/16, патруль 2024/6).
- CodinGame multiplayer — https://www.codingame.com/multiplayer — Tron, Ultimate TTT, Ocean of Code (Battleship), Spring Challenge на гексах.

## YouTube-канали (механіки й дизайн)
- Cracking the Cryptic — варіанти судоку щодня (правила кожного варіанту в описі).
- Game Maker's Toolkit (Mark Brown) — Boss Keys (структура данжів Zelda), дизайн головоломок.
- Thinky Games / Thinky Puzzle Game Jam — огляди нових головоломок.
- Design Doc · Adam Millard (Architect of Games) · Razbuten · Noclip.
- Sebastian Lague / The Coding Train / Code Bullet — реалізації клітинних ігор (Chess AI, Life, Snake AI).
- Displaced Gamers / Retro Game Mechanics Explained — як влаштовані старі аркади (Pac-Man привиди, Tetris randomizer).

## Межові випадки

- Kakuro / KenKen / Str8ts / Futoshiki → `pencil-logic` (числова дедукція без слів).
- Magic squares / Latin squares → `pencil-logic`.
- NYT Pips (2025, доміно на поле з умовами регіонів) → `pencil-logic`.
- NYT Tiles (пари плиток за ознаками) → `falling-match` / mahjong-подібні.
- NYT Vertex (лінії між точками → картинка) → `connect-rotate`.
- Puzzmo: Flipart (обертання плиток-фрагментів) → `connect-rotate`; Really Bad Chess → `chess-abstract`; Memoku → `hidden-deduction`.
- 2048 / Threes (злиття чисел) → `falling-match`.
- Numberlink → `connect-rotate`.
- Hangman — без сітки; описувати лише як предка Wordle (згадка в Wordle).
- Typeshift — диски, не класична сітка; залишено в черзі, бо колонки = 2D-поле.
- Spelling Bee, Letter Boxed — не сітка (соти/квадрат), лишаються як словесні «поля» нестандартної форми.
- Redactle, Contexto, Semantle — словесні, але без поля; не брати.
- Countdown numbers / Digits / Krypto — без сітки; беремо одну (Digits) як числовий «бонус», решта в згадках.

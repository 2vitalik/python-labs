# Python Labs

Лабораторні з Python — це **одна гра на весь семестр**: гра на клітинному полі, яку ти розвиваєш лабу за лабою. Кожна лаба додає до гри нову порцію мови (основи → структури даних → ООП → просунуті можливості), а ігрові можливості з каталогу приносять **монетки** — з них складається оцінка. Бали лише ростуть, захисти — тільки від 80.

<!-- more -->

## Як влаштований курс {#how}

- 🎮 **Гра** — обираєш базову з каталогу або придумуєш свою → [Ігри](/games)
- 📚 **Лабораторні** — 4 обовʼязкові + 1 бонусна, у кожної свій список завдань з теми → [Лабораторні](/labs)
- 🧩 **Завдання** — каталог ігрових можливостей із цінами в монетках → [Завдання](/tasks)
- 💯 **Оцінювання** — монетки → бали; що треба на 69 / 79 / 89 / 99 → [Оцінювання](/grading)
- 📤 **Як здавати** — GitHub, заявки в «Моїй грі», скриншоти й відео, захисти → [Як здавати](/howto)

## З чого почати {#start}

1. Увійти поштою `@nure.ua` і заповнити [профіль](/profile): ПІБ, GitHub, Telegram-бот
2. Створити **приватний** репозиторій на GitHub і розшарити на `2vitalik`
3. Обрати гру — до першої лаби за розкладом
4. Зробити [лабу 1](/labs/1) — до другої лаби за розкладом

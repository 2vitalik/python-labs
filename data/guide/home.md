# Python Labs

Лабораторні з Python — **одна гра на весь семестр** 🎮

- гра на клітинному полі, яку розвиваєш лабу за лабою
- кожна лаба — нова порція мови: основи → структури даних → ООП → просунуте
- ігрові можливості з каталогу — **монетки**; з них складається оцінка

## Як влаштований курс {#how}

- 📚 **Лаби** — 4 обовʼязкові + 1 бонусна, у кожної свої завдання з теми → [Лаби](/labs)
- 🎮 **Гра** — обираєш базову з каталогу або придумуєш свою → [Ігри](/games)
- 🧩 **Таски** — каталог ігрових можливостей із цінами в монетках → [Таски](/tasks)
- 💯 **Бали** — монетки → бали; що треба на 69 / 79 / 89 / 99 → [Бали](/score)
- ✅ **Здача** — GitHub, заявки в «Моїй грі», відео, захисти → [Здача](/howto)

## З чого почати {#start}

1. Увійти поштою `@nure.ua`, заповнити [профіль](/profile): ПІБ, GitHub, Telegram
2. Створити **приватний** репозиторій на GitHub, розшарити на `2vitalik`
3. Обрати [гру](/games) — до першої лаби за розкладом
4. Зробити [лабу 1](/labs/1) — до другої лаби за розкладом

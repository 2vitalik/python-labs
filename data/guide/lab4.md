# Лаба 4: Просунуті можливості

## 📚 Теми лекцій
- Винятки
- Послідовності
- Генератори
- Лексичне замикання
- Декоратори
- Модулі
- Пакети
- Анотації типів
- Модульне тестування

## ✔️ Результат
Гра як справжній проєкт: 
- пакет із модулів
- помилки обробляються
- ключова логіка вкрита тестами

## ⚠️ Обовʼязкові завдання з теми {#required}

1. **Модулі й пакет**: 
   - код розкладено по файлах за відповідальністю
   - двіжок, вивід, рівні…; є `__init__.py`
   - запуск — `main.py` або `python -m game`
2. **Винятки**: 
   - власні класи винятків
   - битий файл рівня, недопустимий хід, тощо
   - `try` / `except` / `finally`
   - `raise … from …`
3. **Анотації типів** 
   - у сигнатурах публічних функцій і методів
   - PyCharm або `mypy` без помилок
4. **Модульні тести** двіжка (`pytest`): 
   - рух, зіткнення, умови виграшу
   - без консолі й графіки

## ➕ Додаткові завдання з теми {#extra}

1. **Послідовності:**
   - власний клас поля або рівня з протоколом послідовності *(`__len__`, `__getitem__`, зрізи)*

2. **Генератори:**
   - `yield` для хвиль ворогів, обходу клітинок, генерації рівня
   - генераторні вирази

3. **Лексичне замикання:**
   - фабрики обробників клавіш або поведінки ворогів

4. **Декоратори:**
   - логування ходів, вимір часу, кешування, перевірка стану гри перед дією

5. **Контекстні менеджери** `with`
   - для файлів рівнів і збережень

6. **Тести:**
   - параметризація
   - фікстури
   - покриття ключових модулів

# Лаба 1: Основи Python

## 📚 Теми лекцій

- Мова Python
- Типи даних і присвоювання
- Умовна команда і логічні вирази
- Цикли
- Функції
- Область видимості (scope)

## ✔️ Результат
Мінімальна гра в консолі:
- поле на екрані
- гравець рухається клавішами
- клітинки реагують
- є виграш і програш

## ⚠️ Обовʼязкові завдання з теми {#required}

1. **Вивести ігрове поле**
   - наприклад, у консоль
   - можна зберігати хоча б у рядку `str`

2. **Зчитати клавішу з клавіатури**
   - наприклад, WASD або курсорні, тощо

3. **Перемістити гравця на полі**
   - залежно від натиснутої клавіші
   - вгору / вниз / вліво / вправо / тощо

4. **Перевірити клітинку під гравцем**
   - наприклад, стіна — не переміщати
   - приз — нарахувати бали гравцю
   - тощо...

5. **Ігровий цикл**
   - зчитати клавішу → перемістити гравця → перевірити клітинку → знову зчитати…
   - допоки не виконано умову виграшу або програшу

6. **Кілька власних функцій**
   - наприклад, `main`
   - `input_key`
   - `move_player`
   - тощо

## ➕ Додаткові завдання з теми {#extra}

1. **Типи даних:** 
   - рядки `str` 
   - числа `int` і `float`
   - логічний `bool`
   - `NoneType`

2. **Умовні команди:**
   - `elif` та `else`
   - логічні `and`, `or`, `not`
   - вираз виду `a < b < c`

3. **Цикли:**
   - `for`
   - `while`
   - генератор `range`
   - `continue`
   - `break`
   - `else` для циклу

4. **Функції:**
   - необовʼязкові параметри (keyword arguments)
   - `*` та `/` у списку параметрів
   - `lambda`
   - вбудовані функції 
      - _кілька окрім `print`  та `input`_
   - вкладені функції

5. **Область видимості:**
   - `global`
   - `nonlocal`

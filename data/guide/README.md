Чернетки з 2026-09-20 за пропозицією [T115](../../.dev/.t/T115-P--guide-on-site.md); питання — [T116](../../.dev/.t/T116-Q--guide-questions.md); походження — Notion-методичка (`data/v2/notion/python/`).

**З 2026-09-22 правда — в Mongo** (колекція `guide`, [T128](../../.dev/platform/.t/T128--guide-editor-v1/report.md)): адмін править текст прямо на сайті (✏️ біля кожного заголовка або «✏️ сторінку»), кожне збереження — у `history` з нотаткою, `/method/history` показує diff і вміє відкотити. Файли тут — **seed і знімок**: при старті API `guide_io.seed()` заливає лише ті slug-и, яких у базі ще нема; `cd app/api && uv run python guide_io.py export` — скинути базу у файли (перед комітом текстів, щоб git-diff був чесний), `… import` — навпаки (upsert, історія з актором `import`). Правка файла після сидування на сайт сама не потрапляє — лише через `import`. NO-EDIT тут не діє: файли правлять обидва (Vitalik + агент).

## Конвенції

- Markdown, UA. Перший `#` — назва сторінки; `##` — підрозділи (потрапляють у зміст); `###` — пункти. У редакторі на сайті розділ = від заголовка до наступного того ж або вищого рівня.
- **Якір** `{#id}` у кінці заголовка або пункту списку — стабільне EN-імʼя для посилань (`/score#79`). Заголовок без `{#id}` отримає авто-id від тексту, але він зміниться разом із текстом — важливе якорити явно.
- **Стиль** — як у Notion-методичці Vitalik: короткі фрази, вкладені пункти замість довгих речень, жирним — ключове слово, емодзі на початку важливих пунктів, без багатослівʼя. Розмір тексту на всіх сторінках однаковий (без `lead`).
- **Виноска** — цитата, що починається з емодзі (`> 💡 …`, `> ⚠️ …`) — рендериться як callout.
- **Розкривашка** — `<details>` + `<summary>Назва</summary>`, далі порожній рядок і звичайний Markdown, у кінці `</details>`; посилання на якір усередині відкриває її сама.
- **Поле-клітинки** — блок ` ```field `: рядки емодзі через пробіл, `[😎]` — хто щойно зробив хід (синя рамка), `(✨)` — ефект на полі (жовта); рендериться сіткою з клітинками фіксованого розміру, тому виглядає однаково на macOS/Windows/Android. Приклади — `game.md`, «Приклади ігрових ситуацій» (перенос із `data/v2/notion/games/`).
- **Монетки** — іконки сайту: 🌱 деревʼяна · 📎 оловʼяна · 🥉 бронзова · 🥈 срібна · 🥇 золота · 👑 корона (кожна = 2× попередньої).
- **Посилання** всередині сайту — відносні (`/tasks`, `/my/game`, `/score#defense`); текст лінка на розділ — як пункт меню (Ігри · Лаби · Таски · Бали · Здача); на сторінці «уся методичка» (`/method`) якорі отримують префікс розділу (`#score-defense`) — лінки `#id` у тексті переписуються самі.
- **«Що змінилось»** — нотатка при збереженні («Що змінив») стає рядком чернетки (службова сторінка `changes-draft`, лише адмін); на `/changes` адмін бачить чернетку над текстом і кнопкою «↑» переносить рядок у публічний список (новіше — вище) або «✕» прибирає.
- `🚧` — незакрите місце; список — у [T116](../../.dev/.t/T116-Q--guide-questions.md).

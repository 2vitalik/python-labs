# guide — методичка курсу: тексти сторінок сайту

Те, що студент читає на сайті: домашня, «Гра», «Лабораторні» (+ 5 лаб), «Завдання», «Оцінювання», «Як здавати». Один файл = один розділ = одна сторінка або блок на сторінці. Чернетки з 2026-09-20 за пропозицією [T115](../../.dev/.t/T115-P--guide-on-site.md); питання — [T116](../../.dev/.t/T116-Q--guide-questions.md); походження — Notion-методичка (`data/v2/notion/python/`).

Редагують обидва (Vitalik + агент), NO-EDIT тут не діє; історія — git. Поки сторінки не реалізовано, це просто чернетки; після реалізації — джерело, яке віддає API.

## Конвенції

- Markdown, UA. Перший `#` — назва сторінки; `##` — підрозділи (потрапляють у зміст); `###` — пункти.
- **Якір** `{#id}` у кінці заголовка або пункту списку — стабільне EN-імʼя для посилань (`/grading#79`). Заголовок без `{#id}` отримає авто-id від тексту, але він зміниться разом із текстом — важливе якорити явно.
- **Коротко / детально**: усе вище `<!-- more -->` — витяг для домашньої (розкривашка) і шапки каталогу; нижче — лише повна сторінка. Витяг має відповідати на «що мені треба зробити» за 5–8 рядків.
- **Виноска** — цитата, що починається з емодзі (`> 💡 …`, `> ⚠️ …`) — рендериться як callout.
- **Монетки** — іконки сайту: 🌱 деревʼяна · 📎 оловʼяна · 🥉 бронзова · 🥈 срібна · 🥇 золота · 👑 корона (кожна = 2× попередньої).
- **Посилання** всередині сайту — відносні (`/tasks`, `/my/game`, `/grading#defense`).
- `🚧` — незакрите місце; список — у [T116](../../.dev/.t/T116-Q--guide-questions.md).

# Лаба 5*: Web-розробка

Пʼята лаба **не обовʼязкова** 👌

- без неї теоретично можна отримати 100 балів
- її завдання — додаткові монетки, тобто швидший шлях до вищої оцінки 😇

> 🚧 Чернетка: у Notion розділ був порожній — завдання нижче від тем лекцій, узгодити перед публікацією.

**Теми лекцій:** 3.01 Протокол HTTP · 3.02 Web-фреймворк FastAPI · 3.03 Чат із файловим сховищем · 3.04 Чат. UI · 3.05 Шаблони Jinja2 · 3.06 Чат із шаблонами · 3.07 Бази даних · 3.08 Чат із базою даних · 3.09 ORM SQLAlchemy · 3.10 Чат з ORM · 3.11 Відокремлення кінцевих точок · 3.12 Розгортання

Результат — у гри зʼявляється **сервер**: рекорди, рівні або статистика живуть в інтернеті.

## Обовʼязкові завдання з теми {#required}

*(якщо робиш цю лабу)*

1. **Сервер рекордів** на FastAPI
    - `POST` результату гри, `GET` таблиці лідерів
    - гра надсилає результат після завершення
2. Сховище — спершу файл (JSON), потім **база даних** (SQLite) через SQLAlchemy
3. **Сторінка** таблиці лідерів на Jinja2

## Додаткові завдання з теми {#extra}

1. Обмін рівнями: завантажити і скачати рівень через API; галерея рівнів
2. Профіль гравця і статистика ігор
3. Кінцеві точки розкладено по модулях (routers); тести API
4. **Розгортання**: сервер на публічній адресі, гра ходить на нього

# Лаба 3: ООП у Python

## 📚 Теми лекцій
- Класи
- Системні методи
- Підкреслення в іменах
- Властивості
- Спадкування
- Множинне спадкування

## ✔️ Результат
Гра на класах: 
- двіжок відокремлено від виводу
- елементи поля — обʼєкти зі спільним базовим класом

## ⚠️ Обовʼязкові завдання з теми {#required}

1. **Класи** для головних сутностей: 
   - гра / поле, гравець / елементи клітинок, тощо
   - стан — в атрибутах, поведінка — в методах

2. **Спільний базовий клас** і **спадкування**
   - наприклад, для елемента поля 
   - прохідність, реакція на гравця — у базовому
   - стіна, приз, ворог перевизначають поведінку, без перевірок «а який це тип»

3. **Системні методи**: 
   - наприклад, `__init__`, `__str__` / `__repr__`

4. **Двіжок окремо від виводу**
   - клас гри сам нічого не друкує
   - вивід — в окремому класі або функції
   - потім консоль легко замінити на графіку

## ➕ Додаткові завдання з теми {#extra}

1. **Підкреслення** в іменах: `_protected`, `__private` (name mangling)
   - а також `_` для неважливого

2. Більше **системних методів**:
   - `__eq__` і `__hash__` · `__len__`, `__iter__`, `__getitem__`, `__contains__` 
   - порівняння `__lt__`… _(для поля, координат, інвентаря)_

3. **Властивості** `@property`:
   - обчислювані 
      - наприклад, чи живий гравець, чи пройдено рівень
   - і **setter** з перевіркою

4. **Множинне спадкування:**
   - міксини поведінки 
      - наприклад, `Movable`, `Collectable`, `Dangerous`, тощо
   - `super()` і порядок MRO

5. Класові й статичні методи, атрибути класу: 
   - лічильники, реєстр типів елементів, тощо

# #8: Bomberman

## **Основний задум**

За певний час потрібно пройти рівень, підриваючи за допомогою бомбочок **цегляні стіни**

**Бомбочка** може також вбити **гравця** (якщо перебувати поруч із нею під час вибуху)

## **Приклад ігрових елементів**

- 👾 — **гравець** *(основна дійова особа)*
- 💣 — **бомбочка** *(яку, може ставити гравець)*
- 💥 — **вибухова хвиля** *(після вибуху бомбочки)*
- 🟢 — **цегляна стіна** *(яку можна підірвати бомбочкою) дерева?*
- 🟫 — **бетонна стіна** *(непрохідна і незнищена стіна)*

## **Приклад ігрового моменту**

Деяке початкове становище:

```lua
▫️ ▫️ 👾 🟢 ▫️ ▫️ 🟢 🟢 ▫️ 🟢 
▫️ 🟫 🟢 🟫 ▫️ 🟫 ▫️ 🟫 ▫️ 🟫 
🟢 🟢 ▫️ 🟢 🟢 ▫️ 🟢 🟢 🟢 🟢 
▫️ 🟫 🟢 🟫 ▫️ 🟫 ▫️ 🟫 🟢 🟫 
▫️ 🟢 🟢 🟢 ▫️ ▫️ 🟢 🟢 🟢 ▫️ 
```

**Гравець** (👾) поставив **бомбочку** (💣) і втік за укриття:

```lua
▫️ ▫️ 💣 🟢 ▫️ ▫️ 🟢 🟢 ▫️ 🟢 
👾 🟫 🟢 🟫 ▫️ 🟫 ▫️ 🟫 ▫️ 🟫 
🟢 🟢 ▫️ 🟢 🟢 ▫️ 🟢 🟢 🟢 ▫️ 
▫️ 🟫 🟢 🟫 ▫️ 🟫 ▫️ 🟫 🟢 🟫 
▫️ 🟢 🟢 🟢 ▫️ ▫️ 🟢 🟢 🟢 ▫️ 
```

Бомба вибухає (💥 - **слід від вибуху**) і знищує сусідні **цегляні стіни** 🟢:

```lua
▫️ 💥 💥 💥 ▫️ ▫️ 🟢 🟢 ▫️ 🟢 
👾 🟫 💥 🟫 ▫️ 🟫 ▫️ 🟫 ▫️ 🟫 
🟢 🟢 ▫️ 🟢 🟢 ▫️ 🟢 🟢 🟢 ▫️ 
▫️ 🟫 🟢 🟫 ▫️ 🟫 ▫️ 🟫 🟢 🟫 
▫️ 🟢 🟢 🟢 ▫️ ▫️ 🟢 🟢 🟢 ▫️ 
```

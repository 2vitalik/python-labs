**Обовʼязкові завдання з теми лаби:**
*(до **69** балів і вище)*

1. Вивести ігрове поле на екран
    - для початку можна зберігати його хоча б в рядку `str`
2. Зчитати клавішу з клавіатури
    - наприклад, ASDW або курсорні
3. Перемістити гравця на полі 
    - в залежності від зчитаної клавіши (вверх/вниз/вліво/вправо)
4. Перевірити клітинку, на яку натрапив гравець
    - наприклад, якщо там стіна, то не переміщати гравця
    - а якщо приз, то нарахувати бали, тощо
5. Організувати ігровий цикл:
    - зчитувати клавішу, переміщати гравця, потім знову зчитувати клавішу…
    - і так далі, допоки не буде виконана умова виграшу або програшу
6. Створити та використати декілька власних функцій:
    - наприклад, `main`, `input_key`, `move_player`, тощо
</aside>

**Додаткові завдання з теми лаби:**
*(до **79** балів і вище)*

- Використайте наступні синтаксичні можливості:
    1. Типи даних:
        1. рядки `str` 
        2. числа `int` та `float`
        3. логічний тип `bool`
        4. `NoneType`
    2. Умовні команди:
        1. використайте `elif` та `else` для умовної команди `if`
        2. використайте логічні операції `and`, `or`, `not` 
        3. використайте вираз виду `a < b < c` 
    3. Цикли:
        1. використайте цикл `for`
        2. використайте цикл `while`
        3. використайте генератор `range`
        4. використайте команду `continue`
        5. використайте команду `break`
        6. використайте `else` для циклу
    4. Функції:
        1. optional parameters (keyword arguments)
        2. використання `*` та `/` у списку параметрів
        3. лямбда-вирази через `lambda`
        4. вбудовані фукнції
        *(використайте декілька окрім `print`, `input` і вже зазначених вище)*
        5. вкладені фукнції
        *(функція оголошена всередині іншої функції)*
    5. Область видимості:
        1. використання `global`
        2. використання `nonlocal`
</aside>
